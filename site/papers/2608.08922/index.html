Clustered Attractor Manifolds and Dynamical Condensation in Self-Attention

自注意力中的簇状吸引流形与动力学凝聚

Card 02 研究问题

研究问题

重复 self-attention 同时更新 token 表示和它们诱导的交互网络，可能导致统一化/rank collapse，也可能形成局域化簇。本文用最小归一化动力系统研究热力学极限中的固定点流形、稳定性和从无结构 Gaussian cloud 出发的 attention-condensation 转变。

Card 03 模型与方法

模型与方法

  • 系统含 $N$ 个定长 $\|x_i\|=\sqrt d$ 的 token，归一 overlap $q_{ij}=x_i\cdot x_j/d$，softmax logit 为 $z_{ij}=\sqrt d q_{ij}$；self-edge 被 mask。
  • attention sharpness $\beta$ 类似逆温度，residual mixing $\gamma$ 控制每层将 token 与注意力加权平均混合，之后重新归一化。
  • 核心序参量是 overlap gap：任一 token 对同簇成员的相似度比所有异簇至少高固定正量。若 $d\sim N\to\infty$，logit 优势为 $O(\sqrt N)$，异簇 attention 指数抑制。
  • 作者解析构造从少数宏观簇到 extensive microscopic fragmentation 的固定点，并线性化 cluster-level 与 intra-cluster perturbations 得稳定条件。
  • 动力学实验从独立归一 Gaussian tokens 出发，测 inverse participation ratio、attention entropy、最大簇比例、有效秩和簇数；Supplement 比较 REM benchmark、线性/多项式 kernel 与预先带角宽的簇。
Card 04 核心结果与证据

核心结果与证据

  • 有限 overlap gap 使簇间注意力按 $\exp[-c\beta\sqrt N]$ 消失，因此热力学极限存在高维 clustered fixed-point manifold，而不是唯一 rank-one fixed point。
  • 该机制允许宏观凝聚簇与数量随 $N$ 增长的微观碎片共存；稳定性同样由 gap 控制，簇内对齐扰动和簇间泄漏在极限中解耦。
  • 从无结构 Gaussian 初态出发，小 $\beta$ 时广泛平均抹平差异，最大簇占比趋 1、attention IPR 随 $N$ 消失，是 diffuse rank-collapsed regime。
  • 只有超过有限 sharpness onset，初始 overlap fluctuations 才被 attention–representation feedback 放大并成核，IPR 保持有限、entropy 相对 $\log N$ 降低，形成 dynamical condensation。
  • 有限 $N$ 下簇间 attention 不为零，fragmented states 会缓慢 coarsen；寿命随 $\beta\sqrt N$ 指数增长，所以有限仿真中的长寿命碎片不等于严格有限尺寸固定点。
Card 05 有效性与局限

有效性与局限

  • 模型只有单头、mask self-edge、固定 norm 和简化 residual dynamics，没有 value/key/query 投影、LayerNorm、MLP 与训练。
  • 热力学结论取 $d\sim N$；固定维度、序列长度远大于维度或真实 scaling 下的相变位置可能不同。
  • cluster identification 与阈值会影响有限尺寸诊断；作者用多指标和尺度趋势减轻但未消除。
  • 固定点流形的存在不说明梯度训练会选择何处，也不自动对应语义簇或良好表示。
  • attention 凝聚既可能保存结构也可能形成 sinks/entropy collapse，论文不赋予性能正负价值。
