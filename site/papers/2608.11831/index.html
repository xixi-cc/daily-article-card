Kernel Methods for Learning Operators with Multiple Inputs and Outputs

多输入多输出算子学习的核方法

Card 02 研究问题

研究问题

多算子学习需要从参数函数与一个或多个输入函数预测一个或多个输出函数。直接把无限维对象塞入单一网络，会混合 observation、representation、learning 与 reconstruction 误差。本文给出 Hilbert 空间上的核 encoder–decoder 统一框架，并问：输入/输出数量增加时，误差率是否必然遭遇整体维数灾难。

Card 03 模型与方法

模型与方法

  • 用线性测量算子 $E_X,E_Y$ 编码函数，通过 minimum-norm/regularized optimal recovery decoder $D_X,D_Y$ 重建；只在有限维 measurement spaces 学习核 surrogate $\widehat G$。
  • 误差分解为 representation error、learning error 和 data-consistency error；乘积空间情形进一步由各输入/输出分量中最差的 reconstruction error 控制。
  • 证明 latent surrogate 上的 operator-valued kernel 经 encoder/decoder 可诱导原函数空间上的 kernel，从而把闭式 kernel ridge training 与函数空间保证连接起来。
  • KernelMO-OV 把参数映到整个算子，kernel matrix 规模主要随参数实例数 $n_\alpha$；KernelMO-PS 学习 $(\alpha,u)\mapsto v$，可同时外推参数与输入，但矩阵随 $n_\alpha n_u$ 增长。
  • 另给 pointwise $(\alpha,u,x)\mapsto v(x)$ 的 mesh-independent 完整乘积表述；灵活性更高，但 kernel system 随输出位置数继续膨胀。
  • 实验用 RBF/Matérn 与可选 PCA encoder，对比 DeepONet、DeepONet-\(C\)、MIONet、MNO。
Card 04 核心结果与证据

核心结果与证据

  • 近似理论的关键结论是：多输入/多输出数量可增加，但收敛率由最难的 constituent approximation 控制，而不是所有分量维数相乘；常数和测量预算仍会随任务数增长。
  • 五类参数 PDE：conservation law、diffusion–reaction–advection、nonlinear Klein–Gordon、parametric diffusion–reaction、parametric wave；统一以 128×64 网格上的 mean relative $L^2$ error 评估 ID/OOD。
  • operator-valued conservation law 上，最佳 KernelMO 为 0.01% ID、0.77% OOD；最佳神经基线分别为 1.23% 与 3.97%。nonlinear Klein–Gordon 从神经基线 4.63% 降到 0.21%，OOD 从 18.50% 降到 PCA 版本 4.11%。
  • product-space 中显式 product kernel 明显优于 vanilla KernelO；parametric wave 例为 2.13% 对 59.28%。但 OOD 没有统一赢家，分布移位类型和 PDE 决定幅度。
  • 效率只在 conservation-law 基准详测：KernelMO-OV 训练低于 0.5 s，而神经算子为 158–250 s；推理约 0.04 ms/sample，PCA 后约 0.004 ms/sample。
  • product-space 全维训练 14.8–15.5 s，对比神经基线 226.79–397.46 s；PCA 降至 4.7–5.19 s，但推理与 MIONet/MNO 大致同量级。
Card 05 有效性与局限

有效性与局限

  • 优势定位在 moderate-data regime；kernel matrix 的平方存储/立方求解趋势限制大样本扩展，完整 pointwise 形式尤其昂贵。
  • PCA 不是普遍增益：conservation-law ID error 可从 0.01% 升至 1.77%，只是计算/正则化折中。
  • Matérn 多数更稳，但 kernel family 与 length scale 明显依赖 PDE；RBF 在部分 OOD 移位可严重退化。
  • 理论使用预设有限维测量和 decoder；learned encoder/decoder、无限维 observation space 与跨 observation operator transfer 被列为未来工作。
  • 实验表明竞争力而非所有任务绝对 SOTA，且效率数字来自单一 PDE 与特定硬件/实现。
