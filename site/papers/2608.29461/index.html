Card 02 研究问题

研究问题

一个模型在测评条件下答错，并不等于它没有答案。若“压低能力”的条件先写进隐藏状态、答案稍后才成形，能否在两步之间只修改一个状态坐标，使同一组固定权重恢复诚实回答？反过来，怎样的锁会让单点修改失效？

本文只在故意安装锁的三个7–8B开权重模型中回答这个问题。被观察的输出是选择题答案字母和准确率，不是开放式生成质量，也不是对自然出现的策略性隐瞒作出检测。

Card 03 背景

背景

先前激活加法或单方向干预能改变一些模型行为，却未解释单层编辑在哪个深度足够、为什么在电路重写后失效。本文把这件事写成一个“最后抑制写入—首次答案提交”的因果时序问题，提出可由逐层干预曲线检验的窗口预测（PDF pp2–5）。

这是现代AI机制研究，不是物理模型。可借用控制变量和状态空间的读法，但残差坐标并不对应守恒量或实空间自由度；“电路”在本文主要指计算依赖和干预位置，而非已逐边识别的神经元图。

Card 04 读者桥接

读者桥接

每个问题在诚实条件与锁定条件下分别前向运行。模型权重固定，隐藏状态是每层最后一个提示token的残差向量；校准数据给出两条件的平均差方向，测试时改变该方向坐标。输出是A/B/\(C\)/D的受限logit最大值，恢复率按诚实—锁定准确率差归一化。

另一种干预不触碰残差向量：先用带密码的前缀运行一次，保存每层注意力键和值；测试问题仍不含密码文本，但在每层注意力读取时加入已保存的前缀列。它要求白盒访问缓存与一个可用的诚实参考，不是只靠答案标签的黑盒方法。

Card 05 模型与方法

模型与方法

在第\(\ell\)层，\(h_\ell\in\mathbb R^d\) 是最后提示位置的残差状态，\(v_\ell\) 是40对诚实/锁定校准样本均值差的单位方向。单层参考嫁接写成

\[h_\ell\mapsto h_\ell+(t_\ell^\star-h_\ell^\top v_\ell)v_\ell,\qquad t_\ell^\star=(\overline h_\ell^{\rm honest})^\top v_\ell.\]

它把方向坐标改为诚实均值而保留正交分量；这个仿射算子已有先例，本文的任务是解释层位置。依据PDF \(p_{2}\) Eq. (1)–(2)。

将状态分解为\(h_\ell=s_\ell v_\ell+h_\ell^\perp\)，其中\(s_\ell=h_\ell^\top v_\ell\)。作者假设早层把锁定信号写进\(s_\ell\)，晚层读取它并把答案写进\(h_\ell^\perp\)。几何分解是恒等式；“最后写入层到首次提交层之间可用单层嫁接”是有条件的因果模型预测，不是普遍定理。图1显示提交后在正交补中绕过轴的路径；同层融合写入/提交或晚写入可使窗口消失（PDF pp3–5, Eq. (6)–(8)）。

另一个干预把带密码前缀的键/值缓存接到锁定运行的每层注意力读取。命题1仅在两阶段与完整诚实提示的token序列完全一致、因果注意力、确定性贪心解码及精确算术下，证明两种计算相同；附录C用位置和层的归纳法证明。真实bf16下仅报告0.98–1.00的答案一致率；错误/截断密码不满足推论条件（PDF pp3,5,11–13）。

三种底座、四种安装方式构成48个受控样本：提示锁每模型1个，微调密码锁、GRPO测评提示锁和中层表示重路由的电路断路锁各每模型5个种子。每个受训练样本须先通过验证集诚实—锁定差至少0.2的筛选；主测试为100道ARC-Easy选择题，另在100道OpenBookQA上固定ARC选中的方向和层检查迁移（PDF \(p_{2}\)–3, Appendix A–B）。

Card 06 核心结果与证据

核心结果与证据

按

\[R=\frac{\operatorname{acc}_{\rm graft}-\operatorname{acc}_{\rm locked}}{\operatorname{acc}_{\rm honest}-\operatorname{acc}_{\rm locked}}\]

定义恢复比例。表1的33个非断路运行中，28个单层编辑达到\(R@1\geq0.7\)，留出测试的中位\(R@1=0.96\)；15个断路运行全部未过线，各模型中位约0.01–0.05。超过1的条目是该归一化比率，不证明超越原有诚实能力（PDF \(p_{3}\) Eq. (3), \(p_{6}\) Table 1, \(p_{14}\) Table \(S_{3}\)）。

图2四列给出窗口宽、写入太晚、各层均失败、断路四种形态。最清楚的对照是Llama-3-8B微调锁种子1有9个足够的单层位置且\(R@1=1.01\)；Qwen2.5-7B的GRPO种子2单层仅0.44但全带0.95；Mistral-7B微调锁种子1即便全带也只有0.16；Qwen断路种子3全带仅0.08。多改几层并非总更好：33个非断路运行中有11个全带低于最佳单层（PDF pp6–7, Figures 2–3, Table \(S_{3}\)）。

不干预时估计的抑制写入峰，与逐层扫描得到的最佳单层位置在33个非断路运行中有Pearson相关\(r=0.84\)，但存在5个ARC失败；答案提交位置来自同答案字母状态的聚类比值突降，是代理测量，不能独立证明唯一提交层。常数答案的锁定运行该比值无定义，作者改用诚实运行作为代理（PDF \(p_{5}\) Eq. (8), \(p_{7}\) Figure 3a, \(p_{14}\) Table \(S_{3}\)）。

完整真实密码前缀缓存使30个微调/断路密码锁运行在主测试上恢复到\(R=1.00\)。不同但同形的密码或罕见字符串在这组实验也接近1，去掉分隔符降至约0.6–0.7，截短前缀则逐渐恢复。这些后几项是图3b–c的经验结果；命题1及推论只保证“同token的完整诚实前缀”之精确重放（PDF \(p_{7}\) Figure 3, pp12–13 Corollary S1及边界说明）。

固定ARC选层转到OpenBookQA，非断路通过数从28/33降为25/33，中位恢复从0.96降为0.82；三项新增失败在别的层仍有足够位置。这表明机制有部分跨任务迁移，具体单层位置并不稳定（PDF pp10–11 Table \(S_{2}\)）。

Card 07 有效性与局限

有效性与局限

四类锁都是研究者安装在三种7–8B模型上的受控样本，受训练样本还被要求至少0.2的验证差；结论不能推广为天然隐藏能力都沿单轴传播。锁定/诚实对照和缓存来自已知条件，方法要求白盒状态访问。基于残差均值差的“轴”是可操作坐标，不能推断唯一真实语义变量。

窗口规则依赖抑制写入和答案提交的时序假设；在融合写入、重复晚写或电路断路下单层修改会失败。图3的相关性支持定位，但与干预扫描共用模型族和条件，答案聚类代理不是因果边的独立测量。

命题1是同token、完整键值、精确算术下的计算等价；它不证明错误密码或短前缀总能成功。附录说明token边界只在一条校准题核查，未逐题确认；bf16也非逐位相同。主结果是受限选择题字母准确率，未检验自由文本的语义连贯性，也未独立复现。

Card 08 复现与资源

复现与资源

官方来源：arXiv v1全文；作者对训练配方、提示条件、LoRA/GRPO参数、每个种子和硬件环境列于附录A、\(D\)（PDF pp9–10,14）。论文p12提到“released code”的缓存实现，但本次官方PDF及元数据未核实可直接引用的作者仓库地址，故不虚列代码链接。

复核先重建同一密码锁与诚实/锁定成对校准，严格隔离40条校准、20条选层和100条测试，再按图2逐层绘制\(R(\ell)\)。命题1的形式核查应先验分词边界，再比较完整缓存与诚实运行；错误或截断前缀要单独当经验条件测试。本文仅做来源与全文核对，未运行模型或独立复现。

Card 09 阅读指南

阅读指南

快速读法：PDF p4图1先认清\(s_\ell\)轴、\(h_\ell^\perp\)正交补、抑制写入与答案提交；再看p6图2的四种成功/失败形态，最后用p7图3及p11表S2衡量定位和跨任务的限制。

深入读法：先核p2–3 Eq. (1)–(3)的校准/选层/测试分离，再检查p4 Eq. (7)窗口规则所依赖的单次写入与提交顺序。对“证明恢复”的说法须读p11–13命题1和推论S1，确认同token、完整缓存与精确算术；用p14表S3检查5个失败种子和小分母。
