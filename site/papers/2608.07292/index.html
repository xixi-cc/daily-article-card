Critical dynamics of a scalar field near four spatial dimensions

Card 02 研究问题

研究问题

具有非守恒序参量的平衡临界动力学通常在红外变成 Model A 式过阻尼，即便微观上存在二阶时间导数和传播模。本文用四维空间附近的两圈 RG 回答两个分开的疑问：严格无局域摩擦的传播表面是否在粗粒化下保持不变？即使保持不变，它是否能抵抗任意小的平衡摩擦–噪声扰动？

Card 03 模型与方法

模型与方法

  • 随机标量场方程同时含二阶时间动力项、空间梯度、$\phi^4$ 相互作用，以及满足 fluctuation–dissipation 的局域摩擦和白噪声；初态从 Gibbs 分布采样。
  • 作者把有限时间 MSR/Janssen–De Dominicis 动力学写成带 BRST 与平衡 KMS 对称的 superspace 作用量，边界项保证初始 Gibbs 权重与动态对称一致。
  • 在 $d=4-\epsilon$ 做两圈展开：静态扇区给出共同的 Gaussian/Wilson–Fisher 固定点，随后分别在 overdamped 边界与 dissipationless propagating 边界重整化时间算符。
  • 传播扇区的振荡 real-time sunset 积分用 Hankel contour 表示提取 UV 奇点；另计算局域耗散复合算符插入，判断无耗散表面对横向扰动的稳定性。
  • 以耗散/传播时间算符的无量纲比值为 crossover 坐标，线性化四个端点附近的 beta functions，得到图 3 的局部稳定性结构。
Card 04 核心结果与证据

核心结果与证据

  • 静态方面，传播与过阻尼理论共享 Gaussian 和 Wilson–Fisher 固定点；差异只在动力学标度。Gaussian 端点分别为 $z_{od,G}=2$ 与 $z_{prop,G}=1$。
  • 过阻尼 Wilson–Fisher 恢复已知 Model A 两圈结果 $z_{od,WF}=2+[6\log(4/3)-1]\epsilon^2/54+O(\epsilon^3)$，惯性算符在该端点无关。
  • 无耗散表面上的相互作用传播固定点满足 $z_{prop,WF}=1-\frac{\epsilon^2}{9}(17/12-2\log2)+O(\epsilon^3)\simeq1-0.00337\epsilon^2$；形式取 $\epsilon=1$ 得 0.9966，仅略偏离弹道 $z=1$。
  • 两圈 self-energy 在 $X=0$ 时不产生与 $i\omega$ 成正比的 UV 发散；诱导的非解析 $i\omega|\omega|$ 在低频更快消失，因此 $X=0$ 表面在该阶 RG 下不生成局域摩擦，即是 invariant。
  • 但耗散插入在传播固定点是 relevant：任意非零摩擦比在红外增长。图 3 因而显示传播 Gaussian 双向排斥、overdamped Gaussian 与 propagating WF 为 saddle、overdamped WF 是唯一在静态和动力方向都局部吸引的端点。
Card 05 有效性与局限

有效性与局限

  • “无耗散表面不生成摩擦”只证明到两圈；它与“对小摩擦稳定”是不同命题，后者结论是否定的。
  • $\epsilon$ 展开严格控制在 $d$ 接近 4；将 $\epsilon=1$ 代入三维得到 0.9966 只是截断估计，修正极小也可能对高阶项敏感。
  • 分析只控制耗散比为 0 和无穷两个端点附近，没有给出有限比值处的全局 beta function，不能证明存在连接两端的单一 crossover 轨迹。
  • 模型是单一非守恒标量序参量；含守恒慢模、QCD Model G/H、非 Markov 记忆核或多分量场需另行分析。
  • generic infrared 为 Model A；传播临界标度只在精细调节的 $X=0$ 表面成立，实验中的长传播 crossover 不等于稳定渐近普适类。
