Exact Fluctuation-Response Relations for Underdamped Langevin Dynamics

欠阻尼 Langevin 动力学的精确涨落–响应关系

2026-08-22 · 原文

热力学不确定性关系把 current fluctuation 与 dissipation 联系起来，但在欠阻尼动力学中，传统 mean-current 关系可能失效。本文对任意时变驱动和一般 additive observable 推导精确有限时间 fluctuation-response equality；它给出 sharp response bound 和动态生成方差的 variational characterization。把 perturbation 选在 irreversible probability flow 方向后，得到任意有限 observation time 都可饱和的 friction-response TUR，进而得到总 entropy production 的精确变分原理。作者还证明，即使在 driven free diffusion 中，velocity-resolved current 的传统 uncertainty factor 也可随耗散指数衰减，而 friction-response factor 保持普适下界。核心结论是 response，而非 mean current 本身，直接连接 fluctuation 与 dissipation。

Card 03 背景

背景

欠阻尼系统中热噪声直接作用于 velocity，而实验 current 常由 position 积分；两者处于不同 phase-space sector。改变 friction 且保持温度还会同时改变 drift 与 diffusion，使路径测度在连续时间极限互相奇异，标准固定噪声 likelihood-ratio 方法并不直接适用。本文通过向 velocity-space probability current 注入 infinitesimal source，把 drift 与 diffusion perturbation 放入同一框架。分类为 pure physics / nonequilibrium stochastic thermodynamics。

Card 04 模型与方法

模型与方法

  • 模型为 $d x_t=v_tdt$、$d v_t=[f_t(x_t)-\gamma v_t]dt+\sqrt{2D}dW_t$，允许任意时变 force。一般 additive observable 为 $J_\tau=\int_0^\tau[\phi_t(z_t)dt+w_t(z_t)\circ dv_t]$，覆盖 occupation、kinetic energy、transport current 和 mixed-parity observable。
  • 定义未来条件贡献 $G_t(z)$ 并构造 Doob martingale $M_t=J_t+G_t(z_t)=\mathbb E[J_\tau|\mathcal F_t]$。Ito 表示给出 amplitude $u_t=w_t+\nabla_vG_t$，于是 Eq. (7)：$\mathrm{Var}(J_\tau)=\mathrm{Var}_0(J_\tau)+2\int_0^\tau\|u_t\|^2_{D,p_t}dt$。
  • 将 source current 与 $u_t$ 配对得到 exact response relation、Cauchy–Schwarz bound 和 dual variational form；选择 source 沿 irreversible velocity probability flow，得到 friction susceptibility、entropy production 与可饱和 observable。附录处理有限时间、长时间、矩阵推广和 driven free diffusion 反例。
Card 05 核心结果与证据

核心结果与证据

  • Eq. (7) 精确分解初始 ensemble 已编码的 variance 与后续噪声动态产生的 variance，不要求 stationarity、Gaussian fluctuation 或确定 time-reversal parity。长时间 Eq. (8) 把 diffusion coefficient 写成 Poisson solution 的局部 Dirichlet form。
  • 有限时间 fluctuation-response equality 的二次型与其 dual variational representation 是严格恒等式；最大化 perturbation field 时可达到等号。沿 irreversible flow 选择后得到 friction-response TUR，并通过显式构造 equality observable 证明任意有限时间可饱和，从而 entropy production 不是只得到下界而是精确 variational supremum。
  • driven free diffusion 反例表明 conventional full-variance current factor 可随 thermodynamic cost 指数下降；相同模型中 response-based、subtracted-variance factor 仍满足 universal lower bound。该证据是解析解/渐近，不是实验拟合。
  • 论文还给多 observable/perturbation 的 matrix inequality；cross-correlation 可收紧 dissipation bound。结论类型为有限时间随机分析定理与可解模型反例。
Card 06 有效性与局限

有效性与局限

  • 主体假设 Markovian underdamped Langevin、additive noise、正定 diffusion matrix 和足够正则的 density/observable；multiplicative noise、non-Markovian friction kernel 或奇异边界需另推。
  • 精确 entropy-production inference 需要能施加或估计指定 friction/irreversible-flow response；在实验中这可能比测 current mean 更困难。
  • 反例说明传统 TUR 不普适，但不代表所有 current observable 都失效；结论依赖 velocity-resolved antisymmetric observable 的选择。论文没有代码或实验数据，也未独立验证。
