Drift and Dependence: Layer-wise Information-Theoretic Bounds for Replay-Based Continual Learning

漂移与依赖：基于回放的持续学习的逐层信息论界

Card 02 研究问题

研究问题

回放把旧任务总体替换为有限 buffer，并在后续更新中反复使用同一批样本，因此同时产生 representation drift 与 data–optimizer dependence。以往整模型单一复杂度项无法指出哪一层最值得稳定。本文在每个深度切开网络，把两条误差通道分离，并寻找漂移与下游放大之间的内部最优层。

Card 03 模型与方法

模型与方法

  • 在第 $\ell$ 层比较旧任务的总体 representation–label 分布与由有限 replay buffer 诱导的经验代理，得到层依赖 drift。
  • 主界把期望 generalization gap 拆为 replay-induced representation drift 与 optimization dependence；后者再分成 stability、plasticity、interaction 和 residual coupling。
  • 有效样本项由旧任务数、每任务 memory $m$ 与当前样本数 $n$ 共同决定；正文写为 $N_{\rm eff}=(T-1)/m+1/n$ 对应的 prefactor 结构，而不是把 replay 次数当独立样本。
  • 用 Wasserstein relaxation 处理总体分布与经验分布 support 不重合的问题；层目标是 drift $D_\ell$ 与上游/下游敏感度 $\bar\rho_\ell$ 的乘积。
  • 对 SGLD 优化给出 trajectory-level log-determinant information budget，并由 Hessian 加权的旧/新任务梯度对齐构造可在线计算的 forgetting diagnostic。
Card 04 核心结果与证据

核心结果与证据

  • 边界分析表明输入层的 representation proxy channel 与深层 amplification 的主导关系不同，最小化 $D_\ell\bar\rho_\ell$ 可直接选择要稳定的层，而不是默认冻结最浅或最深层。
  • Controlled Gaussian 四层网络中，drift 先降后升、敏感度下降，乘积呈内部凸形，最小值集中在第 2 层；两个端点从未被选中。
  • ResNet-10/18/26/34、两种 replay 方法与两个 benchmark 共 12 个组合均出现 drift 的“浴缸形”，12/12 的最小点严格位于网络内部。
  • 随着网络加深，经验最优稳定层系统性向更深位置移动，支持该准则是相对深度权衡而非固定层规则。
  • SGLD 展开把每步 curvature-aware gradient interaction 汇总到 log-det budget；实验中 alignment statistic 与 task-wise forgetting 同步变化，作为监控信号，而非直接声称因果干预。
  • 有限记忆极限与全数据边界可退化到熟悉的互信息/平均稳定性形式，为分解提供一致性检查。
Card 05 有效性与局限

有效性与局限

  • 主界可能数值松；Wasserstein drift 与 sensitivity 的经验估计本身受样本量、尺度和层表征维度影响。
  • 可计算的优化项依赖 SGLD 建模，不能直接等同于实际 SGD、Adam 或带 batch normalization 的训练轨迹。
  • alignment 与 forgetting 的相关性不证明调整该统计量就会减少遗忘，也未自动给出稳定层后的最优正则强度。
  • 12 个深网组合支持 interior funnel，但不足以覆盖更长任务序列、非视觉任务、不同 memory policy 或预训练 foundation model。
  • 逐层切分依赖网络分层方式；skip connection 下层边界和 downstream sensitivity 的定义会影响解释。
