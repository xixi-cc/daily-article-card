FACT: Failure-Aware Causal Training for World-Action Models

FACT：面向世界—动作模型的失败感知因果训练

Card 02 研究问题

研究问题

很多 WAM 先预测成功未来，再逆推出动作，训练数据也以成功示范为主，因此给定坏动作时仍会“幻觉成功”。FACT 反转因果顺序：先生成/给定执行动作，再预测该动作导致的未来视频与任务进度。这样失败 rollout 的动作虽不应被模仿，却能成为有效的后果监督。

Card 03 模型与方法

模型与方法

  • 共享 causal diffusion transformer 同时处理 action、value 和 future-video tokens；序列顺序是 observation/instruction→action→value/future，使世界侧预测因果条件化于动作。
  • teacher-forced clean action slot G 与正在去噪的 action slot A 分开：训练时 value/video 读取真实执行动作 G，避免 noisy action 泄漏错误条件。
  • 成功示范训练 action/value/video 三损失；失败 rollout mask 掉 $L_{act}$，但保留 progress value 与 future video loss，因此坏动作教后果而不教策略复制。
  • 推理 Stage 1 先采 action chunk，填入 G；Stage 2 预测其 value/future。低延迟可直接执行单样本，也可并行采 $N$ 个动作按 progress value 做 best-of-N。
  • 仿真用 RoboTwin，多视角真实平台为双 YAM arms、RealSense D435 主视角与两个 D405 wrist cameras，评估 seen 五任务和 changed color/shape/instruction 的 unseen variants。
Card 04 核心结果与证据

核心结果与证据

  • RoboTwin 中 video co-training 将平均成功率从 81.8% 提至 85.6%，failure-aware 进一步到 87.5%，接近 Motus 87.8% 而报告推理约快 3×。
  • 真实 seen tasks 上基础 FACT 为 82%，加入失败数据达 89%，再用 candidate scoring 达 92%；Motus 为 64%。只有 scoring、没有失败后果训练反而 79%，说明 value head 需负例校准。
  • unseen variants 从 67% 提升到 failure-aware 77%，scoring 后 82%，接近具有大规模机器人预训练的 $\pi0.5$ 85%；比较必须保留预训练规模差异。
  • 移除 video co-training 使真实 seen 从 82% 降至 58%；不做 teacher-forced action condition 降到 77%；失败动作若不 mask imitation loss 则降至 63%。
  • 坏动作条件下 success-only 模型预测成功抓取，failure-aware 模型预测实际失败。失败比例扫描中坏动作 future accuracy 从 32.7% 单调升至 57.3%；$N=4$ 在长时任务完成度与延迟间较平衡。
Card 05 有效性与局限

有效性与局限

  • 失败 rollout 的价值来自正确记录“动作→后果”；若失败标签、进度或时间对齐错误，会训练错误因果接口。
  • best-of-N 是计算换可靠性，每个候选需额外 scoring pass；92% 不是 action-only 延迟下的结果。
  • 任务集中于桌面双臂操作，未覆盖人机交互、移动机器人或开放世界长时序。
  • progress value 是学习代理指标，可能被分布外候选利用；作者提出未来可换 progress estimator。
  • 与 $\pi0.5$ 等 foundation policy 对比的预训练数据规模不同，不能仅凭成功率断言架构绝对优越。
