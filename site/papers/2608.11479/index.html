Convergence Guarantees of Gradient Descent for Neural Networks via Generalized Lipschitz Smoothness

Card 02 研究问题

研究问题

神经网络 loss 通常没有全局 Lipschitz gradient，因为参数 norm 变大时局部曲率也增长；经典 descent lemma 不可直接套用。本文证明激活函数的 Lipschitz smooth/continuous/linear growth 经多层复合后保留为“参数端点 norm 多项式 × 参数距离”的 generalized smoothness，并据此得到无特殊初始化/数据/过参数要求的 stationary-point convergence。

Card 03 模型与方法

模型与方法

  • \(L\) 层全连接网络，激活需 Lipschitz continuous、导数 Lipschitz 且 linearly bounded；覆盖 linear、tanh、softplus、sigmoid，不覆盖 ReLU kink。
  • 输出 loss 对 prediction Lipschitz smooth，MSE 满足常数 $c_J=2$。
  • 逐层递推控制 activation、Jacobian 与 gradient 对参数扰动的变化，得到 local smoothness constant 为两端 weight norms 的显式多项式。
  • 推广 descent lemma：步长小于当前 norm-dependent bound 时 loss 下降；再由 loss telescope 控制 weight norm 不会过快发散。
  • 选择随迭代预算/初始 norm 的固定或调度步长，界定前 \(T\) 步最小 squared gradient norm。

Card 05 有效性与局限

有效性与局限

  • 不适用于标准 ReLU，因为导数不 Lipschitz；“一般网络”限于列出的平滑激活。
  • 只保证某次迭代梯度小，不保证最后迭代、全局最优、训练误差为零或泛化。
  • $T^{-1/L}$ 与 exponential-in-depth constants 对深网可能极松。
  • full-batch deterministic GD，不直接覆盖 SGD、Adam、momentum 或 normalization layers。
  • 步长需按理论 norm bound 足够小，未证明常用大步长/ warmup。
