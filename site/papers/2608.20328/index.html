The Memory Hidden in Response Fluctuations: Trajectory-Level Fluctuation-Response Theory and Inequalities for Non-Markovian Jump Dynamics

响应涨落中隐藏的记忆：非马尔可夫跳跃动力学的轨迹级涨落–响应理论与不等式

2026-08-22 · 原文

现代实验常把非平衡动力学记录为离散事件序列，其速率依赖已实现历史。状态概率的 closed master equation 可因 memory 失效，但每个 transition count 仍有精确随机方程：减去 history-dependent mean tendency 后得到 martingale increment，即给定过去不可预测的部分。不同 transition 和时间的 increment 正交，并构成任意轨迹 observable fluctuation 的完整正交基。展开系数 event-consequence kernel 描述特定历史下某事件对最终 observable 的因果后果；乘以 event intensity 即对应 rate perturbation 的 history-conditioned response。因此 intensity-normalized response 精确等于 fluctuation expansion coefficient，导出有限时间/频率 FRR。对历史平均留下非负 response-heterogeneity gap，可检验候选 memory coordinate 是否 response-sufficient；进一步得到由 dynamical activity 控制的 response-kinetic uncertainty relation。

Card 02 摘要

摘要

现代实验常把非平衡动力学记录为离散事件序列，其速率依赖已实现历史。状态概率的 closed master equation 可因 memory 失效，但每个 transition count 仍有精确随机方程：减去 history-dependent mean tendency 后得到 martingale increment，即给定过去不可预测的部分。不同 transition 和时间的 increment 正交，并构成任意轨迹 observable fluctuation 的完整正交基。展开系数 event-consequence kernel 描述特定历史下某事件对最终 observable 的因果后果；乘以 event intensity 即对应 rate perturbation 的 history-conditioned response。因此 intensity-normalized response 精确等于 fluctuation expansion coefficient，导出有限时间/频率 FRR。对历史平均留下非负 response-heterogeneity gap，可检验候选 memory coordinate 是否 response-sufficient；进一步得到由 dynamical activity 控制的 response-kinetic uncertainty relation。

Card 03 背景

背景

离子通道、单分子酶、transcription 和突触事件都可能出现 history-dependent conditional intensity。低阶 dwell correlation 只能说明过去与未来相关，不能说明哪段历史改变 intervention response。论文不先重建隐藏 Markov network，而是在 observed filtration 上直接建立 stochastic closure，并把 memory 定义为“同一事件在不同历史中造成不同后果”。分类为 pure physics / biophysical stochastic thermodynamics。

Card 04 模型与方法

模型与方法

  • 对每个转移计数 $N_{ij}(t)$ 使用 Doob–Meyer decomposition：$dN_{ij}=r_{ij}(t|\mathcal H_{t-})dt+dM_{ij}$。正交 martingale increment $dM_{ij}$ 产生初值之后全部 trajectory randomness；martingale representation theorem 给 observable fluctuation 的 event-by-event expansion。
  • event-consequence kernel 是给定 pre-event history 时“发生事件”与“继续不发生”对预测终值的差；rate intensity 与 kernel 的乘积给 perturb transition rate 的 conditional response。全历史分辨给 exact FRR，投影/平均到 reduced coordinate 后 slack 即 response-heterogeneity gap，并随 coordinate refinement 单调下降。
  • 理论还把 rate logarithmic sensitivity 约束为 Fisher-information bound 和 response-kinetic uncertainty relation，资源项为 expected event count/dynamical activity。实验部分对 cell-membrane BK 与 mitochondrial BK (mitoBK) thresholded dwell records 做 event–continuation matching、state/age/preceding-dwell projection、shuffle control、split-sample debiasing和 frequency analysis；patch 是统计单位。
Card 05 核心结果与证据

核心结果与证据

  • 严格结果链：martingale basis completeness → kernel=response/intensity → finite-time/finite-frequency exact FRR → coarse-history inequality与非负 gap → activity-controlled R-KUR。Markov limit 中相同当前状态的历史响应相同，gap 闭合并恢复已知 identities。
  • BK 数据出现相反排序：传统 lag-one dwell memory 在 cell-BK 更强（文中 one-sided $p=0.025$），但 state-and-age 后留下的 response-relevant residual 在 mitoBK 更大；原始 residual 超过 state-wise shuffle 的结果出现在全部 25 个 quality-controlled mitoBK patches，exact paired sign test $p=5.96\times10^{-8}$。
  • 加入前一、前二 dwell 后，mitoBK patch-median excess residual 从 0.292 降到 0.237、0.198，但三-dwell reference 为零只是 construction，不证明三段历史完整 response-sufficient。六个电压组 median 约 0.22–0.36，未解析出单调 voltage dependence。
  • 频率结果：mitoBK state-and-age excess residual 从 $0.263$（$\Omega=0.5$）降至 $0.178$（2）和 $0.103$（16）；cell-BK 从 0.087 降到 0.007。24/25 以上 mitoBK patches 在所有采样频率保持 data-minus-shuffle 正号。结论是 response memory 强度和时间尺度不能从 correlation 单独推断。
Card 06 有效性与局限

有效性与局限

  • 理论要求 regular、causal、nonexplosive intensity 以及 observed-channel filtration；遗漏噪声源需要增加 martingale basis，singular/explosive dynamics 不覆盖。
  • BK event–continuation 比较是 observational 而非 controlled intervention；未观测变量可同时影响 event timing 与 future output。rich-history reference 只保留有限 preceding dwells，thresholded records 还会受 missed event 影响。
  • response sufficiency 依赖 observable、perturbation family 和 timescale，不是系统唯一 scalar memory length。实验样本/continuation 有上限，频率窗口和 quality control 会影响估计。
