Card 02 研究问题

研究问题

FNO 等神经算子常在固定全局基中表示解，对局部传播、反应扩散和异质介质不总合适。KNO 把解的 latent representation 视为球面耦合振子场，在网络深度中用局域 Kuramoto-like rotation/synchronization 演化，并研究振子局部不相干能否成为无需额外 uncertainty head 的误差风险信号。

Card 03 模型与方法

模型与方法

  • 输入逐点 lift 为 feature field $h$；随机初始化单位球振子 $q$，band-limited 输入投影初始化 persistent stimulus $s$。
  • 每个 KNO layer 在 canonical uniform grid 上局域耦合邻近振子，计算切空间 rotation vector field，经多步 weight-tied integration 和 retraction/normalization 保持球面约束。
  • feature、oscillator、stimulus 三场共同更新，末端 pointwise projection 输出 PDE 解；随机 $q_0$ 可多次平均评估。
  • 局部 order/incoherence $D_{loc}$ 由邻域振子同步程度构造；比较它与目标几何、逐像素 normalized error 的 Spearman/correlation 及 top-10%-error AUROC/AP。
  • 八类 PDE 任务含 Poisson、wave、Allen–Cahn、连续/离散 translation、Darcy、Airfoil 等，评估 ID/OOD 并与 FNO、RNO、CNO、DeepONet、UNet、AKOrN 等统一比较。
Card 04 核心结果与证据

核心结果与证据

  • 表 1 中 KNO 在 8 个任务的 ID/OOD 分别有 7/6 个排名第一或第二；对五个局部结构显著的任务，ID 与 OOD 均第一。
  • 代表数值：Wave ID/OOD 相对 $L^2$ 为 \(0.0032\pm 0.0012\) / \(0.0137\pm 0.0002\)；Allen–Cahn 为 \(0.0013\pm 0.0001\) / \(0.0251\pm 0.0056\)；Darcy ID 为 \(0.0141\pm 0.0013\)。
  • Poisson 上 KNO \(0.0074\pm 0.0008\)，逊于 CNO \(0.0034\pm 0.0001\)；作者将其解释为简单全局线性 smoothing 已被卷积模型很好捕获，而非 KNO 全面领先。
  • 表 2 消融显示 local coupling 与 rotation 是最大增益源，stimulus 贡献较小；表 3 显示 retraction/normalization 最关键，球面参数化在部分任务不必需但提升总体稳定。
  • 图 2–3 显示初始 $D_{loc}$ 与误差几乎无关，随 learned dynamics 深化才在解的边界/局部结构形成并与误差对齐；该关联在 OOD 仍保留，能定位高误差像素。
Card 05 有效性与局限

有效性与局限

  • KNO 在 uniform grid 上演化，对不规则几何不自然；Airfoil 结果暴露这一限制。
  • 简单线性全局算子上额外振子动力学优势小，甚至不如 CNO。
  • 误差关联是 architecture-native risk signal，但不是 calibrated uncertainty 或严格误差上界。
  • 随机振子初始化与多次平均增加推理方差/成本；积分步数虽 weight-tied 仍增加 wall time。
  • 八个 benchmark 的优势不能替代高分辨率真实 PDE 的守恒律、边界条件和长期稳定性检查。
