Bridge Graphical Models: Coupling, Projection, and Current-Preserving Dynamics for Generative Modeling

桥图模型：生成建模中的耦合、投影与流守恒动力学

2026-08-21 · 原文

连续时间生成模型常由 endpoint-conditioned bridge 构造，但生成时需要的是只观察当前状态和时间、非预见的 Markov decoder。本文把这种 bridge-to-decoder compression 识别为 diffusion、flow matching、rectified flow、Schrödinger bridge 和 field-based model 共有的结构瓶颈，并定义 Markovization gap：给定 Markov 状态后 bridge velocity 的条件方差对时间积分。它等于用 sampler 可见信息预测 endpoint-conditioned motion 的 MMSE，是神经网络训练之前就存在的不可约损失。Bridge Graphical Model (BGM) 将 endpoint coupling、bridge law、Markovian projection 与 current-preserving dynamics representation 分成独立设计项；Poisson/electrostatic model 也被表示为 field-line bridge kernel。CIFAR-10、Fashion-MNIST、latent 和合成 pilot 中，训练前数分钟计算的 feature-space proxy gap 在固定架构、bridge、sampler 和 compute 下与训练 loss/FID 的排序方向一致。

Card 02 摘要

摘要

连续时间生成模型常由 endpoint-conditioned bridge 构造，但生成时需要的是只观察当前状态和时间、非预见的 Markov decoder。本文把这种 bridge-to-decoder compression 识别为 diffusion、flow matching、rectified flow、Schrödinger bridge 和 field-based model 共有的结构瓶颈，并定义 Markovization gap：给定 Markov 状态后 bridge velocity 的条件方差对时间积分。它等于用 sampler 可见信息预测 endpoint-conditioned motion 的 MMSE，是神经网络训练之前就存在的不可约损失。Bridge Graphical Model (BGM) 将 endpoint coupling、bridge law、Markovian projection 与 current-preserving dynamics representation 分成独立设计项；Poisson/electrostatic model 也被表示为 field-line bridge kernel。CIFAR-10、Fashion-MNIST、latent 和合成 pilot 中，训练前数分钟计算的 feature-space proxy gap 在固定架构、bridge、sampler 和 compute 下与训练 loss/FID 的排序方向一致。

Card 03 背景

背景

训练 bridge 可以知道起终点，部署 sampler 却只能知道 $(X_t,t)$。若同一中间状态对应许多方向不同的 endpoint-conditioned velocity，任何 Markov 网络都无法恢复丢失信息。论文把这一误差同函数逼近、优化和 sampler discretization 分开，目标是训练前比较 coupling/bridge 设计。分类为 physics of/for generative AI：概率流、conditional variance、Markov projection 和 current representation 构成统一结构。

Card 04 模型与方法

模型与方法

  • 对 coupling $Q$ 采样端点并由 bridge 产生 $(X_t,U_t)$；最优 Markov velocity 为 $v_t(X_t)=\mathbb E[U_t|X_t]$。gap 是 $G(Q)=\int\mathbb E\|U_t-\mathbb E(U_t|X_t)\|^2dt$，即 Markov vector field 上回归风险的 infimum。
  • BGM 图 1 将 coupling、bridge、projection 与实现同一 probability current 的 ODE/SDE/field dynamics 解耦。理论还给出 gap 与 path-space objective、Girsanov/ELBO 及终点 Wasserstein 误差之间的条件关系；这些 bound 需要文中 regularity 假设。
  • 经验 proxy 用有限样本 kNN 条件方差；合成实验比较 independent 与 minibatch OT coupling；latent benchmark 固定 architecture/optimizer/32-step Euler；pixel pilot 用 64 维 PCA feature，在 CIFAR-10 每配置 CPU 约 9 分钟。
Card 05 核心结果与证据

核心结果与证据

  • 图 2：$n=1000$ 的一次合成实验中 independent gap 4.877、minibatch-OT gap 0.038；$n\in\{500,1000\}$ 的 5-seed 复核显示 OT 约降低两个数量级。
  • 表 2（三个 latent seeds，\(mean\pm SD\)）：在 bridge、architecture、optimizer 和 sampling budget 相同时，minibatch OT 约把 gap 减半、velocity-regression error 降 67%–69%、terminal latent MMD 降 45%–51%；但 1NN statistic 仍远离理想 0.5，说明生成分布并未解决。
  • 表 3/4：feature proxy 在 coupling 排序上与固定条件下 pixel-space training loss、FID（Fashion-MNIST 还包括 KID）方向一致。作者明确 proxy 不是 pixel-space certified lower bound，跨 dataset 的绝对值也不可比较。结论是预训练 diagnostic 的 pilot 支持，而不是普适性能定理。
Card 06 有效性与局限

有效性与局限

  • Markovization gap 只隔离 bridge compression；低 gap 不保证有限网络可逼近、不保证 optimizer 收敛，也不控制 discretization 和 perceptual quality。
  • 真实数据 proxy 依赖 PCA/feature normalization、kNN 和有限样本；CIFAR/Fashion pixel pilots 是受控单次运行，规模远小于现代生成模型。
  • 论文是 work in progress；现场页未提供作者代码仓库，表中结果尚无外部独立复现。Poisson/electrostatic field-line 扩展主要是形式统一。
