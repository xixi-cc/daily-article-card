VIScore: Diagnosing Planning-Relevant Quality in Latent World Models

VIScore：诊断潜在世界模型中与规划相关的质量

Card 02 研究问题

研究问题

latent straightness、state probe 或 empowerment 常只测 encoder/表示，无法解释同一 latent world model 在 search-based planning 中为何成功或幻觉。本文先比较同样瞄准 isotropic Gaussian 的 SIGReg 与可调中心/尺度/形状的 VISReg，再提出跨 encoder、predictor、planner 的 Veracity–Influence–Sobriety 三因素分数。

Card 03 模型与方法

模型与方法

  • VISReg 把 center、scale、shape distribution matching 分量分开加权；batch size 控制经验分布逼近精度，构成 VIS-WM。
  • Veracity 测 open-loop rollout error 是否在任务自身 success tolerance 内，即 imagined transition 可达/真实。
  • Influence 测 action 对 latent future 的可控影响/容量，并在经验 knee 后截断（共享 cap $\tau=82$），避免无限奖励不可用的大变化。
  • Sobriety 比较搜索选出的 action 与候选/验证信号，惩罚 planner 被 predictor hallucination 诱导去选不可实现高分动作。
  • 以 success rate 为外部标签，run-level split 拟合 calibration；比较 straightness、physical-state probing、empowerment，在 seen/unseen model、task、planner 和跨任务 pool 中报告 Spearman 与 calibration error。
Card 04 核心结果与证据

核心结果与证据

  • 短期规划中 VIS-WM 三 seed：PushT $92\pm3.9$、Reacher $82\pm3.8$、OGBench-Cube $70\pm1.7$、Two-Room $92\pm3.7$；对应 LeWM 在可比三项约 91/82/90。
  • 长时 PushT 中 VIS-WM 胜过 6 个方法中的 5 个；六种 unseen PushObj shape 的 matched-batch 实验显示更大 batch 的 VISReg 改善 OOD，而 SIGReg 未带来同样规划收益。
  • VIScore 在 seen/unseen models 与 datasets 的跨任务池中 Spearman 一直超过 0.75，且是唯一在所有测试情景 calibration error 都低于 constant-fit baseline 的指标。
  • 表 6 使用 run-level split，测试 checkpoint 不来自拟合 constant/calibration 的 run；Cube 因 success spread 不超过一个 label standard error，被排除 pooled/calibration，避免伪相关。
  • factor ablation 与六 planners/同 36 checkpoints 检验显示三因素互补：representation-only 指标无法同时诊断 unreachable rollout、低 action influence 和 planner hallucination。
Card 05 有效性与局限

有效性与局限

  • VIScore 是 success association/diagnostic，不是因果保证；提高分数不必然通过训练干预提高策略。
  • veracity tolerance、influence cap 和 sobriety probe 依赖任务/规划器校准，不是无超参数统一常数。
  • 成功率标签噪声和范围压缩可扭曲相关；作者排除 Cube pool 正说明低方差任务不可稳定校准。
  • 多项基线结果借自既有论文，虽标注 reproduced/borrowed，训练协议仍可能不完全对齐。
  • VISReg 的 OOD 优势依赖 batch 对分布 matching 的近似，更大 batch 有显存成本。
