Exact First-Passage Time Response Theory from Steady-State Response

由稳态响应得到的精确首次通过时间响应理论

Card 02 研究问题

研究问题

MFPT 是到达、反应和切换的瞬态量；改变一个或多个 Markov 跃迁率后，通常要重求吸收问题。本文建立精确 correspondence，把任意状态对 MFPT 的有限、线性和高阶响应映射成辅助连续时间 Markov 系统的 steady-state response，从未扰动 MFPT 与 stationary probabilities 直接更新。

Card 03 模型与方法

模型与方法

  • 对象是有限/可数状态 continuous-time Markov chain，生成元跃迁率 $W_{mn}$；$T_{ij}$ 满足 backward equation。
  • 为目标 state 构造 auxiliary recurrent system，使原吸收过程的 MFPT 可由其 stationary occupation/current 表示。
  • 单个 rate 做有限乘性扰动时，利用 stationary distribution 的精确 rank-one response 得到 MFPT rational update，而非只保留一阶。
  • 把响应因子分为 perturbation 上游到起点、从扰动边到目标的 downstream，以及分母反馈产生的 nonlinear contribution。
  • 多 rate 更新可递归应用，并由同一结构推导高阶导数、响应界、curve inference 与同时计算 MFPT/steady state 的算法。
Card 04 核心结果与证据

核心结果与证据

  • 主 correspondence 将本质瞬态的 first-passage response 完全写成辅助系统 steady-state response，适用于任意起点–终点和任意单边 rate perturbation。
  • 精确有限更新展开后恢复线性 susceptibility，并给任意阶响应系数；因此可判断线性近似失效来自分母反馈而非重新求整个网络。
  • factorized decomposition 显示某条 rate 对 MFPT 的作用需要 upstream 可达性和 downstream first-passage 结构同时非零，提供网络位置的物理解读。
  • 由 positivity/normalization 得到 MFPT response 的基本上下界，并可用少量响应点推断整条单 rate 曲线。
  • 图 1 在随机 8-state 网络中做 $10^5$ 次率更新验证 exact formula；生物启发 folding network 用该分解解释此前“加快局部转移反而延长某 MFPT”的悖论。
Card 05 有效性与局限

有效性与局限

  • 理论建立在 Markov、time-homogeneous 跳过程；non-Markov memory 或连续扩散需另行推广。
  • 精确关系仍需未扰动 MFPT 与 stationary probabilities；超大稀疏网络计算成本取决于线性求解器。
  • 接近不可约性破坏、率趋零或 MFPT 发散时，响应分母可奇异。
  • 多 rate 递归的次序/数值误差需控制，虽理论终态应一致。
  • folding 网络是机制示例，不等于对真实蛋白动力学的完整建模。

Card 07 阅读指南

阅读指南

  • 先复习 MFPT backward equation 与 auxiliary steady-state construction。
  • 主定理后立即用单边更新做代数检验。
  • 再读 upstream/downstream/nonlinear decomposition 与 bounds。
  • 最后看 folding network，区分普适公式和应用解释。
