Small-Scale Experiments: Are We There Yet?

小规模实验：我们准备好了吗？

Card 02 研究问题

研究问题

许多工作认为 100M 以下模型的 scaling law 不可靠。本文提出真正的混杂因素是小模型对超参数极敏感：scaling law 只描述每个 parameter–data budget 上的 fully tuned frontier，如果搜索没碰到前沿，观测到的是 tuning noise 而非尺度规律。作者进一步问，小规模证据怎样安全迁移到模型架构决策。

Card 03 模型与方法

模型与方法

  • 训练 4M、8M、17M、34M、67M、134M、268M effective-parameter Transformer；effective count 纳入 attention/unembedding FLOPs、排除 embedding，并以 $c=6pd$ 计 compute。
  • 使用 warmup–stable–decay；从 stable run 的 8 个 checkpoint 分叉 decay，以较低成本得到多个 token budgets。
  • 默认用 4M–34M 拟合、67M–134M 验证、268M 测试，拟合 $L(p,d)=\epsilon+\zeta/p^\iota+\eta/d^\kappa$。
  • 用 random search 研究 loss surface；noisy-quadratic limit 以最佳值 $\alpha$、集中度 $\beta$、有效超参数维度 $\gamma$ 与 seed noise $\sigma$ 诊断是否搜索充分。
  • 通过固定语料下的 perplexity–capability correspondence，把预训练 loss 与 MMLU、OpenBookQA、PIQA 等能力连接；不直接拟合脆弱的 downstream scaling law。
Card 04 核心结果与证据

核心结果与证据

  • scaling law 从 4M 就能出现，但必须沿 fully tuned frontier；4M 模型单 GPU 不到一小时，使数百次搜索仍可能比少量十亿参数运行便宜。
  • 图 5 的 tuning ablation：每尺度 4 或 16 个配置时规律不可可靠辨认，64 个时出现但外推弱，256 个时才得到准确 law。
  • 方法消融中，为每个 parameter–data budget 单独调参使 test MSE 降约 50%；学习率 decay 降约 98%；parameter counting 和 tying exponents 的影响更小，且 tying 在 validation/test 上不一致。
  • 随着参数与数据共同增大，随机配置更常靠近 optimum，估计的有效超参数数 $\gamma$ 下降；只增参数或只增数据不能同样消除 sensitivity。
  • 外推会放大 sampling error：用 4M/8M/17M/34M 各 128 runs 独立拟合时，远端预测最终由不稳定的 irreducible-error 估计支配。
  • pre-norm/post-norm 案例用 post-norm 511/512/128 个配置与 pre-norm 各 128 个配置在 4M/34M/134M 检验；pre-norm 更易调、在观测尺度内 scaling 更好。若共享最终 irreducible loss，优势随 compute 扩大；若分别自由拟合，远外推可反转，因此作者把共享假设明确暴露出来。
Card 05 有效性与局限

有效性与局限

  • “小模型可用”不等于少量 runs 可用；本文的关键成本正是每尺度数十到数百次超参数搜索。
  • scaling law 预测 loss，不直接预测 emergent capability；perplexity–capability correspondence 只有预训练数据组成固定时成立。
  • 更换数据会破坏 correspondence，因此方法目前主要用于 model-centric research，不能支持一般 data-centric 决策。
  • irreducible error 在尚未饱和时统计不稳，超出数据范围很远的架构排序依赖共享/独立渐近值等假设。
  • 实验集中于该 Transformer/语料/优化设置；超参数维度随尺度下降不保证对所有模态、optimizer 或训练不稳定结构成立。
