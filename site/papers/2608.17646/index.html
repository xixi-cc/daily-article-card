Elimination Geometry

消元几何

2026-08-19 · 原文

原文没有单独标为 Abstract 的段落；以下是对 Preface 的忠实中文范围概述，而不是虚构摘要。现代学习系统常让一个机制在许多局部问题上复用，但逐点存在最优对象 $a_x^*$ 并不保证存在一个受共享参数、连续性、有限记忆、输出类型或资源预算约束的全局规则 $A$ 同时实现它们。单行本把局部目标 $H_x(a)$ 消元后的超额目标 $D_x(a)=H_x(a)-J(x)$ 定义为 native defect，并把 $\inf_{A\in\mathcal A}\mathbb E D_X(A(X))$ 定义为 architecture obstruction，以原始 likelihood、divergence、proper score、Bellman objective 或 free-energy 的单位量化部署约束造成的损失。它组织的是一种 typed、native-loss、audit-oriented synthesis：分开 local oracle error、global architecture obstruction、finite-sample generalization 与 implementation error，再针对 obstruction 构造 certificate 和 mechanism-matched repair。作者明确不声称提出新的通用逼近/表示理论，也不声称实证已完成一般性的 certificate–saturation–repair 链。

Card 03 背景

背景

Amortized inference、multitask representation、finite-memory control 与跨样本科学分析都把“每个实例单独最优”替换成“一个机制全局复用”。很多失败被笼统归入 optimization 或 approximation；本书要求先区分三个逻辑层级：local solvability、global realizability、finite-sample certifiability。它把凸对偶、Bregman defect、拓扑 obstruction、控制、information theory 和 learning bounds 接到统一接口上。分类为 pure AI / learning theory synthesis，使用几何和拓扑语言，但不是物理系统论文。

Card 04 模型与方法

模型与方法

  • Primitive interface：对每个 $x$ 给定 fiber、lifted objective $H_x(a)$、eliminated value $J(x)=\inf_a H_x(a)$、oracle set 和 native defect。部署类 $\mathcal A$ 再定义 population/uniform obstruction；风险被明确拆成 model、architecture、generalization、optimization/implementation 四项（图 3.1、表 3.1）。
  • 后续构造包括 Bregman/Legendre native loss、typed min-plus elimination、gauge/quotient reduction、local-to-global gluing、holonomy/monodromy、resource grammar、finite-memory rectangularization、contextual observability 与 confidence-world certificate。每个接口都要求输出语义、attainment、measurability 和 sampling unit 明示。
  • 书中使用四类 laboratory（oracle-preserving coarse-graining、graph-indexed distribution、shared conditional decision、one-pass/local refinement）与后半部 empirical protocols。它给出高概率 bound、拓扑/循环审计以及 intervention protocol，但强调不同章节的定理不能自动串成一条通用 architecture-choice theorem。
Card 05 核心结果与证据

核心结果与证据

  • 核心可证对象是 native architecture obstruction：它在原目标单位中量化固定 deployment contract 相对逐点 oracle 的不可消除损失，并与 finite-sample/implementation gap 分开。图 1.1 和图 3.1展示三层问题及四项风险分解；表 4.2把四类 laboratory 映射到共同词汇。
  • 拓扑部分以 elimination square 的非零 circulation 记录 order dependence（图 9.1），并指出在一般 complex 上 face curvature 为零仍需 period audit；monodromy 是否构成 obstruction 取决于输出是 point、quotient、projector 还是 unordered set（图 14.1）。这些结论依赖明确的 output contract。
  • Preface 声明本版本闭合了 full-column-rank nonnegative sparse inference 的一条 architecture-specific 链：strict active-set neighborhood 给出可计算 one-pass native-loss floor，指定 proximal repair 有显式 sufficient crossing depth；另一个 sealed diabetes case 完成独立的 two-step、patient-average、equal-information/equal-compute decision。作者同时明确：前者 theorem-alignment 是 post-confirmation，优先级未独立解决，两条进展不能合并成一般理论。
  • 实证证据按书中自己的审计标准仍是部分链条：文档明确说没有任何 empirical study 完成一般 certificate–saturation–repair validation chain，也没有 external replication。故本卡把它评为体系化方法论/单行本，而不把 289 页规模当作普适性证据。
Card 06 有效性与局限

有效性与局限

  • 这是 2026 年 research-circulation draft；版权页明确所有 theorem statement、proof、example 和 computational protocol 仍待作者正式审阅，不能等同 peer-reviewed monograph。
  • Native defect 不自动推出正的 population obstruction；worst-case topological cost 不自动推出平均风险；deterministic obstruction 不自动 finite-sample identifiable；repair 也不自动 held-out improvement。每一箭头都需要独立定理或实验。
  • 全书是既有数学传统的 typed synthesis 和 audit workflow，不声称全新的 universal approximation/representation theory。案例没有 general external replication，且 institution、code repository、原始数据和统一运行环境未在文档首页提供。
