Poor Man's Agentic Modeling: Simulating Large LLM-Agent Societies on a Laptop

穷人版智能体建模：在笔记本上模拟大型 LLM 智能体社会

Card 02 研究问题

研究问题

大规模 LLM-agent society 很昂贵，而研究问题常是相变、宏观曲线和随人口 $N$ 的 scaling。本文主张 cheap surrogate 是否有效可在仿真前由“每个 agent 看见什么”与 memory 结构判断，并提出 interaction-order × memory taxonomy 预测 scalar mean-field error 的 $N$ 趋势及所需最小 closure。

Card 03 模型与方法

模型与方法

  • 先用几百到几千次便宜 LLM query（主要 DeepSeek）拟合个体 response curve，再替换每轮 LLM 调用运行任意 $N$。
  • global aggregate feed 属 mean-field cell，sampling error 约 $N^{-1/2}$；community-shared feed 留随 block 数下降的 $O(1)$ floor；local graph feed 需要 pair/graphon closure。
  • memory 轴区分 memoryless 与有限/长记忆，以测得 assimilation kernel 决定截断；commutation defect 连接一步 coarse-graining 误差与宏观 observable。
  • 在 EconAgent 复现和另外七个命名系统上做 cell-by-cell validation，包括 OASIS、AgentTorch、AgentSociety、De Marzo naming 等。
  • 对强曲率 response 额外计算 Jensen gap，对 shared driver/recommender correlation 单独建模；两条被数据否定的朴素预测用无自由参数曲率修正解释。
Card 04 核心结果与证据

核心结果与证据

  • global perception 下 scalar surrogate error 随 $N^{-1/2}$ 消失；community perception 随 $N$ 保持 floor、仅随 communities 数 $B$ 约 $B^{-1/2}$ 降低，符合图 2。
  • EconAgent 的 Phillips curve 机制只有 price-keyed labour channel 可达 published −0.62；2×2 ablation 显示 reasoning signal 而非措辞驱动宏观曲线。
  • 图 3 用 recommender mixing knob $\lambda$ 连续跨越 private→community perception，分开 correlation floor 与 nonlinear Jensen floor。
  • De Marzo critical group size 被重释为 perception resolution $\beta_{eff}(N)$ 是否穿过阈值 1；不穿则 $N_c=\infty$，穿过才有限。
  • AgentSociety 的 scalar error 在 densification 增长/定 degree 留 floor，pair-plus-memory 修复；另一 closure 对百万-agent observable 报告约 $10^3$ 倍加速。
Card 05 有效性与局限

有效性与局限

  • surrogate 旨在宏观 observable，不保留单 agent 推理、语言内容或尾部个案。
  • 拟合 query 覆盖不足会导致 identifiability frontier；同一宏观数可能对应多个微观 channel。
  • taxonomy 需正确知道 perception/recommender；真实平台的隐藏排序逻辑会破坏分类。
  • 曲率与 shared driver 是 interaction×memory 之外的重要轴，朴素 mean field 仍可能因 Jensen inequality 失败。
  • “几美元/笔记本”依赖模型价格、query 数、社会规则和 observable，不能当普遍固定成本。
