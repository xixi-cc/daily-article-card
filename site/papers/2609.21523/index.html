Card 02 研究问题

研究问题

当系统必须先压缩内部状态、之后才知道真正要执行的任务，究竟哪些自由度必须活下来？作者把压缩前可用的有限任务消息与压缩后揭晓的精确任务分开，严格刻画线性任务族中消息数与最小状态维数的折衷。主结果为精确划分—秩前沿，同时给出近似恢复上下界、共有核心子空间规律、最优划分的强 NP-hardness，以及 attention、数字孪生和分层多任务三个构造例子（原PDF物理第1–9页）。

Card 03 背景

背景

这属于表示学习的数学基础，而非已训练模型的压缩实验。预测状态、线性 sketch 与 task-aware compression 都问未来用途需要哪些信息；本篇更具体地固定信息到达顺序：源状态完整可见，任务身份只通过有限 advice 消息提前透露，精确任务在编码之后才公开。作者在原PDF物理第9页说明，其资源计量是最坏情形下连续坐标维数，区别于有随机源分布的通信码率。将它用于物理降阶时，可以把未来测量看成一族线性读出，但这里没有建立热力学存储成本或真实神经网络容量定律。

Card 04 读者桥接

读者桥接

输入是欧氏单位球内的状态 \(x\in\mathbb R^n\)；表示是取决于 advice cell 的连续编码 \(\phi_C(x)\in\mathbb R^p\)；被设计的对象是任务划分、编码器和各任务解码器；目标是对仍可能发生的全部线性任务作精确或一致近似恢复；输出是 \(T_ux\)，可观测量是必要维数及最坏恢复误差（原PDF物理第1–2页）。这里没有梯度训练或语料库。

三个必要概念：advice 是关于任务身份的确定性消息，最多 \(K\) 种符号，可由 \(b\) bits 表示，\(K\le2^b\)；sufficient state 指足以恢复后续任务输出的状态，不要求重建原输入；任务族的联合秩衡量所有潜在读出涉及的独立方向，不等于单任务秩之和。增加消息可能拆开相互独立的读出方向，但若任务共享同一方向，多报任务身份未必进一步节省维数。

Card 05 模型与方法

模型与方法

对每个有限任务 \(u\in\mathcal U\)，给定线性算子 \(T_u:\mathbb R^n\to\mathbb R^{r_u}\)。一个 advice symbol 对应任务集合 \(C\)，其共享编码必须支持所有 \(u\in C\)。堆叠算子定义为 \(T_Cx=(T_ux)_{u\in C}\)，采用输出空间的欧氏乘积范数。连续性是承重前提；不加它，实数编码可出现不受同样拓扑维数约束的病态信息打包。

原PDF物理第2页 Lemma 2.1 先解决单一算子：

\[ \inf_{\phi,\psi}\sup_{\|x\|_2\le1}\|Lx-\psi(\phi(x))\|_2=\sigma_{p+1}(L) \]

公式定位：Official PDF pp. 2, Lemma 2.1。截断 SVD 给上界，Borsuk–Ulam 限制连续编码的下界。

此式中，\(x\) 为欧氏单位球中的源状态；\(L\) 为线性任务算子；\(p\) 为保留连续坐标数；\(\phi\) 为连续编码；\(\psi\) 为连续解码；\(\sigma_{p+1}\) 为第 \(p\)+1 个奇异值，零补齐。

其下界用前 \(p+1\) 个右奇异向量张成空间内的球面，Borsuk–Ulam 保证存在一对反点被编码到同一点，解码器不能同时精确分辨两者；上界由截断奇异值分解达到。因而零误差恢复恰好需要算子秩这么多坐标。再对每个 cell 用这个结果，原PDF物理第2–3页得到：

\[ p^*(K)=\min_{\mathcal P:\,\mathcal P\ \mathrm{partitions}\ \mathcal U,\,|\mathcal P|\le K}\max_{C\in\mathcal P}\operatorname{rank}(T_C) \]

公式定位：Official PDF pp. 2–3, Theorem 2.2, Eq. (1)。需要保留同一消息下所有可能任务的联合行空间。

此式中，\(\mathcal U\) 为有限任务族；\(\mathcal P\) 为至多 \(K\) 个非空 cell 的划分；\(C\) 为共享一个 advice symbol 的任务集合；\(T_C\) 为各任务线性算子按输出堆叠；\(K\) 为advice alphabet 大小；\(p^*\) 为最小共同连续状态维数；\(Part(U)\) 为有限任务族 U 的非空集合划分全体。

下界来自必须恢复整个堆叠输出；可达性来自每个 cell 的秩分解，存储其低维线性编码再选择任务输出块。这个论证说明前沿取决于联合行空间几何，不能仅由任务数量或各任务秩判断。

Card 06 核心结果与证据

核心结果与证据

第一，任务消息是可分配的状态资源：\(p_b^*=p^*(\min\{2^b,m\})\)，其中 \(m\) 为任务数。无消息必须覆盖全部任务；完整身份消息则只需最大的单任务维数。若所有任务都有 \(c\) 维共有核心子空间，每个任务另有 \(g\) 维相互独立的私有方向，均衡划分给出原PDF物理第3–4页 Eq. (4)：

\[ p^*(K)=c+g\left\lceil\frac mK\right\rceil \]

公式定位：Official PDF pp. 3–4, Corollary 2.3, Eq. (4)。只削减未确定任务的私有方向；共有核心子空间不会因消息而消失。

此式中，\(c\) 为共有核心子空间维数；\(g\) 为每个任务私有子空间维数；\(m\) 为任务数；\(K\) 为消息数。

物理读法是共同界面状态必须始终保留，可随区域身份消息减少的是局部自由度。原PDF物理第6–7页数字孪生例中64个区域、界面256维、各区128维，零消息、三 bits、六 bits 分别需要8448、1280、384个坐标；异质区域须均衡维数而不是均衡区域数。这些数是构造的精确秩结果，不是有限元求解性能测量。

第二，近似恢复不能把 exact rank 简单替换为一个唯一的有效秩。原PDF物理第4–5页 Theorem 2.5 保留：

\[ \frac{\sigma_{p+1}(T_C)}{\sqrt{|C|}}\le E_p^{\max}(C)\le\sigma_{p+1}(T_C) \]

公式定位：Official PDF pp. 4–5, Theorem 2.5, Eq. (5)。分支范数和堆叠范数不同，近似情形一般只有上下界。

此式中，\(E_p^{\max}\) 为连续编码/各分支解码后在单位球上的最坏分支误差；\(\sigma_{p+1}\) 为堆叠算子的第 \(p\)+1 奇异值；\(|C|\) 为cell 中任务数；\(p\) 为保留维数。

其中下界的平方根因子来自堆叠欧氏范数与最坏单分支误差的差异；再以阈值奇异值个数可得到划分后的必要和充分维数界。正误差时两界一般不相等。

第三，attention 构造并非利用接近奇异的矩阵作弊。原PDF物理第5–6页取正交 keys 与特定 queries，在逐行 softmax 下：

\[ A=\operatorname{softmax}(\alpha I_s)=\frac12 I_s+\frac1{2s}\mathbf1\mathbf1^\top,\qquad p^*(K)=d_vg\left\lceil\frac mK\right\rceil \]

公式定位：Official PDF pp. 5–6, Section 3.1, Eqs. (7)–(8)。非零奇异值保持在二分之一至一之间，构造中的维数节省由任务不确定性控制。

此式中，\(s\) 为m \(g\) 个 attention 位置；\(\alpha\) 为log(s+1)；\(I_s\) 为单位矩阵；\(\mathbf 1\) 为全一向量；\(d_v\) 为value width；\(g\) 为每个 continuation block 的行数；\(m\) 为block 数；\(K\) 为消息数。

该矩阵条件数为2，行选取后非零奇异值仍在 \([1/2,1]\)。取512个 continuation blocks、每块8行、value 宽度128，9 bits 将524288个必要坐标降为1024；这严格描述构造里的线性 value 读出，不是实测 LLM KV cache 的512倍压缩。原PDF物理第7–8页分层例进一步区分共同、家族、任务三个层次：三 bits 先揭晓家族，维数从3136降至448，后续消息才逼近328的单任务下限。

Card 07 有效性与局限

有效性与局限

原PDF物理第9页明确限制为连续坐标而非有限精度 memory bits，线性任务而非完整非线性推理；若任务算子也需从数据学习，还要另计统计误差。对物理系统而言，该定理适用于指定线性测量，不自动覆盖非线性响应、状态转移或控制闭环。

原PDF物理第4–5页 Corollaries 2.4、2.6 通过 disjoint coordinate tasks 与3-Partition证明，最优 advice 划分一般强 NP-hard，任意固定正容差下仍难；后者将任务算子放大以维持错误容差和秩需求的区分。因此存在精确变分表征并不意味着可以高效找到最优压缩方案。分层例的闭式式子还要求家族子空间足够大及家族不混合的论证成立，不能覆盖全部消息预算。

Card 09 阅读指南

阅读指南

先读原PDF物理第1–3页信息到达顺序和 Theorem 2.2，确认存储的是任务读出所需方向。再看原PDF物理第6页 attention 表格与原PDF物理第6–7页界面/局部状态构造：两者说明为什么任务身份能减少状态，却不能删除所有共同自由度。深读原PDF物理第2页 Borsuk–Ulam 下界、原PDF物理第4–5页范数差异及归约。熟悉线性代数、奇异值分解和基本拓扑连续性即可进入正文；参考文献比较可后读。全文确证没有编号图，封面用题名与忠实摘要，表格数字仍按原页证据解读。
