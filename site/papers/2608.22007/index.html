The Communication Map of a Transformer

Transformer 的通信图谱

2026-08-26 · 原文

Transformer 组件通过向共享 residual stream 写入并从中读取来通信，而机制可解释性过去常逐条电路手工绘制这些连接。本文提出 communication map：仅由权重出发绘制语言模型中每个潜在通信通道，把已有 composition score 推广为统一 coupling coefficient，覆盖从完整 attention-head 电路到单 neuron 的 18 类连接。对所有候选通道的普查从 GPT-2 的 $6.3\times10^8$ 对扩展到 Pythia-6.9B 的 $1.3\times10^{11}$ 对；70–89% 的 head pairs 相对随机方向显著偏离，有些强耦合，有些主动避开。完整图谱在一张消费级 GPU 上耗时从 GPT-2 的 15 秒到 Pythia-6.9B 的 11 分钟。两个应用验证其用途：最强 head-to-head coupling 可盲恢复已知 induction circuits 并把它们组成社区，消融该社区会破坏 in-context copying；汇总所有 head 的 coupling 后还能找到不同于 activation PCA 与 outlier dimensions 的二维 residual-stream 子空间，删除它会在六个模型中消除 induction 能力。作者公开图谱、统计工具与干预套件。

Card 03 研究问题

研究问题

能否用一个与组件类型无关、可统计校准且计算可扩展的权重几何量，系统枚举 Transformer 中“谁能向谁写入信息”，并让图上结构产生可干预验证的功能预测？分类为 pure AI / mechanistic interpretability。

Card 04 背景

背景

residual stream 是 attention heads 与 MLP neurons 的共享通信介质。既有 QK/OV composition scores 适合特定 head-to-head 情形，却难统一 neuron、head 与多种读写通道；激活归因则依赖输入。本文刻意测量 potential connectivity：权重几何允许的通道，而不是任意给定输入上实际流过的信息。

Card 05 模型与方法

模型与方法

  • 把每个组件写成 reader map $R$ 与 writer map $W$，用 trace 归一化的 $C^2(R,W)$ 衡量 gain-weighted directional overlap；SVD 形式把它解释为奇异方向夹角的加权平均。
  • 对 18 种 connection class 分别建立因果层掩码和经验 null；Haar 旋转给出均值 $1/d$，实际 edge selection 使用类内 robust \(z\)-score 与 Benjamini–Hochberg FDR $q=0.05$。
  • 在 GPT-2、GPT-Neo 与 Pythia 家族七个模型上完成全候选普查；应用一把显著 head graph 做 Louvain 社区划分并消融，应用二把各 head 的 coupling profile 汇总后做 RW-PCA，删除得到的二维子空间并与 activation PCA、rogue dimensions、随机子空间比较。
Card 06 核心结果与证据

核心结果与证据

  • 规模与成本：候选通道从 GPT-2 的 $6.3\times10^8$ 到 Pythia-6.9B 的 $1.3\times10^{11}$；fp32 单 RTX 5090 上构图分别约 15 秒与 11 分钟。70–89% head pairs 的方向耦合显著偏离 chance，但方向既可强耦合也可低于 chance。
  • 盲恢复：GPT-2 head graph 的强边形成跨层垂直社区，已知 induction、IOI name-mover 与 S-inhibition heads 集中在特定社区。六个模型的社区消融破坏 82–97.1% clean induction gain；随机/匹配控制远小。
  • 全局二维子空间：只删除 residual width 的两个方向，就在六个模型中消除 82–96% induction gain；Pythia-6.9B 删除 $2/4096=0.05\%$ 维度消除 89.5%，对比 activation PCA 84.5%、rogue dimensions 36.5%。随机二维删除接近零。
  • Figure 2 展示图结构发现；Table 3 提供六尺度干预，Tables 9–10 给跨模型复现和 GPT-2 社区 knockout 分解。证据包含权重全枚举、盲发现与因果干预，而不只相关性。
Card 07 为什么重要

为什么重要

这项工作把电路发现从少量手工假设提升为可枚举的全图搜索，并把几何候选与消融验证连接起来。二维 induction-critical subspace 说明能力可能集中于极低维通信带，同时也为权重级审计、跨模型比较和后续 feature-level mapping 提供可复现基础。

Card 08 有效性与局限

有效性与局限

  • communication map 只刻画 potential connectivity；输入依赖的 attention routing 不可见，强几何耦合不等于每个 prompt 都实际通信。
  • 功能验证集中于 in-context copying/induction，并偏重 head-to-head 结构；neuron wires 和其余社区尚未逐一赋予功能。
  • 模型最大为 Pythia-6.9B，尚未验证更大或架构显著不同的模型。节点是 heads/neurons 而非 sparse features；二维删除的非加性也提醒不能把子空间简单解释成两条独立电路。
