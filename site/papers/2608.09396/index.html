From Objectives to What Models Learn: A Landau Theory of Invariant Learning

Card 02 研究问题

研究问题

IRM、GroupDRO、CORAL、MMD、DANN 等都声称促进跨环境稳定特征，却沿正则强度产生完全不同的模式：有限阈值删除 shortcut、只渐近缩小、非单调反弹或直接崩溃。本文把 feature loading 当 magnetization、正则强度当控制参数，从具体 objective 展开 Landau 有效自由能，用低阶系数预测“模型会学什么”。

Card 03 模型与方法

模型与方法

  • canonical bilinear predictor 将每个稳定/shortcut feature 的端到端 loading 作为序参量 $q$，对内部因子做 variational reduction，得到 $F_{eff}(q;\lambda)$。
  • 在 $q=0$ 附近展开 quadratic mass、quartic stiffness 与更高阶项；不同 invariant objective 对这些系数的修正构成 objective signature。
  • $R_2$ 型修正移动二次项零点，可在有限 $\lambda_c$ 连续消除 mode；纯 $R_4$ 主要限制非零分支幅度，通常只在 $\lambda\to\infty$ 消失。
  • stable 与 shortcut 的环境支持不同，因此临界强度不同；若 $\lambda_c^{shortcut}<\lambda<\lambda_c^{stable}$，存在 selective-retention window。
  • 矩阵扩展把多个耦合 feature 作为向量序参量，phase boundary 由 effective quadratic matrix 的最小特征值穿零决定；实验覆盖 bilinear、1/2 hidden-layer ReLU 与耦合集体 mode。
Card 04 核心结果与证据

核心结果与证据

  • 表 1 给出表型分类：quadratic objective 有有限阈值 mode elimination；quartic objective 有渐近残留；higher-order/off-target 项控制大强度非单调、失稳和 collapse。
  • 图 2 的解析 onset 与训练测量最大绝对偏差仅 $4.7\times10^{-6}$，验证低阶 mass correction 精确移动 bilinear 模型相边界。
  • 图 3 不用拟合训练路径，仅把 objective 推出的低阶系数代入同一 Landau equilibrium，就能预测多方法在 mean-shift 与 correlation-heterogeneity probe 下的 shortcut loading；曲线为 5 模型均值±s.e.\(m\).。
  • 图 4 用 loading 线性外推恢复临界强度，$R_2+R_4$ 与 $R_2$ 共享 onset；MMD-mean、CORAL-full 和 matched IGA 跟随对应 effective-$R_2$ transition。
  • 图 5–7 显示 OOD AUC 只有在 shortcut 被压制且 stable mode 被保留时提高；ReLU 深度改变尺度和尾部但保留定性表型，耦合 matrix regularizer 可利用谱方向保留 compensatory collective mode。
Card 05 有效性与局限

有效性与局限

  • Landau 展开是局部、小 loading/临界附近理论；远离 onset 的高阶尾、爆炸与 collapse 只能定性分类。
  • selective window 需要 objective operator 与真实 stable/shortcut 方向对齐；错位的 quadratic 项会连稳定特征一起删除。
  • 受控环境和 bilinear/ReLU 实验中的 mode 可显式定义，真实高维数据往往不知道哪些 collective direction 稳定。
  • 有限样本会改变 operator alignment 和临界强度；附录审计该效应，但不提供通用无标签估计。
  • 框架预测 regularization path，不证明某个 invariant objective 在任意分布移位下有因果或 OOD 保证。
