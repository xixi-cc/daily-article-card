Towards Compositional Interpretability for XAI

迈向面向可解释人工智能的组合可解释性

作者信息

Card 02 研究问题

研究问题

  • XAI 方法常在局部 attribution、规则、因果或概念模型中使用不同语言。作者问：能否把模型视为可组合过程，并把 interpretability 定义为对部分变量、生成元与具体状态赋予人类可理解含义？
  • 目标不是给出一个新的 saliency algorithm，而是建立比较框架：什么使 linear/rule-based models 被称为 intrinsically interpretable，哪些 causal、DisCoCirc、conceptual 或量子/概率模型可推广为 compositionally interpretable。
Card 03 模型与方法

模型与方法

  • Compositional model 由 structure category S、semantic category \(C\) 与解释函子 [[-]]:\(S\to C\) 构成。S 的 objects 表示变量类型，morphisms/generators 表示基本过程；顺序组合与 tensor product 在 string diagram 中分别对应纵向连接与并排放置。
  • Interpretation 是从抽象变量/生成元和具体 semantic processes 到 human-friendly domain \(H\) 的部分映射。只画出网络计算图不够：若 nodes/edges 没有人类语义，图仍不解释模型。CI model 要有丰富且可重组的 interpreted components。
  • 作者逐类重写 decision trees、neural networks、Transformers、RNN、VAE、causal models、Bayesian networks、DisCoCat/DisCoCirc 与 quantum models，并讨论 diagram surgery、rewrite explanations、interventions 和 counterfactuals。
Card 04 核心结果与证据

核心结果与证据

  • 框架把“结构”和“实现”分开：同一抽象 diagram 可落到 deterministic、stochastic、neural 或 quantum semantics，也可比较不同实现保留哪些可解释构件。这是形式统一，不是经验性能定理。
  • Figure 3 展示 framework richness：普通 input-output evaluation、条件概率、do-intervention 与 functional causal counterfactual 对应不同可执行 diagrams。作者据此主张，interpretability 还取决于模型允许哪些有意义的 diagrammatic calculations。
  • 论文说明传统 linear/rule-based models 的透明性来自其基本 components 已有语义且组合方式可追踪；causal 与 DisCoCirc 等模型也可能满足更一般 CI。黑箱 neural components 可嵌入组合结构，但只有被解释的部分才贡献 CI。
Card 05 有效性与局限

有效性与局限

  • 这是定义、例子与研究纲领，未给出可计算的统一 interpretability score、用户实验或任务性能 benchmark。Category-theoretic representation 很广，能够表示模型不等于解释已经有用或忠实。
  • Interpretation mapping 由人指定且通常部分；不同受众、领域和抽象层可能给出不兼容含义。Human-friendly semantics、faithfulness 与 causal validity 需要外部证据，不能由 diagram syntax 自动保证。
  • 106 页包含大量背景和例子，主张层级需区分：一些是严格 categorical definitions，一些是示意性建模，另一些是关于 XAI 的规范性建议。本卡未独立形式验证。
