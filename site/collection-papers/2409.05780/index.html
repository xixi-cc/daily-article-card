Breaking Neural Network Scaling Laws with Modularity

用模块性突破神经网络缩放律

作者信息

  • Akhilan Boopathy、Sunshine Jiang、William Yue、Jaedong Hwang、Abhiram Iyer 与 Ila Fiete，来自 MIT。论文发表于 ICLR 2025，分析 task modularity 如何改变随输入维数增长的 sample complexity，并提出利用已知模块的训练规则。arXiv:2409.05780v2。
Card 02 研究问题

研究问题

  • 通用 monolithic network 在高维 smooth-function class 上的逼近/泛化常受 curse of dimensionality，样本随 intrinsic dimension 指数增长。若目标由 \(k\) 个只依赖低维 projections 的 modules 组成，模块网络是否能使复杂度依赖单模块维度而非总维数？
  • 实际训练还面临 module assignment/projection 未知。作者希望设计 learning rule，在已知或可学习模块结构下恢复理论优势，并测试 ID 与 OOD组合。
Card 03 模型与方法

模型与方法

  • 理论先用 random-feature/linearized network \(y\)(\(x\))=\(\phi\)(\(x\))W，依据 kernel eigenvalue decay 推导 train/test error 对 model parameters \(p\)、samples \(n\)、output \(d\) 与 input dimension \(m\) 的 dependence。对一般 high-dimensional task，谱衰减导致所需 \(n\) 对 \(m\) 指数增长。
  • Modular task写成多个低维 projection \(U_{j}\) \(x\) 的 component functions。若每个 module 用共享/独立小网络处理，对 \(k\) 增长的 sample complexity 可与总维数解耦。Learning rule交替利用 module-specific losses/gradients，使每个子网对齐一个 projection，而不是随机 initialization 后完全端到端竞争。
  • 实验含高维 sine-wave regression、nonlinear projection variant 与 Compositional CIFAR-10。Figure 4a 对每个维数绘达到指定 test error 所需 samples；蓝色方法、绿色随机 modular 与橙色 monolithic 跨架构/5 seeds比较。
Card 04 核心结果与证据

核心结果与证据

  • 理论模型预测 monolithic sample complexity 随 task dimension指数增长，而理想 modular architecture 只依赖每个 module 的低维 complexity，因而可对总维数近乎不敏感。这一结论要求真实 task分解与架构模块匹配。
  • Figure 4a 中 proposed learning rule 的 required samples 随 dimensions 增长明显慢于两种 baselines；Figure 4b 在固定训练样本下，Compositional CIFAR-10 的 component数增加时方法 accuracy保持更好。浅色为各架构，粗线为平均。
  • Random modular baseline 并未自动实现全部优势，说明模块结构与 specialization learning rule 都重要。论文所称“breaking scaling laws”是对 modular task family 的条件性结果，不是任意数据上超越经验 LLM scaling law。
Card 05 有效性与局限

有效性与局限

  • 任务必须具有可用 modular decomposition，且 module input dimension保持小；若 modules强耦合、共享隐变量或组合数本身爆炸，复杂度优势可能消失。Projection/assignment supervision会注入先验。
  • 理论基于 random-feature/linearized generalization model及特定 eigenvalue assumptions；深度 feature learning 与 optimization 可能偏离。样本复杂度定义依赖目标 error、noise与函数 smoothness。
  • Sine和拼接 CIFAR 是受控基准；真实 VQA/robotics 的模块边界、routing cost和 distribution shift更复杂。比较需匹配参数量、compute和 hyperparameter tuning。本卡未独立复现。
