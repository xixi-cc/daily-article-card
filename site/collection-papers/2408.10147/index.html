In-Context Learning with Representations: Contextual Generalization of Trained Transformers

基于表示的上下文学习：训练后 Transformer 的上下文泛化

Paper Collection · In-Context Learning · 原文

Tong Yang、Yu Huang、Yingbin Liang 与 Yuejie Chi，来自 CMU、UPenn 与 OSU。论文发表于 NeurIPS 2024，分析一层多头 softmax Transformer 如何在带噪 nonlinear regression prompts 中学习 basis representations 并实施 ridge regression。arXiv:2408.10147v2。

Card 01 作者信息

作者信息

  • Tong Yang、Yu Huang、Yingbin Liang 与 Yuejie Chi，来自 CMU、UPenn 与 OSU。论文发表于 NeurIPS 2024，分析一层多头 softmax Transformer 如何在带噪 nonlinear regression prompts 中学习 basis representations 并实施 ridge regression。arXiv:2408.10147v2。
Card 02 研究问题

研究问题

  • 已有 ICL 理论常假设 linear regression 或 prompt 中样本足以确定 task。本文问：当响应由 \(m\) 个未知 basis functions 的线性组合生成，而每个 prompt 只有 \(N\) 个带噪 examples、\(N\) 不足以直接确定 template 时，训练能否学到跨 prompts 共享的 representation？
  • Contextual generalization包含两层：对 prompt 内未标注 query generalize，以及对 pretraining 中未见的 task coefficient \(\lambda\) generalize。作者希望从 gradient descent dynamics 证明，而不只构造理想 weights。
Card 03 模型与方法

模型与方法

  • Task 输出 \(y_{k}=\lambda\)^\(T\)(\(f\)(\(v_{k}\))+\(\epsilon_{k}\))，\(\lambda\) 从 task distribution 采样，\(f\)(v) 是 \(m\)-dimensional basis representation，\(\epsilon\) 为 Gaussian noise。Prompt 拼接 \(N\) labeled examples 与 query positions。
  • 一层 \(H\)-head softmax attention 分别从 prompt \(E^{P}\) 和 query \(E^{Q}\) 形成 value/key/query，再经 output matrix预测所有 query labels。Figure 1 展示矩阵流。训练对 many prompts 的 population/empirical squared loss 做 gradient descent。
  • 在 basis covariance、task distribution、initialization、head 数和 sample size 条件下，作者建立 PL-like geometry/concentration，证明 loss 线性收敛到 global minimum；learned predictor 等价于在 \(f\)-space 中执行 ridge regression。
Card 04 核心结果与证据

核心结果与证据

  • Theorem 1/2 给出一层多头 Transformer 的训练收敛与 prediction characterization：模型并非仅复制 labels，而是通过预训练 heads 学到共享 basis representation，再用 prompt进行正则化回归。误差取决于 \(N\)、\(m\)、噪声 \(\tau\) 与 conditioning。
  • Figure 2 的一层和四层实验显示 training/inference losses下降，并在 unseen examples 与 unseen tasks 上泛化；Figure 3 中 \(N\) 接近 \(m\) 时与 best ridge predictor 的 gap 改善，符合理论 scaling。
  • Figure 4 显示一层模型需要足够 \(H\) 保证理论/经验收敛，但 \(H\) 过大在固定设置下出现 instability 或更慢；四层实验表明深度可改变 head-width requirement，因此一层定理不能直接外推到深网络。
Card 05 有效性与局限

有效性与局限

  • Task family 已知落在固定 \(m\)-dimensional linear span，\(\lambda\)、noise 与 input distribution 满足强结构；自然语言 representations 非独立、basis 未知且任务不必线性。Ridge-regression 等价是该生成模型下的结果。
  • 证明针对一层、特定 softmax parameterization、初始化与 overparameterized heads；宽度/sample lower bounds 可能保守。Population convergence 与有限训练数据之间靠 concentration，超出假设时无保证。
  • 四层结果只是数值 extension，不构成深 Transformer theory。Unseen tasks来自同一 \(\lambda\) distribution，不代表语义上开放域 task transfer。本卡未独立复现。
