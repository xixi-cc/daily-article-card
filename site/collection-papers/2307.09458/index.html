Does Circuit Analysis Interpretability Scale? Evidence from Multiple Choice Capabilities in Chinchilla

电路分析式可解释性能扩展吗？来自 Chinchilla 多项选择能力的证据

Card 01 作者信息

作者信息

  • 作者为 Tom Lieberum、Matthew Rahtz、János Kramár、Neel Nanda、Geoffrey Irving、Rohin Shah 与 Vladimir Mikulik（Google DeepMind）。arXiv:2307.09458v3。论文在 70B Chinchilla 上分析 MMLU 答案内容到 A/B/\(C\)/\(D\) 标签的末端电路。
Card 02 研究问题

研究问题

  • 既有 mechanistic interpretability 电路案例多在小模型。作者问 logit attribution、attention visualization 与 activation patching 是否能在 70B 模型上识别功能节点，以及识别出的 head 特征能否预测更广输入分布上的行为。
  • 范围刻意限制在多项选择的算法步骤：模型已知道正确答案内容后，如何选出对应标签并输出。论文没有解释知识检索、完整 MMLU 推理或 Chinchilla 的一般内部机制。
Card 03 模型与方法

模型与方法

  • Chinchilla 70B 有 80 层、每层 64 个 attention heads。固定最终 RMS 时，各 MLP/head 输出经 unembedding 线性贡献 logits，可一次前向计算直接 attribution。作者在 6 个模型表现较好的 MMLU 主题、每次 128 prompts 上排序净正直接效应。
  • 对候选节点做 resampling activation patching：从答案不同的干预 prompt 取激活注入原 prompt，以正确标签 logit/loss 变化估计总效应；edge patching 用替换目标节点输入中的上游分量估计直接路径。
  • 对 correct-letter heads 进一步检查 attention pattern，以 SVD 压缩 query/key/value 到低维子空间，并构造标签顺序、随机字母等变体，检验“Nth item in an enumeration”解释能否分布外预测。
Card 04 核心结果与证据

核心结果与证据

  • 45 个节点（32 heads、13 MLPs）覆盖所有节点正直接效应和的约 80%；联合 patch 这些节点可恢复接近完整模型的标签输出表现，说明现有工具在这一末端算法上能扩展到 70B。
  • Figure 1 概括 correct-letter heads：query 同时编码“这是标签 token”与正确答案是枚举中的第 \(N\) 项，attention 指向相应 A/B/\(C\)/\(D\)，value 再把该字母写入 logits。若只在普通 MMLU 标签分布上操作，\(Q\)/\(K\)/V 可显著降到三维而不损失该标签行为。
  • 但低维语义解释在随机标签或更广 prompt 分布上只部分成立；head 操作比示意图更杂乱。直接效应和总效应也不完全一致，例如某些上游 head 直接贡献小却通过 correct-letter heads 有大总效应。
Card 05 有效性与局限

有效性与局限

  • activation patching 会把两个 prompt 的内部状态拼接，可能离开自然激活流形；下游备份/补偿可隐藏节点效应。de-noising 评分容易找到一组切断祖先与后代的横截面，而不是完整电路。
  • 直接 logit attribution 固定最终 RMS，末层大扰动时近似可能失效；45 节点的 80% 是“正直接效应之和”的覆盖，不是 80% 全模型因果计算。研究只选 6 个高表现 MMLU 主题，且 Chinchilla 权重/运行环境并非普遍可复现。
  • 低维 SVD 在基准分布保性能不表示得到了唯一语义基；随机标签测试暴露了剩余特征。论文的积极结论主要是工具能运行并定位末端节点，语义外推则是混合证据。
Card 06 复现与资源

复现与资源

  • 原文：https://arxiv.org/abs/2307.09458。官方 PDF SHA-256：aa45497f8dacf7225d462a43d2ca9dbb521adf3b2935543630e37c33dabeb36c。Appendices 给出额外 patching、子空间和 prompt 变体结果。
  • 复现需要相同 Chinchilla 70B checkpoint/tokenizer、6 个主题与 prompt 采样、RMS 处理、ABCD 净 logit 定义、干预配对和 SVD 数据。建议同时测试 zero/mean/resample ablation、更多主题和随机标签，并预注册节点选择阈值。Evidence status: full-text verified; no independent reproduction performed.
