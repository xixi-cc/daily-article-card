Card 02 研究问题

研究问题

  • 在 federated/cooperative learning 中，各网络只看私有、异质数据，却通过参数交换改善整体泛化。论文问：这种从局部专长到全类别能力的转变能否视为真正的集体相变？网络深度和耦合强度如何移动相边界？
  • 作者构建‘本地梯度下降 + 网络间扩散耦合’的最小模型，先对深线性网络做 mean-field coarse graining，再用各自只训练一个 MNIST digit 的非线性网络验证。
Card 03 模型与方法

模型与方法

  • 第 i 个网络以自己的 Di 最小化 local loss，同时每个参数接受 ησ/\(N\) Σj qij(θj−θi) 的 diffusive coupling。全局 test loss/accuracy 衡量集体性能，cross-accuracy matrix 记录网络 i 对私有域 j 的迁移。
  • 理论把每层参数矩阵压缩为平均标量，并定义 local magnetization mi 为跨层平均参数；在小学习率、MSE、一维投影、正交/whitened input 和 mean-field all-to-all coupling 下，得到含 quenched disorder δi= 的有效动力学。\(D=1\) 时等价于带乘性无序的零温 Ginzburg–Landau φ4 模型，\(D\)>1 变为 \(\phi\)^(2D+2) 型变形。
  • 数值理论用 \(N=200\) 和 disorder realizations；实验用 \(N=10\) 个全连接 ReLU 网络，每个只训练一个 MNIST 类别，改变隐藏深度 \(D\) 与 coupling \(\sigma\)，并比较重新初始化和 adiabatic protocol。文末无显式 References 标题，但 PDF pp. 5–6 与 MinerU Markdown 均保留 [1]–[59] 参考文献，已人工核对。
Card 04 核心结果与证据

核心结果与证据

  • 有效理论预测 \(D\)>0 时随耦合增大出现 disorder–order–disorder：中等 \(\sigma\) 打破对称并形成 collective phase，过强 \(\sigma\) 又因集体 regularization/扩散主导而失序。网络越深，集体学习临界点越晚，\(D\)>1 还出现多稳态和初始条件依赖。
  • 理论进一步预测 cumulative cross-accuracy 的学习路径近似 rank one，主要由 disorder vector \(\delta\) 控制：输入—输出相关更强的数据先被其他 units 学会。Figure 2 展示 order parameter、effective loss 和 cross-domain 排名的相区结构。
  • MNIST Figure 3 中平均 accuracy 从约 0.1 的局部 phase 上升到接近 1 的 collective phase；depth-dependent delay、非单调 loss 和 \(D=2\) 的 adiabatic/non-adiabatic 差异与理论定性一致。cross-accuracy matrix 的 leading-rank approximation 也保持较高相关。
Card 05 有效性与局限

有效性与局限

  • 从高维非线性网络到一个 mi 的压缩使用强 mean-field 假设；δi 把整个私有数据域约化为单一相关标量，无法描述类别几何、feature learning 和 optimizer noise。实验支持若干定性预测，不等于从原始网络严格导出了普适有效理论。
  • 验证只用 MNIST、全连接等宽网络、10 个单类 clients、all-to-all 静态等权 coupling 和 vanilla SGD。现实 federated 系统的稀疏/有向/时变拓扑、不同架构、通信压缩和非 IID 程度可能改变相图。
  • accuracy 接近 1 的 collective phase 是这一人为 partition 与训练规则的结果；不能直接外推为隐私保证、通信效率或社会群体‘对齐’。过强 coupling 可能 regularize 或数值发散，文章脚注也明确此边界。
