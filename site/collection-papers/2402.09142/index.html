When Representations Align: Universality in Representation Learning Dynamics

Card 01 作者信息

作者信息

  • 作者 Loek van Rossem 与 Andrew \(M\). Saxe，来自 University College London Gatsby Computational Neuroscience Unit。工作尝试跨 architecture 抽取 representation learning 的 effective dynamics。arXiv:2402.09142v2。
Card 02 研究问题

研究问题

  • 不同深度、连接方式和 activation 的网络常学到定性相似的 representational geometry。若 encoder \(h_{\mathrm{phi}}\) 与 decoder \(y_{\mathrm{psi}}\) 只假定为足够光滑、表达能力不受参数化强约束，gradient descent 是否诱导一个与 architecture details 无关的低维有效理论？
  • 作者先问两数据点之间的 hidden distance、predicted-output distance 与 output alignment 如何共同演化，再测试它能否解释 rich/lazy regimes、XOR 与正交 feature tasks。
Card 03 模型与方法

模型与方法

  • 模型把网络拆为 arbitrary smooth encoder \(h_{\mathrm{phi}}\):\(x\to h\) 与 decoder \(y_{\mathrm{psi}}\):\(h\to y\)，以 squared loss 训练。围绕两输入中点做局部线性化，把参数更新投影到 effective Jacobians \(D_{h}\) 与 \(D_{y}\)。
  • 两点问题闭合为三个变量：||dh||^2 是 hidden representational distance，||dy||^2 是 prediction difference，w 衡量 predicted difference 与 target difference 的 alignment/error coupling；architecture 被压缩为有效时间尺度 \(tau_{h}\)、\(tau_{y}\)。Figure 1 给出 \(X\to H\to Y\) 的几何。
  • 理论曲线只拟合两个 effective rates，然后与不同 connectivity、depth、width、ReLU/leaky-ReLU/tanh 等网络比较；还测试 MNIST 0/1 点对、XOR 多点结构和 orthogonal features，并扫描 initialization scale。
Card 04 核心结果与证据

核心结果与证据

  • Figure 2 中，多种 architecture 的三变量 trajectory 在拟合 \(tau_{h}\)、\(tau_{y}\) 后与同一有效方程定性/定量接近，支持某些 feature-learning dynamics 可在参数化细节上普适。
  • 小 initialization 进入 expressive/rich regime，hidden distances 按 input 与 target geometry 形成结构；大 initialization 更接近 lazy regime，representation 变化弱。理论给出的 final two-point distance 能预测多组 input/output separations。
  • XOR 中足够深的网络 pairwise distances 接近有效理论，但两层网络在小 weights 下偏离，说明‘足够 flexible’是实质条件。多点扩展和 MNIST 案例提供有限支持，作者明确不把当前两点闭式理论称为完整 universal model。
Card 05 有效性与局限

有效性与局限

  • 推导以两点局部线性化和各向同性/自由参数变化近似为核心；architecture-specific inductive biases 被吸收到两个 rates 或直接忽略。理论无法预测这些 rates，而是从 trajectory 拟合。
  • 对更大 datasets 没有清晰可扩展闭式路径；XOR/orthogonal-feature tests 仍很小。深度不足、bottleneck、convolutional locality、attention、normalization 和 optimizer details 都可能破坏 universality。
  • Representation alignment 用 pairwise Euclidean geometry 衡量，不能覆盖 topology、class-conditional manifolds 或 causal features。与 brain representations 的潜在联系仅属动机；本卡未独立复现实验。

复现与资源
