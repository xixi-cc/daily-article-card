How does GPT-2 compute greater-than?: Interpreting mathematical abilities in a pre-trained language model

GPT-2 如何计算大于关系？预训练语言模型数学能力的机制解释

Card 01 作者信息

作者信息

  • 作者：Michael Hanna、Ollie Liu、Alexandre Variengien。arXiv:2305.00586v5。论文以 GPT-2 Small 的年份补全为案例，用 path patching 从行为现象追踪到 attention heads、MLPs 与神经元级机制。
Card 02 研究问题

研究问题

  • GPT-2 Small 面对“The war lasted from 1732 to 17”时，会偏向输出大于 32 的两位年份。作者问：这种有限的 greater-than 行为由哪些内部路径实现，各组件如何把起始年份信息变成输出 logits？
  • 研究对象不是一般算术能力。任务使用固定自然语言模板、特定 BPE 可编码年份与 GPT-2 Small；模型输出还明显受真实世界事件持续时间和训练语料统计影响。
Card 03 模型与方法

模型与方法

  • 数据由 120 个可持续名词、世纪 XX 与两位起始年份 YY 组合而成，并排除无法按预期 tokenization 的年份。核心指标是大于 YY 的候选年份总概率减去不大于 YY 的总概率；另用 YY+1 与 YY−1 的概率差衡量 cutoff sharpness。
  • path patching 将指定组件—路径上的 activation 替换为配对的“01-dataset”值，同时保持其他路径正常，由性能变化定位因果相关边。迭代过程先找直接影响 logits 的组件，再沿 MLP 与 attention 输入向上游追踪。
  • 最终候选回路包含 MLPs 8–11、若干中后层 attention heads 及上游年份表征路径。作者用大规模 ablation 验证回路 sufficiency/faithfulness，并用 logit lens 和神经元分析解释 late MLPs 如何提升大于输入年份的 token logits。
Card 04 核心结果与证据

核心结果与证据

  • 在 10,000 个模板样本上，完整 GPT-2 Small 的 probability difference 为 81.7%（SD 19.3%），cutoff sharpness 为 6.0%（SD 7.2%）。概率热图显示 YY 附近的清晰下三角边界，但高概率通常只延伸到起始年份后的约 15–20 年。
  • Figure 5 汇总候选回路及 patching 验证：late MLPs 8–11 是输出端主要贡献者，attention heads 把 YY token 信息送入这些 MLPs；保留候选路径、腐化其余输入后仍复现 greater-than 型概率热图。附录扩展的完整回路达到 71.5% probability difference，约为主回路结果的 98.3%，cutoff sharpness 为 10.5%。
  • 神经元级分析发现 MLP 10 的一组神经元对数字 token 产生近似阈值式 logit 贡献；其他上下文任务也会激活同一回路。不过该机制在某些不需要 greater-than 的随机序列中仍偏向递增，说明“跨上下文激活”既是复用证据也是系统性错误。
Card 05 有效性与局限

有效性与局限

  • path patching 给出相对于指定腐化输入和路径集合的因果干预证据，但不保证回路最小、唯一或完整。01-dataset 可能产生特殊分布差异；阈值、路径粒度和对 query/key/value 的处理都会改变结果。
  • 结论局限于 124M 参数 GPT-2 Small、合成模板和简单二位数比较。模型的 cutoff 并非精确数学函数，且上下文泛化与训练语料记忆无法由这些实验完全区分；更大模型、更多措辞和真正算术任务需要独立验证。
