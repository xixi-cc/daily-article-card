背景

Card 04 模型与方法

模型与方法

  • Sections II–IV 以 polar/nematic hydrodynamics、spontaneous-flow instability、active length scale 与 defect quasiparticles 组织 active turbulence 和 flow control。
  • +1/2 nematic defect 因 comet-like texture 可 self-propel，−1/2 的三重对称令孤立 core velocity 消失；defect interaction、creation/annihilation 与 texture relaxation 共同决定 active defect gas。
  • Sections V–VII 从 self-phoretic assembly、nonreciprocal coupling 和 chirality 出发；不满足 action–reaction 的 effective interactions 可导致 traveling/oscillating states、odd elasticity 与 non-Hermitian/PT-like structures。
  • Section VIII 比较 FDT violation、thermodynamic uncertainty relations 与 trajectory time-reversal relative entropy；Eq. (7) 给 \(Qdot_{\mathrm{diss}}\ge kBT\) Ddotτ 的 coarse-observation lower bound。
  • Section IX 将 phase-field/Vertex/Voronoi 等 mesoscopic tissue models 与 molecular signaling、active stress、mechanics连接，目标是把 continuum coefficients 绑定到可控实验量。
  • 全文主要综合已发表理论和实验并列开放问题，不进行 meta-analysis、统一仿真或新数据拟合。
Card 05 核心结果与证据

核心结果与证据

  • Figure 2 展示 ±1/2 defect texture/flow：activity 可使 +1/2 对抗 Coulomb attraction并 unbind，但完整 creation–annihilation rate 与 many-body orientation dynamics 仍未解决。
  • 生物案例包括 epithelial extrusion/apoptosis、bacterial multilayering 和 Hydra morphogenesis；相关性与局部 stress evidence 有启发性，但文章反复把时间先后与因果机制列作待检验问题。
  • Figure 3 所引实验用 passive LC interface/磁场对 active nematic alignment；另一路以 geometry、curvature、optogenetic activity patterning 驯化流和引导 defects。
  • nonreciprocal binary/polar models 可产生 dynamical chiral phases、traveling patterns 或 arrested phase separation；这些是各引用模型的结果，不是所有 active mixtures 的必然行为。
  • Figure 7 的 starfish embryos 构成 living chiral crystals 并 collective rotate；hydrodynamic force/torque exchange 展现 chirality 与 nonreciprocity 的宏观后果。
  • Figure 8 的 irreversibility-versus-lag peak 用时间序列正反可辨识性定位 nonequilibrium timescale；Eq. (7) 只给耗散下界，有限观察变量可能漏掉 hidden entropy production。
Card 06 有效性与局限

有效性与局限

  • 这是 2020 讨论形成、2021 定稿的 biased selection；快速发展的 active matter 文献和后来实验可能改变当时的 open-question 状态。
  • active turbulence 与 high-Reynolds-number turbulence 的类比尚无统一 universality classification；能谱、vortex size 和 defect statistics 对模型、friction、incompressibility/geometry敏感。
  • defect-centric reduction 可能在 nematic texture 滞后时失效；polarization 不是独立自由度，不能只推进点 defects 而忽略 background field。
  • frequency-dependent effective temperature \(T\)(\(\omega\)) 可为负，且没有一般原则从它反演 microscopic mechanism；FDT violation 是活动信号，不是完整机理鉴定。
  • trajectory irreversibility 对 nearly any NESS 可用，但取决于 sampling interval 和 observed variables；它不能自动等于总能耗。
  • nonreciprocity、odd elasticity、non-Hermiticity 和 biological function 的桥梁多为结构类比或特定模型/实验，不能视为已建立的一一对应。
  • tissue continuum theory 的核心难点仍是把 coefficients 映射到 signaling 与 cell-scale mechanics；文章提出成功标准而非已完成映射。
