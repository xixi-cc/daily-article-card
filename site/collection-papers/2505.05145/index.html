Understanding In-context Learning of Addition via Activation Subspaces

通过激活子空间理解加法的上下文学习

Paper Collection · Transformer Theory · 原文

Card 01 作者信息

作者信息

  • 作者为 Xinyan Hu、Kayo Yin、Michael I. Jordan、Jacob Steinhardt 与 Lijie Chen；PDF 首页列出 UC Berkeley 和 INRIA。所核对版本为 arXiv:2505.05145v3，主分类 cs.LG。论文是一项针对预训练 LLM 的机制可解释性个案研究，重点是 add-\(k\) 上下文学习，而非提出一个适用于所有 ICL 任务的完备模型。
Card 02 研究问题

研究问题

  • 少样本 ICL 必须从示例对中提取任务规则、聚合该规则并作用于新查询；已有 function-vector 工作能显示这种向量可恢复行为，却较少说明它在大模型一次前向传播中的细粒度表示。论文以 $y=x+k$ 的 add-\(k\) 任务追问：任务信息存在哪些 attention heads、以什么低维坐标表示、又从哪类 token 汇集到最后输出？
  • 这种任务族使不同 prompt 的输入域相同，只有隐藏常数 $k$ 改变，因而比 product-company 一类示例更能排除“仅凭查询域猜答案”的捷径。它仍是算术合成任务：解释结果不能直接当作自然语言 ICL 的一般机制。
Card 03 背景

背景

  • 本文把 transformer 的 residual stream 视为信息载体，把 head 输出、attention 权重和 token 位置作为可干预变量。物理式的变量映射是：任务常数 $k$ 是被编码的信号，head activation 的 PCA 子空间是状态表示，activation patching/mean ablation 是局部干预，intervention accuracy 是可观测输出；这些只是计算机制分析，不意味着网络存在热力学子空间或守恒律。
  • 主模型 Llama-3-8B-instruct 有 32 层、每层 32 个 head、residual dimension 为 4096。作者也报告 Llama-3.2-3B-instruct、Llama-3.2-3B 与 Qwen-2.5-7B 的附录结果；正文的定量因果链主要来自 Llama-3-8B-instruct（\(p\). 3）。
Card 04 模型与方法

模型与方法

  • 五示例 prompt 的每个 demonstration 为 $x_i\to y_i$，满足 $y_i=x_i+k$；取 $x\in[1,100]$、$k\in[1,30]$。作者对每个 head 的 task-specific 平均输出构造 function vector，把它加到零示例 prompt 的 residual stream，并以输出正确率检验该向量是否携带 $k$（pp. 3--4）。
  • 为从 1024 个 heads 中定位机制，定义加权向量 $v_k(c)=\sum_hc_hh_k$，最小化交叉熵加 $\ell_1$ 稀疏项。25 个任务用于训练/域内测试，5 个任务留作 OOD；AdamW 使用 learning rate 0.01、batch 128、$\lambda=0.05$。随后用 mean ablation、单 head 缩放、PCA、周期函数拟合和子空间投影逐层缩小解释对象（pp. 4--7）。
  • 最后，作者把末 token 的投影 head 输出展开为此前 token residual streams 的 attention 加权和，再比较每个示例的 extraction signal。该代数分解把“最后位置的聚合表示”与标签 token 位置的候选信息源联系起来（\(p\). 8）。
Card 05 核心结果与证据

核心结果与证据

  • Figure 1（\(p\). 2）概括主链条：1024 个 attention heads 中仅三个 $(15,2)$、$(15,1)$、$(13,6)$ 对 add-\(k\) 的 task signal 关键；每个 head 的 128 维激活可局域到 6 维，再分成 4 维 unit-digit 与 2 维 tens/magnitude 子空间。图是作者对 Llama-3-8B-instruct 的机制示意，具体可检验的效果须由随后 ablation 与 intervention 数据支持。
  • 稀疏优化得到 33 个 significant heads；其无权重和在同样设置下 intervention accuracy 为 0.85，而按先前 AIE 规则取 top 33 只有 0.31（\(p\). 5）。对 33 个 head 的 mean-ablation 再定位为三主 head：三者合成函数向量的 accuracy 为 0.79、两者 0.61、单 head 0.21；在原 five-shot prompt 中 mean-ablate 三者，clean accuracy 从 0.87 降至 0.43，而随机三 significant heads 大多保持至少 0.86（\(p\). 6）。这是特定干预协议下的必要性/充分性证据。
  • 每个主 head 的 6 个 PCA 方向解释 30 个 task vector 变异的 97%，投影后的函数向量 accuracy 仍为 0.76，对比投影前 0.79（\(p\). 7）。四个周期方向对应 periods 2、5、10，另两个低频方向编码较粗粒度数值；子空间投影的保留/移除实验用于检验 units 与 tens 信息。对 mixed-\(k\) prompt，信号在 $y_i$ token 最强，并且不同示例的信号多为负相关，作者将此解释为后示例倾向修正早示例噪声的 self-correction（pp. 8--9）。
Card 06 有效性与局限

有效性与局限

  • 机制结论受限于加常数、整数范围 $x\in[1,100]$ 与 $k\in[1,30]$、五示例格式和 selected Llama/Qwen 模型；add-\(k\) 特意消除了领域捷径，却也牺牲了自然任务的语义复杂性。79%、0.85 或 0.43 都是所定义 activation intervention 的准确率，不能与正常对话、任意 prompt 或模型总体能力等同。
  • 三 head、六维与周期分解来自稀疏优化、mean-ablation、PCA 和对坐标函数的拟合。前几步自动化较强，但作者在 Discussion 中承认 mean-ablation 有定性判断，最终子空间的定性检查也仍可受分析选择影响（\(p\). 10）。负相关支持“self-correction”解释，但没有单独证明一个普适的纠错算法。

阅读指南
