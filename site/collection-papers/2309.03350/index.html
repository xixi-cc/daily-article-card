Relay Diffusion: Unifying diffusion process across resolutions for image synthesis

Card 02 研究问题

研究问题

  • 相同像素噪声方差并不对应相同的物理破坏尺度：把分辨率从 64×64 提高到 256×256 后，低频信号的 SNR 更高，常用 schedule 在早期不能充分抹除大尺度结构。论文据此追问如何把低分辨率扩散的末态变成高分辨率扩散的等价中间态，而不重新从白噪声开始。
  • 核心不是把低分辨率图作为额外 condition，而是匹配两个分辨率在频率空间中的随机场统计，使生成轨迹跨模型和分辨率“接力”。
Card 03 背景

背景

  • 级联扩散先生成低分辨率图，再由 super-resolution 模型恢复细节。它节省高分辨率早期步骤，却引入条件分布错配：训练时条件通常是真实低分辨率图，推断时却来自上一级生成器。
  • blurring diffusion 将热方程耗散与高斯噪声结合。在 Neumann 边界下，二维热核可由 DCT 对角化，低频模式衰减慢、高频模式衰减快；这给跨分辨率噪声匹配提供了明确的谱语言。
Card 04 模型与方法

模型与方法

  • 在 DCT 坐标 \(u\) 中，模糊前向核写为
  • \[q(u_t\mid u_0)=\mathcal N\!\left(u_t\mid D_tu_0,\sigma_t^2 I\right),\qquad D_t=e^{\Lambda t}.\]
  • 分辨率放大 s 倍后，作者用相关长度约为 s 的 block noise 替代逐像素独立噪声。它由 s×s 独立高斯变量的局域平均构造，因此增强低频噪声，令高分辨率随机场的频谱更接近上采样后的低分辨率噪声。
  • RDM 的高分辨率阶段从“上采样低分辨率样本 + block noise”起步，再以 patch-wise blurring diffusion 逐渐转向独立高频噪声并去噪。训练目标沿用 EDM denoiser，但输入混合了模糊图、独立噪声和 block noise。
Card 05 核心结果与证据

核心结果与证据

  • Figure 2 直接比较 64×64 独立高斯噪声、256×256 同方差独立噪声和 256×256 block noise。中列的低频 SNR 整体抬高；右列 block noise 把谱形拉回低分辨率基准，这是方法的主要物理证据。
  • Figure 3 展示两阶段接力：64×64 模型生成到中间状态后，上采样并加入 block noise，把随机态交给 256×256 patch-wise blurring 模型；高频细节在第二阶段恢复，低频内容不必从头再生。
  • CelebA-HQ 256×256 上，RDM 报告 FID 3.15、precision 0.77、recall 0.55。ImageNet 256×256 上，无 guidance 的 FID/sFID 为 5.27/4.39；加入 CFG 与 class balance 后为 1.87/3.97。后者包含 guidance 和调参，不能与无 guidance 行直接混为单一算法效应。
  • block-noise 消融在训练充分后优于无 block noise 的版本；随机采样强度 \(\eta\) 在两个数据集上均存在中间最优值，说明 relay 的谱匹配仍与采样器离散化耦合。
Card 06 有效性与局限

有效性与局限

  • 作者的谱论证解释了为何同一像素噪声在高分辨率下留下更多低频信号，但它基于自然图像 PSD、DCT 和特定上采样结构，不是对任意数据流形或边界条件的普适定理。
  • 主要比较是 CelebA-HQ 与 ImageNet 256×256 的 FID/sFID/IS/precision/recall；这些分布指标不直接测量语义一致性、文本条件可控性或单样本失真。ImageNet 指标用 50k 样本、CelebA-HQ 用 30k 样本。
  • 作者明确报告尝试直接从数据推导最优 noise schedule 未成功，并推测 schedule 还依赖模型容量、inductive bias 与数据分布细节。因此“分辨率决定 schedule”只是部分状态描述。
  • 该卡核对了公式、图和表；no independent reproduction performed，未重新训练 RDM、复算 FID 或验证公开 checkpoint。
