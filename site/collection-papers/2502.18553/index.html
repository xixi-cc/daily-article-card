Applications of Statistical Field Theory in Deep Learning

统计场论在深度学习中的应用

Deep learning algorithms have made incredible strides in the past decade, yet due to their complexity, the science of deep learning remains in its early stages. Being an experimentally driven field, it is natural to seek a theory of deep learning within the physics paradigm. As deep learning is largely about learning functions and distributions over functions, statistical field theory, a rich and versatile toolbox for tackling complex distributions over functions (fields) is an obvious choice of formalism. Research efforts carried out in the past few years have demonstrated the ability of field theory to provide useful insights on generalization, implicit bias, and feature learning effects. Here we provide a pedagogical review of this emerging line of research.

Card 02 摘要

摘要

  • 核心视角是把网络输出 \(f\)(\(x\)) 当作定义在数据空间上的 field，把随机初始化、Bayesian posterior、数据集抽样和训练轨迹转写为 functional probability measure。
  • 无限宽 standard scaling 给 Gaussian field：Bayesian 预测映射 NNGP kernel regression，gradient-flow dynamics 映射 NTK；场论工具再处理 data averaging、spectral bias 与 scaling laws。
  • 有限宽使 kernel 本身成为 fluctuating/adaptive field；作者综述 perturbation、kernel scaling 与 kernel adaptation 三种近似，并用 MSRDJ generating functional 连接动态 NTK 与平衡 NNGP。
Card 03 背景

背景

  • 深度学习理论的目标不是逐个解析训练实例，而是像统计物理一样寻找 ensemble average、universality、order parameters 与 asymptotic limits；作者同时警告理论方程若比训练本身更难数值求解就失去解释价值。
  • 预备章系统建立 Gaussian integrals、operator algebra、symmetry/eigenfunctions、path integrals、saddle point、Feynman diagrams、Wilsonian RG 与 replica trick 的最低使用接口。
  • 数据空间 measure dμ(\(x\)) 很关键：kernel eigenvalues/eigenfunctions、target coefficients 与 degeneracy 共同决定可学习性；只看架构 kernel 而忽略数据分布会误判 spectral bias。
Card 04 模型与方法

模型与方法

  • 无限宽 Bayesian network 的 prior over \(f\) 是 NNGP Gaussian process；平方损失和 Gaussian weight prior/noise 下 posterior mean 等价 GPR。无限宽 gradient descent 的线性化则由 NTK 控制。
  • 对随机 dataset 做 replica averaging，得到 replica-coupled field action；Equivalent Kernel、effective ridge 和 RG approximation 以不同方式处理有限 P 引入的 fluctuations 与不可学习 modes。
  • 对有限宽 Bayesian network，逐层积分权重产生 multilayer action；1/\(N\) perturbation 描述弱 feature learning，kernel-scaling 用单个/逐层尺度 order parameter，kernel-adaptation 直接求 data-dependent kernels。
  • mean-field scaling 通过随宽度缩放输出、prior/weight decay 与 Langevin noise，使 kernel adaptation 在 \(N\)、P 同增时保持 \(\mathrm{O}(1)\)；standard scaling 与 mean-field scaling对应不同极限。
  • MSRDJ 把 Langevin training 的 delta-functional dynamics、response fields 和 noise average 写成路径积分；无限宽 saddle point 恢复 time-dependent NTK，长时平衡恢复 NNGP posterior mean。
Card 05 核心结果与证据

核心结果与证据

  • Section 2.5 用 symmetry irreducible representations 组织 kernel spectrum：相同 irrep 内 degeneracy 加大所需样本，解释 FCN 与局部 CNN 对高维数据的不同 spectral bias。
  • Section 2.6 假设 kernel/target spectrum 呈 power law，推出 MSE learning-curve exponent 由 data exponent 控制；Figure 2.1 的 4 个二分类 CIFAR/MNIST 10k 子集上，effective-ridge 与 RG curves 匹配 GPR dots，而 EK 在展示区间不适用。
  • Figure 3.1 的单隐层线性 single-index 实验中 kernel-scaling prediction 比 bare NNGP 更贴合 learnability/MSE；每点约 30 个不同 data seeds，但这是专门可解 teacher setting。
  • kernel-scaling 在强 feature learning 会破裂：对 Gaussian data 的高阶 target，finite network 可改变 kernel symmetry/eigenstructure，而只有总尺度 \(Q\) 的模型仍保持 rotational invariance。
  • kernel-adaptation 的线性 CNN 示例预测 sample complexity 从 lazy/GP 的 P∝\(d\) 改为约 P∝\(d\)^(3/4)，Figure 3.2 与实验一致；结论依特定 S、\(N\)、\(C\) 共缩放和 single-index construction。
  • 动态章节主要是推导性一致性检查：MSRDJ 在 infinite-width limit 恢复 NTK dynamics，equilibrium 恢复 NNGP mean；并没有覆盖现实非平衡大模型的端到端预测。
Card 06 有效性与局限

有效性与局限

  • 综述明确称统一理论仍是未来目标，且因篇幅与知识边界省略 NTK hierarchy、neural-network field theory、one-step SGD、窄网络 order parameters 与 distributional dynamics 等路线。
  • GP/NTK 极限缺少 feature learning，常弱于 finite networks；1/\(N\) perturbation 要求 correction 小，P 随 \(N\) 增长时可能出界，不能无条件外推到 mean-field regime。
  • replica trick 涉及整数 replicas 到 \(n\to 0\) 的 analytic continuation；saddle、replica symmetry 与 truncation 都需按具体问题验证，不是自动严格。
  • scaling-law 推导依 kernel/target power-law spectrum，且作者承认 GPR approach 尚不能捕捉经验上 αN 与 αP 的差异；因此是定性机制而非完整 foundation-model scaling law。
  • 多数 feature-learning 检验是线性/单指标/Gaussian 或小型 CIFAR/MNIST 任务；对 transformers、cross entropy、SGD noise、data augmentation 和深层非线性网络的定量有效域未建立。
