Card 02 研究问题

研究问题

  • 二维对称简单排斥过程（SSEP）中，初始时半径 $R$ 圆盘内外分别是 Bernoulli 密度 $\rho_1,\rho_2$，圆周只是被动计数边界，粒子可反复双向穿越。本文精确求有限宏观时间内圆盘粒子数净减少的 annealed 大偏差统计，处理弯曲有限计数区域而非熟知的一维单阶跃电流。
Card 03 模型与方法

模型与方法

  • 在扩散标度 $r=x/\sqrt T$、$r_0=R/\sqrt T$ 下，净流 $Q_T$ 按 $T^{d/2}q$ 缩放；目标是二维 scaled cumulant generating function（SCGF）及 Legendre 变换得到的 rate function。
  • Macroscopic fluctuation theory 用密度 $\rho$ 与流 $j$ 的路径作用量表示稀有事件；annealed 初态还包含相对 Bernoulli 轮廓的初始自由能代价。
  • 作者利用动力学 integrand 对 $\rho$ 和 $j+\nabla\rho$ 的联合凸性，对任意二维最优历史做旋转平均，证明可选择径向对称 minimizer，而非先验假设。
  • 径向 MFT Hamilton 方程经过半线变量替换成为 nonisospectral 可积系统；谱参数随演化而变，反映二维径向几何项，不能直接套一维等谱散射。
  • 通过半线 scattering data、守恒/演化关系与 scalar factorization 闭合边值问题，得到 SCGF 的封闭积分表达，再数值 Legendre 变换出完整 current rate function。
Card 04 核心结果与证据

核心结果与证据

  • 最先解决的关键是降维合法性：凸性与旋转不变性保证全二维变分问题存在径向对称最优解，因此后续一维径向散射不是未经证明的 ansatz。
  • 所得精确 SCGF 同时依赖 $\rho_1,\rho_2$ 与无量纲半径 $r_0=R/\sqrt T$，编码有限圆盘的曲率/双界面效应；它不退化为标准一维 step-current 公式。
  • SCGF 对 counting field 的导数给出所有退火电流累积量，Legendre–Fenchel 变换给出 $I(q)$；大偏差概率在二维按 $\Pr(Q_T/T\approx q)\asymp e^{-T I(q)}$ 的宏观尺度衰减。
  • 图 2 以 $\rho_1=0.7,\rho_2=0.1$ 展示 $r_0=0.5,1,2,4$ 的面积归一 SCGF，并在 $r_0=2$ 给出精确 rate function，直观显示几何尺度改变非高斯尾部。
  • 解满足 annealed 支撑允许的极端净转移边界，并可在小 counting field 展开恢复平均流与高阶涨落；结果覆盖任意有限 $r_0$，而不只是大圆或短时近似。
Card 05 有效性与局限

有效性与局限

  • 模型是 hydrodynamic/MFT 极限的 SSEP；“精确”指该宏观大偏差理论中的闭式结果，不是任意有限晶格、有限时间的逐点概率。
  • 初态是 annealed Bernoulli 圆盘阶跃；quenched 初态、非圆边界或主动吸收边界会改变边界代价与可积结构。
  • 径向化依赖圆形几何和作用量凸性，不能由此断言任意二维计数区域的最优路径都一维化。
  • 非等谱 scattering 推导技术性强，当前短文主要给解析构造与代表性数值图，未提供蒙特卡洛有限尺寸交叉验证。
  • SCGF 到 rate function 的数值 Legendre 变换在极端尾部需控制积分与优化精度。
