B-cosification: Transforming Deep Neural Networks to be Inherently Interpretable

B-cosification：把深度神经网络转化为内在可解释模型

Shreyash Arya、Sukrut Rao、Moritz Böhle、Bernt Schiele · 预印本 · arXiv:2411.00715 · 论文原文 ↗

B-cos 网络把输入对输出的贡献编码在模型本身，可生成内在解释，但从头训练大型架构成本高，且可能损失已有模型或 CLIP 的能力。能否把现有 checkpoint 低成本转换，而不重新完成全部预训练？

研究问题

  • B-cos 网络把输入对输出的贡献编码在模型本身，可生成内在解释，但从头训练大型架构成本高，且可能损失已有模型或 CLIP 的能力。能否把现有 checkpoint 低成本转换，而不重新完成全部预训练？
  • 同时需要区分“函数等价的结构改写”和“真正获得解释性”：仅替换算子可保留预测，却未必让权重与输入贡献对齐。

模型与方法

  • 第一步用 \(B=1\) 并保留 bias 等方式，将 conventional layers 改写为函数等价的初态；第二步采用立即设 \(B=2\)、将 bias 置零后再 fine-tune，得到 B-cos 动态线性形式。逐渐改变 B 或衰减 bias 是比较过的备选策略，最终转换会改变函数。
  • 监督分类实验覆盖 DenseNet、ResNet、ViT 等 ImageNet checkpoint；解释质量用 Grid Pointing Game localization 和与 post-hoc methods 的比较。CLIP 版本还检查零样本分类能否保留。
  • Figure 1 左侧比较从头训练 B-cos 与 B-cosified 模型的准确率曲线，右侧展示不同阶段解释图；Figure 2 专门展示 CLIP 转换后的细粒度可视解释。

核心结果与证据

  • Figure 1 报告 B-cosified DenseNet-121 和 ViT-S 达到从头训练 B-cos 精度分别约快 4.7× 与 9.0×；Table 4 对 DenseNet 报 5.0×。比较从已有预训练 checkpoint 开始，不包含原预训练成本，且不同架构的最终精度表现不完全一致。
  • 动态 W(\(x\))\(x\) 的 Grid Pointing Game localization 显著优于未转换 checkpoint，并接近从头训练 B-cos；Figure 4 显示其相对若干 post-hoc 方法也有优势。CLIP 转换后零样本能力部分保留但并非无损：Figure 5 中 natural 数据原 CLIP、ImageNet 转换和 CC3M 转换分别为 51.5、47.2、44.7。图注称始终优于 Text2Concept，但 specialized 类的 ImageNet 转换 34.3 低于后者 34.9。
  • 解释图是模型内在贡献 summary，但 localization benchmark 只检验与目标区域重合，不直接验证解释的因果忠实性或人类可理解性。

有效性与局限

  • B-cosification 仍需数据和 fine-tuning，转换成本随模型与数据规模变化；若只有闭源 API 或无原训练分布就难以应用。B 值和 bias 去除策略可能影响性能与稳定性。
  • Grid Pointing Game 容易受物体面积和背景偏差影响，彩色解释图的视觉细节不是充分的 faithfulness 证据。应加入删除/插入、反事实、参数随机化和 human-grounded tests。
  • CLIP 结果覆盖有限架构与 benchmark；生成模型、检测/分割和域外数据的能力保持尚未充分验证。本卡未独立复现。
