Card 02 研究问题

研究问题

  • B-cos 网络把输入对输出的贡献编码在模型本身，可生成内在解释，但从头训练大型架构成本高，且可能损失已有模型或 CLIP 的能力。能否把现有 checkpoint 低成本转换，而不重新完成全部预训练？
  • 同时需要区分“函数等价的结构改写”和“真正获得解释性”：仅替换算子可保留预测，却未必让权重与输入贡献对齐。
Card 03 模型与方法

模型与方法

  • 第一步把 conventional layers 改写为 functionally equivalent B-cos 形式，处理 bias、normalization、激活和 B 参数；第二步用逐渐增大 B、减小 bias 等 schedule fine-tune，使模型形成动态线性 summary W(\(x\))。
  • 监督分类实验覆盖 DenseNet、ResNet、ViT 等 ImageNet checkpoint；解释质量用 Grid Pointing Game localization 和与 post-hoc methods 的比较。CLIP 版本还检查零样本分类能否保留。
  • Figure 1 左侧比较从头训练 B-cos 与 B-cosified 模型的准确率曲线，右侧展示不同阶段解释图；Figure 2 专门展示 CLIP 转换后的细粒度可视解释。
Card 04 核心结果与证据

核心结果与证据

  • B-cosified DenseNet-121 和 ViT-S 达到原 B-cos 精度的速度分别约快 4.7× 与 9.0×，并保持与标准预训练模型接近的分类精度。这个 speedup 相对于从头训练 B-cos，不是相对于零成本 post-hoc explanation。
  • 动态 W(\(x\))\(x\) 的 Grid Pointing Game localization 显著优于未转换 checkpoint，并接近从头训练 B-cos；Figure 4 显示其相对若干 post-hoc 方法也有优势。CLIP 转换在保持零样本能力的同时给出更细致解释。
  • 解释图是模型内在贡献 summary，但 localization benchmark 只检验与目标区域重合，不直接验证解释的因果忠实性或人类可理解性。
Card 05 有效性与局限

有效性与局限

  • B-cosification 仍需数据和 fine-tuning，转换成本随模型与数据规模变化；若只有闭源 API 或无原训练分布就难以应用。超参数 schedule、bias 去除与 B 增长可能影响稳定性。
  • Grid Pointing Game 容易受物体面积和背景偏差影响，彩色解释图的视觉细节不是充分的 faithfulness 证据。应加入删除/插入、反事实、参数随机化和 human-grounded tests。
  • CLIP 结果覆盖有限架构与 benchmark；生成模型、检测/分割和域外数据的能力保持尚未充分验证。本卡未独立复现。
