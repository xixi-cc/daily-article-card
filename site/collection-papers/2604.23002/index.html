FormalScience: Scalable Human-in-the-Loop Autoformalisation of Science with Agentic Code Generation in Lean

FormalScience：用 Lean 智能体代码生成实现可扩展的人机协同科学形式化

Paper Collection · AI for Science · 原文

FormalScience 把自然语言/LaTeX 科学推导转成 Lean4：LLM 生成代码，Lean 编译器提供可执行错误反馈，agent 迭代修补，人类领域专家对语义对齐作二元判断。 应用到物理后得到 FormalPhysics：200 道大学水平问题、非形式化解答及 Lean4 statement-proof，主要覆盖量子力学与电磁学。 核心结论是“能编译”不等于“保留物理语义”：数据达到 100% formal validity，但 logical preservation 72.0%、mathematical consistency 72.5%，并出现系统性语义漂移。

Card 03 背景

背景

  • 数学 autoformalisation 常依赖 Mathlib 已有对象；物理中的 Dirac notation、非交换算符、矢量微积分和积分使自然语言到 Lean 的映射更难。
  • 论文区分四个对象：自然语言 statement/proof 与形式语言 statement/proof。FormalPhysics 是少数四者齐全的数据集，因此既可测试 theorem proving，也可测试完整 autoformalisation。
  • 研究目标不是消灭人类环节，而是让不精通 Lean 的领域专家把判断集中在“形式代码是否仍代表原推导”。
Card 04 模型与方法

模型与方法

  • 管线先由少量人写示例扩展问题，再由 Claude Sonnet 4.5 生成 Lean；编译失败时根据结构错误或语义错误选择重生成或最小 unified-diff patch，最多 25 次。成功编译后，人类判断对齐，拒绝则让 LLM 按固定 prompt 改写再编译（Section 2, Appendix A–\(C\)）。
  • benchmark 比较从每个数据集随机取 200 例；Formal Validity 由 Lean4 编译器给出，其余 Formal Quality、Logical Preservation、Mathematical Consistency 由 GPT-4.1-mini 判断，并用 Qwen2.5-Coder-7B 做约 6000 个成对判断的稳健性分析。
  • 模型实验含 zero-shot、带编译错误的 self-refinement、无人工 agentic pipeline 与完整 FormalScience；agent 可调用表面 guard、编译、错误分类和 patch 工具。
Card 05 核心结果与证据

核心结果与证据

  • Table 2 中 FormalPhysics 平均每题含 \(6.41\pm 2.34\) 个对象和 \(6.22\pm 2.13\) 个公式，复杂度接近 Herald-Proof，高于 miniF2F 等数学集；其 \(\mathrm{FV}=100\)%、\(\mathrm{FQ}=73.5\)%、\(\mathrm{LP}=72.0\)%、\(\mathrm{MC}=72.5\)%。
  • Table 3 的 GPT-5.1 zero-shot 只有 14.5% FV，self-refinement 为 17.0%；GPT-OSS-20B agentic 管线把 FV 从不足 10% 提到 31.0%，而完整 GPT-5.1/Claude-4.5 人机管线为 100%。这些设置模型、工具与人工投入不同，不能当作纯模型排名。
  • 第二判断器更保守，但两者在所有 metric/setting 都把 GPT-5.1 排第一；\(phi=0.28\)–0.37 且 \(p\)<10^-19，说明共享一定质量信号。Kendall \(\tau\) 在六个比较中为 0.2–1.0，中位数 0.80，次级效应仍依赖 judge。
  • 定性审查发现 notational collapse 与 abstraction elevation：例如原问题需要三维线积分，Lean 可能只证明 \(x\)−\(0=x\)；约 25% 样本出现 abstraction elevation。编译成功只证明替代形式对象内部一致，未必证明 Maxwell 方程或原物理推导（Figs. 2–3）。
Card 06 有效性与局限

有效性与局限

  • FormalPhysics 仅 200 例，集中在量子力学、电磁学与大学难度，不能外推到统计物理、广义相对论、化学或生物。
  • Lean4/Mathlib 缺少关键物理原语本身会迫使抽象化；因此 semantic drift 既可能来自模型，也可能来自目标形式库的表达能力。
  • LP/MC/FQ 主要依赖 LLM-as-a-judge；独立 judge 支持主趋势但给出不同绝对分数和部分不同的 self-refinement 效应。
  • 完整管线约需一个月专家时间；每个 200-example agent baseline 在 RTX 5090 上超过 100 GPU-hours。100% 编译率没有消除成本或语义核验负担。
