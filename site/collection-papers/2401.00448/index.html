Beyond Chinchilla-Optimal: Accounting for Inference in Language Model Scaling Laws

超越 Chinchilla 最优：把推理成本纳入语言模型缩放律

Card 02 研究问题

研究问题

  • Chinchilla 缩放律在给定预训练算力下平衡参数量 N 与训练 token 数 D，却把模型生命周期中的推理需求 I 排除在目标函数外。若模型要服务十亿量级请求，最小训练损失的模型未必是总算力或总美元成本最低的模型。
  • 论文求解给定目标质量和推理量时的 N、D：是否应训练更小模型并用更多 token 补回质量，以换取每一次推理都更便宜？
Card 03 背景

背景

  • 经验损失写成 \(\mathrm{L}(N,D)=E\)+A/\(N^{\mathrm{alpha}}+B\)/\(D^{\mathrm{beta}}\)；训练计算近似与 ND 成正比，而 autoregressive 推理成本近似与 N 乘输入/输出 token 数成正比。加入 I 后，目标面沿小 N、大 D 方向倾斜。
  • 这是一种 amortization 问题：额外预训练只付一次，减小 N 的推理收益在全部请求上重复累积，因此 break-even 取决于生命周期流量与硬件效率。
Card 04 模型与方法

模型与方法

  • 作者分别最小化 training+inference FLOPs 与现实美元成本；后者区分训练、prompt processing 和 generation 的 MFU、硬件价格与请求长度。给定 loss 水平扫描 N,D，和不计推理的 Chinchilla-style 解比较。
  • 实验训练 47 个、150M–6B 参数模型，token/parameter 比最高到 10,000；用 validation loss 与多任务 Gauntlet average 检验超长训练能否让小模型匹配较大模型。
  • 作者还逐步扩展用于拟合缩放律的数据范围，检验仅在常见 token/parameter 区域拟合是否可外推到极端长训练。
Card 05 核心结果与证据

核心结果与证据

  • Figure 1 的 13B→7B 示例最直观：在约 2T 推理 token 需求下，把更多算力移到 7B 的预训练可匹配质量，并因推理更便宜节省约 1.7×10^22 FLOPs，即 17%。
  • 当推理量接近预训练数据规模，最优解系统性地变为更小 N、更大 D；论文把约十亿请求视为足以显著改变选择的现实量级。47 个模型中，loss 与 Gauntlet 指标在极端 tokens/parameter 范围仍继续改善。
  • Figure 5 显示常规训练比率上拟合的参数曲线不能准确描述 150M 的长训练轨迹；因此结论既支持 inference-aware allocation，也警告缩放律的外推依赖采样设计。
Card 06 有效性与局限

有效性与局限

  • 推理成本模型依赖请求长度、batching、KV cache、量化、memory bandwidth 与实际 MFU；这些会随硬件和 serving stack 改变。美元最优不等于能耗、延迟或显存约束下最优。
  • 实验最大仅 6B，极端比率证据主要来自较小模型；不能无条件外推到前沿模型、不同数据质量或 post-training。固定 loss/Gauntlet 也不保证能力谱、安全性和上下文长度等价。
  • 结论是条件优化而非“小模型总更好”。该卡 no independent reproduction performed，未重拟合缩放律或训练模型。
