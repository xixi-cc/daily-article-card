Card 01 作者信息

作者信息

  • Elliott Abel 等十五位作者。论文把每个已训练网络的内部表示转成 diffusion operator，再以 diffusion geometry/PHATE 构造“网络之网络”的低维景观，arXiv:2411.12626v2。
Card 02 研究问题

研究问题

  • 比较神经网络通常看权重距离或单一准确率，但参数对称性使权重空间距离难以解释。若从同一输入样本上的内部表示出发，能否定义对网络功能几何更敏感的距离并观察模型群体流形？
  • 这样的景观是否能用于 architecture search、区分高低性能模型，并借助拓扑数据分析、谱熵和层次聚类刻画单个网络内部表示？
Card 03 模型与方法

模型与方法

  • 对每个网络提取隐藏层表示，在样本点之间构造核与 Markov diffusion matrix P；网络间距离由 diffusion matrices 或其诱导距离矩阵比较。再把网络作为点，用 PHATE/diffusion geometry 嵌入模型群体。
  • Figure 1 的 A–\(C\) 展示训练多网络、构造每网 diffusion graph、计算网络间距离并可视化 landscape；\(D\) 则对单网表示做 persistent topology、diffusion spectral entropy 与 hierarchical clustering。
  • 实验覆盖 MNIST MLP、CIFAR-10 CNN/ResNet，以及不同学习率、性能与随机网络。评价包括高性能模型间距离一致性、accuracy 在 landscape 上的组织和谱熵相关性。
Card 04 核心结果与证据

核心结果与证据

  • PHATE landscape 中模型按 architecture 和 test accuracy 形成结构；高性能网络的内部 diffusion geometry 相互更接近，而随机/低性能模型分散。Figure 3 在三种架构设置展示 accuracy gradient。
  • 高性能 ResNet 的 class-distance heatmaps 与 dendrograms 更一致，随机网络类结构模糊。Diffusion Spectral Entropy 随 test accuracy 增加，跨 MLP、CNN、ResNet 呈正相关。
  • 这些结果说明内部表示几何可作为模型比较信号；论文展示 architecture-search 可能性，但没有证明低维邻近必然意味着可迁移性、鲁棒性或相同算法。
Card 05 有效性与局限

有效性与局限

  • 网络距离依赖选取的数据样本、层、激活归一化、核带宽和 diffusion time；更换数据分布可能重排 landscape。PHATE 是非线性可视化，二维邻近不能当作高维距离的无失真证明。
  • 同任务模型的 accuracy 与 geometry 相关，可能部分来自共同的 class separation；需要控制预测 logits、参数量和训练 recipe，确认指标提供独立信息。
  • 实验架构和数据集较小，未覆盖大语言模型或跨任务网络。architecture search 的实际收益需与训练早停、廉价 proxy 和重复 seed 比较。本卡未独立复现。
