Frequency Bias and OOD Generalization in Neural Operators under a Variable-Coefficient Wave Equation

变系数波动方程下神经算子的频率偏置与分布外泛化

Neural operators learn to map initial conditions to the terminal solution of partial differential equations (PDEs), providing a surrogate for the full operator mapping. This enables rapid prediction across different input configurations. While recent neural operator architectures have demonstrated strong performance on diverse PDE tasks, their behavior under structured distribution shifts remains insufficiently understood. To investigate this, we study operator learning in a wave propagation setting governed by a one-dimensional variable-coefficient wave equation, using two representative architectures, the Fourier Neural Operator (FNO) and the Deep Operator Network (DeepONet). To examine their generalization under distribution shifts, we consider structured out-of-distribution (OOD) settings that independently vary input frequency and coefficient smoothness. Card 02 摘要

摘要

  • 研究对象是一维保守型变系数波动方程 utt=\(\partial x\)(c(\(x\))^2 ux)，输入为初位移 \(u_{0}\)(\(x\)) 和波速场 c(\(x\))，输出为固定终止时刻 \(u\)(\(x\),\(T\))。
  • 作者独立构造两类 shift：训练未见的高频初值，以及改变 c(\(x\)) 空间粗糙度；相同数据、优化条件下比较 FNO 与 DeepONet。
  • FNO 在 ID 和 smoothness shift 下误差更低，却在 high-frequency OOD 下突然恶化；DeepONet 总体误差更高，但退化更平缓。增加 FNO retained modes 没有修复该问题。
Card 03 背景

背景

  • 标准随机 held-out 可能保持同一频谱结构，因而掩盖模型只在训练频带内插值；波动问题恰能把输入频率和介质平滑性分别控制。
  • FNO 在 Fourier space 学习全局谱耦合并截断为固定低频 modes，隐含偏向平滑结构；DeepONet 以 branch coefficients 与 coordinate-conditioned trunk bases 展开，没有显式固定频率截断。
  • 论文关注 representation bias，而刻意不引入预训练、attention 或多分辨率模型等额外因素；因此结论只针对两种 canonical implementations。
Card 04 模型与方法

模型与方法

  • 训练/ID 初值由 \(Ku\le Ktrain\) 的随机 sine sums 生成；frequency OOD 使用 Ku>Ktrain。波速场为 Kc 项随机频率叠加，并以 smooth/medium/rough regimes 构造 smoothness shift。
  • reference data 用空间和时间二阶、flux-based conservative finite differences，满足 CFL 条件，并在系数界面 harmonic averaging；边界为 homogeneous Dirichlet，初速度为零。
  • 两模型都用 Adam、relative \(L_{2}\)、batch 32、最多 100 epochs、early stopping 10、固定 seed 2026 和 128 grid points；FNO 默认 16 modes/width 64/4 layers，DeepONet branch/trunk/latent 均 128。
  • 除 relative \(L_{2}\) 外，作者计算 c(\(x\))^2 \(ux^{2}\) 的空间积分作 energy-like diagnostic，并做 prediction error 的 Fourier spectral decomposition；该量并未宣称为严格守恒总能量。
Card 05 核心结果与证据

核心结果与证据

  • Figures 2–4 显示 FNO 在 Validation、ID、OOD-smoothness 保持波形与较低误差，但 high-frequency OOD 出现局部 phase shift 和 oscillatory distortion；DeepONet 的误差升高较缓且空间分布更均匀。
  • Figure 5 表明 FNO 的失败不是仅丢掉最高清晰度：误差跨多个 mid-to-high modes 同时抬升，说明训练得到的谱耦合关系在新频率输入下整体失稳。
  • Table 2 的 retained-mode ablation：8/16/32 modes 的 ID relative \(L_{2}\) 为 0.2073/0.1989/0.2390，而 frequency-OOD 为 1.2978/1.3564/1.4673；扩大谱容量反而未改善 OOD。
  • 同一消融的 smoothness-OOD 误差约 0.0594/0.0588/0.0602，明显稳定；因此 frequency content shift 与 coefficient smoothness shift 不能合并成一个笼统 OOD 分数。
  • 作者将差异解释为 architecture representation bias；这是由受控现象和消融支持的机制推断，不是已经证明的普适因果定理。
Card 06 有效性与局限

有效性与局限

  • 只有一维、固定终止时间、合成初值和变系数波动方程；不能直接外推到 shocks、二维/三维 turbulence、真实传感器或长期 autoregressive rollout。
  • 所有主实验用固定随机种子 2026；虽然 train/validation/ID/OOD 分别用独立 seeds，仍缺多 seed 均值与置信区间，结果对训练随机性有待核验。
  • FNO 与 DeepONet 的参数化和 activation 不同，所谓公平比较是相同训练预算而非完全匹配容量；DeepONet 的较平缓退化伴随更高绝对误差。
  • 增加 modes 的消融只能排除“默认 modes 太少”这一简单解释；不能证明所有频率自适应、anti-aliasing 或 hybrid FNO 都会同样失败。
  • energy-like diagnostic 不含完整动能项，不能当作波动方程总能量守恒检验。
Card 07 复现与资源

复现与资源

  • 复现需使用 appendix 的 Ku/Kc split 规则、独立随机 seeds、同一 conservative solver/CFL/harmonic averaging，并明确 Ktrain 和三个 coefficient regimes。
  • 至少输出四个 split 的 relative \(L_{2}\)、逐 mode spectral MSE、空间 residual、energy-like diagnostic，以及 8/16/32 retained-mode 表；只复现 ID 分数无法验证主结论。
  • 进一步核验应运行多个训练 seeds，并增加同参数量的 local-spectral/hybrid baselines，检查现象是否由架构还是优化偶然性驱动。

阅读指南
