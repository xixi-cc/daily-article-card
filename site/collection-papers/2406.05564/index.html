Automata Extraction from Transformers

从 Transformer 中提取自动机

Card 01 作者信息

作者信息

  • Yihao Zhang、Zeming Wei 与 Meng Sun，来自 Peking University。论文把 encoder-only Transformer 的 formal-language classifier 近似成 deterministic continuous-state automaton，再用 \(L\)* 提取 DFA。arXiv:2406.05564v1。
Card 02 研究问题

研究问题

  • RNN 有逐 token 隐状态，传统 automata extraction 可直接把它聚类；Transformer 一次处理整个序列，没有显式递归 state。论文问：能否构造一个 stateful surrogate，既拟合 Transformer 的输出，也对齐其 representation，然后从 surrogate 自动提取可读 DFA？
  • 提取的 DFA 应在测试字符串上与 Transformer 保持高 consistency，并暴露模型实际学到的规则或错误，而不只是重建目标正则语言。
Card 03 模型与方法

模型与方法

  • 第一步 \(Transformer\to DCSA\)：取 encoder 最后一层 [CLS] representation \(r\)*，训练 deterministic continuous-state automaton 逐字符更新连续 state s，并同时最小化 classification loss 与 representation-alignment loss，使 final s* 逼近 \(r\)*。
  • 第二步 \(\mathrm{DCSA}\to DFA\)：把 DCSA 当作 membership oracle，使用 \(L\)* active learning 维护 observation table；equivalence queries 通过采样字符串比较候选 DFA 与 surrogate，并用 counterexample 细化。Figure 1 展示数据、Transformer、DCSA、\(L\)* 与 consistency evaluation 的闭环。
  • 实验在 Tomita grammars、modular arithmetic 等 regular languages 上训练 BERT-like encoder classifiers，分别评估 Transformer–DCSA、DCSA–DFA、Transformer–DFA consistency，并比较有无 representation alignment。
Card 04 核心结果与证据

核心结果与证据

  • 在多数 fully trained regular-language tasks 上，提取 DFA 与 Transformer 达到很高一致率，且若 Transformer 学对目标语言，DFA 往往恢复接近标准的状态结构。Figures 3、5 给出 Tomita 4 与 mod-3 的实例自动机。
  • 对未完全训练的 Tomita 3 Transformer，提取结果仍能高一致地模仿其实际输出，说明方法倾向于解释模型而非强制返回 ground-truth automaton；这正是诊断用途的重要区分。
  • 消融显示 representation alignment 改善 surrogate state 与 Transformer representation 的对应，并提升部分 extraction consistency。不过 consistency 只在有限采样集上估计，不是形式等价证明。
Card 05 有效性与局限

有效性与局限

  • 范围限于 binary/finite-alphabet regular languages 与 encoder-only classifiers；自然语言、长上下文或需要 stack/counter 的非正则行为不能由有限 DFA 精确表示。DCSA capacity 和训练质量会成为额外近似误差源。
  • \(L\)* 的经典保证需要精确 membership/equivalence oracle；本文 equivalence query 依赖采样，因此可能漏掉稀有 counterexamples。提取 DFA 的大小与稳定性会随采样分布、最大长度和阈值变化。
  • 高 Transformer–DFA consistency 不说明 DFA 内部状态与 Transformer 具有唯一神经对应，也不证明全输入域等价。论文语句与表格排版存在若干抽取/写作噪声，结论需回到原 PDF 核对。本卡未独立复现。
