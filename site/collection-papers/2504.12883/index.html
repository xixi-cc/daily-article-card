作者信息

Card 02 研究问题

研究问题

  • 无显式正则的优化动力学会选择特定插值解；加入 weight decay 等 penalty 后，显式与隐式偏置如何共同决定最终解？
  • 作者区分 positional bias、bias type 改变和 range shrinking，并问动态关闭正则能否利用早期引导又避免最终过度收缩。
Card 03 模型与方法

模型与方法

  • 在 mirror flow/geometry 框架中加入 αh(\(x\))，推导正则如何修改镜映射、Bregman geometry 和可达集合；给出三类效应的条件。
  • 把结果应用到 sparse coding、matrix sensing、单层 attention 与 LoRA，并做数值实验比较常数 weight decay、无正则和训练中途 switch-off schedule。
Card 04 核心结果与证据

核心结果与证据

  • Figure 1 总结：正则可移动偏置中心、把 \(L_{2}\) 型选择变为 \(L_{1}\) 等不同类型，并缩小动力学可达解范围。
  • 正则即使后来关闭，早期轨迹已改变位置/几何，可能留下持久影响；适时 switch-off 在报告任务上改善泛化。
  • 最优关闭时机依赖问题和噪声；实验收益不证明所有深网 weight decay 都应动态关闭，离散优化也只是连续 flow 的近似。
Card 05 有效性与局限

有效性与局限

  • 理论基于连续时间、特定可解模型与正则形式；Adam、momentum、有限步长、归一化和 stochasticity 会改变 implicit bias。
  • “偏置类型”需在参数化与函数空间中区分，重参数化可改变表面 norm；动态 schedule 还增加调参自由度。
  • 论文给出的图形、相关性或有限规模干预只支持其明示范围；跨数据、架构、模型规模与训练制度时需要重新验证。本卡未独立复现，不能把受控实验直接提升为普适机制。
  • 对结论做强审计时，应设置能产生相似表面指标的替代机制、匹配参数量与计算预算、报告失败案例和置信区间，并检查阈值、归一化、样本选择及评价器是否预先偏向作者假说。
  • 若论文声称发现机制，还应要求前向预测新的干预结果，而不只事后解释已有曲线；至少应在未用于选择假说的数据、不同随机种子和合理替代基线上保持。
  • 此外应明确负结果的含义：未观察到效应可能来自统计功效、测量误差或实现差异，不能自动当作理论反证；观察到效应也需排除共同原因。
