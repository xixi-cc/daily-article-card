An exact mapping between the Variational Renormalization Group and Deep Learning

Card 01 作者信息

作者信息

Card 02 研究问题

研究问题

  • 深层网络逐层提取 coarse features 的图像与 real-space RG 相似，但类比何时是数学等价？论文从 Kadanoff variational RG 的 trace condition 出发，把 coarse variables 与 RBM hidden units 精确配对。
  • 问题不是声称所有 deep learning 都是 RG，而是：给定满足自由能保持条件的 RG coupling \(T_{\mathrm{lambda}}\)(v,\(h\))，能否构造同一 joint distribution 的 RBM；反过来哪些 RBM 定义有效 RG。
Card 03 背景

背景

  • variational RG 在 microscopic spins v 上引入 hidden/coarse spins \(h\) 和 coupling \(T_{\mathrm{lambda}}\)，要求对 \(h\) 求和后不改变原 partition function/可观测自由能。新 Hamiltonian 由 joint Boltzmann weight coarse-grain 得到。
  • RBM energy E(v,\(h\)) 也是 visible-hidden bipartite coupling；边缘化一层产生下一层 effective distribution。两者的 algebraic structure 因而可逐层堆叠。
Card 04 模型与方法

模型与方法

  • 作者令 RBM energy 等于 microscopic Hamiltonian \(H\)(v) 减 variational coupling \(T_{\mathrm{lambda}}\)(v,\(h\))，归一化后 RBM joint probability 与 RG joint weight 相同；trace condition 保证 visible marginal 保留原物理分布。
  • 1D nearest-neighbor Ising 用解析 block-spin RG 构造对应 RBM/DNN；2D Ising 在 \(J=0.408\) 采样 40,000 configurations，用 stacked RBMs、contrastive divergence 与 \(L_{1}\) regularization 无监督训练。
  • effective receptive field 由各层 weight matrices 连乘，检查高层 hidden unit 在 visible lattice 上对应的空间块，从而比较 learned hierarchy 与 Kadanoff blocking。
Card 05 核心结果与证据

核心结果与证据

  • Figure 1 的 2×2 block-spin 图展示 physical coarse variable 如何替代四个 spins；同一层在 RBM 中由 hidden units 与 visible block 耦合实现。
  • 映射是 construction-level exact：任何满足 trace condition 的 variational RG 可写成 RBM energy；但任意训练得到的 RBM 若不满足该条件，不自动保持 free energy，也不必是合法 RG。
  • 2D Ising stacked RBM 的 effective receptive fields 随层加粗并呈局域块结构，支持网络自组织出 RG-like coarse-graining；这是数值观察，不证明通用视觉/语言网络学习同一 fixed point。
Card 06 有效性与局限

有效性与局限

  • exact mapping 的方向与条件常被后续引用过度扩张：关键是 trace condition/free-energy preservation，普通 RBM objective 不强制它。RG 提取 long-distance relevant operators，而 task-trained network 可保留与标签相关但物理上 irrelevant 的特征。
  • 2D 实验规模小、靠近临界 Ising 且使用 RBM/CD；现代 discriminative transformers、ReLU CNN 与非平衡数据不在证明范围。
  • receptive-field resemblance 是定性 evidence，未计算完整 RG flow、critical exponents 或 universality。该卡 no independent reproduction performed。

Card 08 阅读指南

阅读指南

  • 先检查 trace condition，再逐式对应 \(T_{\mathrm{lambda}}\)、E(v,\(h\)) 与 hidden marginal；最后看 Figure 1 和 2D receptive fields，严格区分 exact construction 与 learned-RBM observation。
  • 物理上 deep layer 可视作一次 real-space decimation 仅在 measure preservation 成立时；否则它只是形式相同的 latent-variable transform。
