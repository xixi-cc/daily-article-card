LLMs learn governing principles of dynamical systems, revealing an in-context neural scaling law

大语言模型学习动力系统支配规律，并呈现上下文内神经缩放律

Card 02 研究问题

研究问题

  • LLM 的 time-series extrapolation 可能只是局部模式延续，也可能在上下文中估计了支配下一状态的条件分布。作者问：对离散 Markov chain、logistic map、Lorenz system、Brownian motion 和 geometric Brownian motion，预测是否随已观察轨迹长度系统改善？
  • 第二个问题是如何从 multi-digit token probabilities 重构连续数值的 probability density，而不依赖采样大量 completions；以及这种上下文内误差是否呈 power-law-like scaling。
Card 03 模型与方法

模型与方法

  • 将时间序列格式化为纯数字文本，向 LLaMA-2 7B/13B/70B 提供前缀，不做 fine-tuning、instruction prompt 或 task-specific examples。离散系统直接读出下一状态 token distribution；连续系统使用 Hierarchy-PDF，按数字位递归查询条件 token probabilities，并把分支概率组合成多分辨率 density。
  • 随机系统以 Bhattacharyya distance 比较预测与解析 transition PDF；确定系统以预测均值与真实下一状态的 squared deviation from mean 衡量。上下文长度从短前缀扩展到约千步，并与 unigram/bigram、linear/nonlinear AR(1) baselines 比较。
  • 对 noisy logistic map，输入扰动 epsilon 经局部映射 \(f\) 给出近似条件分布 \(N\)(\(f\)(\(x\)),[sigma \(f\)'(\(x\))]^2)，同时检验 mean 与 variance；非平稳 Brownian 类系统被单独讨论。
Card 04 核心结果与证据

核心结果与证据

  • Figure 1 显示多数系统的 loss 随 context length 下降，并在 log-log 图上近似幂律；Markov chain、noisy logistic map 与 Lorenz 等系统在更长上下文中逐步接近真实 transition rule。Brownian motion 与 geometric Brownian motion 明显偏离统一 power law，作者归因于缺少 stationary distribution。
  • Hierarchy-PDF 能从 LLaMA-13B 的逐位 token probabilities 重建 noisy logistic map 的非均匀下一状态分布，预测不仅追踪 mean，也恢复与局部 derivative 相关的 variance。多种 baseline 对照支持模型利用了超过一阶固定统计的上下文信息。
  • 所谓 in-context neural scaling law 是经验拟合：它描述固定模型在一次 prompt 内增加观测状态时的 loss decay，不是训练 compute/model/data scaling law，也未证明模型形成符号化 governing equation。
Card 05 有效性与局限

有效性与局限

  • 系统维度和数值格式受控，许多轨迹由已知低维方程生成；结果不能直接外推到高维 PDE、稀疏/不规则观测、测量噪声或真实实验数据。数字 tokenization、精度和 prompt delimiter 都可能改变性能。
  • 对 context-length power law 的区间有限，曲线有 crossover，两个非平稳过程偏离；指数不是普适常数。更长上下文同时提供更多统计样本与更近期状态，不能仅据此区分 Bayesian-like estimation、memorized numeric patterns 或算法执行。
  • LLaMA-2 训练语料可能包含相关方程或时间序列模式；论文不做 data-contamination 证明。zero-shot transition prediction 与长期 rollout stability、causal mechanism recovery 不等价；本卡未独立复现。
