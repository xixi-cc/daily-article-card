AI Agents Can Already Autonomously Perform Experimental High Energy Physics

AI 智能体已能自主执行实验高能物理分析

Large language model-based AI agents are now able to autonomously execute substantial portions of a high energy physics (HEP) analysis pipeline with minimal expert-curated input. Given access to a HEP dataset, an execution framework, and a corpus of prior experimental literature, we find that Claude Code succeeds in automating all stages of a typical analysis: event selection, background estimation, uncertainty quantification, statistical inference, and paper drafting. We argue that the experimental HEP community is underestimating the current capabilities of these systems, and that most proposed agentic workflows are too narrowly scoped or scaffolded to specific analysis structures. Card 03 背景

背景

  • 实验 HEP 分析常耗费数年，许多工作是重复性代码、文档检索和标准统计流程。JFC 的研究问题是：当前通用 coding agent 在少量专家输入下，能否把这些步骤串成完整、可审查的分析。
  • 与每一步由物理学家监督的 human-in-the-loop 路线不同，JFC 把中间审查交给专门 reviewer agents，把人类决策集中到 10% 部分解盲后的单一门控。
  • 作者强调示例用于展示能力，不等同于正式发表的测量；除两篇压缩成 letter 的案例外，其余分析没有按作者本人发表工作的标准逐项核验（pp. 2, 13–14）。
Card 04 模型与方法

模型与方法

  • 流程分阶段执行：策略与实现、预期结果、仅用 Asimov 数据的统计模型、固定随机种子的 10% 部分解盲、人类批准、全量解盲。审查角色检查分析策略、代码、统计模型、图形和文字是否一致（Fig. 2）。
  • 部分解盲必须通过拟合收敛、goodness-of-fit、pull/constraint、信号注入和异常检查；同一审查面板给出批准或返工，人类只在证据包通过后决定是否进入全量解盲（pp. 10–13）。
  • ALEPH 检索库收集 1503 条记录，其中 721 条有源材料、575 条转为 Markdown；ALEPH 分析可用该检索，DELPHI 与 CMS 分析没有使用同一文献库，因此并非所有案例条件相同。
  • 主文列出六项 Claude Opus 4.8 分析及四项更早的 Opus 4.6 DELPHI 运行；另以相同 CMS prompt 比较 Codex GPT-5.5 与 Claude Fable 5，但作者将其标为 preliminary、indicative，而非受控模型 benchmark。
Card 05 核心结果与证据

核心结果与证据

  • Table 2 显示系统从短 prompt 生成 \(Z\) lineshape、Rb/Rc/AFB、EEC、event shapes+αs、CMS \(H\to \tau\tau\) 等分析，并公开完整 analysis notes、代码、图和 prompt。Figure 7 给出约 10 小时量级的单分析墙钟时间，但包含订阅限流等待，不能当作纯计算成本。
  • Figure 3 中多数标量测量与已发表参考值的偏差在 |pull|<2；ALEPH ΓZ 为 −3.4σ，论文追溯到公开数据能区间有限。CMS 与 αs 的表面一致性还伴随远大于参考工作的不确定度。
  • CMS \(H\to \tau\tau\) 得到 \(\mu\)̂=\(1.20\pm 1.13\)，对应 published \(\mu\tauh=1.01\pm 0.41\)；中心值仅差 0.16σ，但智能体结果误差约为发表值三倍。分解研究把预期不确定度降到约 0.65，仍约为参考结果的 1.6 倍（Fig. 4）。
  • 首次 CMS 拟合因 tt̄ 背景使用任意 ±35% 先验得到 \(\mu\)̂=\(0.34\pm 1.20\)；接入已做但未连入拟合的 b-tag 控制区估计后才移动到 \(1.20\pm 1.13\)。早期自制 GOF 还曾错误地产生 \(p\approx 0.99\)，后来改用 saturated-model test 后主拟合 \(p=0.065\)（pp. 17–18）。
  • ALEPH Lund plane 是作者所称的 e+e− 中候选首次测量；自动审查纠正了“高显著性排除生成器”的过强表述，但约 3% unfolding 建模系统误差因只有一套完整探测器模拟而无法用替代生成器交叉检验。它应被视为待社区独立核验的候选结果。
Card 06 有效性与局限

有效性与局限

  • 开放数据往往只含完整实验样本的子集，探测器模拟、触发与内部校准信息也受限；这些约束会扩大统计和系统误差，不能归因于智能体本身。
  • 展示任务以标准测量为主，更复杂的多控制区、先进多变量方法与多通道联合拟合尚未证明；智能体擅长检索并复用成熟套路，不保证能可靠发明新分析策略。
  • 论文观察到系统常能诊断问题却没有完成修复闭环；这比显眼的代码失败更危险，因为表面完整的分析可能携带细微物理偏差或漏掉系统误差。
  • 不同 backbone 的 CMS 比较只有同一 prompt/框架/部分数据，结果彼此不同；样本数、随机性和独立重复均不足，不能据此排名模型。所有科学结论仍需专家逐项审查和独立复现。
