Analyzing Transformer Dynamics as Movement through Embedding Space

将 Transformer 动力学分析为嵌入空间中的运动

Paper Collection · Transformer Theory · 原文

Card 01 作者信息

作者信息

  • 作者为 Sumeet S. Singh（Turnitin LLC）。arXiv:2308.10874v2。论文提出一个 embedding-space 视角，把 Transformer 的层间表示更新称为 encoding walk，把自回归生成称为 decoding walk，并尝试以此统一 attention 与无 attention 序列模型。
Card 02 研究问题

研究问题

  • Transformer 的 residual-stream 向量如何随层移动，并最终把上下文映射到下一个 token？作者希望用过滤、聚合、向量相似度和位置偏置这些操作，给出从架构到语言行为的系统级叙述。
  • 论文进一步提出较强主张：训练学习路径概率，推理只沿已学习路径采样，因此所谓 in-context learning 不包含参数学习。这里应区分“没有权重更新”这一事实与“没有上下文诱导的新算法/状态计算”这一有争议解释；后者并未被文中实验充分证明。
Card 03 模型与方法

模型与方法

  • 作者把 layer norm、\(Q\)/\(K\)/V-output 投影与前馈层视为逐位置的静态 filters，把 attention 视为唯一显式跨位置的 cluster-and-aggregate：query-key 相似度和相对位置 bias 形成权重，value features 被加权汇总。
  • Figure 4 将 Transformer 画成 filters 与 soft clustering 的交替组合。沿某个位置追踪从 token embedding 到顶层 context vector 的近邻、相似度图和 attention/position-bias maps，构成 encoding walk；自回归时每个 context vector 邻近的 token 决定下一步。
  • 实证使用约 15 个模型（文中示例含 \(T_{5}\)-small、Flan-\(T_{5}\) 系列、Falcon-7B 等）观察 embedding 的 UMAP、相似度图、位置核与层间近邻。concept-space 部分把语义片段预聚合成向量，测试分层组合后还能否保持下一 token 或下一概念预测。
Card 04 核心结果与证据

核心结果与证据

  • 相似度图显示格式分隔符、数字和括号等高共现结构形成不同带状/块状模式；Flan-\(T_{5}\) attention map 中相对位置 bias 的量级足以显著改变 softmax 前分数。作者据此把 attention 描述为“带位置偏置的关联聚合”。
  • encoding-walk 示例显示部分位置的层间表示长期停留在原 token 邻域，另一些 decoder 位置逐层移动到预测 token 邻域。这是对真实模型激活的描述性证据，但 nearest-token 投影会丢失 residual stream 中不与词嵌入基对齐的成分。
  • concept composition 的两个测试最高约 85% 与 95% 以上，但未达到若理论严格成立应有的 100% 以上基准。作者因此承认 concept-space theory 未被证明，最多提示 Transformer 可能部分支持复合概念映射。
Card 05 有效性与局限

有效性与局限

  • 论文把 inner product、共现和角距离建立为三向对应，但这些量受 layer norm、unembedding tying、各层基变换与训练目标共同影响；观察到相关性不能证明共现是唯一成因。UMAP 与 nearest-neighbor 是低维/词表投影，不能完整表征高维激活。
  • “attention 不判断相关性”“模型总在幻觉”“不存在 in-context learning”等措辞超出所展示证据。attention weights 受 query 内容影响，模型即使不更新权重，也可在激活中执行上下文条件算法。论文未与 induction-head、mesa-optimization 或线性 probe/causal intervention 基线作决定性检验。
  • 概念实验依赖人工语义分段和简单 mean/weighted-mean 聚合，得分未达理论预期；模型、任务和指标实现细节分散在附录。因而这张卡把工作定位为可检验的解释框架和探索性证据，而非已确立的 Transformer 理论。
