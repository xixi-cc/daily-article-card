Are Transformers Able to Reason by Connecting Separated Knowledge in Training Data?

Transformer 能否连接训练数据中分散的知识进行推理？

作者信息

  • Yutong Yin 与 Zhaoran Wang。论文设计 Fragmented at Training, Chained at Testing（FTCT）合成任务，检验 Transformer 能否把训练中从未共同出现的短因果链在测试时连接成长链，arXiv:2501.15857v8。
Card 02 研究问题

研究问题

  • 语言模型可能在不同文档见到 \(A\to B\) 与 \(B\to C\)，却从未见完整 \(A\to B\to C\)。测试时给少量 demonstrations，它能否组合分散知识，而非回忆完整链或只做局部 next-token continuation？
  • 能力取决于 causal depth \(N\)、训练 child-chain 最大长度 \(M\)、模型深度/heads 和 few-shot 数量；作者还问内部是否形成定位 parent vertex 的 induction-like attention。
Card 03 模型与方法

模型与方法

  • 先采样有向 causal structure 与节点 value transformations。训练数据只含长度≤\(M\) 的 fragmented child chains，并混入 noise vertices；测试要求生成更长 chained sequence，确保完整推理链未在训练中出现。
  • Few-shot examples 提供任务格式，随后 query 要预测按因果父子顺序变换的 vertices/values。Figure 1 展示结构、训练碎片、测试长链与 downstream preprocessing 的全流程。
  • 评价拆为 whole-chain accuracy、vertex-order accuracy、value accuracy 等；扫描 \(N\)、\(M\)、模型架构与 shots。Attention weight 和 hidden-state probes 检查模型是否关注 parent vertices。
Card 04 核心结果与证据

核心结果与证据

  • 在有 few-shot demonstrations 时，一定范围的 Transformer 可连接未共同出现的 child chains，测试表现随 relative knowledge ratio（训练片段覆盖相对测试链）上升。Zero-shot 明显更弱。
  • Figure 2/3 显示因果深度增大或 \(M\) 相对变短时 whole-chain accuracy 快速下降；部分模型能预测正确 vertices，却在 values 或完整序列上失败，说明聚合指标应拆解。
  • Attention/probing 发现某些 heads 聚焦 parent vertex，probe 对 parent replaced values 的准确率高于其他位置，支持模型学到结构化检索信号。但相关 head 和 probe 不是完整因果算法证明。
Card 05 有效性与局限

有效性与局限

  • FTCT 是人工图与符号序列，训练/测试生成器共享规则；自然知识的歧义、矛盾、实体链接和开放世界缺失未覆盖。Few-shot examples 可能直接教会输出算法格式。
  • 保证完整长链未出现并不排除模型从局部频率或位置模板利用捷径；需换图同构、符号重映射、长度外推和 adversarial noise 控制。
  • probe 可解码 parent information 不证明模型用它产生答案，attention weight 也非因果证据；需要 activation/path patching。标题问题只能在所测规模和任务上条件回答。本卡未独立复现。
