A Theoretical Framework for Grokking: Interpolation followed by Riemannian Norm Minimisation

顿悟式泛化的理论框架：插值之后的黎曼范数最小化

Card 01 作者信息

作者信息

  • Etienne Boursier、Scott Pesme 与 Radu-Alexandru Dragomir 合作完成，分别署 INRIA/Universite Paris-Saclay、INRIA Grenoble 与 Telecom Paris。PDF 首页记录 arXiv:2505.20172v2 [cs.LG]（2025-11-05）及 NeurIPS 2025。论文提出一个纯优化的 grokking 机制：小 weight decay 的梯度流先迅速插值，再在很慢的时间尺度上沿零训练损失解流形降低参数范数。
Card 02 研究问题

研究问题

  • Grokking 的典型曲线是训练损失很快为零、测试损失长时间平台、随后才明显改善。作者问这是否能在不诉诸特定表征相变或任务结构的条件下，由正则化优化本身解释。具体地，给一般训练损失 F，加很小 \(L_{2}\) decay lambda 后的梯度流，lambda 趋零时是否呈现两个彼此分离的动力学：先逼近无正则流的插值临界点，再在 \(t\) 约为 1/lambda 的尺度上选择一个更小范数、可能泛化更好的解。
Card 03 背景

背景

  • 过参数模型的零损失解通常不是一点而是 critical manifold。无正则 gradient flow 由初始化决定落到其中某处；小 weight decay 在任何固定有限时间内看似可忽略，因此表面上应有相同极限。但论文强调 \(t\to infinity\) 与 \(lambda\to 0\) 的极限不可交换：先长时间训练再令 decay 很小，会得到不同于无正则终点的低范数选择。这里的“Riemannian norm minimisation”是指在临界流形携带的诱导度量上做范数下降，不是简单地在环境欧氏空间投影。
Card 04 模型与方法

模型与方法

  • 作者对光滑 F 考察 dot w=-nabla F(w)-lambda w，假定无正则流收敛并对临界流形有足够正则结构。奇异摄动分析给出 fast phase：regularised path 跟踪无正则流至临界流形；slow phase：以缩放时间沿流形上的黎曼梯度流减小 \(l_{2}\) norm。实验包括 rank-3 matrix completion（随机观测 20 by 20 矩阵一半条目、factor U,V）、两层 ReLU 拟合少量一维样本，以及 diagonal linear Fourier-feature network。训练记录 train/test loss、norm、函数快照和重构奇异值；离散迭代以 \(t_{k}=gamma\) \(k\) 对齐连续理论。
Card 05 核心结果与证据

核心结果与证据

  • 主结论是：lambda 小时，初期到达插值 critical manifold 的轨迹近似不含 decay 的 gradient flow，之后在 1/lambda 量级的慢时间上下降参数 norm，并趋向该流形中低范数解。Figure 1 概括两相机制。Figure 2（第 6--7 页）在低秩矩阵补全中显示训练 loss 快速归零而 test loss长平台；晚期 norm 降低时 test loss 改善。其右面板显示早期多条重构奇异值都大，grokking 开始后仅三个向真实 rank-3 奇异值靠拢，其余衰减。Figure 3 的两层 ReLU 也显示慢 norm 下降与函数从训练点插值向三 ReLU teacher 的泛化靠近。作者将这些视为权重衰减诱导的低复杂度选择，而非训练误差再次降低。
Card 06 有效性与局限

有效性与局限

  • 优势是把延迟泛化写成明确的 singular-perturbation/流形选择问题，并将时间尺度同 lambda 关联；矩阵补全的谱图提供了直观的结构选择证据。理论并不自动覆盖所有深网：需要 F 光滑、无正则流收敛和适当流形条件；ReLU 不光滑，论文也只将其作为相似现象的数值例子。低 \(l_{2}\) norm 与更好泛化在这些受控任务中相关，却不是所有数据、参数化或正则化下的充分因果判据。实际训练是离散、小 batch、可能 Adam 的过程，lambda、stepsize、初始化和数据噪声均可改变可见窗口；论文解释的是一类 grokking，不排除熵、表示或优化器动力学的其他机制。
Card 07 复现与资源

复现与资源

  • 最低成本复核是按文中矩阵补全设置生成 rank-3 20 by 20 真矩阵、观测 50% entries，以 lambda=1e-3、stepsize 1e-2 的 factorised GD 追踪完整矩阵 test error、||U||_F^2+||V||_F^2 和 \(UV^{T}\) 奇异值。必须将绘图横轴转换成 \(t=gamma\) \(k\)，训练足够久覆盖 1/lambda 尺度；只跑 fast phase 会错误否定机制。再可复现一维 ReLU/diagonal-linear toy，保存每个函数快照与独立 test grid。验证定理还需检查 F 的光滑性和临界流形假设，不能从曲线本身推出。本卡只核验 30 页 PDF、完整 MinerU Markdown 和既有渲染页，未执行代码、数值积分或证明复算。
Card 08 阅读指南

阅读指南

  • 先读 Figure 1 与 Theorem 1 的假设，把“fast tracks unregularised flow”和“slow selects along manifold”分开。随后阅读两个极限不交换的论证，这是为什么极小 decay 最终仍有大效果。Figure 2 是最干净的可视例：左图确认时间尺度，右图展示低秩谱选择；不要忽略它的合成矩阵边界。再看 Figure 3，认可 ReLU 现象但不把它等同于光滑定理。最后阅读附录的离散时间换算，避免将 \(t\) about 1/lambda 误认为恒定的 iteration 数；它要除以 stepsize 才对应步数。
