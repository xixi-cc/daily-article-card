Data-driven model discovery with Kolmogorov-Arnold networks

用 Kolmogorov–Arnold 网络进行数据驱动模型发现

Mohammadamin Moradi、Shirin Panahi、Erik M. Bollt、Ying-Cheng Lai · 预印本 · arXiv:2409.15167 · 论文原文 ↗

研究问题

  • 稀疏回归的效果依赖候选函数库；作者关注在所选幂或 Fourier 字典下不易稀疏表示的混沌系统。只凭观测轨迹，能否学习在相关区域再现部分长期动力学特征的近似模型？
  • 作者讨论辨识的潜在非唯一性：不同函数表达可能产生相近的吸引子表现；这并不证明它们的不变集或动力学严格相同。

模型与方法

  • 方法用 KAN 边上的一元可学习函数拟合离散映射或连续系统的离散演化；正文比较 Ikeda map 和三维生态模型的轨迹、吸引子图及 Lyapunov 指数。作者称补充材料含分布和散度比较，本次未取得该材料核验。
  • Figure 1 是不同表示可能产生相似动力学的概念示意；实际 Ikeda 例子使用 2-4-2 与 2-10-2 等结构。吸引子图相近不证明不变测度严格相等。
  • Ikeda 映射案例使用 10,000 个数据点和 80% 训练划分；生态模型同样使用 10,000 点、采样间隔 \(\Delta t=0.5\) 和 90% 训练划分。比较依赖这些数据与架构条件，未展示公平的定量 SINDy 或 MLP 基准。

核心结果与证据

  • Ikeda map 的测试轨迹因混沌随迭代分离，所展示的吸引子轮廓相近；较宽 KAN 的 Lyapunov 指数约为 [0.5033, −0.7311]，真值约为 [0.5025, −0.7263]。这是有限样本比较，不能证明两个模型严格等价。
  • 生态模型图中吸引子形状相近，但真值指数 [0.0053, 0, −0.2288] 与 KAN 的 [0.0095, −5.8×10⁻⁶, −0.3932] 存在明显偏差，最负项绝对值相差约 72%。作者将偏差归因于数值 Jacobian；该归因未在正文中得到独立验证。
  • 作者将模型轨道与真实轨道的关系类比为 shadowing，同时指出小的一步误差不保证正确的轨道或不变测度；本文没有建立适用于这些案例的严格 shadowing 定理。正文将 KL 等详细比较指向单独补充材料，本次未核验。
  • 训练目标的一步拟合、有限长度吸引子图和 Lyapunov 指数分别回答不同问题；相图相似并不能代替分布比较或证明长期统计相同。

有效性与局限

  • 实验只覆盖两个低维合成动力系统，观测基本无噪声，尚未验证高维、部分可观测、非平稳或真实实验数据。KAN 的架构、节点数和正则化会改变得到的表达式，不能据吸引子吻合便断言机制正确。
  • 吸引子图形相似可能掩盖局部向量场、瞬态或因果结构差异；正文中的生态模型 Lyapunov 谱也存在明显偏差。论文仅提供有限案例，不构成通用辨识或统计一致性保证。本卡未独立复现，单独补充材料未核验。
  • 若目标是科学发现而非仿真替代，还需要在观测域之外检验外推、干预响应和参数可辨识性，并用已知守恒律或对称性约束候选模型。否则一个统计上合格的 surrogate 仍可能给出错误机制解释。
