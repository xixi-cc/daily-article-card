Two failure modes of deep transformers and how to avoid them: a unified theory of signal propagation at initialisation

深层 Transformer 的两种初始化失效模式及规避：信号传播统一理论

Alessio Giorlandino、Sebastian Goldt · 预印本 · arXiv:2505.24333 · 论文原文 ↗

错误初始化会使 self-attention 产生两种不同问题：rank collapse 将所有 token 映射到近同一表征；entropy collapse 则让 attention 过度饱和、随机聚焦少数 token，训练不稳定。作者问如何以架构参数精确预测并同时避开它们。 两种风险不能互相抵消。

研究问题

  • 错误初始化会使 self-attention 产生两种不同问题：rank collapse 将所有 token 映射到近同一表征；entropy collapse 则让 attention 过度饱和、随机聚焦少数 token，训练不稳定。作者问如何以架构参数精确预测并同时避开它们。 两种风险不能互相抵消。

背景

  • 全连接网络的 edge-of-chaos 理论追踪两个输入的相似性；Transformer 还要处理序列 token、attention softmax、layer norm、skip 和 MLP。已有缩放规则不能给出包含常数的完整深度初始化处方。 因而仅用单一方差缩放不足以判断深层注意力是否稳定。

模型与方法

  • 论文在大宽度下解析 token cosine similarity、attention entropy 和反向梯度，通过与 Random Energy Model 的对应精确处理 attention。以 query/key weight scale beta 与 attention residual strength alpha 建立单层/多层 update map，再用算法生成 trainability diagrams；在 BERT/TinyStories 上检验。 具体地，作者以平均平方 token 范数 \(q\)、不同 token 的平均 overlap \(p\) 以及 \(rho=p\)/\(q\) 压缩表示几何；对每个 block 迭代 \(q\)、\(p\) 的更新。查询/键初始化取 \(sigma_{Q}^{2}=sigma_{K}^{2}=beta\)*sqrt(log \(T\))/\(d\)，并用 REM 的配分函数处理 softmax 的大偏差，而不是把 softmax 分子、分母分别取平均。临界尺度为 \(beta_{c}(q,p)=sqrt\)[2/(\(q\)(\(q\)-\(p\)))]；注意力行的二阶 inverse participation ratio 用来区分离域与局域 attention。残差则以 \(alpha_{\mathrm{SA}}\)、\(alpha_{\mathrm{MLP}}\) 的平方项加入 \(q\)、\(p\) 更新，最后扫描 beta 与 alpha 生成有限深度 trainability diagram。

核心结果与证据

  • Figure 1 显示低 beta 的均匀 attention 会产生 rank collapse，高 beta 的饱和 attention 产生 entropy collapse，中间配合足够 alpha 可训练。Figure 2 给单层 beta--rho 相图及有限宽仿真，Figure 3 显示大 beta 时 attention entropy 迅速趋零、低 beta 时 query gradient 消失。理论还预测 residual/gain 控制可阻断随深度 rho 到一的趋势，Figure 4 检验这一点。 单层结果给出清楚的两侧机制：beta<\(beta_{c}\) 时 attention 近乎均匀，输出趋向 token 平均，rho 饱和到 1；beta>\(beta_{c}\) 时 token 多样性未立即消失，但 IPR 非零，少数随机 key 主导，Shannon entropy 降低。Figure 2 用 \(d=512\)、\(T=1024\) 的模拟确认相图并显示临界附近的有限尺寸偏差。Figure 3 的单层 TinyStories masked-LM 实验取 \(beta_{c}(rho=0)=sqrt(2)\)，高 beta 的熵很快接近零；其 query-gradient 图在不同 \(T=2048\)/4096/8192、\(d=256\)/512/1024 下支持低 beta 梯度消失。Figure 1 的 60 层 BERT 则以 beta约0.02 的小方差和 \(alpha_{\mathrm{SA}}=1\).5或2 作为可训练案例，\(alpha_{\mathrm{SA}}=1.0\) 为 rank-collapse 案例；另以 12 层、\(beta=1.8\) 分离 entropy-collapse 的训练失败。

有效性与局限

  • 强项是把两类常被混淆的故障放到同一解析框架，并同时含前向和梯度条件。边界来自所用 Transformer、初始化分布和大宽度近似；有限尺寸在相变附近偏离，训练后动态不等同于初始化图。不同 causal/autoregressive 位置和优化器需另行检查。 结论描述的是初始化附近的平均信号传播；它没有取代以多种序列长度、随机种子和下游任务所做的稳健性检验。 临界结果是 \(d\),\(T\) 同时趋大、非因果序列并具有近似 simplex token 几何时的预测；有限 \(T\) 在 \(beta_{c}\)/2 之后已出现非 Gaussian 波动，论文明确将临界附近视为渐变 crossover。因果 Transformer 的早期 token 只有有限历史，不能用 \(q\)、\(p\) 两个量完整描述，理论主要近似较晚位置。高 beta 的 entropy collapse 也不能单靠增大 skip connection 消除。gain-controlled attention 的 30 层 TinyStories 结果被作者称为 preliminary，尚未构成大规模模型或不同数据集上的稳定性结论。

复现与资源

  • 复核可对给定 \(T\)、\(d\)、depth、alpha、beta 在随机初始化时测 token cosine、attention Shannon entropy 和 query gradient，再与 update map 比较。训练验证需固定 TinyStories、BERT 配置、learning rate 与 seeds，分开报告 rank/entropy 失败。本文卡未运行代码。 记录每层曲线而非只报末层，可以分辨渐进性 rank collapse 与单层 attention 饱和。 对 Figure 3 的最小复现，论文附录指定 1-layer、1-head masked-LM，TinyStories 掩码概率0.15、embedding dimension 768、AdamW learning rate 5e-4、batch size 64、1 epoch、weight decay 0.01、warmup ratio 0.05，并固定标准初始化给非 \(Q\)/\(K\) 权重。对 Figure 1 的 BERT 对照，使用 ReLU、6 attention heads、embedding dimension 600、absolute positions，并分别固定 beta、\(alpha_{\mathrm{SA}}\)、\(alpha_{\mathrm{MLP}}=1\)。数值检查还应记录每层 rho、attention entropy/IPR、\(Q\) gradient Frobenius norm 与训练 loss，而非只报告最终 loss；同时扫描 \(T\)、\(d\) 检验有限尺寸漂移。

阅读指南

  • 先读 Figure 1 分清两个 collapse；再读单层 Figure 2--3 了解 beta 的双侧风险；最后看深度传播与 gain-controlled 方案。不要将蓝色区域理解为任意训练设置的性能保证，它是初始化信号稳定性条件。 可把两条边界分别当成表示退化与注意力退化的诊断门槛。 这也是图的用途。 需交叉阅读。
