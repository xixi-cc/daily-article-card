Card 02 研究问题

研究问题

  • 大型推理模型在平面到平面（初态与目标态都可分散在三根柱上）的汉诺塔规划中经常失败。本文追问失败发生在哪里：模型从未形成世界状态，还是形成后在长链式推理中丢失？作者用可控的小 Transformer 建立机制证据，再把同一套几何 probe、activation patching 与 steering 用到两个开放权重推理模型。
Card 03 模型与方法

模型与方法

  • 小模型是 6 层、隐藏维 128、4 attention heads 的 GPT-2 式 decoder，仅在 move tokens 上计算交叉熵；训练数据为符号生成的四盘 flat-to-flat 最优轨迹。
  • 汉诺塔四盘共有 $3^4=81$ 个合法配置，状态图呈 Sierpiński 三角。distance-matching 线性 probe 将 residual state 投到二维，使欧氏距离拟合图最短路距离；另用逐盘三分类 probe 读取每个盘所在柱。
  • 在 SEP token 做 activation patching：把 clean 初态激活替换进 corrupted 初态，观察输出计划有多少盘的行为转移，以检验表示是否被因果使用。
  • 大模型实验使用 Qwen3.6-27B 与 DeepSeek-\(R_{1}\)-Distill-Qwen-32B，分别在 prompt 末端 A、承诺输出计划的位置 B、逐步发出 moves 的位置 \(C\) 探测状态。
  • steering 用外部符号 tracker 维护当前真实棋盘，在每个生成 token 向当前配置的 clean prompt activation 方向注入强度 $\alpha$；因此它是带 oracle state tracker 的因果干预，不是无辅助解题算法。
Card 04 核心结果与证据

核心结果与证据

  • 小模型达到 99.2% token-level、93.2% sequence-level 验证准确率；SEP 最佳层的几何 probe Spearman 约 0.94、Pearson 约 0.90，81 状态最近邻检索完全正确，图 3 重建 Sierpiński 结构。
  • SEP 处四个盘分类均为 100%；到 MOVE token，较大盘降到 90.70% 和 79.25%，平均 92.47%。activation patching 在各层以 64%–79% 的样本产生部分状态转移，平均转移约 1.44–1.46 个盘，说明表示不只是相关 probe。
  • 两大模型在 prompt 末端 A 都近乎完美：Qwen 中层 Spearman 0.935、最近状态准确率 1.00，DeepSeek 也达 0.936/1.00；但 Qwen flat-to-flat 只解对约 51%，表明“表示存在”不等于能维持并用于规划。
  • 表 4 中 Qwen 在 B 位置最近状态准确率降至约 0.75–0.83，逐盘 probe 接近随机；到 \(C\) 位置联合几何较弱而逐盘信息部分恢复，形成 planning 时统一表示→execution 时因子化表示的转移。
  • 对 Qwen 的失败样本 steering 在 $\alpha=2$ 时使 48 个失败中 26 个变为最优解，总体从 33/81（41%）升到 59/81（73%）；DeepSeek 最好仅修复 6/72，且 $\alpha$ 从 0.5 到 10 时 parse errors 从 29 增至 60，显示干预不跨模型稳定迁移。
Card 05 有效性与局限

有效性与局限

  • 除 baseline 外核心机制实验集中于 $n=4$ 汉诺塔；规则图高度几何化，结论是否适用于开放世界或连续状态尚未验证。
  • 两个大模型都来自 Qwen 系，不能代表所有架构与训练方案。
  • 多项图表基于单随机种子；probe 的线性可读性本身不是因果证据，作者依赖 patching/steering 补足但仍可能有非目标方向扰动。
  • steering 需要外部 tracker 知道每步真实状态，在状态昂贵或含糊的任务中不可直接使用。
  • Qwen 与 DeepSeek 的差异同时混入输出格式失败和表征对齐差异；作者将二者分离列为开放问题，并提醒状态 steering 可被用于非良性目标。
