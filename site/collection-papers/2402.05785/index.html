Limits of Transformer Language Models on Learning to Compose Algorithms

Transformer 语言模型学习算法组合的局限

Card 02 研究问题

研究问题

  • 若 Transformer 已从数据中学会组成算法的所有 primitive sub-tasks，它能否以更少额外样本复用这些 primitives 学会完整 composition？作者把可能性从 constant-shot \(H_{1}\) 排到最差的 \(H_{4}\)：composition 所需样本甚至超过分别从头学习各 subtask 的总和。
  • 研究同时比较 supervised LLaMA training 与 GPT-4/Gemini few-shot prompting，并问 gradient descent 记忆某些 feedforward/compositional concepts 是否存在一般 sample inefficiency。
Card 03 模型与方法

模型与方法

  • 构造 PEN、PERM、HSS、MUL 四类离散算法任务。每个程序被转换为 compositional graph \(G_{A}\)(\(x\))，edges 是 match、left/right、reverse、count、multiply 等 primitives；训练集可分别覆盖完整 task 与所有 subtasks。Figure 1 给出 PEN pseudo-code 到 graph 的映射。
  • 从头训练不同规模 LLaMA，扫描 task/subtask samples，比较达到高 accuracy 的 sample thresholds，并尝试 auxiliary prediction heads 暴露中间结果。GPT-4 与 Gemini-Pro 测试 zero/few-shot、task description、chain-of-thought、analogical CoT 和 code interpreter multi-round correction。
  • 理论部分从 complexity classes 与 gradient-descent learner 出发，构造可高效计算但在特定 feedforward memorization 设置下需要大量 examples 的 concept families，为经验 inefficiency 提供条件性支持。
Card 04 核心结果与证据

核心结果与证据

  • LLaMA 能分别把 primitives 学到接近完美，却在完整 composition 上需要更多数据；Figure 3 的四任务曲线使 \(H_{2}\)、\(H_{3}\) 不符，作者认为 \(H_{4}\) 最贴合：完整 task threshold 超过 subtask thresholds 之和。
  • 中间 auxiliary losses 没有把 composition sample complexity 降到 primitives reuse 的理想区间。GPT-4 与 Gemini 在 PEN/PERM 上即使给出强提示、CoT 或代码执行仍不稳定；某些失败来自无法可靠执行 primitive，另一些来自多步错误未被 correction loop 修复。
  • 理论结果说明‘可计算’不蕴含‘能被所假定 gradient-descent learner sample-efficiently 学会’，但它不是对实际 Transformer optimization 的 tight lower bound。实证与理论共同反驳本 benchmark 上的强组合泛化假设。
Card 05 有效性与局限

有效性与局限

  • 四类任务是受控 synthetic strings/programs，覆盖的 composition depth、primitive definitions 和 output formats 有限；结论不能直接等同于自然语言 reasoning、软件工程或人类算法学习。作者也未提出修复方案。
  • Sample threshold 依赖 tokenizer、model size、training curriculum、optimizer 和 success criterion。subtask 切分并非唯一；换一种 reusable interface 或显式 scratchpad 可能改变结果。proprietary GPT-4/Gemini 版本与 prompting 有时间依赖。
  • 理论针对特定 learner/complexity construction，不能证明所有 gradient methods 或 Transformers 的 unconditional lower bound。few-shot prompting failure 也不能排除更长 context、tools、fine-tuning 或 architecture priors；本卡未独立复现。
