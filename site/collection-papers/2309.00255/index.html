Card 02 研究问题

研究问题

  • 不同设备和任务需要不同计算预算，分别训练/存储许多模型代价高。已有 slimmable、early-exit、once-for-all 方法常限于特定架构/维度、子模型数量少，或需额外搜索与蒸馏。论文问能否用一个 checkpoint 同时训练大量可直接部署的子模型。
  • SortedNet 的目标是在宽度、深度、attention heads、embedding 等多个维度按预定义顺序截取参数，让计算预算对应唯一候选，并通过随机子模型训练维持主模型和子模型性能。
Card 03 模型与方法

模型与方法

  • sorted architecture 将每个目标维度的子模型固定从索引原点截取；它推广 nested architecture，因为跨多个维度组合后，子模型不必彼此全包含。训练前定义候选维度和采样分布，每步分别采样截断边界并取参数集合交集。
  • 更新有两种：stochastic loss 只训练本步抽到的子模型；stochastic summation 同时累加该模型及其目标子模型损失。共享参数接收来自不同预算路径的梯度，分类层默认共享。排序可依据计算量/预期精度，使推理时无需 NAS 搜索。
  • 评估包括 MobileNetV2/ResNet 的 CIFAR-10，BERT/RoBERTa 的 GLUE，以及 LLaMA-13B 的 GSM8K；还利用中间子模型做 confidence early exit 和 self-speculative decoding，由完整模型验证 draft tokens。
Card 04 核心结果与证据

核心结果与证据

  • Figure 2a 同时评估 160 个 MobileNetV2 宽度×深度子模型；普通只训练最大模型的 baseline 中许多子网低于 12%，SortedNet 的若干子网零样本保留最大模型性能的至少 96%，只排序宽度时最高约 99%。
  • 重新训练筛选出的较优子模型集合时，SortedNet 可保留独立最大模型约 99% 性能。Table 2 在 CIFAR-10 多宽度比较 SortedNet 与 Network Slimming、LCS-\(p\)、Universal Slimmable 等；结果支持该协议下的竞争力，但不同方法的归一化/蒸馏和训练预算需逐列核对。
  • BERT/RoBERTa 的 GLUE 子模型随可用深度增加而改善。LLaMA-13B/GSM8K 的 Table 4 报告 self-speculative/early-exit 组合接近约 2× 推理加速；这是特定硬件、batch、接受率和任务上的系统结果，不是所有生成设置的固定倍数。
Card 05 有效性与局限

有效性与局限

  • 160 个子模型共享一次训练不等于每个都达到独立最优；结果矩阵仍有较弱预算点，额外训练 classifier 可再提高约 2%–15%。候选排序和采样分布是超参数，若部署预算分布变化，训练资源可能分配不当。
  • 理论界比较共享子网与独立同构模型，在 Lipschitz gradient、相近梯度/参数等条件下控制差异；递推因子 (1+ηL) 本身可随步数放大，不能单独证明长期收敛或泛化。
  • 共享权重产生梯度冲突，论文的 stochastic accumulation 是经验缓解而非保证。推理加速依赖 draft/verify 成本和 token 接受率；模型存储减少也不自动意味着训练显存、总训练 FLOPs 或端侧延迟无开销。
