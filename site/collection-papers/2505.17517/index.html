The Spacetime of Diffusion Models: An Information Geometry Perspective

扩散模型的时空：信息几何视角

Rafal Karczewski、Markus Heinonen、Alison Pouplin、Soren Hauberg、Vikas Garg · 预印本 · arXiv:2505.17517 · 论文原文 ↗

如果把扩散模型的终端噪声 \(x_{T}\) 当 latent，并以 deterministic probability-flow ODE 作为 decoder，常规 pullback 度量能否得到有意义的数据内禀测地线？作者证明这种做法失败：latent 中的最短路解码后必为数据空间直线段，因而忽略模型学到的几何。替代问题是如何让“一个 latent 状态所代表的去噪分布”成为几何对象，并在全部噪声尺度上定义非退化、可计算的距离和最短编辑路径。

研究问题

  • 如果把扩散模型的终端噪声 \(x_{T}\) 当 latent，并以 deterministic probability-flow ODE 作为 decoder，常规 pullback 度量能否得到有意义的数据内禀测地线？作者证明这种做法失败：latent 中的最短路解码后必为数据空间直线段，因而忽略模型学到的几何。替代问题是如何让“一个 latent 状态所代表的去噪分布”成为几何对象，并在全部噪声尺度上定义非退化、可计算的距离和最短编辑路径。

背景

  • 扩散前向核把 clean data \(x_{0}\) 逐渐变为高斯噪声，采样可用随机 reverse SDE 或与其边缘分布一致的 deterministic PF-ODE。生成模型的 pullback geometry 通常将数据空间欧氏度量拉回 latent；但可逆确定 decoder 会使该结构仅是欧氏直线的坐标重写。随机 decoder 则给每个状态一个 \(p\)(\(x_{0}\)|\(x_{t}\))，可使用 Fisher-Rao 度量比较分布改变。困难是 \(x_{T}\) 近似无记忆，\(p\)(\(x_{0}\)|\(x_{T}\)) 对终端噪声几乎不变，Fisher metric 会塌缩为零。

模型与方法

  • 作者把 latent 从单一 \(x_{T}\) 提升为 \(z\)=\(x_{t},t\) 的 (\(D\)+1) 维 spacetime，代表所有噪声层级上的 denoising posterior。clean datum \(x\) 对应 (\(x\),0) 和 Dirac 后验。论文证明该去噪分布族是 exponential family，因而 Fisher-Rao 能量可改写为依赖 expectation parameter 的形式；该参数用 Tweedie 公式及近似 denoiser 估计，避免沿曲线反复运行 reverse SDE。数值上离散一条固定端点曲线，最小化 Fisher-Rao 能量求 geodesic；其长度定义为 Diffusion Edit Distance（DiffED）。同一几何还被加入方差或禁区约束，用于分子转变路径采样。

核心结果与证据

  • 第一，作者指出 PF-ODE pullback 的 geodesic 虽会在 noise space 弯曲，却在 data space 解码成直线，Figure 2 因而给出负面基线。第二，时空 Fisher-Rao 构造恢复非平凡结构，并通过 exponential-family 结论得到 simulation-free 曲线能量估计。Figure 4（第 8--9 页）展示不同 ImageNet 图像对的 geodesic：每条路径由清晰源图进入噪声态，再逐步去噪到目标，作者将其长度解释为最小总 edit cost。第三，Alanine Dipeptide 上 Figure 5--7 显示所求 geodesic 可作为 transition-path sampling 的骨架，并可加入低方差或避开限定区域的约束；论文称其结果与专用方法具有竞争性，而非证明普遍最优。

有效性与局限

  • 框架的清晰贡献是先严格否定一个诱人的 ODE pullback 解释，再以 stochastic posterior 的信息几何提出可计算替代；将时间纳入坐标也精确处理了终端无记忆的度量塌缩。限制同样明确：接近 clean endpoint 时 posterior 接近 Dirac，局部 KL/Fisher 距离数值上趋于无穷，实际优化须把端点放在非忽略噪声水平；DiffED 又明显慢于 LPIPS/SSIM 等相似度。exponential-family 与能量估计依赖文中的扩散模型、近似 score/denoiser 和离散优化，图像路径的“编辑”解释是作者的语义，不构成对人类感知距离的通用验证。

复现与资源

  • 论文给出代码链接 https://github.com/rafalkarczewski/spacetime-geometry。最小复核可从训练好的小型 score model 出发，比较 PF-ODE pullback path 解码后的直线性，再从多个 \(t\) 的后验估计 Fisher-Rao 能量。完整 DiffED 复核需记录噪声 schedule、denoiser、Tweedie expectation-parameter 近似、曲线节点数、端点最小噪声、能量优化器与收敛阈值；随后用相同 image pairs 比较 geodesic 长度而非只看中间帧。分子实验还须固定势能、数据预处理、约束函数和采样随机性。本卡仅核验 25 页 PDF、完整 MinerU Markdown 和已有渲染页，未运行仓库、生成路径或基准比较。

阅读指南

  • 先读第 2--4 节，把 PF-ODE、reverse SDE 和 decoder 的不同角色分开；尤其不要把“相同边缘分布”误读为“相同几何”。接着读第 5 节的 memorylessness 论证，理解为何必须用 \(x_{t},t\) 而非只用 \(x_{T}\)。然后以 Eq. (4) 和 exponential-family 能量推导检查何处节省了 reverse-SDE 采样。Figure 4 最适合直观看 DiffED，但需连同其定义和 Section 8 的端点不稳定/计算慢限制阅读。最后再看 Figure 5--7，把分子结果视为该几何的受控应用与约束能力展示，而非对所有 transition path 方法的覆盖性结论。
