Geometric Dynamics of Signal Propagation Predict Trainability of Transformers

信号传播的几何动力学预测 Transformer 可训练性

Card 02 研究问题

研究问题

  • 深 Transformer 初始化后，token 表示随层数传播时何时发生 rank collapse，何时保持区分性？同时，反向梯度何时消失或爆炸？论文试图用初始化时可算的少数序参量预测训练结束后的 test loss。
  • 作者把 \(n\) 个 token 看成嵌入空间中的相互作用粒子，将一层 Transformer 视为离散时间映射；问题于是转化为粒子构型的有序—混沌相变和切空间稳定性。
Card 03 背景

背景

  • token 几何由 Gram 矩阵 \(C_{ij}=X_i\cdot X_j\) 描述。置换对称初始化下，对角元为 \(q\)、非对角元为 \(p\)，原本 \(n(n+1)/2\) 个自由度缩成二维更新映射 \((q,p)\mapsto(q',p')\)。
  • attention 倾向平均 token 并造成低秩吸引，非线性 MLP 可产生排斥和角度放大。残差强度与权重方差因此充当控制参数，决定 line fixed point 与 regular-simplex fixed point 的稳定性。
Card 04 模型与方法

模型与方法

  • 模型含单头 self-attention、逐 token 两层 tanh MLP、token norm 与各自残差支路。权重取独立高斯系综，在宽度和 token 数较大时对随机参数平均，得到 \(q,p\) 的确定性层间映射。
  • angle Lyapunov exponent \(\lambda_a\) 测量构型离 rank-one fixed point 的角扰动每层增长率；gradient exponent \(\lambda_g\) 测量输入—输出 Jacobian 的 Frobenius norm 指数增长率。\(\lambda_a=0\) 是 forward edge of chaos，\(\lambda_g=0\) 是无梯度爆炸/消失边界。
  • 作者用随机深网络直接迭代检验解析相图，再在图像分类 Transformer 上扫 attention/MLP residual strength 和 MLP weight variance，比较初始化指数与训练后的 test loss。
Card 05 核心结果与证据

核心结果与证据

  • Figure 2 将解析更新方程的红色曲线/箭头与有限宽度数值轨迹叠加。不同初始化从 simplex-like 构型向 line collapse 或非零角 fixed point 演化，说明二维几何闭合不仅是定性比喻，也能追踪层间动力学。
  • 无 MLP 时，attention 使 token 吸引并趋于一条线；加入足够强的非线性 MLP 后出现 repulsive chaotic phase，token 接近 regular \(n\)-simplex。Figure 4/5 显示解析与数值的 \(\lambda_a\)、\(\lambda_g\) 等值线总体吻合。
  • 训练实验的低 test-loss 区域靠近两条零指数曲线的交点：只满足 edge of chaos 仍可能梯度爆炸，只满足 gradient criticality 仍可能 forward rank collapse。论文据此把“双临界”提出为初始化的必要且充分条件（在其模型族与实验范围内）。
Card 06 有效性与局限

有效性与局限

  • 解析闭合依赖随机独立权重、大宽度/大 \(n\)、置换对称与 attention 分母集中等假设；训练会破坏这些条件。Figure 3 支持局部吸引性，但不等于对任意语义相关 token 序列都严格成立。
  • 主理论使用单头、tanh MLP、简化 token norm 和 acausal attention；论文虽测试 causal attention，现代架构中的多头、GELU、LayerNorm 参数、RoPE、gating 与训练中相关性可能移动临界面。
  • 初始化指数与最终 loss 的关联来自有限架构和数据集扫描，不是对所有优化器、数据规模与任务的因果定理。该卡 no independent reproduction performed，未重跑相图或训练。

阅读指南
