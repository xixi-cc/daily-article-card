Regression as Classification: Influence of Task Formulation on Neural Network Features

将回归表述为分类：任务形式如何影响神经网络特征

作者信息

Card 02 研究问题

研究问题

  • 连续标签通常用平方损失回归，但实践中把标签离散成 bins、用交叉熵训练分类器，再取各 bin 中点的期望，有时反而更准。论文问：这种“binning phenomenon”能否由梯度优化的隐式偏置解释，而不只归因于损失曲线或正则化？
  • 作者聚焦带偏置的两层 ReLU 网络，把无限宽网络表示为特征空间上的向量测度。输入层神经元对应一维分段线性函数的 kink；回归与分类的隐式范数问题可能选择不同的最优 support，从而影响有限宽网络能否学到所需 kink。
Card 03 模型与方法

模型与方法

  • 有限网络 \(F(x)=\Sigma_{j}\) \(b_{j}\)(\(a_{j}^{\mathrm{Tx}}\))_+ 在无限宽极限写成单位球面上向量测度 \(\nu\) 的积分。回归的最小总变差插值问题要求 \(F\nu(x_{i})=y_{i}\)；分类的 margin 问题要求正确类别相对其余类别至少有指定间隔。
  • 对一维输入，作者把特征重新参数化为方向 s∈{-1,1} 与 kink 位置 c。定理构造回归 support \(R_{\mathrm{reg}}\)（分段线性插值斜率发生变化的点及端点）和分类 support \(R_{\mathrm{class}}\)（类别切换/bin 边界诱导的点）；两者可能差异很大。Figure 3 用 \(y\)=|\(x\)| 展示分类离散化会引入跨整个输入域的更多候选 kink。
  • 合成实验用多尺度三角形 teacher，50 个等宽 label bins，训练/验证各 250 点。比较 10,000 隐藏神经元的平方损失回归与 500 神经元、50 维输出的交叉熵分类；各做 30 次随机初始化和学习率扫描，分类输出通过 bin 中点期望还原连续值。
Card 04 核心结果与证据

核心结果与证据

  • 理论结果给出一维隐式偏置问题的稀疏最优 support：\(R_{\mathrm{reg}}\) 只在真实分段线性插值的斜率变化处需要特征，而 \(R_{\mathrm{class}}\) 还受每个类别边界和类别数 \(k\) 影响。它说明任务表述会改变被偏好的输入特征位置，但没有证明有限网络梯度下降一定到达这些最优测度。
  • 合成任务中，30 次初始化的回归 RMSE×10² 为 best 3.70、mean 4.55、worst 6.85；分类为 0.86、1.21、1.54，且方差更小。最差回归模型只恢复大三角形的 kink，遗漏小尺度 support；分类模型恢复更密集特征并降低误差。
  • 高维实验给出类似的临界线分布迹象，但主定理仍是一维。附录中三层回归网络没有出现同样欠拟合，说明现象不是“分类天然优于回归”，而是特定深度、数据几何、离散化与优化偏置的交互。
Card 05 有效性与局限

有效性与局限

  • 分析限于两层 ReLU 和与既有隐式偏置理论相近的最小范数问题；重参数化后总变差中出现的因子被作者为简化而忽略。最优 support 与实际有限网络训练困难之间只有经验联系，尚无定理保证何时平方损失会卡住。
  • 实验是人工一维 teacher，两个模型的隐藏宽度、输出维度和参数数不同，并分别调学习率；classification 使用 label order 不敏感的普通交叉熵，bin 邻接关系没有显式利用。bin 数、边界、解码规则和噪声都会改变结论，真实回归任务上是否获益需独立验证。
