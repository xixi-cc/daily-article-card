Closed-Form Interpretation of Neural Network Latent Spaces with Symbolic Gradients

作者信息

Card 02 研究问题

研究问题

  • 一个 latent neuron 可能编码概念 \(g\)(\(x\))，但通过未知可逆单调/非线性 \(\phi\) 变成 \(f\)(\(x\))=\(\phi\)(\(g\)(\(x\)))。直接用 symbolic regression 拟合 neuron value 会把 \(\phi\) 也拟合进去，复杂且常失败。作者问：能否在对 \(\phi\) 不变的等价类上搜索人类可读公式？
  • 关键观察是 \(\nabla f\)=\(\phi\)'(\(g\))\(\nabla g\)，因此归一化梯度方向在符号/尺度处理后与 \(g\) 的梯度共线。比较 gradient fields 可绕过 latent value 的非线性重参数化。
Card 03 模型与方法

模型与方法

  • 先用 Siamese/triplet network 学习对某个 transformation 保持不变的 latent，或从 autoencoder 等模型取目标 neuron。Figure 1a 展示 anchor/positive/negative shared-weight training；panel b 说明直接比较 latent values 与候选 equations会受非线性编码阻碍。
  • 候选 \(g\) 是由变量、常数和算子组成的 symbolic expression tree。对数据点自动微分 neuron \(f\) 与候选 \(g\)，比较 normalized gradients 的 MSE；genetic/symbolic search在 error 与 expression complexity 间形成 Pareto front。
  • 实验包含 matrix trace/determinant/eigen-related invariants、Hamiltonian systems 的 energy、spacetime quantities 等。Tables 1–3 对照 analytical 与 retrieved expressions，允许整体符号、尺度或单调等价。
Card 04 核心结果与证据

核心结果与证据

  • Figure 1 展示方法逻辑：latent scatter 对候选 values 可能没有线性关系，但正确 symbolic tree 的 gradient direction与 neuron一致。等价类 \(H\)-\(tilde_{g}\) 包含所有 \(f=\phi\)∘\(g\)，因此解释目标是找到同一 level-set geometry 的简单代表。
  • 在多项 matrix invariants 与 conserved quantities 上，Pareto fronts包含 analytical expression 或代数等价式；direct symbolic regression 对非线性 latent encoding 常失败。结果支持 gradient matching 对 scalar reparameterization 的鲁棒性。
  • 恢复成功依赖 latent 确实近似一维标量概念、候选 grammar含正确运算且 input gradients可辨识。相同 level sets 的公式只能确定到 reparameterization，不能声称恢复唯一物理单位或规范。
Card 05 有效性与局限

有效性与局限

  • Normalized gradient 在 ∥\(\nabla f\)∥或∥\(\nabla g\)∥接近零处不稳定；critical points、piecewise activations 和噪声会放大方向误差。若 \(\phi\)'变号或非可逆，简单等价论证失效。
  • 单个 neuron 可能混合多个概念，真实概念也可能分布在 subspace/manifold；逐 neuron scalar equation 无法覆盖这类 distributed representation。Symbolic search 的 grammar、complexity penalty 与预算决定可发现范围。
  • Siamese training 使用已知 positive transformations，已经注入 invariant supervision；方法说明如何读出，不证明网络从原始任务自发发现。实验以低维科学系统为主。本卡未独立复现。
