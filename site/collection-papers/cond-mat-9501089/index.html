Card 02 研究问题

研究问题

  • 系统从均匀相淬火到 broken-symmetry phase 后，domain 为什么通常只剩一个增长尺度 (\(\mathrm{L}(t)\))？如何由 conservation law、curvature、transport mechanism 与 defect dimensionality 推出 growth law，并预测 correlation/structure-factor scaling functions？
Card 03 背景

背景

  • 粗粒化自由能为 (F[\phi]=\int[\tfrac12(\nabla\phi)^2+V(\phi)]\(d^{\mathrm{dx}}\))。Model A 让 order parameter 局部弛豫，Model B 强制总 order parameter 守恒；相同静态自由能因此可产生不同动态指数。
  • 综述以 domain walls、vortices、strings、monopoles 等 topological defects 统一不同 (\(\mathrm{O}(n)\)) 模型；defect core 的短尺度结构决定高波数散射尾。
Card 04 模型与方法

模型与方法

  • dynamic-scaling hypothesis 写成 (\(C(r,t)=f(r/L)\))、(\(S(k,t)=L^{\mathrm{dg}}(kL)\))。作者结合界面运动、energy-dissipation scaling、exactly soluble limits、Gaussian auxiliary-field approximations 与 simulations/experiments，逐类建立 growth laws。
  • 非守恒 scalar 界面满足 Allen–Cahn (v=-\(K\))，给 (\(L\)\sim \(t^{1\)/2})。守恒 scalar 由 Gibbs–Thomson chemical potential 和 bulk diffusion 控制，给 (\(L\)\sim \(t^{1\)/3})。
Card 05 核心结果与证据

核心结果与证据

  • curvature-driven Model A domain 的 collapse time 随 (\(R^{2}\)) 缩放，因此 (\(\mathrm{L}(t)\)\sim \(t^{1\)/2})；守恒 Model B spherical domain 有 \(\dot R\sim-R^{-2}\)，因此 (\(\mathrm{L}(t)\)\sim \(t^{1\)/3})。这两个指数来自不同 transport constraints，而非不同 equilibrium phases。
  • generalized Porod law 对 scalar interfaces 给 (S(\(k\),\(t\))\sim[\(Lk^{d+1}\)]^{-1})；对 (\(\mathrm{O}(n)\)) defects 给 (S(\(k\),\(t\))\sim[\(L^{\mathrm{nk}}^{d+n}\)]^{-1})。tail exponent 直接记录 defect codimension。
  • 非守恒 vector systems 通常 (\(L\)\sim \(t^{1\)/2})，二维 XY 情形有 logarithmic correction (\(L\)\sim(\(t\)/\ln \(t\))^{1/2})。流体输运、非零 volume fraction、quenched disorder 或长程相互作用可引入 crossover 或改变增长律。
Card 06 有效性与局限

有效性与局限

  • 综述把 growth law、scaling function 和 defect scattering 连接起来，并持续用 exact result、approximation、simulation 与 experiment 交叉检查，而不把单一 closure 当成普适证明。
  • dynamic scaling 本身除简单模型外通常未被严格证明。OJK、Mazenko 等 Gaussian closures 可分别拟合某些 correlators，却可能无法同时给出 (\(C\)) 与四点函数的绝对幅度；守恒场的朴素近似甚至会错误地产生 (\(t^{1\)/4})，除非正确纳入 bulk diffusion。
