作者信息

Card 02 研究问题

研究问题

  • 视频生成需同时扩展时空 context、分辨率、identity consistency、instruction editing 与同步音频。论文问：能否以统一的 flow-matching Transformer/latent pipeline 训练基础 video model，再通过 post-training 分化出 personalization、editing 和 video-to-audio 能力？
Card 03 背景

背景

  • 原始 1080p 视频 token 数过大，Movie Gen 先用 temporal autoencoder 把时间/空间各压缩 8 倍，在 768 px latent 上生成，再用独立 spatial upsampler 到 1080p。最大 73K-token context 对应 256 frames，即 16 s、16 FPS。
  • Figure 1 直接展示 text-to-video、reference-image personalization、instruction editing 和 synchronized video-to-audio，是整套系统能力边界的最重要可视化。
Card 04 模型与方法

模型与方法

  • 30B Llama-style Transformer 以 flow matching 从 Gaussian latent 生成 image/video，线性路径写作 \(x_t=(1-t)\epsilon+t x\)；训练从 text-to-image 开始，再 joint image-video progressive resolution pretraining，最后用高 aesthetic/motion 数据 finetune。数据规模为约 100M video-text pairs 与 1B image-text pairs。
  • TAE 的时间压缩为 \(T_{\rm latent}=\lceil T_{\rm RGB}/8\rceil\)。personalization 用 reference identity post-training；editing 在缺少真实 edit-pair 数据时构造 synthetic paired supervision；13B audio model 在约 1M hours audio 上学习 text/video-conditioned waveform latent，并支持长视频分段 extension。
Card 05 核心结果与证据

核心结果与证据

  • Figure 1 用真实输出帧代替长篇能力罗列：同一组模型覆盖 prompt-conditioned motion、人物一致性、局部/全局 instruction edits，以及水声、雷声等同步谱图。
  • Movie Gen Video Bench 有 1,003 prompts，并公开 non-cherry-picked outputs。pairwise human evaluation 的 overall-quality net win rate 相对 Runway Gen3 为 35.02%，相对 Sora 为 8.23%（作者定义为 moderate），相对 Kling1.5 为 3.87%（on par）。
  • 1080p 是 768 px base output 经 separate upsampler 得到；16 s/16 FPS 是最大 context setting，不代表所有功能或 aspect ratios 都在该长度、分辨率、速度上统一评估。
Card 06 有效性与局限

有效性与局限

  • 模型权重、训练代码和训练数据未公开，论文主要可复核的是 benchmarks、样例与方法描述，而非 exact reproduction。internet-scale data 的来源/授权、人物 reference consent、deepfake 和 audio impersonation 都是系统级风险。
  • human A/B 受 prompt set、five-sample selection、downsampling 和 closed commercial baseline access 影响；net win rate 不是绝对质量。视频仍会在复杂 object interactions、physics、counting、文字和长时一致性上失败；Figure 1 是精选能力展示。
