Scan and Snap: Understanding Training Dynamics and Token Composition in 1-layer Transformer

扫描与冻结：理解单层 Transformer 的训练动力学和 token 组合

Paper Collection · Training Dynamics · 原文

作者：Yuandong Tian、Yiping Wang、Beidi Chen、Simon Du。arXiv:2305.16380v4。论文从 SGD 轨迹出发分析一个 self-attention 加 decoder 的单层 transformer，提出 attention 先“扫描”判别性 token、后在相变处近似“冻结”的机制。

Card 01 作者信息

作者信息

  • 作者：Yuandong Tian、Yiping Wang、Beidi Chen、Simon Du。arXiv:2305.16380v4。论文从 SGD 轨迹出发分析一个 self-attention 加 decoder 的单层 transformer，提出 attention 先“扫描”判别性 token、后在相变处近似“冻结”的机制。
Card 02 研究问题

研究问题

  • next-token loss 如何从均匀初始化中塑造 token composition？作者关心 attention 是否偏向对某个输出类别独有的 distinct tokens、抑制跨多个输出共有的 common tokens，以及这种稀疏选择是否最终退化为 winner-takes-all。
  • 分析假设无 positional encoding、序列长度趋于无穷、decoder 学得显著快于 attention，并把 token embeddings 诱导的矩阵重新参数化为可独立研究的 \(Y\)、\(Z\)；它不是对一般多层 LLM 训练的完整定理。
Card 03 模型与方法

模型与方法

  • 数据由 sequence classes 生成：给定 query token \(m\) 和待预测 token \(n\)，上下文 token l 服从 P(l|\(m\),\(n\))。若 l 只与一个 \(n\) 共现则为 distinct token；若跨多个 \(n\) 出现则为 common token。attention score 是该共现频率与可学习 logit exp(\(z_{\mathrm{ml}}\)) 的乘积再归一化。
  • 模型用一层 softmax attention、LayerNorm 和线性 decoder，在 cross-entropy 下做 batch-size-one SGD 理论分析。作者先求出快变量 decoder 的反传梯度，再推导慢变量 attention logits 的相对增长率、common-token 抑制与 distinct-token 之间的频率排序。
  • 理论把轨迹分为两段：早期 decoder 梯度增强，attention 扫描并稀疏化；约在 \(t_{0}\)=O(\(K\) log \(M\)/ηY) 后 decoder 接近高置信度，反传速度下降，attention 只按对数速度变化，视觉上形成固定 token mixture。
Card 04 核心结果与证据

核心结果与证据

  • Theorems 1–2 给出 discriminative bias：common tokens 因对多个输出类别贡献相互竞争而被系统性压低，distinct tokens 获得正相对增益。对同一类别的 distinct tokens，共现概率较高者更早占优，形成 frequency bias。
  • Theorem 3 描述 scan-and-snap 相变：attention 早期向少数高频 distinct tokens 集中，却在 decoder 学习使梯度衰减后停止快速尖化，而非达到 one-hot stationary point。Figure 2(\(d\)) 显示冻结后蓝色 distinct-token 组合仍保留多个非零成分，黄色 common tokens 接近被抑制。
  • Syn-Small/Syn-Medium 实验复现了学习率控制：固定 attention 学习率时，提高 decoder 学习率会更早 snap 并留下更稠密组合；提高 attention 相对学习率则得到更稀疏表示。WikiText2 的一层和三层模型也显示底层 attention 随训练稀疏并近似冻结，但真实语料实验只支持现象，不验证所有生成模型假设。
  • Adam 会随学习率选择不同 distinct-token subsets，论文将其视为可调归纳偏置，但没有给出 Adam 对应理论。
Card 05 有效性与局限

有效性与局限

  • 无位置编码与 \(T\)→∞ 使 token 频率等于条件概率，排除了顺序、有限样本涨落和长程结构；ηY≫ηZ 的双时间尺度也不代表常见端到端超参数。\(Y\)/\(Z\) 独立参数化忽略共享 embedding 低秩约束，理论初始化为零而实际只近似均值为零。
  • distinct/common 是相对数据分布的标签：小数据可能把偶然 token 误判为 distinct。WikiText 可视化没有建立 token 语义、预测因果贡献或下游性能之间的定量链条；多层模型的层间 token composition 也未被理论覆盖。
