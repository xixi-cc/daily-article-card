Card 02 研究问题

研究问题

  • HEP analysis 要把物理目标翻译为 selection、BOSS/ROOT code、distributed jobs、fits、systematics 与 branching fraction。论文问多智能体能否在无人手写代码情况下执行这条真实 pipeline，并得到与已发表/基准一致的结果。
  • 可靠性瓶颈不仅是物理知识，还包括 schema-compliant tool calls、远程环境、长期任务状态、particle naming 和失败恢复；因此评价必须落到 sub-task 与最终物理量。
Card 03 背景

背景

  • 分支比测量通常由 signal yield、efficiency、parent count 与子衰变 branching fractions 组合；任何 selection、MC truth matching 或 fit model 错误都会系统性偏移。LLM 的流畅解释不能替代 execution receipts。
  • Dr.Sai 把 host orchestration、agent reasoning、data/storage、tools 与 remote worker 分层，并用 HEP-RAG 与形式化 HepScript 限制自由文本到可执行分析动作的映射。
Card 04 模型与方法

模型与方法

  • Figure 1 中 Host/Planner/Coder/Tester/Calculator/Reflector 六角色共享 task scheduler、memory 与 data layer；工具层连接 code worker、BOSS/ROOT、monitoring 和 distributed storage。
  • 任务按 DAG/层级系统拆分，runtime snapshots 与 logs 支持异步长任务恢复；particle spelling database 与 anchor-word mechanism 处理 HEP 术语，HepScript 将 selection/fit 步骤结构化。
  • 验证重测 10 个 J/psi decay channels，覆盖普通、BNV 与 CLFV 类型；另用多种 LLM、不同 retry/reflection budgets 统计 sub-task success、failure modes 与 token cost。
Card 05 核心结果与证据

核心结果与证据

  • Figure 1 明确 scientific control plane：LLM 不直接伪装成 detector expert，而通过受限工具、memory 和 worker 执行可检查步骤；这也是系统可审计性的主要来源。
  • Dr.Sai 在真实 BESIII environment 自动完成 10 个 branching-fraction remeasurements，结果与 established benchmarks 一致；但“一致”应按每通道 uncertainty、selection 与 fit outputs 逐项读，而不是只看总体成功。
  • 性能研究显示适度 reflection 提升多数模型可靠性，但收益依赖 baseline tool proficiency。主要失败集中在 tool initiation 与 structured arguments；GPT-4o 较善启动但会在复杂参数 schema 出错，过多 reasoning 不能弥补 functional-call weakness。
Card 06 有效性与局限

有效性与局限

  • 10 个已知测量是 retrospective benchmark，不等于发现未知物理；published answers、analysis conventions 与 RAG 可能提供强先验。真正 autonomous discovery 还需 blinded signal regions 和 pre-registered validation。
  • 结果依赖 BESIII-specific BOSS、data access、MC、fit models 和人工构建工具/RAG；系统成功不是单一 LLM 的功劳。外推到其他实验需重新建立 domain constraints。
  • 论文的 retry success 和 token cost 不代表 physics correctness；必须保存 job outputs、plots、fit covariance、systematics 和 human sign-off。该卡 no independent reproduction performed。
