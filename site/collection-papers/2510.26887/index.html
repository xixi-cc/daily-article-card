The Denario project: Deep knowledge AI agents for scientific discovery

Card 02 研究问题

研究问题

  • Denario 问的是工程与认识论的组合问题：多智能体系统能否把 idea、文献新颖性检查、方法规划、代码执行、绘图、论文写作与同行式评审串成可组合工作流，并在多个科学领域产出可由专家审阅的研究对象？
  • 评价对象不是单次问答质量，而是一条长因果链。任何早期文献遗漏、数据误读或代码错误都可能在后续图表和论文中被语言模型包装成连贯叙事，因此模块接口、记录和人类验证比文风更关键。
Card 03 背景

背景

  • 端到端 AI scientist 系统通常同时承担提出假设、选择方法和解释结果，失败难以归因。Denario 采用模块化设计，使每个阶段既可单独调用，也可由 Cmbagent deep-research backend 规划和控制。
  • 论文把科学工作视为带反馈的状态机：输入文本/数据进入若干 agentic modules，模块内部可有 propose–critique 或 planner–executor 循环，产物以 Markdown、代码、plots 与 PDF 形式传给下一阶段。
Card 04 模型与方法

模型与方法

  • 系统包含 Idea、Literature、Methods、Results、Paper、Reviewer 等模块。Idea 用 idea maker 与 idea hater 迭代；Literature 可向 Semantic Scholar 反复查询直到给出 new/not-new 判断；Methods 形成计划；Results 写并执行代码；Paper 组织文本与图；Reviewer 读取 PDF 页面并输出评审。
  • Planning & Control 维护任务图和执行状态，允许模块交换消息与返回局部产物。多种 LLM 可作为底层，具体模型、prompt、API 与外部检索服务构成实验条件，而不是可忽略的实现细节。
  • 论文展示 13 个跨学科生成研究案例，并邀请相应领域专家按 context understanding、methods、insights、novel analysis 等维度给分并写 review-like feedback；同时专门列出 failure modes、伦理和科学哲学讨论。
Card 05 核心结果与证据

核心结果与证据

  • Figure 1 给出最简系统图像：输入文字与数据进入橙色系统边界，多个可嵌套模块通过蓝色消息边通信并产生多个输出。它说明 Denario 的核心不是单一“大 agent”，而是带显式边界的异质工作单元。
  • 作者报告系统能从数学物理、行星科学、医学、化学到天体物理生成完整分析和论文；附录公开这些产物，使读者能检查其论证、代码和图，而不仅接受总体分数。
  • 专家评价呈现明显任务依赖。材料科学热图中 context understanding 强，但 methods、insights 与 novel analysis 随 prompt 下降；各示例 review 同时指出合理结构与具体科学缺陷。这支持“可产生有用候选研究”，并不支持“自治地产生可靠发现”。
Card 06 有效性与局限

有效性与局限

  • 13 个案例不是预注册随机基准，领域、prompt、模型和展示选择可能带来 selection bias；专家人数、标度校准和 inter-rater reliability 也不足以把分数解释为总体成功率。
  • 系统使用外部文献 API、LLM 与代码执行环境，版本漂移会改变输出。语言模型能够形成可信叙事，却不能自动保证数据 provenance、统计检验、单位、边界条件或引用真实性；Reviewer module 与生成器共享模型家族时还可能共享盲点。
  • 主文诚实讨论 hallucination、错误传播、资源成本、双重用途、署名和科学劳动结构。对任何真实科研采用，都应保留人工课题所有权、可追溯中间产物和独立复核。该卡 no independent reproduction performed，未执行 Denario。

Card 08 阅读指南

阅读指南

  • 先看 Figures 1–3 与 Table 1 锁定模块和控制流，再抽查一个附录论文的输入—方法—代码—图—结论链；最后读 Section 6 的 failure modes 与 Section 7 的伦理/认识论，而不要只浏览成功案例。
  • 面向物理学家，建议把 Denario 当作实验控制系统而非作者主体：每个 agent 输出都是待校准的仪器读数，只有 provenance、独立检验与可否证预测闭合后才构成科学证据。
