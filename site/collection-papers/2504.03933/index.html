Language Models Are Implicitly Continuous

语言模型在隐式上是连续的

Card 01 作者信息

作者信息

  • Samuele Marro 等六位作者研究 Transformer 是否在离散 token 之间形成平滑、连续的隐式函数表示，并给出时空连续扩展，arXiv:2504.03933v1。
Card 02 研究问题

研究问题

  • 语言数据以 token 序列离散呈现，但神经网络是连续函数逼近器。模型在 token 位置之间或 embedding 邻域中是否定义出有结构的连续插值？
  • 作者区分时间连续：token 持续区间与非整数位置；空间连续：embedding/句子输入可取中间值，并问多个现代 LLM 是否共享。
Card 03 模型与方法

模型与方法

  • 把离散句子嵌入连续时间阶梯函数，再定义输入和输出的连续 extension；在位置/embedding 间插值，观察 logits、hidden states 和语言行为的平滑性。
  • 在 Llama2/3、Phi3、Gemma/2、Mistral 等模型上测试连续采样与理论性质，并形式化扩展 Transformer 的 attention/position 机制。
Card 04 核心结果与证据

核心结果与证据

  • 多模型在所测插值上呈系统性平滑变化，支持其隐式表示连续函数而非只在离散点任意取值。
  • Figure 1 给出连续化构造；实验展示非整数时间或空间中间输入仍产生结构化输出，并讨论语言/工程应用。
  • 连续性主要来自模型映射与选定插值路径；embedding 空间中间点未必对应人类可解释句子，平滑也不等于“像人一样推理”。
Card 05 有效性与局限

有效性与局限

  • 不同 tokenizer、position encoding、normalization 与插值路径会定义不同连续扩展；数学上网络连续可能是架构平凡性质，语义意义需额外证明。
  • 局部平滑不能保证全局语义拓扑，跨 token 边界或远距离插值可能穿越分布外区域。
  • 论文给出的图形、相关性或有限规模干预只支持其明示范围；跨数据、架构、模型规模与训练制度时需要重新验证。本卡未独立复现，不能把受控实验直接提升为普适机制。
  • 对结论做强审计时，应设置能产生相似表面指标的替代机制、匹配参数量与计算预算、报告失败案例和置信区间，并检查阈值、归一化、样本选择及评价器是否预先偏向作者假说。
  • 若论文声称发现机制，还应要求前向预测新的干预结果，而不只事后解释已有曲线；至少应在未用于选择假说的数据、不同随机种子和合理替代基线上保持。
  • 此外应明确负结果的含义：未观察到效应可能来自统计功效、测量误差或实现差异，不能自动当作理论反证；观察到效应也需排除共同原因。
