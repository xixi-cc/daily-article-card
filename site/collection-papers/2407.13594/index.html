Card 02 研究问题

研究问题

  • 机制解释常用电路、features 或手写程序描述网络计算，但“解释有效”往往只靠任务表现或局部干预。两个内部机制不同的模型可在数据上 extensionally equivalent，因此只验证输入输出可能接受错误解释。
  • 论文问：若把神经网络分解为 concrete components、把解释分解为 abstract components，并在每层之间放置 abstraction/concretization maps，哪些组合一致性条件足以区分局部语义是否真正对应？
Card 03 模型与方法

模型与方法

  • Concrete network description \(d_{t}\) 与 human-readable abstract description \(d_{h}\) 都是组件序列。Abstraction \(\alpha_{i}\) 把第 i 层 concrete state 映到 abstract state；concretization \(\gamma_{i}\) 提供反向对应。公理要求初始抽象正确、每一步近似 commuting、最终输出一致，并加入可组合性、reconstruction 与非平凡性条件。
  • 每条 probabilistic axiom 在输入分布 \(D\) 上允许误差 \(\epsilon\)。验证可通过 sampling 或 formal methods；失败位置指出哪一层抽象没有保持语义，而不只是最终答案不对。
  • 作者在训练的 2-SAT Transformer 上提出 parser、clause representation 与 classifier 的解释，并对 modular addition 的既有机制解释做验证；附录给出 attention、QK decomposition、neuron decision trees 与 abstract operators。
Card 04 核心结果与证据

核心结果与证据

  • Figure 4a 是 extensional-equivalence 反例中的 concrete ground-truth computation：内部先分别求倒数，再比较。另一个 abstract model 可在测试输入上输出相同结果，却通过不同内部路径；只做 causal scrubbing/input-output check 可能无法区分。公理要求中间 abstraction maps 逐组件对齐。
  • 2-SAT 案例中，第一 block attention 表现出四-token clause 周期，第二 literal positions 聚合 clause 信息；第二 block/readout 再分类。作者用公理定位哪些 parser/neuron interpretations 通过，哪些仅在总体 accuracy 上看似合理。
  • 该框架把解释验证从单个 scalar faithfulness 变成一组可归因义务。它并不自动生成解释，也不保证所选 abstract vocabulary 对人有意义；它验证的是给定解释相对模型、分解和分布的结构一致性。
Card 05 有效性与局限

有效性与局限

  • 公理依赖用户选择的 component boundaries、\(\alpha\)/\(\gamma\) maps 与输入分布；不同分解可能让同一解释通过或失败。高概率验证不是全域证明，分布外输入仍可能破坏 commuting。
  • Abstract states 可被设计得过细而复制网络，也可过粗而失去内容；非平凡性与 reconstruction 约束缓解但不消除“编码答案”的投机解释。Formal verification 对大模型可能不可扩展。
  • 实证集中于小型 algorithmic Transformers，2-SAT 和 modular addition 的内部变量可手工定义；扩展到自然语言与多层大模型需要自动抽象、统计置信界和更强 human-meaning criteria。本卡未独立复现。
