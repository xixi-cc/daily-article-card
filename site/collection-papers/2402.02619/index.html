作者信息

Card 02 研究问题

研究问题

  • 一个低损失 Transformer 在多位加减法中究竟实现了什么算法？仅凭线性 probes 或 attention patterns，容易把相关节点误认为完整机制；长 carry/borrow cascades 提供了可系统攻击候选算法的边界案例。
  • 作者希望同时建立逻辑证据（候选 sub-tasks 能对所有 \(n\)-digit inputs 给出正确输出）与机械证据（模型内部节点和 edges 因果执行这些 sub-tasks），并比较不同 seed、深度、位数和加/减/混合训练的共性。
Card 03 模型与方法

模型与方法

  • 从头训练 2–3 层、3–4 头、约千万参数的小 Transformer，任务覆盖 5–15 位 addition、subtraction 或 mixed arithmetic。早期模型暴露长 carry/borrow failures 后，训练分布加入对应 edge cases；多数模型在单 GPU 一小时内达到 >99.999% accuracy。
  • 不先假定小学从右向左算法，而是从 internals 定义 SA/SC/ST 等 single-digit quantities 和 SV/MV 等多位不确定 carry/borrow。TriAdd 从当前位向左逐步消除 U，形成符合 autoregressive causal order 的 left-to-right exact algorithm。
  • 对 46 个模型做节点映射，29 个高准确模型形成 family-level circuit skeleton；代表模型再用 activation patching、edge/path patching、matched controls 与 alternative-mechanism ablations 检验 resolved-carry subtask。
Card 04 核心结果与证据

核心结果与证据

  • Figure 1 展示 addition 算法：各位先把 carry 状态分类为 0、1 或 uncertain U，后续 token 逐步用更低位信息把 U 解为确定 SV，再计算 answer digit。对应 subtraction 用 cascading borrow MV 决定符号和 digits。
  • 29 个 >99.999% 模型共享 sub-task/circuit skeleton，但具体 heads/MLPs 的分配可随 seed、depth 和 operation 改变。worked examples 中，patching 对 resolved-carry nodes/paths 给出 causal effects，matched controls 排除若干仅相关解释。
  • mixed models 的部分节点对 addition 与 subtraction 呈 polysemantic；从 addition weights 初始化和从 scratch 训练都可形成共同 skeleton。论文把结论限定为该受控模型家族，而非声称所有语言模型采用同一算术算法。
Card 05 有效性与局限

有效性与局限

  • 精确算法由模型分析启发但经数学 soundness 检查；这证明该算法能完成任务，不自动证明每个模型唯一实现它。family map 和 causal interventions 增强机械归因，但完整 edge-level sufficiency 只在少数 worked examples 深挖。
  • 模型小、tokenization 固定、数据合成且任务窄；对预训练 LLM、不同数字编码、乘除法或自然语言算术没有 transfer claim。训练集 edge enrichment 改变了最易学 mechanism，可能不是自然分布下的算法。
  • Patching 依赖替换分布与 control design，polysemantic nodes 使单节点标签近似。>99.999% 仍非形式化零错误；逻辑算法 soundness 与模型 empirical accuracy 必须分开。本卡未独立训练或复现 causal analysis。
