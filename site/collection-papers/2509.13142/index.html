Formalizing dimensional analysis using the Lean theorem prover

用 Lean 定理证明器形式化量纲分析

Dimensional analysis is fundamental to the formulation and validation of physical laws, ensuring that equations are dimensionally homogeneous and scientifically meaningful. In this work, we use Lean 4 to formalize the mathematics of dimensional analysis. We define physical dimensions as mappings from base dimensions to exponents, prove that they form an Abelian group under multiplication, and implement derived dimensions and dimensional homogeneity theorems. Building on this foundation, we introduce a definition of physical variables that combines numeric values with dimensions, extend the framework to incorporate SI base units and fundamental constants, and implement the Buckingham Pi Theorem. 摘要

Card 03 背景

背景

  • 普通编程语言和 CAS 已能做单位检查或 Buckingham Pi 计算，但作者指出此前实现没有同时形式化量纲的代数结构、物理变量运算和定理级正确性。Lean 的 kernel 可检查每个通过解析的证明，使“公式能运行”与“量纲关系已证明”分开。
  • 论文区分 physical quantity、physical variable、unit 与 dimension；物理变量抽象为 P=⟨V,\(D\)⟩，算符分别作用在数值和量纲上（正文 pp. 2–3, Eqs. 1–2）。
Card 04 模型与方法

模型与方法

  • 核心类型为 dimension B E := \(B \to E\)，其中 E 满足 CommRing；抽象的 B 允许用户定义 ISQ、kinematic 或自定义基量纲系统（\(p\). 4）。
  • 乘除法对应指数逐项加减，单位量纲是零映射，逆元是指数取负；作者把这些实例接入 Lean type classes，并证明量纲在乘法下满足结合律、单位元、逆元和交换律（pp. 4–8）。
  • PhysicalVariable 把值与量纲绑定；同量纲变量可加减，不同量纲变量通过乘除和幂运算生成新类型。自定义 cast 与 tactic 自动证明形式不同但逐基量纲相等的表达式（pp. 8–12）。
  • 补充材料把 Buckingham Pi 写成量纲矩阵的 kernel：Pi 群数量 \(p=n\)−rank，具体无量纲组合来自矩阵核（SI pp. 17–18, Eqs. 9–11）。
Card 05 核心结果与证据

核心结果与证据

  • Lennard–Jones 势 V=4ε[(\(\sigma\)/\(r\))^12−(\(\sigma\)/\(r\))^6] 被编码为输出 energy 量纲的函数；类型系统自动处理 (\(\sigma\)/\(r\)) 的无量纲幂与 energy×dimensionless 的转换（\(p\). 14, Eq. 8）。
  • 作者给出 \(LJ_{\mathrm{zero}}_{\mathrm{energy}}\) 定理：当 \(r=\sigma\) 且 \(\sigma\).\(value\ne 0\) 时，势能等于零；另一个定理形式化势能对距离的导数，并得到 force 量纲的解析表达式（\(p\). 14）。
  • 正文结论还包括 derived dimensions、dimensional homogeneity theorem、SI units/fundamental constants 与可复用代码库；证据是 Lean 源码链接和文中展示的定理陈述。
  • 结论类型：代数性质与示例定理是 kernel 检查的形式化证明；“可作为未来形式化科学基础”是作者的工程展望，不是已完成的大规模用户研究。
Card 06 有效性与局限

有效性与局限

  • 量纲正确只是物理正确的必要条件，不能证明方程描述现实，也不能检查模型假设、近似、边界条件或参数有效区间。
  • 框架依赖用户正确声明基量纲、指数类型、单位和物理变量；错误的语义建模仍可能得到内部一致的证明。
  • Lennard–Jones 案例证明了零点与导数关系，但论文没有给出与主流单位库的性能、可用性或大型科学代码迁移 benchmark。
  • Buckingham Pi 的矩阵核给出无量纲组合空间，但具体选择并不唯一；形式化结果也不自动决定哪些 Pi 群最有物理解释力。
