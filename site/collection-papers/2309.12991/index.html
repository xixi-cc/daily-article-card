Deep learning probability flows and entropy production rates in active matter

用深度学习研究活性物质中的概率流与熵产生率

Paper Collection · Active Matter · 原文

稳态 Fokker–Planck current 与 probability-flow velocity 满足 \[j=b\rho-D\nabla\rho,\qquad v=\frac{j}{\rho}=b-D\nabla\log\rho.\] 因此在 drift $b$ 与 diffusion $D$ 已知时，网络只需从 SDE 样本学习 score $\nabla\log\rho$，即可闭合 probability flow 及相应的局部/全局 entropy production。 作者把 score matching 与 stationary score-FPE residual 合并，并构造 permutation-equivariant particle transformer；大系统只关注每粒子及 64 个近邻，使同一权重可用于不同 N。 从两粒子可视化、64 粒子 harmonic trap 到 4096 粒子 MIPS，结果显示熵产生集中于 cluster–gas interface；MIPS 网络零微调迁移到 N=32768 和多 packing fractions。

Card 02 摘要

摘要

  • 稳态 Fokker–Planck current 与 probability-flow velocity 满足
  • \[j=b\rho-D\nabla\rho,\qquad v=\frac{j}{\rho}=b-D\nabla\log\rho.\]
  • 因此在 drift $b$ 与 diffusion $D$ 已知时，网络只需从 SDE 样本学习 score $\nabla\log\rho$，即可闭合 probability flow 及相应的局部/全局 entropy production。
  • 作者把 score matching 与 stationary score-FPE residual 合并，并构造 permutation-equivariant particle transformer；大系统只关注每粒子及 64 个近邻，使同一权重可用于不同 \(N\)。
  • 从两粒子可视化、64 粒子 harmonic trap 到 4096 粒子 MIPS，结果显示熵产生集中于 cluster–gas interface；MIPS 网络零微调迁移到 \(N=32768\) 和多 packing fractions。
Card 03 背景

背景

  • 全局 EPR 可从 forward/reverse path measure 的 KL 定义，但 active-particle time reversal 选择有争议且只给一个标量；直接 microscopic density 又随 \(N\) 进入高维。
  • 稳态仍可有 \(j\ne 0\)：probability-flow ODE \(Rdot=v(R)\) 确定性地沿 current 搬运样本并保持 \(\rho\)，不应与原随机 SDE trajectories 混同。
  • 系统 EPR \(sdot_{\mathrm{sys}}\)(\(r\))=∇·v(\(r\)) 可逐点正负交替，稳态平均 Eρ[∇·v]=0；total EPR density |v|²_{\(D^{-1}}\) 非负，平均后给所选 reverse process 的 global EPR。
Card 04 模型与方法

模型与方法

  • Hyvärinen score-matching objective 为
  • \[\mathcal L_{\mathrm{SM}}(h)=\mathbb E_\rho[\lVert h\rVert^2+2\nabla\!\cdot h].\]
  • 在论文采用的正则性与边界条件下，其 population minimizer 是 score；附加的 $\mathcal L_{\mathrm{FPE}}=\mathbb E_\rho[(\nabla\!\cdot\hat v+\hat v\!\cdot h)^2]$ 约束 stationary FPE，实验通常取 $\lambda_1=\lambda_2=1$。
  • validation 包含 FPE residual、score-matching integration-by-parts identity 和 Eρ[∇·v]=0；这些是必要 internal consistency checks，但不是有真值 score 时的独立误差。
  • 网络分别嵌入位置 \(x_{i}\) 与取向 \(g_{i}\)，以多头 self-attention 学粒子交互，再用 shared particle-wise decoder 输出 equivariant score；直接输出 score 而非 scalar logρ gradient，减少高阶 autodiff。
  • 64 粒子 thermal case 用 Boltzmann-informed initialization：在 \(v_{0}=0\) 的精确 equilibrium score 上学习 correction。MIPS 为 \(\epsilon=0\)，stationary position density singular 且尺度分离严重，因此只用 denoising loss 学 \(g\)-score。
  • MIPS local transformer 对每粒子只输入其 64 nearest neighbors，并在 particles 上 batching；局部性/weight sharing 让参数量不随总 \(N\) 变化。
Card 05 核心结果与证据

核心结果与证据

  • 两粒子 ring 的 Figures 2–3 可与低维 density/current 真值对照：probability-flow limit cycles 连接碰撞 modes；system EPR 在碰撞/分离区正负交替，样本平均约 10^-3、相对标准差很小。
  • 64 粒子 trap 的 Figures 5–6：\(v_{0}=0\) 时网络恢复 equilibrium signal；随 activity 增大，取向 EPR 与 total EPR 主要形成 cluster 边缘 ring，而非均匀分布。
  • attention rollout 显示网络学习 spatially local、略长于 direct force cutoff 的邻域；这支持近邻 ansatz，但 attention weight 不是因果相互作用测量。
  • MIPS Figure 7：取向 probability-flow magnitude 与 system EPR 主要集中于 dilute/condensed interface，也在 gas collisions 出现 pockets，与 coarse-grained 理论预期一致。
  • Figures 8–10/\(S_{9}\)–\(S_{11}\)：只在 \(N=4096\)、\(\phi=0.5\) 训练的模型直接用于 \(N\le 32768\) 与 \(\phi=0.01\)…0.9，输出随无 cluster→碰撞 \(gas\to interface\to dense\) cluster 呈物理一致形态。
  • 这里的 transfer 证据主要是守恒诊断和结构可视化，没有在目标 \(N\)/\(\phi\) 上可得的 exact score 或独立 EPR ground truth，因此“正确泛化”仍是物理一致而非误差界。
Card 06 有效性与局限

有效性与局限

  • global EPR Eq. (19) 要求 \(D\) invertible 和特定 reverse-time dynamics；MIPS 取 \(\epsilon=0\) 时 \(D\) 在位置分量奇异，不能无条件套用完整 \(D^{-1}\) total-EPR 公式。
  • MIPS 实际只学习 \(\nabla g\) logρ；position score 被热噪声 denoising 绕开，所以展示的是取向 probability flow/EPR 的丰富部分，不是完整 microscopic score reconstruction。
  • Eρ[∇·v]=0、FPE residual 等可被近似模型同时满足而仍有局部误差；大 \(N\) 没有 independent solver/reference density，缺少定量 external validation。
  • local 64-neighbor ansatz适合短程排斥与 MIPS；有长程 hydrodynamic/alignment interactions 或不同 density 时固定邻域可能截断重要信息。
  • 只研究无 alignment 的 active OU particles；Vicsek-type alignment、实验测量噪声、部分观测和未知 drift 都列在覆盖范围之外。
Card 07 复现与资源

复现与资源

  • 两粒子/64 粒子必须保存 SDE discretization、force smoothing、burn-in、sampling lag、activity sweep、score/FPE 两项 loss 与每项 diagnostic distribution。
  • 64 粒子：Euler–Maruyama \(\Deltat=10^-3\)、\(\epsilon=\gamma=0.1\)、\(T=200\)、10^7 trajectories，RAdam batch 64、250k iterations；4-layer/4-head、embedding 256，每 run 单 \(A_{100}\) 约 48 \(h\)。
  • MIPS：\(\epsilon=0\)、\(\gamma=10^-4\)、\(\Deltat=0.1\)、\(v_{0}=0.025\)、\(\phi=0.5\)；12 初态热化至 1/\(\gamma\) 后各取 10,000 samples、lag 20，生成每条约 RTX8000 24 \(h\)。
  • MIPS training 固定 64 neighbors、batch 1024 particles、denoising \(\sigma=0.01\)、500k steps、peak lr 10^-6、单 \(A_{100}\) 24 \(h\)；目标 \(N\)/\(\phi\) 不做微调。
