Counting in Small Transformers: The Delicate Interplay between Attention and Feed-Forward Layers

小型 Transformer 中的计数：注意力与前馈层的微妙协作

Card 01 作者信息

作者信息

  • Freya Behrens、Luca Biggio 与 Lenka Zdeborová，来自 EPFL 等机构。论文发表于 ICML 2025，以 histogram task 分析单层 Transformer 中 token mixing、embedding dimension \(d\) 与 FFN hidden size \(p\) 的协作。arXiv:2407.11542v3。
Card 02 研究问题

研究问题

  • 给定长度 \(L\) 的 token sequence，histogram task 要在每个位置输出该 token 在全序列出现的次数。任务简单但同时需要比较 token identity、跨位置聚合与离散计数，适合分离 attention 与 feed-forward layer 的职责。
  • 作者比较 dot-product attention、带 BOS 的 attention 与 content-independent linear mixing，并切换 softmax；问不同架构会学到何种计数策略、最小 embedding/FFN capacity 如何依赖 vocabulary \(T\)。
Card 03 模型与方法

模型与方法

  • 模型是一层非自回归 Transformer block：token embeddings 经 mixing matrix A 聚合，再残差连接到每个位置，逐 token FFN 输出 count class。实验固定 \(T=32\)、\(L=10\)，网格扫描 \(d\),\(p\) 从 1 到 128，每个配置 5 seeds。
  • 作者推导两类策略。Relation-based counting 让 attention 比较 query token 与其他 tokens，通过同/异 token overlap 或 BOS softmax weight 编码 count；FFN 只需解码一维计数方向，因此 \(p\) 可很小。Inventory-based counting 则把每个 vocabulary item 的数量分别存进 representation，通常需要 \(d\) 或 \(p\) 随 \(T\) 扩展。
  • 机制核查包括 embedding cosine overlaps、attention matrices、BOS contribution、FFN response curves 与 trained-regime heatmaps；附录还测试 frozen random embeddings 和 Mistral/Llama prompting。
Card 04 核心结果与证据

核心结果与证据

  • Figure 1 的六个 \(d\)×\(p\) heatmaps 显示清晰相边界：BOS+softmax 在较大 \(d\) 时可用极小 \(p\) 达到高精度，符合 relation-based strategy；linear mixing 和部分 dot variants 更依赖 \(p\ge T\) 或 \(d\ge T\) 的 inventory capacity。Softmax 会同时帮助 BOS 归一化策略并破坏某些可直接读 count magnitude 的方向。
  • Figure 3 对一个 \(p=2\)、\(d=45\) 的 BOS+softmax 模型做 introspection：same/different/BOS embeddings 的 overlap 分离，BOS attention weight 随 query token count 变化，FFN 基本只沿这一标量方向划分 1…\(L\)，达到 99.9%。
  • Figure 4 展示 inventory-based models 的 attention/representation 把 token-specific counts 写入多个方向，由 FFN 充当 look-up/readout。理论显式构造与经验 regime 大体一致，但训练能否找到某一策略仍受初始化和优化影响。
Card 05 有效性与局限

有效性与局限

  • 主模型仅一层、无 causal mask、无 positional encoding、固定短序列与合成 iid tokens；现代 decoder LLM 的多层 residual computation 和自回归输出可能实现不同算法。
  • Heatmap 星号表示 5 runs 中至少一次达到 100%，点表示至少一次超过 99%；均值颜色与 best-run marker 必须一起读，不能把可达性当作稳定训练概率。理论 capacity construction 也不等于 SGD 隐式偏置。
  • 附录对 7B/8B LLM 的 counting prompts 是有限样本、特定 prompt 与 temperature-zero 诊断，不能直接比较一般算术能力。Relation/inventory 是有证据支持的两类机制，不保证穷尽所有混合策略。本卡未独立复现。
