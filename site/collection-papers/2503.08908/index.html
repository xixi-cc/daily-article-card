Card 02 研究问题

研究问题

  • 许多 LLM 无法无限重复一个词，而会突然输出无关文本；这种可由普通用户触发的失效来自 tokenizer/采样，还是内部 attention dynamics 的结构性变化？
  • 作者特别检验重复 token 自身是否变成或扰乱 attention sink，造成 residual norms、位置关注和输出 logits 的级联偏移。
Card 03 模型与方法

模型与方法

  • 在多种开源 LLM、tokens、长度和 prompts 上测量 failure point，记录逐层逐头注意力、BoS 与重复 token 表征范数，并与自然文本基线比较。
  • 通过消融/替换关键 attention links、sink token 和激活来测试因果关系；比较模型、token frequency 与位置因素，区分共同模式与个别实现。
Card 04 核心结果与证据

核心结果与证据

  • Figure 1 的平均注意力图显示重复序列产生显著 sink 结构；随长度增长，重复 token 表征范数与初始 token 关系异常，并在失败前后发生转变。
  • 对相关 attention 组件的干预能改变或推迟失效，提供比相关热图更强的因果证据。现象连接了重复任务 vulnerability 与维持正常流畅生成的 attention-sink 机制。
  • 失败并非所有 token/模型同一阈值出现，且 greedy/sampling、上下文模板和位置编码会影响结果。
Card 05 有效性与局限

有效性与局限

  • 重复单词是极端分布外输入；其机制不应直接外推到普通 repetition、长上下文退化或所有 jailbreak。attention weight 本身也不是完整因果解释。
  • 模型权重闭源或版本更新会改变阈值；安全含义是可触发行为偏离，不等于现实攻击危害已被量化。
  • 这些结论针对论文所测的受控数据、架构与优化设置；跨模型、跨任务或跨尺度使用时必须重新验证，不能把相关性、可视化或有限样本结果直接解释为普适机制。本卡未独立复现。
