PURE: Turning Polysemantic Neurons Into Pure Features by Identifying Relevant Circuits

PURE：通过识别相关回路把多义神经元拆成纯特征

作者信息

Card 02 研究问题

研究问题

  • 单 neuron 的 maximally activating images 往往混有无关语义，例如同一 unit 同时响应 hairy dogs 与 maze patterns。只按 activation magnitude 对样本聚类，得到的是输入外观群组，不一定定位到网络内部实现各语义的不同 subgraphs。
  • PURE 假设每个‘pure feature’对应独特 functional circuit，而 polysemanticity 来自多个 circuits 共享目标 node。研究问题是：能否用对目标 neuron 的 partial backward attribution，按 lower-layer functional connectivity 聚类，从一个实际 neuron 定义多个可在测试时激活的 virtual neurons？
Card 03 模型与方法

模型与方法

  • 把 circuit 表示为跨相邻 layers 的 relevance-message DAG。对目标 neuron 的 \(n_{\mathrm{ref}}=100\) 个最高激活 ImageNet test samples，使用 Layer-wise Relevance Propagation (LRP) 把该 neuron activation 逐层分配到 lower neurons；聚合 messages 得到每个样本的 circuit/node-attribution vector。
  • 对 reference attribution vectors 做 \(k\)-means，文中常取两个 clusters。每个 cluster 定义一个 virtual pure neuron 及其 reference centroid；新 test sample 先计算同类 attribution vector，再分配给最近 circuit。为生成 feature visualization，作者裁剪 neuron-relevant image patches。
  • 实验扫描 ImageNet-pretrained ResNet-34/50/101 的 penultimate-layer neurons。评估以 CLIP embedding 衡量 purified reference sets 内部距离、clusters 间距离，并用 DINOv2 作替代 foundation embedding；对照包括按原 neuron activations 或 image embeddings 直接聚类。
Card 04 核心结果与证据

核心结果与证据

  • Figure 1 的 neuron 2 同时由 maze 与 hairy-dog patches 激活；PURE 识别两组 circuits 后，virtual neuron 2a 的 top patches 主要是 dogs，2b 主要是 maze。Figure 3 给出不同 polysemanticity 程度下的 UMAP/reference sets，展示 purification 不是只在单一例子上定义。
  • Figure 4 报告用 CLIP feature-visualization distance 衡量时，PURE 在若干设置下得到更紧的 within-cluster 与更分离的 semantics，并优于 activation-based clustering；作者也指出收益对 semantics 是否 localized、目标 neuron 和 cluster choice 有差异。
  • 方法没有修改原模型或声称发现唯一因果 circuit：virtual neurons 是 post-hoc sample assignment。它的价值在于把‘目标 neuron 激活了什么’换成‘激活目标 neuron 时，下游到上游的 functional connectivity 属于哪一类’。
Card 05 有效性与局限

有效性与局限

  • 核心假设——每个 monosemantic feature 有唯一/可聚类 circuit——未由实验普遍证明；同一语义可能由多个冗余 circuits 实现，不同语义也可能共享大部分路径。\(k\)-means 和预设 cluster number 会把连续变化强制离散化。
  • 所谓 interpretability improvement 主要由 CLIP/DINOv2 embeddings 代理，而不是 human rating 或 controlled ground-truth concepts。Foundation models 自身的 bias、texture sensitivity 与 semantic geometry 会进入评价；作者在 Limitations 中明确提出需要 human feedback。
  • 实验仅覆盖 ImageNet ResNets 的 penultimate layer；向 Transformers/LLMs、早期 convolution layers 或 recurrent computation 外推未经验证。每个 test sample 需要 partial backward pass，计算成本高于 activation clustering。本卡未独立复现。
