Sloth: scaling laws for LLM skills to predict multi-benchmark performance across families

Sloth：用 LLM 潜在技能缩放律预测跨家族多基准表现

Paper Collection · AI Agents · 原文

作者信息

Card 02 研究问题

研究问题

  • 单 benchmark scaling law 浪费跨任务相关结构，也难预测同一模型在多指标上的表现。是否存在低维 latent skills，共同生成知识、推理、指令遵循等 benchmark scores？
  • 若 skill 而非每个 benchmark 独立缩放，能否跨模型家族共享规律、估计 instruction tuning 的技能增量，并预测复杂下游任务或未测模型？
Card 03 模型与方法

模型与方法

  • Sloth 类似带结构约束的 factor model：benchmark score 由 loading matrix \(\Lambda\) 组合多个 latent skill，加 family-specific intercept；skill level 再由 log model size、training tokens 等输入的平滑 scaling function产生。
  • 模型联合拟合公开 LLM families 的规模、token 与多 benchmark 数据，用 held-out family/model 预测 MAE 评价；对照包括只用 size、tokens 或逐 benchmark regression。Figure 1 汇总家族内预测误差。
  • 通过 loadings 给潜在维度解释性命名，如 knowledge、reasoning、instruction following；再比较 base/instruction-tuned 配对的 skill shift，并将预测 skill 输入下游回归。
Card 04 核心结果与证据

核心结果与证据

  • Sloth 的平均 MAE 与直接使用 size+tokens 的强基线相当或更低，说明跨 benchmark 的低维结构提供有效 inductive bias；但并非每列/每家族都最好。
  • Figure 2 的 loadings 显示不同 benchmark 混合依赖多个 skills；Figure 4 中 reasoning 对 model size 更敏感，knowledge 对输入总体更陡。Instruction tuning 对 instruction-following skill 的增益远大于仅扩大 size/tokens 带来的变化。
  • 共享 intercept 版本提供更 family-independent 的曲线，但家族特定训练数据、architecture 与评测污染仍可能被 intercept/skill 吸收。下游预测示例展示可用性，不构成对所有新家族的保证。
Card 05 有效性与局限

有效性与局限

  • latent skills 的旋转/可辨识性有限，给维度命名依赖 loading pattern 与研究者判断；相同预测可由不同因子分解近似实现。Benchmark 饱和、离散分数和缺失数据也影响拟合。
  • 公开参数量与 token 数常不准确，训练数据质量、mixture、architecture、compute 与 post-training 未被完全观测；family intercept 会提高拟合，却可能削弱真正跨家族外推。
  • benchmark contamination 和共同题型会制造相关性，潜在维度不必对应模型内部机制。模型选择与置信区间应与 point MAE 一起报告。本卡未独立复现。
