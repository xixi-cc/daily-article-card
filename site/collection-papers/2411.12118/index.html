Card 02 研究问题

研究问题

  • 单层 attention 可直接检索共享 token，但链式问题要求先找到一个关系，再用中间答案触发下一次检索。Transformer 如何通过多层 head 组合实现这种条件信息流？
  • 随着检索链深度 \(D\) 增大，任务对层数有什么下界；各条 attention path 是同时形成，还是沿较短子问题到完整链呈现 implicit curriculum 和 apparent emergent jump？
Card 03 模型与方法

模型与方法

  • 作者定义 retrieval 与 conditional retrieval 数据。后者加入 intermediate context（IC）版本，使每个链位置可有局部监督/可解子目标；无 IC 版本用于比较。Figure 1 给出两类问题例子。
  • 理论上根据初始 token/position embedding 的共享信息图，计算在每一层 attention 后哪些位置可能获得哪些变量，从而给出完成 \(D\)-step chain 所需层数。
  • 实验训练不同层数的 Transformer，记录总 validation loss 和每个链位置 partial loss；对 12/24 层模型用 attention 路径、平均权重和 ablation 逆向工程电路，并记录各路径越过 0.5 阈值的 epoch。
Card 04 核心结果与证据

核心结果与证据

  • 大语言模型在直接 retrieval 上表现较好，但 conditional retrieval 更难，说明仅有局部模式匹配不足。合成实验显示层数不足时特定链位置无法解决，符合信息流分析。
  • 有 IC 时，训练往往按链位置逐步改善：浅层/短路径先学会，随后更深 stacked heads 形成完整 retrieval circuit。Figure 7 把逆向工程路径与各 attention path 的出现 epoch 对齐。
  • 总体 loss 可能在最后必要路径形成时突然下降，看似 emergent ability；partial losses 揭示此前已有渐进子能力。这支持“聚合指标造成突变表象”的解释，但只针对设计的链式任务。
Card 05 有效性与局限

有效性与局限

  • 信息流下界建立在简化 attention、token 与位置共享图上；MLP 记忆、连续 superposition、更多 heads 或不同 positional encoding 可能绕开离散路径计数。阈值化 attention 也会遗漏弱而协同的连接。
  • IC 提供额外结构，implicit curriculum 可能是数据设计的直接结果。自然语言中的 retrieval chain 更嘈杂，模型可利用语义先验和训练记忆，而非相同 stacked circuit。
  • 电路逆向工程基于有限 runs 和 seed；attention weight 高不等于因果必要，需 activation/path patching 验证。本卡未独立复现。
