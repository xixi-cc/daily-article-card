Complexity Matters: Dynamics of Feature Learning in the Presence of Spurious Correlations

复杂度很重要：伪相关存在时的特征学习动力学

作者信息

Card 02 研究问题

研究问题

  • 常见叙述把伪特征视为‘比核心特征容易’，但容易的含义、相关强度 \(\lambda\) 和 feature complexity 如何共同改变 gradient descent dynamics 并不清楚。本文问：伪特征更简单或与标签更相关时，核心特征的收敛会怎样改变？网络内部是否形成相互分离的 core/spurious subnetworks？
  • 第二个问题直接关系到 debiasing：若伪特征只在 early phase 短暂出现，JTT/SPARE 一类早期识别策略可能有效；若伪与核心学习阶段重叠，且伪权重在核心已学会后仍保留，这一假设就会失效。
Card 03 模型与方法

模型与方法

  • 作者构造 Boolean Spurious Features Dataset，把输入拆成互不重叠的 core coordinates \(x_{c}\)、spurious coordinates \(x_{s}\) 与无关 coordinates。标签由 balanced Boolean core function \(f_{c}\) 决定；以概率 \(\lambda\) 令 \(f_{s}\)(\(x_{s}\)) 与 \(f_{c}\)(\(x_{c}\)) 同号，以 1−\(\lambda\) 令两者异号。\(\lambda=0.5\) 表示无相关，\(\lambda\) 越接近 1 表示 confounder 越强。
  • 复杂度通过 parity degree 或 staircase Fourier learning order 控制。实验测量模型输出与 \(f_{c}\)/\(f_{s}\) 的 correlation、从 hidden representation 线性解码出的 correlation、达到 0.95 core correlation 所需 epochs，以及单神经元权重轨迹。覆盖小型 MLP、CIFAR-MNIST Domino、Waterbirds，并比较随机初始化与 ImageNet 预训练。
  • 理论部分聚焦 one-hidden-layer ReLU 学习 XOR/parity 的受控情形，在假定 core 与 spurious neuron groups 保持分离等条件下分析 margin/weight dynamics；它解释若 \(\lambda\) 较大，spurious weights 为什么不会在 core confident 后自动消失，以及平衡数据重训最后层为何能减弱它们。
Card 04 核心结果与证据

核心结果与证据

  • Figure 3 显示在固定 core \(degree=10\) 时，\(\lambda\) 越强，达到 0.95 core correlation 的时间快速上升；更简单的伪 parity 或 staircase 也更显著拖慢 core learning。每根柱来自 30 次重复，支持‘复杂度与相关强度共同控制收敛’而非只有相关强度。
  • Figure 2/4 的输出、解码和 neuron trajectories 表明网络会形成以 core coordinates 或 spurious coordinates 为主的两类子网络；但 staircase 与真实图像组合中，两种特征的学习阶段未必清晰分离。Figure 5 进一步显示低 \(\lambda\) 时伪 decoded correlation 可能回落，高 \(\lambda\) 时则持续保留。
  • Figure 6 的对照指出，依赖 early spurious spike 识别 minority examples 的 JTT/SPARE 在简单 parity 情形更成功，在复杂 staircase/Domino 上受限。Figure 7 与理论分析支持 balanced retraining 尤其在高 \(\lambda\)、core margin 较弱时降低 spurious margin；这是一项机制解释，不等于对所有真实数据的普遍最优保证。
Card 05 有效性与局限

有效性与局限

  • 合成数据刻意令 core 与 spurious coordinates 完全分离，并用 parity/staircase 的训练次序代表复杂度；真实特征可能共享像素、语义和因果路径，无法唯一拆成两个 Boolean functions。Domino/Waterbirds 是补充证据，但不足以校准这一抽象。
  • 理论不是完整 end-to-end proof：作者明确假设部分未知 feature-learning 行为，尤其 core/spurious subnetworks 始终分离仍难严格证明。有限数据、optimizer、width/depth、pretraining 会改变动力学；附录也显示预训练模型对 \(\lambda\) 与伪复杂度更不敏感。
  • ‘spurious’由实验构造定义，并不意味着所有相关特征都应删除。约 2,500 GPU-hours 的大量扫描提高内部稳定性，但本卡未独立复现；0.95 threshold、hyperparameters 与选取的 decoder 仍可能影响时间尺度比较。
