HarnessWAM: Bridging Prediction and Deliberation in World Action Models

HarnessWAM：弥合世界动作模型的预测与审议鸿沟

World Action Models provide finite-horizon prediction and local control but do not by themselves maintain global task state, verify outcomes, or recover across long embodied episodes. HarnessWAM adds a model-external VLM Task Manager with evidence-grounded scene belief and a structured task graph, projects open-ended plans into the validated skill interface of the WAM, and coordinates execution through a fast progress loop and event-triggered slow deliberation. With a fixed LingBot-VA checkpoint in controlled comparisons, the framework reaches 59.6% full-task and 69.9% subtask success on RoboMemArena; it reaches 23.7% on RoboCerebra Ideal. Ablations identify executable-space projection as the largest contributor, while task state, progress events, semantic verification, and local embodiment recovery make separable contributions.

Card 03 背景

背景

  • WAM联合未来观测、环境状态与动作生成，擅长短时物理预测和局部操作，但不显式保存跨阶段证据。
  • 抽屉关闭后，当前图像不再显示此前内容；若只依赖当前帧，未观察与已观察为空会被混淆。
  • 数字agent常有离散工具和明确反馈，物理环境却连续、部分可观测且可能发生不可逆变化，因此需要显式状态与能力边界。
  • 论文的核心主张不是修改WAM权重，而是检验外部运行时能否把同一局部策略组织成长程行为。
Card 04 模型与方法

模型与方法

  • 事件状态z_k=(\(B_{k}\),\(G_{k}\),\(M_{k}\),\(r_{k}\))分别保存scene belief、task graph、task memory与active-skill execution state；harness在事件时刻更新状态并选下一个局部目标。
  • scene fact写成subject、predicate、object、value、epistemic status、confidence与RGB evidence引用，明确区分observed、inferred和unknown。
  • task graph节点包含operation、typed arguments、preconditions、effects、termination与recovery，并允许unresolved symbolic variables延迟到证据充分时绑定。
  • capability-conditioned projection检查primitive能力、参数类型、依赖、holding/embodiment state和当前场景，只允许改写尚未执行的graph suffix。
  • 快循环由WAM action chunks与progress estimator组成；估计器读取最近5步双视角RGB和skill instruction。慢循环只在milestone、failure、budget或binding变化等语义事件触发VLM。
  • progress只提出candidate event，不能单独推进task graph；Task Manager还需按当前RGB、历史、belief和预期effect做semantic verification。
  • 每个motor node保存初始arm与gripper状态；局部失败时先恢复embodiment state、清除局部WAM history，再保留全局scene knowledge修订剩余计划。
Card 05 核心结果与证据

核心结果与证据

  • RoboMemArena含26个长程任务，平均1076 environment steps，68.9%的subtasks依赖历史；四类为transfer、occlusion、counting与sequence。
  • 每个任务20 rollouts，并匹配initial states、random seeds、observation interfaces和task-level budgets；同WAM诊断与消融共享同一LingBot-VA checkpoint。
  • Table 1中HarnessWAM平均SRtask/SRsub为59.6/69.9，比公开PrediMem高21.1/14.7个百分点；与同checkpoint的Static Plan相比高11.7/7.9点。
  • 四类中相对Static Plan的full-task提升在occlusion为16.8点、sequence为12.5点；counting的subtask下降1.9点但full-task上升6.4点，显示局部完成率与正确组合不同。
  • Table 2在RoboCerebra Ideal给23.70%，高于GPT-4o Planner + OpenVLA的21.92%和HPE的21.10%；这是公开方法间比较，不等同同checkpoint控制实验。
  • Table 3移除executable projection后平均full/subtask由59.6/69.9降至18.5/38.3，为最大消融；移除progress events降至38.3/50.7，移除task state降至47.7/61.1。
  • progress-only switching仍有68.4% subtask却仅55.4% full-task；sequence上97.9% subtask对应72.5% full-task，支持语义结果验证不能由进度阈值替代。
  • 移除recovery使平均full/subtask下降5.4/2.2点；该消融把failure后的恢复改为终止，因此测得的是完整恢复机制的边际作用。
  • Table 4中raw VLM plan的executability仅13.8%；normalization后42.3%，完整projection后72.9%，同时dependency satisfaction由67.5%升至92.9%。
  • Figure 3展示探索三个抽屉、保存非空顶层抽屉证据、重新打开并放入cookie的单个代表性rollout，是机制示意而非成功率统计。
Card 06 有效性与局限

有效性与局限

  • 最强因果证据来自共享LingBot-VA权重、初始状态和seeds的内部变体；与PrediMem、π0.5等公开数字仍可能受模型、训练数据和评测实现差异影响。
  • RoboMemArena与RoboCerebra均为benchmark结果；论文把real-world manipulation列为未来方向，不能据此声称真实机器人部署已经验证。
  • Task Manager固定为Qwen3-VL-32B-Instruct，未给不同VLM规模、成本、延迟或故障模式的系统敏感性分析。
  • progress estimator有专门训练目标与episode-level split，但正文未报告其单独校准误差、误报漏报或跨域泛化。
  • 恢复依赖保存的arm/gripper state并回到局部初态；在不可逆接触、碰撞或场景物体已变化时不保证安全或可恢复。
  • 有限task graph与bounded budget保证终止，不保证成功；59.6%的full-task也意味着约四成RoboMemArena rollout未完成。
  • 计划质量Table 4使用reference decompositions做离线节点/依赖分析，虽不馈入在线agent，仍与最终环境成功不同。
  • 全文没有给统计置信区间或显著性检验；20 rollouts/task提供重复，但表中仅报告macro averages。
  • 开放的primitive ontology受WAM训练分布约束，增加新技能仍需先验证能力与control interface。
  • 作者未在正文提供代码仓库链接；可复现性依赖LingBot-VA checkpoint、benchmark环境、Task Manager prompts和progress-estimator训练数据是否公开。
Card 07 复现与资源

复现与资源

  • 冻结每个benchmark的LingBot-VA checkpoint，并为Whole Task、Static Plan、HarnessWAM及五个消融复用相同initial states、20 seeds、observation interface和budget。
  • 保存每个事件的RGB引用、scene facts、confidence、symbol bindings、graph revision、retry count、progress trace和Task Manager decision，而不只保存最终success。
  • 分别实现SRtask乘积式全任务判据、macro-average SRsub以及RoboCerebra key-state completion，避免混用指标。
  • 检查progress predictions永不直接推进graph；必须有语义outcome verification，并记录候选事件到最终decision的对应关系。
  • projection复现实验按raw、normalization、full constraints三阶段保存syntax、dependency、binding和executability，核对Table 4。
  • 恢复实验保存节点初始q/\(u\)、failure frame、restore trajectory、清空的local state与保留的global memory，以判断恢复是否真正归因于机制。
  • 对公开基线仅复述论文表格，不把其视作同配置复现；优先报告同checkpoint的Whole Task和Static Plan差值。
