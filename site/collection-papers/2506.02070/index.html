  • 生成模型的共同任务是把易采样的初始分布 p_init 输运到数据分布 p_data。流匹配和扩散看似使用不同训练目标与采样器，能否在概率路径、连续性方程和随机微分方程的统一语言中推导？

Card 03 背景

背景

  • 确定性 flow 由速度场 u_t(x) 生成微分同胚，密度满足 continuity equation；diffusion 则在 drift 上叠加 Brownian noise，密度满足 Fokker–Planck equation。两者都是对概率分布随时间演化的动力学描述。
  • 困难不在指定端点，而在构造中间概率路径 p_t 及其可学习速度/score。直接拟合边缘场通常不可得，conditional path 则以单个数据 z 为终点，允许解析写出 target，再通过条件期望恢复 marginal field。
Card 04 模型与方法

模型与方法

  • Figure 4 用图像直观展示 Gaussian conditional path：t=0 是噪声，t=1 收缩到数据样本。教程随后区分 conditional 与 marginal probability path，并证明用 conditional vector field 做均方回归与边缘 flow matching 具有相同梯度。
  • ODE 采样积分 dX_t=u_t(X_t)dt；SDE 采样加入扩散项，并可借助 score 在保持同一边缘分布族的前提下改变 stochasticity。Diffusion 的 denoising、noise prediction 与 score prediction 被写成等价参数化，差异主要是时间权重和数值条件数。
  • 后半部分把 classifier-free guidance 解释为放大 conditional 与 unconditional vector fields 的差，讨论 latent autoencoder、U-Net/DiT、attention、time/text conditioning、训练配方和视频生成。

Card 06 有效性与局限

有效性与局限

  • 统一框架依赖连续时间、足够正则的密度与向量场；真实网络只近似 target，有限步 ODE/SDE solver 会产生离散化误差，路径选择还强烈影响训练方差和采样刚性。
  • conditional flow matching 的目标等价是期望意义上的，不能保证有限容量网络、有限数据和特定优化器达到相同边缘场。classifier-free guidance 改善条件一致性通常牺牲 diversity，并会把 score/model error 放大。
  • 教程覆盖面广，某些架构和系统细节必然随代际变化；读者应把数学骨架与具体模型名称分开。该卡 no independent reproduction performed。
