Card 02 研究问题

研究问题

  • 高维输入的可能组合数随层级深度指数增长，但 CNN 往往用远少于穷举所需的样本学习。论文问：哪些低阶统计信号使网络逐层发现等价的“同义”子结构，并给出所需样本数的标度？
  • 作者希望把“深度学习组合结构”从直觉变成可测 order parameter：交换同义子结构时，隐藏表示的敏感度何时下降？
Card 03 背景

背景

  • Random Hierarchy Model 从类别 alpha 出发，每层随机选择 \(m\) 个等价表示，每个父 feature 再由 s 个低层 feature 组合，重复 \(L\) 层得到长度 \(s^{L}\) 的输入。词表大小 v、类别数 nc、同义数 \(m\) 控制冗余和难度。
  • 尽管单个输入维数和规则空间巨大，随机 composition rules 在低层 patch 与类别之间产生微弱相关；当样本涨到相关信号超过 sampling noise 时，网络可先学低层同义不变性，再向上组合。
Card 04 模型与方法

模型与方法

  • 作者训练深度 \(L\)+1 的 CNN，并比较 shallow fully-connected 与 uncorrelated RHM。test error 给出任务学习转变，synonymic sensitivity \(S_{k\),l} 测量在第 l 层交换第 \(k\) 级等价表示对激活的影响。
  • 理论用经验频率 \(f\)(alpha|mu) 的 signal-to-noise：规则诱导的类相关信号与有限 P 的 multinomial noise 相等时得到 crossover。主标度为 P* 约等于 nc \(m^{L}\)，而全数据穷举规模 Pc 可更大。
  • 通过改变 v,\(m\),nc,\(L\),s 检验 data collapse；另做 layerwise training、隐藏表示有效维数与 lazy/kernel regime 比较，区分 feature learning 与只记忆固定相似度。

核心结果与证据

Card 06 有效性与局限

有效性与局限

  • RHM 的规则随机、层级均匀、同义数固定，缺少自然图像与语言的长程依赖、语法歧义、噪声和非平稳频率；P* 标度是模型内结论，不是现实数据的直接样本需求公式。
  • 解析论证依赖频率信号和近独立采样，常数与有限尺寸 crossover 会受优化器、卷积结构和参数化影响。深度 \(L\)+1 与生成深度匹配也是有利先验。
  • 实验展示相关与 representation invariance 的同步，但没有完整证明 SGD 必然实现逐层统计检验。该卡 no independent reproduction performed。
