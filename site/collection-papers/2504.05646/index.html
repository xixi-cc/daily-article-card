研究问题

  • attention KV cache 随序列增长；能否把信息压缩到固定数量的 memory slots，同时在序列建模任务中控制信息损失？
  • 作者以在线压缩目标导出状态依赖的更新，并研究固定状态推理与分块训练；局部正交性本身不保证历史信息不受干扰。

模型与方法

  • 把 cache compression 建模为在线低秩优化，每步用一次 gradient descent 得到 state/input-dependent gates；将输入投影到各 slot 的正交补后更新。
  • 推导高效 recurrence，并用 chunk-wise parallel approximation 加速训练；在语言建模和 associative recall 上跨 context length、模型大小和 memory slots 比较线性注意力/RNN 基线。
  • 在作者给出的球面归一化中，若旧槽为单位向量、增量与之正交，更新后旧方向的投影乘以小于等于 1 的因子；因此稳定范数与完整保留过去读出是不同问题。

核心结果与证据

  • Figure 1 说明写入增量在归一化前相对当前槽正交；这并非相对全部历史 token 正交。单位球归一化会缩小旧方向分量，后续更新也可能改变读出。
  • 语言建模、消融与合成记忆任务表明，在论文所测模型和配置下方法具有竞争力；部分基线或困难任务更好，不能由此保证任意长度上下文的无损记忆。
  • 质量实验使用的分块配置与训练吞吐测量不同：部分质量实验采用 \(C=1\) 或 4，吞吐 Figure 8 展示 \(C=16\) 或 64；不能把两者直接合成同一配置的质量—速度优势。
  • Table 3 的 110M FineWeb-Edu 设置下，Lattice 以 \(m=16\) 报告困惑度 15.52，所列 TTT 的 \(m=64\) 为 15.60；这是该设置中的对照，不证明一般情况下压缩四倍无损。Figure 7 的部分高难度记忆配置表现较弱，不能只报告成功案例。

有效性与局限

  • 固定 slots 可能饱和；正交于当前槽不保证对旧 token 无干扰或任务语义上的新颖性。归一化、遗忘门和分块近似均影响实际记忆。
  • 论文测试语言建模与合成 associative recall，但真实长文档的稀有精确记忆、跨段检索和生成质量仍需检验。部分所示困难记忆配置和吞吐设置下其他基线更好。
  • 质量与吞吐采用不同块大小；需要在等参数、等 FLOPs、相同配置及实际 cache bytes 下比较。本卡未独立复现。
