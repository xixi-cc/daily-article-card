Lattice: Learning to Efficiently Compress the Memory

Card 01 作者信息

作者信息

Card 02 研究问题

研究问题

  • attention KV cache 随序列增长；若 \(K\)-V 矩阵近低秩，能否在线压缩到固定数量 memory slots，同时避免新 token 覆盖旧信息？
  • 目标是亚二次/固定状态推理，并保留并行训练；更新规则还应可解释为只写入当前记忆尚未包含的新颖成分。
Card 03 模型与方法

模型与方法

  • 把 cache compression 建模为在线低秩优化，每步用一次 gradient descent 得到 state/input-dependent gates；将输入投影到各 slot 的正交补后更新。
  • 推导高效 recurrence，并用 chunk-wise parallel approximation 加速训练；在语言建模和 associative recall 上跨 context length、模型大小和 memory slots 比较线性注意力/RNN 基线。
Card 04 核心结果与证据

核心结果与证据

  • Figure 1 显示标准 superposition 把完整 \(h\) 写入而产生干扰，Lattice 只加正交分量；门控决定各 slot 写入强度。
  • 报告中 Lattice 用明显较少 memory 在语言建模与 recall 上优于强基线，并保持长 context 性能，支持低秩/新颖性假设。
  • 固定 slots 最终仍会饱和；正交于当前状态不等于任务相关，chunk approximation 也可能积累误差。
Card 05 有效性与局限

有效性与局限

  • 基准与训练分布有限，真实长文档的稀有精确记忆、跨段检索和生成质量可能不同；低秩结构随层/任务变化。
  • 应比较等参数、等 FLOPs、等 wall-clock 与真实 cache bytes，不能只按理论复杂度或 slot 数判断。
  • 论文给出的图形、相关性或有限规模干预只支持其明示范围；跨数据、架构、模型规模与训练制度时需要重新验证。本卡未独立复现，不能把受控实验直接提升为普适机制。
  • 对结论做强审计时，应设置能产生相似表面指标的替代机制、匹配参数量与计算预算、报告失败案例和置信区间，并检查阈值、归一化、样本选择及评价器是否预先偏向作者假说。
  • 若论文声称发现机制，还应要求前向预测新的干预结果，而不只事后解释已有曲线；至少应在未用于选择假说的数据、不同随机种子和合理替代基线上保持。
  • 此外应明确负结果的含义：未观察到效应可能来自统计功效、测量误差或实现差异，不能自动当作理论反证；观察到效应也需排除共同原因。
