Physics-Inspired Interpretability Of Machine Learning Models

物理启发的机器学习模型可解释性

Card 01 作者信息

作者信息

  • 作者：Maximilian P. Niroomand、David \(J\). Wales（University of Cambridge）。arXiv:2304.02381v2，发表于 ICLR 2023 Physics for Machine Learning Workshop。短文把分子 energy-landscape 的 disconnectivity graph 与 order-parameter 思路移植到小型神经网络 loss landscapes。
Card 02 研究问题

研究问题

  • 常见 feature importance 往往围绕一个训练解的权重或输入梯度，但过参数网络存在大量功能相近的局部 minima，单点解释可能依赖偶然 parameterization。作者问：能否先按 transition-state barriers 组织整片 loss landscape，再找同一 minima group 中跨解保持不变的 weights，把它们视为驱动决策的候选 order parameters？
  • 这里的“可解释性”是定位稳定关联的输入连接，不等同于完整因果解释。方法假设 conserved raw weights 能跨 minima 对齐；隐藏单元 permutation、scale symmetry 或 reparameterization 会破坏这种直接比较。
Card 03 模型与方法

模型与方法

  • 流程先用 energy-landscape optimization 收集 loss minima 和连接它们的一阶 transition states。disconnectivity graph 的叶节点是 minima，分支合并高度表示连接 basin 所需越过的最低 barrier；在某一 level 下共享祖先的 minima 构成 group。
  • 对 group 中每个 network weight 计算跨 minima 标准差；若 \(\sigma\)(w)<\(n\)（实验取 \(n=0.01\)），就标为 conserved。再把这些边映射回 input–hidden–output 网络，检查它们是否集中连接某个输入 feature。
  • 实验用单隐藏层小网络处理二维 synthetic checkerboard 和匿名、PCA-reduced 的 29 维 credit-card fraud 数据。最佳解 AUC 均超过 0.95；验证通过随机置换 conserved weights，并与置换同 cardinality 的随机 weight set 比较性能下降。
Card 04 核心结果与证据

核心结果与证据

  • Figure 1 展示 checkerboard 模型的 disconnectivity graph：不同 minima groups 具有不同颜色的 conserved edges，且两个真实输入节点都在不同 group 的稳定连接中出现。它说明 landscape 可能支持多种实现同一任务的机制，而不是唯一 feature circuit。
  • credit-card 图中一组包含 global minimum 的 minima 共享指向 input node 6 的 conserved weights。置换这些 weights 比置换任意同样数量的随机 weights 更强地降低性能，支持其功能重要性；但原数据匿名且经 PCA，作者只能定位第 6 个分量，不能给出可读业务含义。
  • 论文只报告两个小任务和少量图示，没有系统给出 group 数、minima sampling coverage、置换效应分布或与 saliency/SHAP 等基线的定量比较。“适用于任意 architecture”明确被作者写作待验证建议，而非结果。
Card 05 有效性与局限

有效性与局限

  • 完整枚举深网 minima/transition states 极其昂贵，disconnectivity graph 对采样算法、起点、barrier search 和重复解去重敏感。原始 weight 坐标受 neuron permutation、sign/scale symmetry 影响；若不先做 symmetry alignment，同一函数可能看似不 conserved。
  • 阈值 \(n=0.01\) 依赖参数尺度，没有跨层归一化或统计显著性解释。permutation ablation 会把权重移到分布外位置，性能下降不一定等于该 feature 的独立因果作用；更稳健的检验需 retraining、conditional interventions 和 matched random controls。fraud 数据的类别不平衡与 split protocol 也未在主文充分展开。
