Scaling Laws for Post Training Quantized Large Language Models

Card 02 研究问题

研究问题

  • pretraining NLL 随参数量近似可预测，但量化后 loss 可能在相邻 bit-width 间突变，单靠 model size/bit count 无法选择部署点。论文问：能否把 PTQ 看作 weight-space perturbation，并用局部 loss landscape、SQNR、format geometry 与 GPTQ effect 恢复可预测性？
Card 03 背景

背景

  • 量化写作 (w\to \(Q(w)=w\)+\Delta w)。若 minima 近似二次，Hessian 已足够；实际 radial NLL profile 却先平坦、随后快于 quadratic 上升、最后 plateau，因此 20 dB 以下的简单 Taylor fit 常失败。
  • Figure 1 左侧复现 float NLL 对 weight count 的 family scaling，右侧把随机方向 radial landscape 与 Taylor approximations 放在一起，直接显示 PTQ 可预测性为何需要 landscape shape。
Card 04 模型与方法

模型与方法

  • 作者以 (\mathrm{SQNR}=20\log_{10}(\|w\|/\|\(Q\)(w)-w\|)) 统一比较不同维数；对每个 family/size/format 测 RTN 与 enhanced GPTQ 前后 loss，并提取 RTN 点的 radial slope。
  • random-forest inputs 包括 parameter count、float NLL、RTN SQNR/NLL、landscape slope、precision/exponent bits/block size；训练来自 GPT-2、OPT、BLOOM、Llama-2/3，测试留出 Pythia-1B、MPT-7B。
Card 05 核心结果与证据

核心结果与证据

  • Figure 1 把两条尺度关系并置：更大模型通常 float loss 更低，同 family 内也通常有更宽 flat basin；因此同一 SQNR perturbation 对不同 model size 的 NLL 代价不同。
  • 36 种 MX formats 覆盖 block size 16–128、element precision 2–6 bits。GPTQ 可同时降低 SQNR（离原 weight 更远）和 NLL，且 mxint3 可能显著改善而 2/4/6 bit 仅小幅改变；这排除了“更小 perturbation 必然更好”的单变量解释。
  • held-out Pythia/MPT prediction 与 observation 接近对角线，支持 landscape features 跨 family 有信息；Figure 6 给出 memory–NLL Pareto frontier。但论文没有把一个封闭解析 power law 拟合为普适定律，最终 predictor 是有限数据 random forest。
Card 06 有效性与局限

有效性与局限

  • 最大模型 13B，远小于当前最大 LLM；主要指标是 WikiText-2 validation NLL，不能直接外推到 instruction following、reasoning 或 downstream accuracy。held-out models 只有两个，且均仍属于 decoder-only transformer。
  • 128 calibration sequences、enhanced GPTQ、MX formats 和 family-specific tokenizers 都会改变结果。随机径向 landscape 不是 quantization direction 的完整 Hessian geometry；random forest 可预测不等于揭示因果缩放机制。
