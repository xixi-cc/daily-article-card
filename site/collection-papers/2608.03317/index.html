Hydrodynamic description of proliferating active matter

增殖活性物质的流体动力学描述

We develop a continuum theory for proliferating active matter starting from a microscopic stochastic model of self-propelled particles undergoing birth, death, and nonlocal competition. Beginning from the master equation, we derive mean-field evolution equations for the particle density and polarization fields and close the resulting hierarchy through a von Mises ansatz, providing a coupled hydrodynamic description applicable to a broad class of proliferating active systems. As an application, we study the recently introduced Active Brownian Bug model, in which the form of flocking emerges despite the absence of explicit alignment interactions. Linear stability analysis predicts both Turing and Hopf instabilities, whose analytical thresholds agree with numerical simulations. Card 02 摘要

摘要

  • 微观粒子带位置与离散朝向，发生birth、death、nonlocal competition、orientation-dependent hopping与tumbling。
  • mean-field与连续极限生成angular-moment hierarchy；von Mises closure用ρ和P重建所有orientation moments，在强极化时仍保持正且归一。
  • Active Brownian Bug化简为含nonlocal logistic growth、self-advection、density-gradient forcing和nematic correction的两场PDE。
  • homogeneous state的linear stability有finite-\(k\) Turing与Hopf两类不稳定，分别对应stationary clusters与traveling waves。
  • 非线性数值显示无显式alignment也能形成coherently drifting clustered flock，机制是density gradient产生polarization、polarization反过来advect density。

模型与方法

  • square lattice允许site多重占据；state \(n_{x}\)^θ记录位置x和M个orientation，master equation含WB、WD、WC、WH、WT五类transition rates。
  • 非对称hopping在continuum limit给v0 \(n\)̂(\(\theta\))·∇，对称部分给D_T∇²；symmetric tumbling给D_R∂_θ²。
  • birth/competition kernels分为空间S与orientation Φ并假设homogeneous/isotropic；mean-field factorization关闭occupation correlations。
  • angular Fourier modes \(\rho_{n}\)=∫\(\rho\)(\(x\),\(\theta\))e^{inθ}dθ中ρ_0=\(\rho\)、\(\rho_{1}=P_{x}\)+\(iP_{y}\)；von Mises ansatz由|P|/\(\rho=I_{1}(\kappa)\)/\(I_{0}\)(\(\kappa\))反解κ。

Card 05 核心结果与证据

核心结果与证据

  • homogeneous nonzero fixed point为ρ=1、\(p=0\)；linearization后transverse polarization总稳定，density与longitudinal polarization形成2×2 Jacobian。
  • Turing条件要求top-hat Fourier transform S̃(\(k\))<0，并满足μS̃(\(k\))<−[k²+Pe²k²/(2(k²+\(D_{r}\)))]；Pe升高把pattern onset推向更大μ。
  • finite-\(k\) Hopf在trace越过0且determinant仍正时发生，threshold \(\mu_{c}\)=−(2k_c²+\(D_{r}\))/S̃(\(k_{c}\))；Turing–Hopf交点由trace=det=0给出。
  • quasi-1D Figure 3在D_r=0.7的μ–Pe平面显示homogeneous \(D\)、stationary patterned PC与structured flocking SSF，Turing/Hopf解析线与onset区域相符。
  • patterns先经Turing形成；较大μ和Pe后左右对称polarization非线性破缺，clusters以共同速度漂移，ψ从约0变为接近1。
  • 局部机制由两项闭环：−Pe∇\(\rho\)/2在cluster edges生成outward polarization，−Pe∇·p使density advect；nonlocal demographic coupling同步邻近clusters的drift方向。
  • 二维Figures 4–5再现homogeneous、stationary hexagonal asters与traveling aligned hexagonal clusters；\(\mu\)=350时Pe=1.5为stationary、\(Pe=3\).5为traveling example。
  • forward/backward parameter sweeps显示bistability与hysteresis，说明Turing和Hopf相关transition具有subcritical nonlinear character。
  • continuum没有再现particle model的spatially disordered但globally polarized F phase；作者归因于被mean-field丢失的density/demographic fluctuations。
Card 06 有效性与局限

有效性与局限

  • 从master equation到deterministic PDE用了mean-field factorization，消除了birth–death shot noise与parent–offspring correlations；缺失F phase正显示这些fluctuations可能关键。
  • von Mises假设orientation distribution单峰；counter-propagating、nematic、multimodal或defect core附近可能不适用，虽比first-harmonic closure更适合强polarization。
  • ABB原birth rate是max(0,b−\(cN_{R}\))，continuum去掉positivity clipping并只选参数使rate不负；高density或扰动区可能越出等价范围。
  • linear thresholds只判断homogeneous state onset，不预测secondary drift、selected velocity、hysteresis width或fully nonlinear phase boundaries。
  • 论文把continuum phases与既有particle ABB定性对照，没有在同一参数映射下给逐点density structure factor、velocity或critical threshold误差。
  • 2D phase maps在固定L=10、\(D_{r}=0\).7和有限终止t=10上生成；long-time、system-size与noise robustness未系统展示。
  • ψ是spatial average of P/\(\rho\)，低密度区可能放大数值误差；需与total polarization及center-of-mass velocity交叉检查。
  • 无显式alignment不等于无effective alignment：offspring继承方向、density gradients和nonlocal cluster coupling提供间接polar-order feedback。
  • biological generality仍是理论框架层面；没有具体tissue/bacteria实验参数拟合或数据验证。
