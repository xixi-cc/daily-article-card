Function Vectors in Large Language Models

大语言模型中的函数向量

Card 01 作者信息

作者信息

Card 02 研究问题

研究问题

  • ICL prompt 同时包含 exemplars、格式与任务。论文问模型内部是否存在一种可从上下文中抽取、再注入另一上下文以触发同一输入—输出映射的紧凑表示，而不只是当前 token 的语义 offset。
  • 作者把这种候选表示称为 function vector（FV）：它不直接计算答案，而是触发模型已有的任务程序。关键检验是 causal portability——从 ICL 提取的向量能否在 shuffled-label、zero-shot 和自然语言模板中改变行为。
Card 03 模型与方法

模型与方法

  • 对每个任务构造 10-shot prompts，先把 labels 打乱形成 corrupted prompts；逐 attention head 做 activation patching，用恢复正确输出概率的 average indirect effect（AIE）对 heads 排名。GPT-\(J\) 中通常取跨任务 AIE 最高的 10 个 heads。
  • 任务 \(t\) 的 head activation 在许多 clean prompts 上求均值，再把选中 heads 的平均输出求和形成 vt。推理时把 vt 加到指定 residual-stream layer；比较无向量 baseline、整层平均 activation 与因果筛选的 FV。
  • 实验覆盖 GPT-\(J\)、GPT-NeoX 和 Llama 2 多个尺寸，40 余个词级/映射任务；另检查 middle-layer 位置、自然文本 portability、输出空间信息、向量组合和反向/无关 control。
Card 04 核心结果与证据

核心结果与证据

  • 高 AIE heads 主要聚集在 early-middle layers，并倾向 attention 到 exemplars 的 output tokens（Figure 3）。加入由这些 heads 构成的 FV 后，多模型在 shuffled-label 与 zero-shot 条件下均显著提高目标任务 accuracy，且通常优于整层平均 activation。
  • Table 2 对 6 个代表任务做 seed macro-average；额外 34 个任务中，GPT-\(J\)+FV 与 Llama-2-70B+FV 的 zero-shot accuracy 分别报告约 46.1% 与 74.2%，相对各自低 baseline 有大幅提升。数值是特定任务集合/提示/评分上的结果，不是通用 zero-shot 能力。
  • Antonym FV 可迁移到自然句式；部分 FVs 相加能触发复合任务。输出空间 decoding 能恢复一些任务信息，但单独重建 output-space vector 不足以复制 FV 效果，支持它不只是普通词向量差。
Card 05 有效性与局限

有效性与局限

  • Activation injection 是因果干预，但仍是模型外人为操作：恢复行为说明该方向能介导任务，不证明自然运行只靠一个向量，也不保证被选 heads 构成完整 ICL circuit。论文明确称 FV 尚非对 ICL 的完整解释。
  • 任务以短、相对简单的映射为主，accuracy 常依赖 exact/有限候选匹配；自然语言、长输出、multi-step reasoning 和 instruction-tuned/chat 模型的可迁移性需另测。选 10 heads、提取 prompt 数、注入层和向量尺度都是自由度。
  • FV 是跨 prompts 的均值，可能同时编码任务、输出词分布、格式和数据集偏差。组合实验只有部分成功，不能视为稳定的函数代数；跨模型向量也未证明可直接传递。
