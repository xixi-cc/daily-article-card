Harness VLA: Steering Frozen VLAs into Reliable Manipulation Primitives via Memory-Guided Agents

Harness VLA：用记忆引导智能体把冻结 VLA 组织成可靠操作原语

Language-conditioned manipulation requires both precise contact-rich control and robust reasoning over language, scenes, and long horizons. End-to-end Vision-Language-Action (VLA) models provide strong local visuomotor skills, but they are trained on in-distribution task trajectories and often fail under deployment perturbations such as semantic retargeting, goal re-binding, spatial-layout shifts, and unstable local contacts. LLM coding agents provide complementary semantic and compositional reasoning, but purely analytic primitives struggle with irregular grasping, constrained placement, and articulated-object interaction. We present Harness VLA, a memory-augmented agentic framework that exposes a frozen VLA as a retryable contact-rich primitive and composes it with a small fixed library of analytic primitives for grounding, staging, transport, navigation, and release. Card 03 背景

背景

  • 论证节点“冻结 VLA 的短板常在任务组织，而非单次接触动作”。
  • 端到端 VLA 擅长局部、接触丰富的动作，却会在定位、搬运、重试与长时程状态维护上累积误差。
  • Harness VLA 不微调底层策略，而是在其外部加入语言条件规划器、固定原语库与记忆。

  • 研究问题是：同一个冻结 VLA，经过结构化编排后能否抵抗指令重定向、位置交换和跨场景随机化？
  • 改动对象是执行组织层，而不是 VLA 权重。

Card 04 模型与方法

模型与方法

  • 论证节点“文件式闭环让每一步都有可检查状态”。
  • Task-Specific Memory 给出任务级成功原语序列与参数化先验。
  • planner 读取当前图像/状态，输出单个 JSON 原语调用。
  • 执行器返回观测、成功标志与诊断，再决定继续、重定位或恢复。
  • 解析原语负责 MOVE/ROTATE/GRIPPER/NAVIGATE 等确定性动作。
  • VLA-ACT 专注难以手写的接触丰富局部技能。
  • 闭环价值来自可重定位、可重试和显式失败模型，而不是一次生成更长的动作序列。
  • 论文定义 agentic execution loop、文件式 REPL 与统一原语接口。 （\(p\). 3; source/tex/\(arxiv_{\mathrm{version}}\).tex:87-163）
  • 论证节点“标准 LIBERO：编排基本保持了冻结骨干的能力”。
  • \baselinecomparison同一 RLinf 发布的 $\pi_0.5$-SFT checkpoint；四个 LIBERO suite，各 100 trials。总体成功率$95.3\%\[96.0\%\]+0.7$ 个百分点Harness 没有牺牲标准任务能力；增益的主要检验应看扰动基准。
  • Harness VLA (CC) 在标准 LIBERO 为 384/400，冻结骨干为 95.3%。 （\(p\). 8; source/tex/\(arxiv_{\mathrm{version}}\).tex:174-221）
  • 论证节点“LIBERO-Pro：固定原语编排显著缓解分布偏移”。
  • \baselinecomparison指令重定向与位置交换；headline 对比采用论文报告的 RATS overall。LIBERO-Pro overall$43.8\%\[82.4\%\]+38.6$ 个百分点直接冻结 $\pi$RLinf 为 $50.0\%$；提升不能只归因于 VLA 骨干。
  • Harness VLA (CC) overall 82.4%，RATS 43.8%，直接骨干 50.0%。 （\(p\). 8; source/tex/\(arxiv_{\mathrm{version}}\).tex:222-280）
  • 论证节点“消融式对照显示：空间扰动尤其依赖任务记忆”。
  • LIBERO-Pro Goal 的零样本设置关闭目标任务的 Task-Specific/Global Memory 检索。
  • 指令重定向：zero-shot $79.0\%$，few-shot $87.0\%$，差距较小。
  • 位置交换：zero-shot $31.0\%$，few-shot $87.0\%$，差距巨大。
  • 作者据此把空间增益归因于参考 seed 中学到的定位—分段—接触时机组织。
  • 记忆并非一般提示词缓存；它主要固化任务特定的原语分工与交互点。
  • 零样本与少样本 Goal-S/Goal-\(T\) 对照量化了任务记忆贡献。 （\(p\). 10; source/tex/\(arxiv_{\mathrm{version}}\).tex:281-340）
  • 论证节点“同一接口跨到 RoboCasa365 与 RoboTwin C2R”。
  • RoboCasa365：冻结 RLDX-1 直接基线总体 $30.0\%$；Harness (Codex) 达 $55.4\%$。
  • RoboTwin C2R：同一冻结 LingBot-VLA 从 $50.4\%$ 提升到 $58.0\%$/ $58.4\%$。
  • 不同环境使用不同冻结 VLA backend，但 planner 面向同一统一 VLA-ACT 接口。
  • 跨基准结果支持“原语组织层可迁移”，但不等于底层策略本身通用。
  • 最可信的贡献是接口级复用；跨平台仍依赖各自的冻结专用 checkpoint。
  • RoboCasa365 和 RoboTwin C2R 使用各自冻结骨干并报告 harness 增益。 （\(p\). 9; source/tex/\(arxiv_{\mathrm{version}}\).tex:240-340）

Card 06 有效性与局限

有效性与局限

  • 论证节点“冻结 VLA 的短板常在任务组织，而非单次接触动作”。
  • 端到端 VLA 擅长局部、接触丰富的动作，却会在定位、搬运、重试与长时程状态维护上累积误差。
  • Harness VLA 不微调底层策略，而是在其外部加入语言条件规划器、固定原语库与记忆。
  • 部署时原语词表冻结：解析器只能选择和参数化已有工具，不能临时发明新动作。
  • 研究问题是：同一个冻结 VLA，经过结构化编排后能否抵抗指令重定向、位置交换和跨场景随机化？
  • 改动对象是执行组织层，而不是 VLA 权重。
  • 论文将 frozen VLA 暴露为固定原语，并由 planner 组织执行。 （\(p\). 2; source/tex/\(arxiv_{\mathrm{version}}\).tex:82-163）
  • 论证节点“结论边界：记忆、规划器与基准协议都参与结果”。
  • few-shot 设置先在参考 seed 上生成 Task-Specific Memory；不是纯零样本。
  • Harness (Codex) 与 Harness (CC) 的结果不同，说明 planner 本身是系统变量。
  • RoboTwin 使用后训练的专用 LingBot-VLA；不能把全部 C2R 能力归给 harness。
  • 长时程闭环带来延迟、API 成本和错误传播；作者也指出对 planner—VLA 的开放式反馈仍有限。
  • 结果证明结构化编排有效，但严格归因必须同时写清骨干、记忆和 planner。
  • 论文结论与限制讨论开放式反馈、骨干依赖及 planner 变量。 （\(p\). 16; source/tex/\(arxiv_{\mathrm{version}}\).tex:442-466）
  • 论证节点“三点带走：冻结骨干、固定原语、可恢复记忆”。
  • 把 VLA 限定为接触丰富原语，可减少它承担的长时程规划负担。
  • Task-Specific Memory 固化任务分解，Global Memory 固化跨任务规则与失败模型。
  • 同骨干对照表明增益来自执行组织，而不是简单换更强模型。
  • 真正开放的问题是：如何让证据、记忆和恢复在更多机器人上保持可归因与可扩展。
  • Harness VLA 的核心不是“LLM 控机器人”，而是把冻结策略变成可检查、可重试的工具。
  • 论文总结统一原语、两类记忆与跨基准增益。 （\(p\). 16; source/tex/\(arxiv_{\mathrm{version}}\).tex:442-466）
