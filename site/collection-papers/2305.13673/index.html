Physics of Language Models: Part 1, Learning Hierarchical Language Structures

语言模型物理学（一）：学习层级语言结构

Card 01 作者信息

作者信息

  • 作者：Zeyuan Allen-Zhu（Meta/FAIR）、Yuanzhi Li（MBZUAI）。arXiv:2305.13673v4。论文构造必须进行全局层级解析的 synthetic CFG，训练 GPT 类模型，并用 probing 与 attention 分析检验其内部是否形成类似动态规划的信息流。
Card 02 研究问题

研究问题

  • 许多机制可解释性任务只需复制或局部匹配，不能代表递归推理。作者问：当字符串长达数百 token、局部高度歧义且需要 CFG parsing 时，autoregressive transformer 能否学到正确分布；隐藏状态和 attention 又如何承载 nonterminal（NT）祖先与边界信息？
  • 合成 CFG 给出了已知生成树和动态规划基线，便于精确标注内部状态；代价是符号、规则和训练分布都远比自然语言受控，因此不能把结果直接等同于真实语言模型的句法推理。
Card 03 模型与方法

模型与方法

  • 作者设计多组分层概率 CFG，每条规则展开为 2 或 3 个子符号，生成长且局部不可消歧的字符串。模型包括绝对位置 GPT、relative attention、RoPE、仅位置 attention、固定多窗口 uniform attention，以及 encoder-only DeBERTa 对照。
  • 外部评价同时检查生成字符串是否属于 CFG、生成分布的 entropy/support diversity，以及模型 next-token distribution 与已知 CFG distribution 的 KL divergence，避免把记忆少量合法字符串误当规则学习。
  • 内部评价用 multi-head linear probes 从各层 hidden states 预测不同深度的 NT ancestor、NT boundary 和 subtree index；再按相对位置和 boundary relation 汇总 attention，寻找从邻近低层子树边界向高层边界传递信息的模式。robustness 部分给输入/预训练数据注入结构扰动。
Card 04 核心结果与证据

核心结果与证据

  • Results 1–3：relative 与 rotary GPT 在多数 synthetic CFG 上能高准确率生成合法且多样的字符串，并逼近真实 next-token distribution；绝对位置 GPT 在较难 CFG 上显著较差，甚至落后固定 uniform attention 变体。该比较限于本文架构、训练长度和 CFG family。
  • Results 4–5：训练后 hidden states 可被线性 probe 以接近完美准确率读出多层 NT ancestors 和 boundaries，信息尤其集中在相应 subtree 的结束位置。Figure 2 把 CFG/DP 解析树与模型中的 boundary encoding、跨边界 attention 对齐。
  • Results 6–9 显示部分 heads 具有 position-based 与 boundary-based attention：当前高层边界会关注相邻低层 NT boundaries，类似 inside-style DP 合并子区间。作者称其为 DP-like information flow；由于证据主要来自 probe 和 attention pattern，而非逐步 causal replacement，不能认定模型严格执行某个唯一 DP 程序。
  • 额外结果表明 encoder-only masked-LM 对深层 CFG 较弱；在训练语料加入约 10% 结构噪声可显著提高对 corrupted prompts 的恢复，并诱发是否继续犯语法错误的 mode switch。
Card 05 有效性与局限

有效性与局限

  • linear decodability 不等于该变量被模型因果使用，attention weight 也不等于完整信息流。更强验证应干预特定 NT code、边界 heads 或 residual directions，并测量 CFG completion 退化；不同 probes 还可能从分布冗余中读出标签。
  • 语法是人工分层且 terminal vocabulary 很小，模型、序列窗 512、训练步数和规则族均受控。对 relative/RoPE、uniform attention、autoregressive/encoder-only 与噪声训练的优劣结论不应外推为所有自然语言任务或相同参数预算下的普遍架构排名。
