Card 02 研究问题

研究问题

  • 给定起点分布 \(\pi_{0}\) 与终点分布 \(\pi_{T}\)，扩散/flow matching 能给出输运，但不保证接近动态最优输运。Schrödinger bridge（SB）以参考扩散 \(Q\) 为先验，寻找满足两端边缘约束且相对熵最小的随机路径；困难是高维数值算法会随交替迭代积累时间离散和模型误差。
  • 论文提出 Iterative Markovian Fitting（IMF）及其神经实现 DSBM：始终保留端点边缘，在 Markov 路径族与 \(Q\) 的 reciprocal class 之间交替拟合。
Card 03 背景

背景

  • 动态 SB 定义为
  • \[P^{\rm SB}=\arg\min_{P:P_0=\pi_0,P_T=\pi_T}\mathrm{KL}(P\Vert Q).\]
  • reciprocal class R(\(Q\)) 包含与 \(Q\) 共享条件 bridge \(Q_{\)|0,\(T\)} 的路径测度；Markov 类 \(M\) 则要求未来在给定当前状态后与过去独立。SB 是同时属于 \(M\) 与 R(\(Q\)) 并满足端点约束的唯一测度。
Card 04 模型与方法

模型与方法

  • IMF 从已有正确端点的 bridge mixture 开始，交替更新
  • \[P_{2n+1}=\operatorname{proj}_{\mathcal M}(P_{2n}),\qquad P_{2n+2}=\operatorname{proj}_{\mathcal R(Q)}(P_{2n+1}).\]
  • Markovian projection 用 bridge-matching regression 学漂移，保持所有单时刻边缘；reciprocal projection 保留当前端点 coupling、重新填入参考 bridge。作者证明相邻迭代到 SB 的 KL 单调不增，并在温和条件下收敛到唯一固定点。
  • 实际 DSBM 交替训练 forward/backward drift，避免单向近似端点偏差累积；每轮只缓存 (\(X_{0}\),\(X_{T}\)) 而非完整轨迹。\(\sigma\to 0\) 时 DSBM-IMF 接近 iterative/rectified flow。
Card 05 核心结果与证据

核心结果与证据

  • Figure 2 展示两组 Gaussian mixture 间学得的 probability flow：\(\sigma\) 从 0 增大时路径由近似直线 OT 逐渐变成更扩散的熵正则输运，直观呈现噪声强度控制“最短路径—随机平滑”权衡。
  • 二维任务上，有 OT solver 的 OT-CFM 通常取得最低 \(W_{2}\)；不调用 OT solver 时 DSBM 优于普通 FM/CFM，并在 SB 方法中较 DSB 更稳定。\(d=50\) Gaussian 实验显示均值、方差、协方差向解析 SB 收敛。
  • MNIST↔EMNIST、CelebA、AFHQ 和流场超分辨展示高维适用性；作者报告 DSBM 相比 DSB 约快 30%，且迭代中图像质量不出现相同恶化。但 CIFAR-10 生成只比 Bridge/Flow Matching 小幅改善。
Card 06 有效性与局限

有效性与局限

  • 理论收敛针对精确投影与足够丰富的函数族；神经回归、有限样本和 SDE 离散都会破坏精确端点保持。forward/backward 交替缓解但不消除误差。
  • 算法每轮仍需从已学过程采样并缓存端点，计算随外循环增长；小 \(\sigma\) 接近非正则 OT 时数值更难，恰是许多应用最关心的确定性极限。
  • 不同实验混用 \(W_{2}\)、path energy、FID、LPIPS 和视觉样本；它们分别验证边缘、轨迹代价或感知质量，不能互相替代。
  • 该卡核对全文、定理、算法与实验；no independent reproduction performed，未训练 SDE 或复算五随机种子指标。
