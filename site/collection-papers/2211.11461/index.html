Card 02 研究问题

研究问题

  • 遗传编程、强化学习等符号回归通常随机搜索表达式空间，可能漏掉真正最优式；同时“拟合更准”和“表达式更简单”形成 Pareto front，选哪一个常依赖主观规则。作者问：在限定 operator basis 与最大复杂度后，能否完整枚举表达式，并用一个信息论量统一排名？
  • Exhaustive Symbolic Regression（ESR）的保证是条件性的：若树复杂度不超过上限、表达式来自给定基函数集、重复化简正确且连续参数找到全局最优，则搜索不会漏掉该有限空间中的最优式。它不保证真实物理规律位于搜索空间，也不保证参数优化绝不失败。
Card 03 模型与方法

模型与方法

  • 表达式写成含 nullary、unary、binary operator 的有根树，并用 preorder operator list 唯一生成树。算法先枚举合法树拓扑，再装饰节点；随后用代数/SymPy 化简、数值检验和参数重命名识别重复式，只对唯一且含参数的函数做多次 BFGS 拟合。
  • 复杂度 \(k\) 定义为树节点数。示例 basis {\(x\),a,inv,+,-,×,÷,pow} 到 \(k\le 10\) 时，朴素 1.68×10⁸ 个列表缩为 5.2×10⁶ 个合法树、134,234 个唯一表达式和 119,861 个需参数优化的函数。Figure 1 展示表达式、树与 operator list 的对应。
  • 模型选择采用 two-part minimum description length：编码残差似然、树结构/节点选择，以及参数值所需精度。Fisher/Hessian 对角项刻画参数必须调得多精细；最终用单一 description length 排名，而不仅保留 accuracy–complexity Pareto front。
Card 04 核心结果与证据

核心结果与证据

  • 在 cosmic chronometers 与 Pantheon+ supernovae 上，ESR 对 \(y\)(\(x=1\)+\(z\))=\(H\)(\(z\))² 搜索到约 40 个 description length 比 ΛCDM Friedmann 形式更短的函数。若把 x³ 作为单个 pow 结构计入，ΛCDM 分别约排第 38 与 34；自由幂 Λfluid 仍在 top 100。
  • 这些低红移函数在 \(z\)≲1 区间几乎不可区分，简单单项式可近似 ΛCDM 的低阶 Taylor 系数。因此结果说明现有低红移数据与 MDL 编码下并不唯一选择标准膨胀史，而不是证明 ΛCDM 被推翻；CMB、BAO、结构形成等外部证据不在该拟合中。
  • mock ΛCDM chronometer 研究显示，在约 20% 当前误差下需约 10³ 个测量才常把 ΛCDM 排首；误差减半后只需数百个，1–5% 精度时少量点也可能恢复。该 forecast 依赖相同 basis、MDL 与模拟分布。
Card 05 有效性与局限

有效性与局限

  • 搜索规模随复杂度和 basis 指数增长，合理资源下只能到复杂度约 10，本文仅做单变量。重复检测不完美，仍会留下等价式；穷举阶段可保证覆盖，但每个表达式的非线性参数优化仍可能停在局部解。
  • MDL 的树编码、operator multiplicity、参数精度近似和 Fisher 对角化都是建模选择；更换 basis 或把 x³ 视为原子 operator 会改变复杂度与排名。符号回归式的简短、外推明确不意味着物理因果正确；宇宙学示例也没有联合系统误差或全部 cosmological probes。
