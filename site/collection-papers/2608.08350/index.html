Card 02 研究问题

研究问题

  • 深网临界初始化被认为能避免信号相关在深度方向快速坍缩或爆炸，但“前向相关能传播”与“梯度下降真正按什么核学习”之间缺少直接桥梁。本文在先无限宽、再无限深的 sequential limit 中，把相关递推、端到端 Jacobian 与 NTK 联结起来，并比较 Gaussian 和 orthogonal 权重在有限宽深下的偏差。
Card 03 模型与方法

模型与方法

  • 研究全连接网络的 NTK 参数化，权重方差 $\sigma_w^2$、偏置方差 $\sigma_b^2$ 构成相图；激活类包含 tanh 与正弦等满足光滑/矩条件的函数。
  • 无限宽平均场给出方差、协方差和输入相关 $\rho_\ell^{\alpha\beta}$ 的确定递推；只有权重–偏置平面上的单一临界点可使方差和相关都以代数而非指数速率趋于固定点。
  • 作者用随机矩阵自由概率计算逐层与端到端 overlapped Jacobian 的谱矩，分别处理 Gaussian 矩阵和满足 $WW^\top=\sigma_w^2I$ 的 orthogonal ensemble。
  • NTK block 被重写成各层 correlation 与部分 Jacobian transport 的加权和；在 least-squares frozen-NTK 动力学中，NTK 特征值控制每个残差模的衰减率。
  • 理论用有限宽/有限深正弦网络检验，包含 proportional output $n_{out}=O(N)$ 与 fixed-output 两种标度，以及深度到 $L=N=1024$ 的谱实验。
Card 04 核心结果与证据

核心结果与证据

  • 临界点且满足 $\phi_2=0$ 时，输出相关在无限深仍显式依赖输入相关；端到端 Jacobian 的第一谱矩却按代数律约 $1/L$ 消失，因此 dynamical isometry 失败并不妨碍可预测 NTK。
  • 核心式 (92) 表明 orthogonal 初始化下，适当的宽度–深度–输出维标度中，NTK block 在 Frobenius 范数意义收敛到输出相关乘单位阵，比例常数仅由激活函数决定。
  • Gaussian 初始化的 leading finite-size fluctuations 随深度累积，维持谱集中要求宽度随深度增长；orthogonal 权重消除该主导项，NTK block 谱标准差随深度约 $L^{-1/2}$ 缩小。
  • 图 6 显示 Gaussian 端到端 Jacobian 谱随深度扩展并病态化，orthogonal 谱则受控地整体代数下降；理论在 $L\lesssim N$ 前两者均吻合，超过后 Gaussian 偏离而 orthogonal 保持。
  • 图 7–8 的 $N=L=1024$ 实验显示 orthogonal NTK 谱与 correlation kernel 清晰对齐，Gaussian 出现强谱噪声，且 proportional output $n_{out}=64$ 时更严重。
Card 05 有效性与局限

有效性与局限

  • 结论依赖先无限宽再无限深的 sequential limit 及 NTK/frozen-kernel 参数化，不描述有限宽 feature learning 主导的训练。
  • 相关能传播并不自动意味着任务好学；NTK 只是保留相似结构，若输入表示与标签不对齐，相关谱仍可能妨碍分类。
  • 严格的相关–NTK 等价需要临界点、激活矩条件和特定宽深/输出标度；离临界初始化会恢复指数特征深度。
  • orthogonal 初始化改善有限尺寸谱控制，但不是 dynamical isometry；端到端 Jacobian 均值仍消失。
  • 深度很大时数值可能因 floating-point precision 过早坍缩，论文中的机器精度现象不能与理论渐近律混为一谈。
