Scaling Parameter-Constrained Language Models with Quality Data

用高质量数据扩展参数受限语言模型

Card 02 研究问题

研究问题

  • 传统 scaling law 把所有 training tokens \(D\) 视为等价；参数受限时，继续加入低多样性或模型化文本可能不如少量高质量数据。论文问能否用易计算的 diversity 与 syntheticity 把 \(D\) 改写为 effective tokens \(D_{q}\)。
  • 目标是在 \(N\)、raw \(D\) 与数据属性之间建立 microscopic correction，并预测八个 reasoning tasks 的平均准确率，而不仅是 held-out language-model loss。
Card 03 背景

背景

  • 同一 token budget 的信息增益取决于重复度、覆盖和 teacher-likeness。diversity score 近似语料内部变化；syntheticity 用 teacher perplexity/生成倾向刻画文本是否接近高质量模型分布。
  • 作者把质量压进乘性 factor \(Q\)，使 \(D_{q}=DQ\)；在参数固定时，\(Q\) 改变相当于有效增加/减少训练样本，但这种标量压缩必然丢失 domain-specific composition。
Card 04 模型与方法

模型与方法

  • 数据来自 RefinedWeb 的多种 sampling 比例和由 Qwen 等 teacher 生成/改写的 synthetic corpora；每个 model size 配 2–10B tokens，在分布式 GPU 上预训练。
  • Diversity 与 syntheticity 进入指数形式 \(Q\)=exp(\(c_{1}\) Dr+\(c_{2}\) S)，再嵌入参数/数据 scaling function G(\(N\),\(D_{q}\))。常数由 200+ runs 拟合并 bootstrap standard errors。
  • 评价在八个 zero-shot reasoning benchmarks 汇总 accuracy；消融 model size、data size、sampling 与 synthesis，并检查 predicted vs true accuracy correlation。
Card 05 核心结果与证据

核心结果与证据

  • Figure 3 左图把不同 \(N\)、\(D\)、语料的 accuracy 对 \(D_{q}\) 重画后更接近共同趋势；右图显示拟合 \(Q\) 随 diversity/syntheticity 的方向。该方向是作者指标下的经验结果，不应泛化为“越 synthetic 越好”。
  • 预测 G(\(N\),\(D\)) 与 RefinedWeb 模型真实 accuracy 的 Pearson correlation 为 +0.83；Figure 4 显示 \(Q\) 的收益在 token 较少时更明显，\(D\) 足够大后 raw token count 主导。
  • 模型/数据消融支持 parameter-constrained setting 中 quality adjustment 有信息量，但 scatter 仍显著，说明单个 \(Q\) 无法完全解释任务差异与 optimization noise。
Card 06 有效性与局限

有效性与局限

  • diversity 与 teacher-defined syntheticity 是代理量，teacher bias、语言/domain 和 preprocessing 会改变其含义；拟合出的 \(c_{1}\),\(c_{2}\) 不能脱离语料与 benchmark 使用。
  • +0.83 是相关而非严格 held-out causal scaling law；200+ runs 的训练 family、data sources 与相邻 checkpoints 可能造成依赖。accuracy 饱和和离散 benchmark 也不满足平滑 power-law 假设。
  • 有效 token 不是数据版权、事实性或安全质量的完整衡量。该卡 no independent reproduction performed。
