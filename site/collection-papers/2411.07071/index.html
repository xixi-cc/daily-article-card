Universal Response and Emergence of Induction in LLMs

大语言模型的普适响应与归纳行为涌现

Card 01 作者信息

作者信息

  • Niclas Luick。论文借鉴响应函数与 scaling collapse 的物理语言，通过微扰残差流研究 Gemma、GPT-2 与 Llama 中 induction 行为沿层深涌现，arXiv:2411.07071v1。
Card 02 研究问题

研究问题

  • induction heads 常通过重复序列上的 attention patterns 识别，但单头定义可能忽略分布式电路。作者问：若轻微缩放一个输入位置的 residual vector，整个模型输出和隐藏态的响应是否具有跨扰动强度、层和模型的普适缩放？
  • 响应在何处开始呈现“前一段中某 token 后继者”的 induction signature，能否用不依赖单个 attention head 的全网络量来定位涌现？
Card 03 模型与方法

模型与方法

  • 对重复随机 token 序列，在输入层把单个位置向量缩放为 (1-\(\epsilon\))\(x\)，其他位置不变；比较原/扰动前向传播，定义幅值差、角度差及方向响应矩阵。Figure 1 展示 perturb–forward–compare 流程。
  • 作者改变 \(\epsilon\)、被扰动位置、读出位置和残差层 ℓ，寻找经 susceptibility 重标度后的 response collapse；随后观察响应随层和 token offset Δj 的结构，定位 induction 对角线。
  • 主要模型为 Gemma-2-2B，并在 GPT-2-XL、Llama-3.2-3B 等模型检查末层缩放行为。方法只需前向传播，不直接消融单个 head。
Card 04 核心结果与证据

核心结果与证据

  • 弱扰动区内，不同 \(\epsilon\) 的幅值和角度响应经一个尺度因子重标后近似塌缩，且这一形式沿多层保持。作者将其称为 scale-invariant 或 universal response。
  • Gemma-2-2B 中 induction signature 随深度逐步形成：响应矩阵在与重复周期相符的 offset 上增强，方向响应和幅度响应给出互补迹象。Figure 4 追踪这种结构沿层出现。
  • GPT-2-XL、Llama-3.2-3B 与 Gemma 末层展示相似弱扰动 collapse，但 scaling coefficient 和层内细节不同。跨三个模型的相似性是有限经验普适性，不是模型族无关定理。
Card 05 有效性与局限

有效性与局限

  • 缩放 embedding/residual 位置是人工干预，未必对应自然输入变化；响应可能受 layer norm 抵消、token 频率和随机序列分布影响。线性弱扰动区外的行为不服从同一缩放。
  • induction signature 由响应几何识别，并未通过因果路径 patching 证明这些响应单元对任务输出必要。重复随机 token 任务也比自然语言中的长程检索简单。
  • “普适”依据少量公开模型与尺度，模型训练数据和架构不同但样本数有限。需更多 seed、模型规模、tokenizer 和任务验证。本卡未独立复现。

复现与资源
