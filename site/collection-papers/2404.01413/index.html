Is Model Collapse Inevitable? Breaking the Curse of Recursion by Accumulating Real and Synthetic Data

Card 02 研究问题

研究问题

  • 模型反复训练自己生成的数据会不会必然坍缩？先前结论多假定第 n 代只用第 n-1 代合成数据，丢弃历史真实样本。现实 web corpus 更可能累积旧数据。
  • 论文问：只要保留原始真实数据并累积每代 synthetic data，误差是否仍随代数无界增长，还是趋于有限平台？
Card 03 背景

背景

  • replacement 形成纯 Markov feedback：采样误差、mode undercoverage 与拟合噪声逐代成为下一代唯一真值。accumulation 则把每次偏差与持续存在的 real anchor 混合。
  • 需区分 dataset size effect 与 composition effect；简单让 replacement 数据集也增长，仍不等同保留不同历史代和真实数据。
Card 04 模型与方法

模型与方法

  • 语言实验递归预训练 9M GPT-2 与 125M Llama2 on TinyStories，按 replace/accumulate 生成后续 corpus，比较 validation cross-entropy、learning curves 与文本。
  • 跨模态复核用 GeoDiff 分子构象与 CelebA VAE；Figure 6 直接展示多代 face samples。线性 regression toy model对每代 generated targets 拟合，允许解析 test error。
  • 理论扩展先前递归线性模型：replacement error 随 iteration 增长；accumulation 对全部历史 targets 做回归，使噪声贡献被增长样本池平均，得到代数无关的 finite upper bound。
Card 05 核心结果与证据

核心结果与证据

  • Figure 1 左右并列两种数据流：replacement 的 real anchor 在首代后消失，accumulation 的每代训练集保留 Data 1、Data 2…；这是结论成立的精确定义。
  • 语言、分子 diffusion 与图像 VAE 都显示 replacement loss 恶化，而 accumulation 保持平台；Figure 6 中 replacement faces 最终 mode collapse，accumulation 保留质量/多样性。
  • 线性模型 Figure 7 中 replacement test error 近线性增大，accumulation 快速饱和；解析上界证明在该 Gaussian linear setting 中坍缩非必然。
Card 06 有效性与局限

有效性与局限

  • 避免无界 collapse 不等于保持原始分布无偏，也不等于 synthetic data 有益；有限平台可高于 real-only baseline。accumulation 的存储和训练 compute 随代数增长。
  • TinyStories、GeoDiff、CelebA 与有限代数不足以覆盖 web-scale filtering、模型同质化、版权、adversarial SEO 或 real-data share 下降。实验混合比例和 sampling temperature 决定结果。
  • 线性定理不能直接推广 nonlinear foundation models；它证明机制可能性而非互联网未来。该卡 no independent reproduction performed。
