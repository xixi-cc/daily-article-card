Three Mechanisms of Feature Learning in a Linear Network

线性网络中特征学习的三种机制

Paper Collection · Training Dynamics · 原文

作者 Yizhou Xu 与 Liu Ziyin，单位包括 EPFL、MIT Research Laboratory of Electronics 以及 NTT Research。论文发表于 ICLR 2025，研究 finite-width network 从 kernel 到 feature-learning regimes 的可解动力学。arXiv:2401.07085v3。

Card 01 作者信息

作者信息

  • 作者 Yizhou Xu 与 Liu Ziyin，单位包括 EPFL、MIT Research Laboratory of Electronics 以及 NTT Research。论文发表于 ICLR 2025，研究 finite-width network 从 kernel 到 feature-learning regimes 的可解动力学。arXiv:2401.07085v3。
Card 02 研究问题

研究问题

  • 无限宽 NTK 极限把训练近似为固定 kernel，但实际有限宽网络会改变内部表示。能否找到一个从任意初始化都可精确求解、同时包含 kernel phase 与 feature-learning phase 的最小模型，并把‘特征学习’分解为可观测的原型机制？
  • 作者进一步研究 width、output normalization、两层 learning rates 和 initialization scales 的共同缩放如何决定 phase，而不是把宽度单独当作 kernel behavior 的充分条件。
Card 03 模型与方法

模型与方法

  • 核心模型是一隐层 linear network，数据位于一维子空间，但允许任意有限 hidden width 与 arbitrary initialization。两层参数分别以 \(eta_{u}\)、\(eta_{w}\) 做 gradient flow，输出由 gamma 缩放；通过 \(p_{i}\)、\(q_{i}\) 变量变换，作者给出权重和 NTK 随时间的 exact solution。
  • 用相邻两层权重的 normalized product zeta 衡量 alignment。根据初始几何与尺度，feature learning 可表现为：原本不对齐的层逐渐 alignment；近乎正交的层发生 disalignment；或两层相对方向变化小但范数重新分配，即 rescaling。kernel phase 中对应变化在尺度极限下消失。
  • 随后对各超参数写幂律 scaling exponents，导出 finite/infinite width phase diagrams。实验覆盖 linear、ReLU、sigmoid、swish、leaky-ReLU，两层与更深 FCN，MNIST、CIFAR-10 和 ResNet-18；用相对权重位移、alignment 和 accuracy 检验定性外推。
Card 04 核心结果与证据

核心结果与证据

  • exact solution 给出从任意初值到收敛的特征与 kernel 演化时间尺度，并说明 phase 由 gamma、width、layerwise rates 与 initialization 的组合决定。有限宽也可通过其他尺度趋于极限进入 kernel phase；大宽度本身不唯一决定 lazy behavior。
  • Figure 1 中，线性模型解析曲线与数值点吻合：feature-learning scaling 下 zeta 显著趋近 alignment 或离开 near-orthogonal initialization，而 kernel scaling 基本冻结。多种 nonlinear activations 出现相同定性方向。
  • MNIST 深层 FCN 延续 layer alignment/disalignment；CIFAR-10 的 phase engineering 显示，把 Kaiming setting 调到 feature-learning phase 时最佳 test accuracy 约提高 5%，把 Xavier 调到 kernel phase 时约下降 10%。这些结果支持机制可迁移，但并非 exact theory 对真实数据性能的定量预测。
Card 05 有效性与局限

有效性与局限

  • 严格可解部分是一隐层线性网络且训练数据位于一维子空间；非线性、深层和高维数据结果是经验上的定性相似，不能把 exact formulas 原样用于 ResNet。附录消融扩大范围，但未消除模型差异。
  • alignment 指标压缩了表示几何：层对齐可能与 generalization 相关，却不是 feature quality 的完备度量；disalignment 或大权重范数也不必在所有任务中有害。性能差异同时受具体 kernel、优化时间和 hyperparameters 影响。
  • phase diagram 依赖预设的渐近幂律路径；同一有限模型在有限数值下可能处于 crossover，而非清晰相。训练 loss/最终解与路径机制需区分，作者的主要结论针对 dynamics；本卡未独立复现。
