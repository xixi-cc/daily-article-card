Card 02 研究问题

研究问题

  • 模型在未见算式上答对，可能只是记住 token 组合或做数值插值，并不代表学会交换律 a+\(b=b\)+a、单位元 a+\(0=a\)。怎样设计训练/测试集合，排除这些平凡捷径？
  • 若模型确实学习结构，这些性质在不同代数运算、群阶和训练集规模下何时涌现，隐藏状态中是否出现可测的 commutativity/identity signal？
Card 03 模型与方法

模型与方法

  • 作者在有限循环群 \(Z_{n}\) 上生成多项加法序列，并构造符号不同的运算 ⊕ 与不满足目标性质的对照 ⊖。训练/测试共享 token 集，但把某些排列或含单位元位置组合系统留出，保证测试需要结构泛化。
  • 为排除纯数值计算与 token memorization，输出 label 和运算符可重新映射，训练集只暴露受控组合。Figure 1 列出三种运算的训练/测试例子，Figure 2 定义各层 hidden states 与 attention 变量。
  • 定义层级指标 \(S_{\mathrm{com}}\) 与 \(S_{\mathrm{ide}}\)，比较交换置换或插入单位元前后的隐藏表示相似性；在 \(Z_{7}\)、\(Z_{11}\)、\(Z_{13}\) 和不同训练规模 \(K\) 上记录训练/测试 accuracy 与指标沿层变化。
Card 04 核心结果与证据

核心结果与证据

  • 训练过程出现分阶段泛化：训练 accuracy 可先升高，而交换律/单位元留出测试在更多步后才突增。Figure 3 显示 \(Z_{7}\) 的时间曲线以及不同群阶随 \(K\) 的最终准确率；更大训练集通常提高结构泛化。
  • 对满足性质的 + 运算，深层 hidden states 的 \(S_{\mathrm{com}}\) 和 \(S_{\mathrm{ide}}\) 增强；对重新标记但同构的 ⊕ 也可出现相应信号，而对非交换/无单位元对照 ⊖ 不应呈相同模式。Figure 4 用层级热图展示差异。
  • 结果支持模型能从数据诱导部分代数不变量，而不只回忆见过的字符串；但“学习群结构”是基于两条性质和有限受控任务的结论，不代表形成完整抽象代数推理系统。
Card 05 有效性与局限

有效性与局限

  • 任务使用很小的有限群、固定表达格式和从头训练模型，结构信号可能依赖 tokenizer 与位置模板。对更复杂群、非阿贝尔运算、组合嵌套和自然语言问题的泛化未知。
  • 留出设计降低记忆捷径，却难以穷尽所有统计线索；例如特定 token 频率、序列长度或输出映射仍可能帮助分类。需要随机化符号、长度和 group isomorphism 做更严格 out-of-distribution tests。
  • \(S_{\mathrm{com}}\)/\(S_{\mathrm{ide}}\) 是研究者定义的表征相似度，相关增强不证明这些方向因果实现运算；需 activation patching 或 direction ablation。本卡未独立复现。
