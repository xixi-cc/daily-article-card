When does compositional structure yield compositional generalization? A kernel theory

组合结构何时带来组合泛化？一个核理论

Card 01 作者信息

作者信息

  • Samuel Lippl 与 Kim Stachenfeld，来自 Columbia University Center for Theoretical Neuroscience 与 Google DeepMind。论文发表于 ICLR 2025，从固定组合表示的 kernel regime 研究组合泛化。arXiv:2405.16391v3。
Card 02 研究问题

研究问题

  • Disentangled 或 compositionally structured representation 让共享组件的输入更相似，但这是否足以保证对新组合泛化？作者把表示本身固定，隔离训练集统计与 kernel readout，寻找可学习函数的精确限制。
  • 论文特别分析 symbolic addition、context dependence 与 transitive equivalence，并问偏置训练集如何产生两种失败：memorization leak（训练特例污染未见组合）和 shortcut bias（训练相关性让模型选择错误组件）。
Card 03 模型与方法

模型与方法

  • 输入由 \(C\) 个 categorical components \(z\)=(z₁,…,\(z_{C}\)) 构成。组合结构要求 kernel similarity 只依赖两个输入重合的组件集合；随机权重无限宽网络保持这种结构。模型在固定 feature map \(\phi\)(\(x\)) 上训练零初始化线性 readout，因此预测属于 kernel regression/gradient-descent regime。
  • 作者定义一个 conjunction \(J\) 为若干组件的联合取值。Theorem 4.3 表明，测试预测只能把训练中见过的 conjunction 对应函数项相加，即 conjunction-wise additivity；未在任何训练样本中出现的 conjunction 不可直接使用。
  • 理论预测随后在随机 feature/kernel simulations，以及 MNIST/CIFAR 上训练的 ConvNet、ResNet 与 Vision Transformer 中检验。作者用 representational salience、additive predictor 的 R²、任务 accuracy 与训练集构型对照理论。
Card 04 核心结果与证据

核心结果与证据

  • Figure 1 概括链条：组合输入产生 overlap-based similarity；随机网络保持该相似性；kernel readout 对新样本只能线性组合 familiar conjunctions。这个限制不是“完全不能泛化”，而是把可实现泛化函数限制为 conjunction-wise additive 类。
  • 对 symbolic addition，模型能泛化但斜率由 cross-component salience 和已见 rows/columns 数量决定；对 context dependence，shortcut bias 可让不相关组件主导；对 transitive equivalence，所需 \(A=B\)、\(B=C\)⇒\(A=C\) 不是训练 conjunction 的加性组合，因此 kernel model 原理上失败。
  • 深网实验在有限设置中与理论一致：其预测可被 conjunction-wise additive predictor 高 R² 解释，并复现 memorization leak/shortcut bias。该一致性支持 kernel-like mechanism，但不证明 feature-learning 网络始终停留在 kernel regime。
Card 05 有效性与局限

有效性与局限

  • 定理假设 fixed compositionally structured representations、kernel model、zero-initialized linear readout 与特定 overlap symmetry。端到端 feature learning、attention、recurrence、external memory 或显式关系图可以产生训练中未见的 conjunction computation。
  • “Disentangled 不足以保证组合泛化”是条件性结论：表示结构仍可能有帮助，但还需要合适任务函数与覆盖训练统计。Transitive equivalence 的 impossibility 适用于所定义 kernel/additive class，不是所有神经网络的不可计算性。
  • MNIST/CIFAR 实验只覆盖少量架构、任务与训练尺度；高 additive R² 是行为拟合证据，不排除不同内部机制。表示 salience 与训练偏置共同变化时需谨慎解释因果。本卡未独立复现。
