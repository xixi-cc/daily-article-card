Closed-Form Interpretation of Neural Network Classifiers with Symbolic Gradients

利用符号梯度对神经网络分类器作闭式解释

Card 02 研究问题

研究问题

  • 分类器的 sigmoid/logit 只需在 decision boundary 两侧给出正确符号，因此同一分类概念可由无数单调变换表达。直接对网络输出做 symbolic regression 往往只复制不可读变换，或找到另一个同样能分类但并非网络实际采用的概念。
  • 论文问：能否消去一维可逆变换 phi，把网络 latent score 所编码的等价概念还原为简短闭式表达；同一方法能否解释隐藏层中的单个 neuron。
Card 03 模型与方法

模型与方法

  • 去掉最终 sigmoid 得到 latent model \(f\)。若 \(f\)(\(x\))=phi(\(g\)(\(x\))) 且 phi 可逆可微，则 \(f\) 与目标闭式概念 \(g\) 的梯度处处平行；归一化梯度消去未知尺度 phi'(\(g\))。作者据此把信息等价类写成具有相同 normalized gradient field 的 \(C_{1}\) functions。
  • 解释流程先训练 binary classifier，再对输入采样并用自动微分计算 normalized nabla \(f\)；随后用 genetic symbolic regression 搜索表达式 \(T\)，使其 normalized gradients 匹配网络。symbolic search space、可用算子、复杂度和上下文先验共同定义‘human-readable’。Figure 1 概括 neural function equivalence class 与 symbolic space 的交点。
  • 实验用 2–6 个变量的合成 decision functions，并与直接 symbolic classification 比较；沿 error-complexity Pareto front 选择拐点附近候选，再以 correlation、functional form 与 classification behavior 检查。
Card 04 核心结果与证据

核心结果与证据

  • 理论上，正的可逆标量变换只改变梯度大小而不改变方向，因此 normalized gradient field 可把 classifier latent score 嵌入同一 concept equivalence class。该构造解释了为什么复制 logits 不等于找到最简 decision concept。
  • 六个主要合成实验中，文中报告四个恢复 exact functional form，两个得到良好 symbolic approximation；直接 symbolic classification 只找到六个中的三个。Figure 2 用椭圆 decision boundary 展示网络输出与真实 \(g\) 非线性相关，而 gradient-based symbolic model 可恢复 \(g\)。
  • 额外实验允许多个 high-level concepts 同时解决分类：直接 symbolic classification 选择一种可行边界，而本文方法揭示网络实际学习了两种特征的组合。这支持‘interpret trained model’与‘重新找一个分类规则’的区分，但证据仍来自低维合成任务。
Card 05 有效性与局限

有效性与局限

  • 等价性依赖 \(C_{1}\) smoothness、相关区域内非退化梯度及合适的可逆单调关系；normalized gradient 在梯度接近零时数值不稳，方向符号和采样覆盖也需处理。复杂决策边界可能需要分片或多输出推广。
  • symbolic search 只能返回预先给定算子、变量与复杂度预算中的表达式；找不到式子不证明网络无可解释概念，找到相关式也需验证全域而非训练点。genetic search 随机性与 Pareto 拐点选择影响结果。
  • 实验维度仅 2–6、边界人工生成且结构较短，尚未证明可扩展到高维图像、文本或大型隐藏层。‘任意单 neuron’是框架适用范围，实际可恢复性仍取决于输入坐标和候选语言；本卡未独立复现。
