Convexifying Transformers: Improving optimization and understanding of transformer networks

凸化 Transformer：改进 Transformer 网络的优化与理解

作者信息

Card 02 研究问题

研究问题

  • 标准 self-attention 含 softmax(QKᵀ)、矩阵乘积和多层非线性，训练是高度非凸问题；attention-only 网络还可能退化。作者问：能否替换 attention 的具体参数化，使正则化训练问题等价为可全局求解的凸程序，并由凸形式直接解释模型偏好的 token 结构？
  • 这里“凸化 Transformer”不是对任意标准 Transformer 做无损变量替换。论文先用受 simplex 约束的 token 凸组合替代 softmax QK attention，再对这一 alternative attention 及其带 gated-ReLU FCN 的版本建立等价凸形式。
Card 03 模型与方法

模型与方法

  • 对 token 矩阵 \(X\)，作者把 softmax(U)\(X\) 放宽/重写为 WX，其中 W 每行非负且和为 1。多头 alternative attention 对各头分别学习 token convex combination、特征方向和输出权重，并用平方 Frobenius 正则。
  • 利用参数缩放，标量输出的非凸正则问题先等价为对头输出系数的 ℓ₁ 正则，再进一步化为单一矩阵 \(Z\) 的凸问题：损失依赖 trace(ZᵀX)，正则为各 token 行的 ℓ₂ 范数之和。该 group-lasso 形式显式鼓励整行归零，即跨 token 的稀疏选择。
  • 论文扩展到多输出，并用固定门控模式的 gated ReLU 表示带 FCN 的单块模型。实验包括 pretrained BERT 第六层 MRPC activations 的 student–teacher 拟合，以及 mod 97/mod 15 算术任务上的 grokking；深层版本通过堆叠凸块构造，但堆叠后整体未被同一单块凸等价定理覆盖。
Card 04 核心结果与证据

核心结果与证据

  • Theorem 1 对标量输出证明 alternative attention 的正则训练与 group-lasso 凸程序等价，并给出从 \(Z\) 恢复非凸参数的方法；Theorem 2 处理多输出；Theorem 3 在固定 gated-ReLU patterns 下处理含 FCN 的块。等价性揭示 token sparsity，但不等于标准 softmax Transformer 的训练问题已被凸化。
  • BERT student–teacher 实验中，凸模型获得比标准非凸与 alternative 非凸模型更低的正则目标和测试误差，attention map 也更接近 teacher；作者认为非凸基线可能陷入局部极小，但有限实验不能排除优化器和参数化差异。
  • mod 97 上标准非凸模型约 10³ 次迭代达到满训练准确率，却超过 10⁵ 次才泛化；凸方案达到 99% 测试准确率约快 10×且测试损失更低。增加层数改善两类模型，但所谓 deep convex model 是凸层的堆叠，不保证整体训练仍是单一全局凸问题。
Card 05 有效性与局限

有效性与局限

  • 核心理论改变了 attention 机制：自由 simplex 权重不再由输入相关的 QK softmax 生成，表达归纳偏置和参数共享不同。gated-ReLU 凸化依赖固定随机门控；多层堆叠超出单块证明。因此结论应表述为一种可解释的 convex attention alternative，而非标准 Transformer 的普遍精确凸化。
  • 实验规模小：冻结 BERT activation 的层间拟合和模块算术，均非端到端大型语言模型。各模型参数量、FLOPs 和正则结构不同；学习率/\(\beta\) 虽经验证集网格搜索，仍不足以建立广泛效率优势。论文自身明确需要大规模验证。group sparsity 说明数学正则偏好，不自动保证自然语言 token 具有语义可解释性。
