How do Transformers Learn Implicit Reasoning?

Transformer 如何学习隐式推理？

Jiaran Ye、Zijun Yao、Zhidian Huang、Liangming Pan、Jinxin Liu、Yushi Bai、Amy Xin、Weichuan Liu、Xiaoyin Che、Lei Hou、Juanzi Li · 预印本 · arXiv:2505.23653 · 论文原文 ↗

一个模型答对 (\(e_{1}\),\(r_{1}\),\(r_{2}\)) 到 \(e_{3}\)，可能是记住答案，也可能内部复用 bridge entity \(e_{2}\)。作者问这种区别在训练行为、数据暴露与隐藏表征中有何可测证据，尤其是第二 hop 的具体组合是否必须作为 query 出现才能泛化。

研究问题

  • 一个模型答对 (\(e_{1}\),\(r_{1}\),\(r_{2}\)) 到 \(e_{3}\)，可能是记住答案，也可能内部复用 bridge entity \(e_{2}\)。作者问这种区别在训练行为、数据暴露与隐藏表征中有何可测证据，尤其是第二 hop 的具体组合是否必须作为 query 出现才能泛化。

背景

  • CoT 让中间步骤可见，但隐式推理只输出最终答案。先前工作常以 probing 判断 intermediate 是否可解码；作者认为可解码不等于可复用。于是提出 cross-query semantic patching 定位可替换的语义状态，并以同一 bridge entity 在不同 query 的 cosine cohesion/alignment 描述几何重用。

模型与方法

  • 作者构造 ID/OOD 实体和原子 triples，以及两跳、三跳组合 query；训练 8-layer GPT-2，系统移除 ID/OOD triples 或让某些 triples 从 second-hop query 角色缺席。对 clean/counterfactual query 做 semantic patching，找出 \(r_{1}\) token 中层的中介位置；随后收集相同 \(e_{2}\) 的 hidden state，计算 ID Cohesion、OOD Alignment 和可视化 cosine 聚类。

核心结果与证据

  • Figure 2 报告记忆、ID generalization、cross-distribution generalization 三阶段，ID cohesion 随 Test-II 上升，OOD alignment 之后才随 Test-OI 上升。只用 Train-II query 仍可获得 Test-II，加入 ID atomic triples 则更快；但将某 triple 排除出所有 second-hop query 后，对相应 test query 的泛化明显失败。Figure 4 的 patching 把 bridge 表征定位在 \(r_{1}\) token 中层；Figure 5 显示 Phase I 散乱、Phase II ID 聚集、Phase III OOD 才对齐。

有效性与局限

  • 优点是行为、query-level ablation、因果 patching 与余弦几何相互对应，明确区分“事实存在”与“作为第二 hop 被使用”。限制是合成关系图、固定模型与训练配置；cosine clustering 是成功相关的表征指标，不单独证明逐步算法执行。原子 triples 加速而非必需的结论只适于其生成分布，OOD 定义也不是自然语言开放域推理。

复现与资源

  • 论文给出代码 https://github.com/Jiaran-Ye/ImplicitReasoning。复核应生成完全可控的 entity/relation split，分别记录 Test-II、Test-OI 等；对第二-hop exposure 做单独消融。patching 需固定 reference layer/token、counterfactual 构造与 logit metric；聚类需按真实 bridge entity 分组并报告随机基线。本文卡未运行代码、训练或 patching。

阅读指南

  • 先看 Figure 2 理清三个阶段，再读 second-hop ablation，避免把 atomic facts 与组合 query exposure 混同。接着看 Figure 4 的 patching anchor 与 Figure 5 的几何演化；作者主张的是跨 query 表征一致性，而非中间实体一定能被线性解码。最后读三跳结果，评估机制在更长组合链上的一致性与边界。
