Card 02 研究问题

研究问题

  • Reversal curse 指训练语料包含‘A 的关系对象是 B’后，causal language model 仍不能在反向 prompt 中给出 A，即使自然语言语义上两种表述互逆。Expressivity 只能说明 Transformer 可以表示对称关系，不能解释 SGD/CE 是否会选择它。
  • 本文问：在 bilinear next-token model 与 one-layer Transformer 中，seen direction 的 logit 增长是否传递到 reverse logit？类似地，分别学会 \(A\to B\) 与 \(B\to C\) 后，为什么模型不会自动把 \(A\to C\) 的 indirect relation 写进 direct next-token weights，从而需要 explicit chain-of-thought/in-context computation？
Card 03 模型与方法

模型与方法

  • Bilinear 模型对输入 embedding \(x\) 与候选 \(y\) 定义 logit l_Θ(\(y\)|\(x\))=\(x\)^TΘy，以 softmax cross-entropy 训练。数据对 \(i\ge 2\) 同时给出 (\(x_{i}\),\(y_{i}\)) 与 (\(y_{i}\),\(x_{i}\))，但 held-out pair 只给 forward (\(x_{1}\),\(y_{1}\))，测试 reverse (\(y_{1}\),\(x_{1}\))。Random Gaussian embeddings 在高维近正交。
  • One-layer Transformer 用 token embeddings U、attention score reparameterization \(Z=UW_{\mathrm{QW}}_{K}^{\mathrm{TU}}^{T}\)/\(\sqrt d\) 与 decoder/value reparameterization \(Y=UW_{V}^{\mathrm{TU}}^{T}\)。三-token setup 下 attention 只面对一个 contextual token，主要动力学落在 \(Y\)；作者在 step size、vocabulary、batch 与 initialization assumptions 下证明 seen-direction \(Y\) entry 增长，而 transposed unseen entry 基本不更新。
  • 实验生成 disjoint entity sets A/B、inverse relation tokens 与随机 bijection。Training pairs 含双向序列，validation pairs 只含随机一向并在另一向测试；multi-layer Transformers 扫 12/24/48 layers、12 heads、vocabulary 20–2000、entity length 1–3 与 positional/embedding variants，曲线平均 10 seeds。
Card 04 核心结果与证据

核心结果与证据

  • Bilinear Theorem 2 给出 separation：训练 loss 可降到任意小，而 reversal loss 在足够高维、small initialization 等条件下仍有正下界。直观上 \(\Theta_{\mathrm{ij}}\) 与 \(\Theta_{\mathrm{ji}}\) 是不同自由度；训练 \(x=e_{i}\to y=e_{j}\) 直接增加前者，不要求增加后者。
  • One-layer Theorem 3 得到相似结论：对 training sequence，正确 next-token probability 随时间趋近 1；对应 validation reverse probability 不优于约 1/\(M\) 的 uniform scale。Figure 1 的 multi-layer 实验中，blue train negative log probability 接近 0，而 red reverse validation curve从约 15 上升到 50–60，10-seed band 保持巨大间隔。
  • Figure 2 直接画 logits matrices：seen forward/双向 entries 的 diagonals 很大，held-out reverse matrix diagonal 接近 0。COT 扩展把问题称为 intransitivity：\(A\to B\)、\(B\to C\) weights 变大不强迫 \(A\to C\) weight 变大；附录 multi-layer experiments 复现这一 train/validation separation。
Card 05 有效性与局限

有效性与局限

  • 定理针对 single-token entities、三-token sequences、random/near-orthogonal embeddings 与 one-layer reparameterized dynamics，并依赖大 vocabulary、step-size、initialization 等技术条件。真实语言的 paraphrases、shared subwords、pretraining semantics 和 multiple contexts 会给 reverse direction 提供额外关联。
  • Multi-layer experiments 是合成随机 bijection，而不是自然知识问答；它验证该 construction 下的 failure mode，不证明所有 reversal curse 都由同一 \(Y\) asymmetry 唯一造成。论文附录还指出 ICL setting 中 reversal curse 可消失，说明 inference context 能实现不同计算。
  • ‘COT necessary’是特定 direct-output task 和 model/data assumptions 下的理论表述；外部 memory、bidirectional objectives、data augmentation、planning 或 learned symmetric parameterization 都可能改变结果。Figure 1 的 validation loss 甚至变差与 unconstrained CE competition 有关，不等于模型完全没有语义能力。本卡未独立复现。
