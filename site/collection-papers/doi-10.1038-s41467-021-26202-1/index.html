Learning non-stationary Langevin dynamics from stochastic observations of latent trajectories

从潜在轨迹的随机观测中学习非平稳朗之万动力学

Card 02 研究问题

研究问题

  • 许多神经决策模型用低维 diffusion/Langevin 变量表示不可直接观测的证据积累，但实验只给出由潜变量随机产生的 spikes，trial 又可能在潜变量触及边界时结束。若错误假设稳态初始分布、反射边界或忽略终止选择，就会把非平稳采样偏差误认为势垒。论文问：能否从随机观测同时恢复势 \(\Phi\)(\(x\))、diffusion \(D\) 和非平衡初始分布 \(p_{0}\)(\(x\))？
Card 03 背景

背景

  • 潜变量 \(x\)∈[-1,1] 满足 overdamped Langevin equation，力 F=−dΦ/dx；神经 spike counts 条件于 \(x\) 服从已知 Poisson observation model。传统 stationary density 只约束 \(\Phi\)∝−log \(p_{\mathrm{eq}}\)，无法处理每个 trial 从 \(p_{0}\) 启动、有限时长以及吸收边界造成的选择偏差。
  • Figure 3 以 ground-truth 线性势为例：只有同时包含非平衡 \(p_{0}\)、吸收边界和 absorption operator 的完整模型恢复直线；删去任一组成都会产生虚假 valley 或 barrier。
Card 04 模型与方法

模型与方法

  • 作者把路径联合似然分解为初始分布、相邻时间的 Fokker–Planck transition、每个时间 bin 的 Poisson emission、末次观测到终止时刻的传播，以及表示已观测终止条件的 absorption probability。通过前向—后向递推对所有潜在轨迹积分，而非先从 spikes 点估计 \(x\)。
  • \(\Phi\)(\(x\)) 和 \(p_{0}\)(\(x\)) 在空间网格上非参数化，\(D\) 同时优化；边界可设 absorbing/reflection 并与数据生成规则一致。模型选择不只最大化训练 likelihood，而比较不同 trial subsets 推断特征的一致性，用 Jensen–Shannon divergence 和 bootstrap 评估稳定性。
Card 05 核心结果与证据

核心结果与证据

  • Figure 3 的 200 条合成 trials 表明：完整 non-stationary model 恢复线性 ground truth；忽略 absorption、改成 reflecting boundaries 或用 equilibrium \(p_{0}\) 都会制造并不存在的双稳/单稳结构。这是论文最关键的 failure-control，因为它显示错误机制假设可造成定性错误。
  • 在 ramping 与 stepping 两类决策动力学中，方法能联合恢复 \(\Phi\)、\(p_{0}\) 和 \(D\)。Figure 4 使用 200、1600 或 400 trials 展示数据量与不同 ground truth 下的恢复；更多 trials 缩小不确定性，但有限样本仍可能让细节漂移。
  • 特征一致性准则在合成数据中帮助选择合适空间分辨率和模型复杂度。所有结果都来自已知 Poisson observation function 的 synthetic datasets；本文没有在真实神经记录上验证 recovered potential 的生物解释。
Card 06 有效性与局限

有效性与局限

  • 方法当前是一维、Markov、白噪声、时间不变势与常数 \(D\)；跨 trial 的缓慢漂移、colored noise、多维决策变量和未知 observation function 不在验证范围。吸收边界和终止时刻必须被正确记录，否则 likelihood specification 仍会偏置。
  • 非参数网格提高灵活性，也带来数据量、正则化和可识别性要求；\(\Phi\) 的加法常数不可识别，\(p_{0}\)、\(D\) 与势形在短 trial 中可能互相补偿。作者提出扩展到多维和多观测流，但这属于未来方向。合成恢复不能替代真实数据的 posterior predictive checks 与干预验证。
