Is your batch size the problem? Revisiting the Adam-SGD gap in language modeling

批量才是问题吗？重新审视语言模型中的 Adam–SGD 差距

Teodora Srećković、Jonas Geiping、Antonio Orvieto · 预印本 · arXiv:2506.12543 · 论文原文 ↗

语言模型通常用 Adam 训练，已有解释将它优于 SGD 归因于稀有词、曲率异质性或梯度方向。本论文倒过来问：经过同样认真的调参，有没有让带动量 SGD 接近 Adam 的训练制度？批量改变时，哪些解释还能成立？

研究问题

  • 语言模型通常用 Adam 训练，已有解释将它优于 SGD 归因于稀有词、曲率异质性或梯度方向。本论文倒过来问：经过同样认真的调参，有没有让带动量 SGD 接近 Adam 的训练制度？批量改变时，哪些解释还能成立？（PDF 第1–3页）
  • 读者桥：输入是已分词文本，Transformer 将前缀表示为隐藏向量，输出下一 token 的概率分布；网络参数随小批量梯度更新，以降低预测损失。评价量是独立验证集上的困惑度，越低越好。批量是每次更新使用的序列数；它同时改变梯度估计噪声与给定 token 预算下的更新次数，不能只当作硬件吞吐参数。（第4–6、16页）

模型与方法

  • 主体是12层、160M 参数的因果语言模型，训练 SlimPajama，并检查 FineWeb 及250M、410M、1B 参数模型。基础比较不使用 weight decay；Adam 的第二矩衰减系数固定为0.95；文中 SGD 默认含动量。原始梯度先做全局范数裁剪，再更新动量。RMSNorm、RoPE 与 SwiGLU 等实现细节在附录 A，不能把这里的结论直接当作所有 Transformer 的性质。（第4、16–17页）
  • Figure 1 控制序列长512、13亿训练 token、1亿验证 token、10% warmup 后余弦学习率，扫描批量64、256、1024及两种优化器各自的学习率与动量。Section 2.3 另用序列2048、WSD 调度及不同训练长度，分别固定 token 总数和更新步数；这两组实验的序列长度、调度与预算不同，数字不应混算。（第2、4–6页）
  • 机制检查分两步：grafting 交换两种优化器的更新方向与幅度，检验哪部分对大批量 SGD 更不利；另在固定相同谱、改变分块结构的二次损失上研究噪声与符号更新。后者是解释用的简化动力学，不是语言模型的精确约化。（第9–12、20页）
  • 设网络参数为向量 $X_t$，平均损失为 $f$，学习率为 $\eta$，小批量大小为 $B$，单样本梯度噪声协方差为 $\Sigma(X)$，$W_t$ 为标准多维 Wiener 过程。原文 Eq. (2) 给出 SGD 的连续时间扩散近似，矩阵根作用于噪声：
\[dX_t=-\nabla f(X_t)\,dt+\sqrt{\frac{\eta\Sigma(X_t)}{B}}\,dW_t\]
  • 该近似中，增大批量减弱扩散幅度，而平均梯度漂移没有显式批量因子。它在论文的早期训练解释中提示 SGD 的进展更取决于更新次数；不能据此断言噪声对长期泛化或实际 SGD 动量无影响。（第11页 Eq. (2)）
  • 在独立高斯梯度噪声、对角协方差下，原文 Theorem 1 引用已有结果，得到 SignSGD 的一阶弱近似。其漂移项为：
\[b_{\mathrm{sign}}(X)=-\operatorname{erf}\!\left(\sqrt{\frac{B}{2}}\,\Sigma(X)^{-1/2}\nabla f(X)\right)\]
  • 这里 $b_{\mathrm{sign}}$ 是 Eq. (3) 中 $dt$ 的系数，$\operatorname{erf}$ 及协方差逆根按坐标作用。梯度相对噪声较小时，误差函数近似线性，漂移随 $\sqrt{B}$ 增强；大信噪比后逐渐饱和。SignSGD 先取梯度符号，因而“符号正确的概率”直接受批量影响。此式只写漂移，未把原式的扩散项设成零；定理针对 SignSGD，作者对 Adam 的联系是机制解释，不能转写为已证明的 Adam 收敛律。（第11–12页 Eq. (3)、Theorem 1）

核心结果与证据

  • 最直接的定量结果在第18页 Table 1：批量64时，最佳 Adam/SGD 的验证困惑度为28.77/30.76；批量256时为28.20/33.08；批量1024时为29.36/65.94。各值对应各自调好的学习率与动量。小批量显著缩小差距，但表中 SGD 并未严格达到与 Adam 相同的数值；大批量优势仍明显属于 Adam。（第2页 Figure 1，第18页 Table 1）
  • Figure 3 左侧固定 token 预算，SGD 随批量增大而变差；右侧固定更新步数，增加训练步数会缩小差距。Figure 5 进一步给出410M 与1B 参数的两组小批量训练，在足够长训练后 SGD 可超过 Adam。它们分别用批量8、500k步和批量16、850k步，不能把“某些长训练可超过”外推为相同时间预算下的一般优势。（第5–6页 Figures 3–5）
  • 稀有 token 的困惑度差异、沿更新方向的曲率和 Hessian 分块异质性都与部分失败制度相符，但不能单独解释这里的小批量成功。Figure 10 的 grafting 中，保留 Adam 方向、改用 SGD 幅度仍接近 Adam；反向组合更像 SGD。对动量最大坐标做5%、10%、20%裁剪能改善大批量 SGD，但 Figure 11 并未完全补平差距；这是受控干预的有限证据，不能声称方向问题已被彻底解决。（第7–10页 Figures 6–11）
  • Figure 9 的二次模型及 Figure 13 的高斯噪声实验与“符号方法漂移受信噪比影响”一致。统计模型说明一种可能的批量加速来源；它并未识别语言模型所有噪声结构，也没有证明 Adam 的完整经验差距只由该机制决定。（第9、11–12页）

有效性与局限

  • 固定 token 总数不是固定墙钟时间：小批量需要更多参数更新且硬件利用率较差。作者在第6页明确指出 SGD 在现实大批量预训练中效率仍不足。1B 结果来自单块 \(A_{100}\) 80GB、无梯度累积的小批量长训练；不能当作多设备工业训练建议。
  • 所有性能都是给定网格中的最佳结果，反映调参制度而非无条件优势。序列长度、学习率调度、动量、裁剪与比较预算必须一起固定；当它们改变时需重做比较。附录 A 对精度同时出现 bfloat16 训练配方与 FP16 设置描述，复现者需以公开代码的实际配置核对，不能凭卡片消除原文差异。（第16–17页）
  • SDE 是小步长弱近似，Theorem 1 的高斯、独立、对角协方差假设与语言模型中可能相关且重尾的噪声不等价。早期平均漂移的区别不自动控制最终验证困惑度；已有稀有词、曲率解释是被限定适用范围，未被这项实验全面推翻。（第7–12页）
