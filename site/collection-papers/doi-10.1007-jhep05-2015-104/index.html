Card 02 研究问题

研究问题

  • 两个 QFT 在有限测量下有多难区分？作者把 Euclidean path-integral weight 视为 field-configuration space 上的概率分布，用 KL relative entropy 定义理论邻近性，并问它如何连接 coupling-space geometry、RG coarse graining、fine tuning 与 EFT landscape。
Card 03 背景

背景

  • 对同一 field space 上的分布 \(p\)、\(q\)，\(DKL(p||q)\ge 0\) 且不对称；大量独立样本误认概率按 exp[-\(N\) DKL] 衰减。QFT 版本比较的是 Euclidean configuration measures，不是同一 Hilbert space 上 density matrices 的 quantum relative entropy。
  • 若两理论的 field/operator content 不同，作者要求把它们嵌入共同 master UV theory；这个选择以及 UV regularization 是定义的一部分。
Card 04 模型与方法

模型与方法

  • 对 actions Sp、Sq，有 DKL=\(p\)+log(Zq/Zp)。用局域 operators Oi 的小 coupling deformation 展开到二阶，得到 connected two-point functions 的积分，即 Fisher metric。
  • UV contact terms 通常 scheme dependent；若给定 finite UV completion，regularization 可固定。对于 CFT 的 exactly marginal deformations，体积归一化后的二阶项化为 Zamolodchikov metric。
Card 05 核心结果与证据

核心结果与证据

  • 论文建立从 relative entropy 到 coupling-space metric 的局部关系：附近 CFT 的 DKL 二阶项由 Zamolodchikov metric 测量。对于 relevant deformation，cutoff dependence 记录实验分辨率；coarse graining 后 DKL 下降，表达 RG 丢失区分 UV theories 的信息。
  • 作者还提出以 UV 与 IR distinguishability 的比率描述 fine tuning，并把 landscape EFT 是否可区分转成相对熵阈值。这些是框架与 toy examples，不是对真实 Standard Model landscape 的数值普查。
  • RG 单调性来自 stochastic/coarse-graining map 下 relative entropy 的 data-processing 性质；它不等于任意 scheme 下所有有限 counterterm 部分都形成普适 c-function。
Card 06 有效性与局限

有效性与局限

  • Euclidean weights 必须可归一化并可作为正概率测度；复杂作用量、sign problem 与 gauge redundancy 需要额外处理。连续 QFT 的 DKL 含 UV/volume divergences，只有指定 regulator、比较方向和 normalization 后才有操作意义。
  • 近邻 metric 只保留 coupling difference 的二阶项；远距离理论的 KL 不对称且不满足三角不等式。landscape 与 fine-tuning 讨论依赖共同 master theory、可测 observables 与实验 cutoff，不能直接当成自然性定理。
