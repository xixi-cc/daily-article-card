Card 02 研究问题

研究问题

  • Induction circuit 通常由前层 previous-token head 与后层 induction head 组成：先把前一 token/label 写入 residual stream，再由后层匹配当前 query 并复制对应 value。训练 loss 常在 induction heads 出现时突然下降，但多个 heads 是否冗余、match 与 copy 哪些步骤导致相变并不清楚。
  • 传统 ablation 在训练后删除 head，只回答已形成 circuit 是否必要；progress metrics 多为相关。本文问能否像 optogenetics 一样，在整个训练过程中固定某个 activation/pattern 到其理想值，隔离 remaining subcircuit 的学习曲线，从而对形成机制做干预性判断。
Card 03 模型与方法

模型与方法

  • 任务是 Omniglot few-shot classification：每个 sequence 有两组 exemplar–random-label pairs 与 query exemplar；labels 在每个 context 随机重映射，held-out classes/label pairs 测 ICL。图像先经 frozen ImageNet ResNet18，随后输入小型 two-layer attention-only Transformer。
  • 作者实现 JAX call-with-all-aux：第一次 forward 缓存 attention patterns、head outputs 或 residual components；第二次 forward 用 mask 把指定 activation clamp 成基线/理想值。Pattern-preserving ablation 可保持某 heads 的 attention map 同时关闭其他 outputs，减少 routing confound。
  • 他们把形成分为三组：\(A=previous\)-token attend+copy；\(B=induction\)-head QK routing/match；\(C=value\) routing+label copy。Toy tensor-product loss展示多个平滑增长变量共同学习会在 saddle 附近产生 plateau/phase change；逐组 clamps 再追踪真实模型的 isolated learning curves。
Card 04 核心结果与证据

核心结果与证据

  • Figure 1 给出 circuit 与任务：前层把 label 和 exemplar 信息并置，后层 QK 完成 match、V/O 完成 copy。训练后 single-head ablation 几乎不降 accuracy，而多 heads 组合才产生明显影响，说明 induction heads additively redundant；previous-token 到 induction heads 也呈 many-to-many wiring。
  • Clamping experiments 将突然 loss drop 拆成三个各自平滑形成的 subcircuits A/B/\(C\)；只有它们共同 co-evolve 时出现明显 phase change。该因果证据比 weight composition score 更直接，但 clamp 同时改变优化路径，解释限于 intervention 所定义的 counterfactual。
  • Figure 6 扫 data diversity：classes 增多主要延迟 QK-match subcircuit B，labels 增多主要延迟 copy subcircuit \(C\)；这两种 bottleneck 最终都把整体 phase change 推后。Appendix 报告普通 1e6-sequence run 在 2018 MacBook Pro 约 7 分钟，利于多 seed 复查。
Card 05 有效性与局限

有效性与局限

  • 模型只有两层、attention-only，任务是 50-class/1-exemplar 等受控 Omniglot setup；自然语言与 frontier LLM 包含 MLP、更多 layers/heads、positional structure 和多种 competing algorithms。Induction circuit 对这里的 task 很重要，不等于解释所有 ICL。
  • Activation clamp 具有因果干预优势，但把 activation 固定为‘理想/最终’模式可能提供模型在自然训练时不可获得的信息，并改变其他 components 的 gradient distribution。作者比较多种 previous-token clamp，仍不能排除所有 off-manifold effects。
  • Redundancy 使 single-head ablation 的必要性测试失灵，但 additive performance 不证明 heads 在所有 inputs 功能等价。Toy tensor product 解释 plateau 是机制类比，不是 Transformer dynamics 的数学推导。本卡未独立复现。

复现与资源
