Grokked Transformers are Implicit Reasoners: A Mechanistic Journey to the Edge of Generalization

经历 Grokking 的 Transformer 是隐式推理器

Card 01 作者信息

作者信息

Card 02 研究问题

研究问题

  • 语言模型能记住 atomic facts，却常不能把参数记忆中的两个事实隐式组合。作者构造 composition 与 comparison 两类任务，问 Transformer 是否最终能在不输出 chain-of-thought 的情况下推理，以及训练内分布 ID 与系统性 OOD 泛化为何不同。
  • 另一个问题是 grokking 的控制量：泛化延迟主要由样本绝对数量决定，还是由 inferred facts 与 atomic facts 的比例 \(\phi\) 决定？作者还希望在网络内部找到从记忆电路转向泛化电路的可测变化。
Card 03 模型与方法

模型与方法

  • Composition 数据由 (\(h\),r₁,b) 与 (b,r₂,\(t\)) 推出查询 (\(h\),r₁,r₂,\(t\))；comparison 数据由实体属性值比较产生 <、=、> 标签。训练集混合 atomic 与 inferred facts，并将组合或实体子集划分为 train、ID test 与 OOD test。主要模型是小型 causal Transformer，持续训练到训练误差早已饱和之后。
  • 作者扫描实体数、模型规模与 \(\phi\)，并以 accuracy 随 optimization steps/epochs 的曲线识别 grokking。内部机制用 logit lens 解码中间 state，用 causal tracing 替换对应 token 的隐藏状态，测量某 state 对最终 prediction 的影响。
  • Figure 4 的 composition circuit 将计算分为两段：低层从 \(h\),r₁ 恢复 bridge entity b，并把 r₂ 保留到中层；高层再用 b,r₂ 检索 \(t\)。作者跟踪 causal strength 与中间 token 的 mean reciprocal rank，观察第二跳在 grokking 期间逐渐形成。
Card 04 核心结果与证据

核心结果与证据

  • Composition 的 train 与 ID test 最终接近满分，但 OOD accuracy 即使训练到约两百万步仍接近零；comparison 则出现 OOD 系统性泛化。\(\phi\) 增大显著加快 ID grokking，而固定 \(\phi\) 改变训练集大小不改变定性延迟，支持“关键是数据分布而非单纯 critical data size”的受控结论。
  • Figure 4a 给出 composition generalizing circuit：layer 5 的一个 state 编码 bridge b，另一个保留 r₂，二者在高层汇合得到 \(t\)。Figure 4b/c 显示相关 causal connection 与 r₂ representation 在 grokking 阶段增强；这是机制关联证据，但 causal tracing 仍依赖所选 intervention。
  • 在更大搜索空间任务中，完全 grokked 的专用 Transformer 接近满分，而论文测试的 GPT-4-Turbo/Gemini-1.5-Pro 直接、CoT 与 retrieval variants 表现较差。该比较是特定合成协议、特定时间点模型，不应外推成通用模型排名。
Card 05 有效性与局限

有效性与局限

  • 任务使用符号化实体、固定推理规则和受控 train/OOD splits；自然语言中的歧义、共享语义、pretraining 与多任务迁移可能改变结果。Composition OOD 失败并不证明 Transformer 原理上不能组合，只证明这一训练设置没有获得所需系统性。
  • Logit lens 将中间状态投到输出词表，causal tracing 用替换式 intervention；两者可能受 decoder basis、off-manifold perturbation 与 correlated pathways 影响。得到的简洁 circuit 是经过 pruning 的解释，不是唯一因果分解。
  • \(\phi\) 与速度的关系来自有限模型和数据范围，训练计算开销很大；固定 \(\phi\) 的 size sweep 只能反驳该协议下的简单 data-size explanation。对商业模型的结果会随版本与 prompting 变化。本卡未独立复现。
