Card 02 研究问题

研究问题

  • 实空间 RG 的粗粒化规则常凭经验，迭代会放大错误；通用机器学习又缺少场论可解释性。论文问：能否直接最大化局域 block 与远端 environment 的 mutual information，一步学习最相关 lattice operators、order parameters 与 scaling dimensions？
Card 03 背景

背景

  • RSMI principle 认为最优 coarse-graining \(H\) 保留 I(\(H\):E)，buffer B 排除短程相关；在临界系统中最优压缩由 relevant operators 决定。难点是高维 mutual information 的估计和离散 coarse variable 的可微优化。
  • RSMI-NE 用神经网络互信息下界与卷积 filter Λ共同训练；其物理可解释性来自优化目标，而不是网络结构本身。
Card 04 模型与方法

模型与方法

  • 可见区V经 \(h\)=\(\tau\)(\(\Lambda\)·v)压缩为二分量 binary \(H\)，critic fΘ估计 IΛ(\(H\):E)，Λ与Θ用 stochastic gradient descent 联训。buffer thickness LB 充当直接选择长程尺度的旋钮，无需迭代 RG map。
  • benchmark 是 square-lattice interacting dimer model，低温有四重 columnar order，\(\mathrm{TBKT}=0.65\)(1)以上为 algebraic critical phase；continuum 对应 sine-Gordon height field，V cos4φ 与 stiffness \(g\)(\(T\)) 控制相关。
Card 05 核心结果与证据

核心结果与证据

  • Figure 2 中低温最优 RSMI 为 log4，准确编码四种 columnar states；IΛ(\(T\)) 的非解析性定位 BKT transition，临界相中它随 buffer algebraic decay。独立训练得到 columnar、plaquette、staggered 三类 pristine filters。
  • columnar filter 在低温成为已知 dimer-symmetry-breaking order parameter，过 TBKT 后消失；高温 staggered filters 对应 emergent electric field \(\nabla \phi\)。滤波器 ensemble overlap 还显示 plaquette correlations 与 symmetry restoration。
  • 以 learned plaquette network 的 correlator 拟合 \(T\)→∞ scaling dimension 得1.00037，对应场论预测1.0。代码公开，但论文只在已知 dimer field theory 上验证；‘automated theory building’仍是前景而非完整自动生成新理论。
Card 06 有效性与局限

有效性与局限

  • 互信息神经下界、有限样本和随机优化可能漏掉等价/近简并 filters；作者通过多次训练分析 ensemble，但没有全局最优证明。binary H维度预先指定，虽称可系统选择，主结果未做广泛容量扫描。
  • 非平衡 formal understanding 尚缺；文中非平衡例证来自 companion work。BKT 有限尺寸、buffer/block大小、Monte Carlo采样质量和已知 height mapping 都影响定量解释。
