PDEBENCH: An Extensive Benchmark for Scientific Machine Learning

PDEBench：面向科学机器学习的大规模偏微分方程基准

Makoto Takamoto、Timothy Praditia、Raphael Leiteritz、Dan MacKinlay、Francesco Alesiani、Dirk Pflüger、Mathias Niepert · 预印本 · arXiv:2210.07182 · 论文原文 ↗

PDEBench 提供可下载高保真数据、可配置数据生成代码、统一 API、FNO/U-Net/PINN 与 gradient-based inverse baselines，以及面向科学失败模式的多维指标。

摘要

  • PDEBench 提供可下载高保真数据、可配置数据生成代码、统一 API、FNO/U-Net/PINN 与 gradient-based inverse baselines，以及面向科学失败模式的多维指标。
  • 范围含 1D/2D diffusion-reaction、advection、Burgers、diffusion-sorption、1D/2D/3D compressible NS、2D incompressible NS、Darcy 和 shallow-water，共 11 类表项、不同参数形成 35 datasets。
  • 论文的核心观察是整体 RMSE 不足以表示物理质量：边界、守恒、最高频谱、局部最大误差和时间 rollout 会暴露不同失败。

背景

  • 每个 PDE、boundary/initial condition 和参数分布定义不同任务，不能像 ImageNet 那样把所有物理系统视为同一 i.i.\(d\). 数据集。
  • forward surrogate 近似 state \(history\to future\) state；inverse benchmark 则从未来 observation 反推 initial condition，再检查该估计经过 surrogate 后能否重现未来。
  • ground truth 来自 classical simulators，因此 benchmark 评价的是对给定离散 solver/data-generating assumptions 的模仿，不直接等于实验真值。

模型与方法

  • Table 1 的规模从 1D 1024×200、10000 samples 到 3D compressible NS 128³×21、100 samples；2D compressible NS 为 512²×21、1000 samples，分辨率与样本数随计算成本明显不同。
  • 指标含 RMSE、nRMSE、max error、conserved-value RMSE、boundary RMSE，以及 low/mid/high-frequency RMSE；频域指标用于检测 shock/小尺度结构被平均误差掩盖。
  • baseline 用 FNO、U-Net、PINN；data-driven split 为 90% train、10% validation/test，PINN 因每次只针对一个 IC/BC，选 10 samples 独立训练并平均。
  • autoregressive U-Net 比较 one-step、recurrent 与 pushforward training；inverse 以 gradient 优化 initial condition，通常用 \(T=15\)，CFD 用 \(T=5\)。

核心结果与证据

  • FNO 在多数 forward datasets/metrics 优于 U-Net 与 PINN，并在许多问题的频谱上约 4×10^-4 error；但这是论文 baseline 配置，不代表所有后续实现。
  • Burgers 非线性增强时 FNO high-frequency fRMSE 可恶化约两个数量级；说明低 overall RMSE 仍可能漏掉 shock/high-frequency dynamics。
  • Darcy 的 normalized error 会在 forcing/solution amplitude 很小时显得大；compressible NS overall RMSE 远差于简单 PDE，3D inviscid 反而优于 2D 的现象被作者归因于较低分辨率带来的平滑，而非 3D 更容易。
  • autoregressive test error 随 rollout steps 快速累积；pushforward training 在较长 horizon 更稳定，因此论文采用它作 U-Net baseline。训练时间窗之外的 advection/Burgers extrapolation error 单调增长。
  • inverse benchmark 中 FNO 通常优于 U-Net，但 initial-condition error 与最终 prediction error并不相同；误差常集中于 mid/high frequencies。

有效性与局限

  • benchmark 主要是 hydromechanical/time-dependent PDE；未覆盖 quantum、multiphase flows 或 non-rectangular domains，复杂 geometry 与真实传感噪声也有限。
  • 不同 datasets 的 solver、resolution、sample count 和 time horizon 不同，不能把 raw RMSE 直接跨 PDE 排名难度；低分辨率可人为平滑复杂性。
  • PINN 与 amortized operator baseline 训练单位不同：PINN 每实例重训，FNO/U-Net 先跨样本训练；速度/精度比较必须注明 query count 与摊销。
  • \(v_{7}\) 数据与当前仓库可能有修订；使用 benchmark 时需记录 DOI 文件 hash、生成参数和预处理，而非只引用项目名。

复现与资源

  • 代码：https://github.com/pdebench/PDEBench；数据永久 DOI：10.18419/darus-2986，DaRUS dataverse 提供单数据集下载。
  • 复现应锁定 dataset filename/hash、equation parameters、solver resolution、split、baseline config 与 random seeds，并同时输出 RMSE/nRMSE/max/cRMSE/bRMSE/fRMSE 和 per-step rollout curves。

阅读指南

  • 先读 Table 1 了解数据规模不均，再读 Appendix B 的指标定义；不要只复制 Figure 2 的 aggregate RMSE。
  • 随后看 Figs. 3–5，重点是 shock 高频、低幅归一化、CFD 分辨率与 rollout accumulation 四类反例。
  • 最后读 limitations 和数据生成 Appendix \(D\)；新增模型应先复用相同文件/split，再做扩展任务。
