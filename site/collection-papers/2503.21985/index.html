研究问题

  • 等变网络保留有用归纳偏置，但输出至少继承输入自对称；当目标是苯的非对称取代、对称 latent 的图解码或桌到椅时，确定性函数无法表达。
  • 能否用等变条件分布而非函数给出必要充分表示条件，并通过随机 canonicalization 既破坏单样本对称又保持分布等变。

模型与方法

  • 在论文给出的群作用、可测规范化等条件下，Theorem 3.4 以输入相关 inversion kernel 的群元素和额外独立噪声 \(\epsilon\) 表示等变条件分布；实验主要研究对称破缺，省略 \(\epsilon\)，因而抽象存在性定理不能直接变成实验网络对任意分布的无条件保证。
  • SymPE 将随机规范化得到的编码注入等变 backbone。Theorem 6.1 在群不变输入、相应等变条件分布与噪声等条件下给出总体平方风险投影关系；它不保证任意损失或有限样本训练都得到改进。

核心结果与证据

  • Figure 1 说明确定性等变映射必须保留输入稳定子；单个随机样本可破缺输入自对称，而条件分布仍可等变。
  • 所测随机图重构中 SymPE 为 0.77%，Laplacian 编码为 0.98%；QM9 的 SymPE NLL 为 30.3、DiGress 为 129.7，且各模型参数与指标并不完全可比。
  • Ising 对照中，分布内 relaxed convolution 能量 −1.49 低于 SymPE 的 −1.46，而分布外两者为 −1.42 与 −1.47；这表明结果依条件和指标变化，并非所有设置均最优。

有效性与局限

  • 抽象表示依赖论文的群作用和可测性条件，也使用额外独立噪声；具体群的可采样规范化与有限网络表达能力需另行建立。实验省略该额外噪声，不能将定理无条件推广到实验网络。
  • 实验指标改善需与参数量、positional encoding 容量和随机样本数等算力比较；生成分布等变不保证单样本物理合法。
  • 随机 canonical frame 还可能增加预测方差，因此需要校准采样数与不确定度。
  • 这些结论针对论文所测的受控数据、架构与优化设置；跨模型、跨任务或跨尺度使用时必须重新验证，不能把相关性、可视化或有限样本结果直接解释为普适机制。本卡未独立复现。
