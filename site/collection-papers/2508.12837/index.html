Learning In-context n-grams with Transformers: Sub-n-grams Are Near-Stationary Points

Transformer 的上下文 \(n\) 元语法学习：低阶 \(n\) 元语法是近驻点

Aditya Varre、Gizem Yüce、Nicolas Flammarion · Proceedings of the 42nd International Conference on Machine Learning, PMLR 267:60924-60963 · 论文原文 ↗

训练 Transformer 在上下文中预测下一个 token 时，测试损失有时长时间停在台阶上，然后才学会使用更长的历史。本文问：对由 \(n\) 元语法产生的序列，较低阶的 \(k\) 元语法解为何能成为损失地形中的慢梯度区域？这里的“台阶”是优化轨迹现象，“驻点”是模型参数处的总体损失梯度性质；两者不能直接画等号。

研究问题

  • 训练 Transformer 在上下文中预测下一个 token 时，测试损失有时长时间停在台阶上，然后才学会使用更长的历史。本文问：对由 \(n\) 元语法产生的序列，较低阶的 \(k\) 元语法解为何能成为损失地形中的慢梯度区域？这里的“台阶”是优化轨迹现象，“驻点”是模型参数处的总体损失梯度性质；两者不能直接画等号。
  • 论文给出一个一般的交叉熵驻点充分条件，再为受限制的两层 attention-only Transformer 构造表达 \(k\) 元语法计数估计量的参数，并在序列长度与参数尺度趋于无穷时证明总体损失梯度消失。有限规模训练曲线和注意力图提供对应的数值例子，但没有证明优化必经这些构造点。

背景

  • 将上下文学习限制在有限字母表的齐次马尔可夫链，使“模型用了多长历史”可以由计数规则精确定义。Edelman 等先观察到均匀预测、unigram、bigram 等阶段；本文进一步询问这些中间规则在总体目标函数中的梯度结构。工作属于纯 AI 的学习动力学理论及数值例子，不把训练损失视为热力学自由能，也不把台阶称作严格相变。

模型与方法

  • 一次任务先从先验 \(\mathcal P\) 抽取一套转移概率 \(p_\tau\)，再由它生成长度为 \(T\) 的 token 序列 \(x^T\)。字母表大小为 \(S\)。真过程假设 \(n-1\) 阶马尔可夫性与时间齐次性；模型接收当前序列，输出下一个 token 的概率向量，跨任务和序列的目标是总体交叉熵。所谓 in-context，是模型参数在该序列内不更新，而利用这条序列中的重复历史估计当前任务的转移概率。（正式版 PDF 物理页 3，§2.1–2.2）
  • \(k\) 元语法估计量先找出与末尾的 \(k-1\) 个 token 相同的历史，再对这些历史后面的 token 计数并归一化：
\[\widehat p_k(x_{T+1}=a\mid x^T)=\frac{\sum_{l=k}^{T}\mathbf 1\{x_{l-k+1}^{l-1}=x_{T-k+2}^{T}\}\mathbf 1\{x_l=a\}}{\sum_{l=k}^{T}\mathbf 1\{x_{l-k+1}^{l-1}=x_{T-k+2}^{T}\}}.\]

其中 \(a\) 是候选下一 token，\(l\) 是上下文中的计数位置，\(\mathbf 1\) 为指示函数。\(k=1\) 时历史为空，得到全序列的经验频率；增加 \(k\) 会保留更多条件信息，但每种历史可用的样本减少。（物理页 3，Definition 2.1）

  • 理论模型有两层分离式 attention。第一层的各个头按相对位置读取先前 token，并与跳连结果拼接；第二层比较位置之间的历史、平均匹配历史后面的 token。嵌入正交，第一层注意力仅由位置决定，第二层 value 固定，无第二层残差与 MLP。这些选择使模型的输出直接成为概率向量。对 \(k<n\) 的构造，停用读取更早位置的头；当尺度 \(c\to\infty\)，softmax 选择相同的 \(k-1\) 历史，得到上述计数规则。（物理页 4–7，§2.3、§4.1，Eq. 8，Appendix B.1）
  • 关键充分条件针对 score，即参数改变时对数预测概率的导数。如果 score 只依赖任务分布及序列后缀，且模型预测等于真分布在该后缀上的条件概率，则对较早历史求平均后，总体交叉熵梯度为零。这里 score 是统计量/导数，不能把它理解为注意力图本身；论文再利用稀疏注意力和 softmax 导数的界，把该条件应用于特定参数构造。（物理页 5、7–8，Proposition 3.2、Theorem 4.1；物理页 15–20，Appendix B）

核心定理与证据

  • Proposition 3.2 是充分条件：若 score 只看给定后缀，而模型输出又等于该后缀的真实条件分布，总体梯度消失。它适用于比本文 Transformer 更一般的下一个 token 预测模型，但并不声称每个台阶都满足这些条件。（物理页 5，Proposition 3.2；物理页 20–21，Appendix \(C\)）
  • Figure 2 与 Eq. 8 展示构造机制：第一层把历史 token 放入不同块，第二层只对匹配历史的位置给权重，随后平均位置上的 token。停用较远历史的头即可从 trigram 规则退到 bigram 规则；在 \(c\to\infty\) 极限，Lemma B.1–B.2 给出这种计数表示。（物理页 6–7，Figure 2、Eq. 8；物理页 14–15，Appendix B.1）
  • Theorem 4.1 将该构造处的梯度控制为两类误差：有限序列的 \(k\) 元语法估计误差，以及有限参数尺度下注意力未完全硬选择的误差。论文在 \(T,c\to\infty\) 且取 \(c=\Theta(T)\) 的渐近条件下得到梯度趋零，因此称为近驻点；这是总体损失的一阶陈述，未给出有限训练过程的驻留时间或跨台阶跃迁定理。（物理页 7，Theorem 4.1；物理页 15–20，Appendix B.2；物理页 36–37，Lemma \(H\).6）
  • Figure 1 的四元语法训练测试损失（纵轴）随训练步数（横轴）呈分段下降，虚线是各阶计数估计量的交叉熵水平；曲线停留位置与较低阶水平接近。这是训练数值例子，不是梯度定理的证明。更细的 trigram 例子中，Figure 3 的两个第一层头先近似均匀，随后都指向前一个 token，后期其中一个再指向前两个位置；这与从较低阶到较高阶历史的解释一致。（物理页 2，Figure 1；物理页 8–9，§5、Figure 3）
  • Figure 3 的具体设置为 \(n=3\)、\(S=5\)、\(T=32\)、Dirichlet 参数 \(\alpha=0.5\) 的合成序列；两层简化模型、第一层两个头、one-hot 嵌入，Adam 学习率 0.01、batch 128、无 weight decay，测试集 \(2^{16}\) 条序列。附录的更一般 attention-only 模型与五个随机种子支持类似的头部次序，但不证明所有初始化都会按此路径训练。（物理页 8–9，§5；物理页 37–40，Appendix I、Figures 5–8）

有效性与局限

  • 定理使用总体交叉熵、特定的分离式两层架构、正交嵌入、固定 value 和明确构造的参数；结论在 \(T,c\to\infty\) 下成立。有限上下文、有限训练集、weight decay、一般大型语言模型及 SGD 的逃逸时间均未由主定理控制。Appendix F 讨论更一般架构所需的额外归一化或 MLP，不能据此把简化模型的定理直接推广为一般 Transformer 定理。（物理页 4、7–9、28–30）
  • 计数估计依赖相同历史出现；有限长度下历史未出现时分母可能为零，本文的渐近论证没有给出本卡可引用的通用有限长度平滑规则。Lemma \(H\).6 的极限论证使用高阶马尔可夫链的遍历性；对不满足这些条件的序列分布不能照搬。（物理页 3，Definition 2.1；物理页 34–37，Appendix \(H\)）
  • 正式版物理页 3 对交叉熵 \(\ell\) 的显示定义漏写负号；物理页 20 的证明明确使用负号，并据此得到 Lemma 3.1 的梯度方向。本卡沿用作者在证明中实际使用的交叉熵符号约定，但不把页 3 的显示式原样当成无歧义公式。原文讨论“台阶后因曲率或噪声逃逸”是解释而非已证明的动力学机制。（物理页 3、8、20）
