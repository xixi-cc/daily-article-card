Neural networks trained with SGD learn distributions of increasing complexity

经 SGD 训练的神经网络会学习复杂度逐渐增加的分布

Card 01 作者信息

作者信息

  • 作者：Maria Refinetti、Alessandro Ingrosso、Sebastian Goldt。arXiv:2211.11567v2，发表于 ICML 2023。研究结合可解 perceptron 动力学与 CIFAR 深网实验，提出 distributional simplicity bias（DSB）。
Card 02 研究问题

研究问题

  • 已有 simplicity bias 多描述网络先学低频或简单函数，但没有直接说明训练数据的哪些统计量在何时控制泛化。作者问：SGD 是否先利用类别均值、协方差等低阶统计，随后才依赖更高阶 cumulants；能否通过一系列匹配不同统计阶数的“clone distributions”观察这一顺序？
  • DSB 不是给每个真实分布指定一个绝对复杂度。它比较在同一初始化和训练方案下，网络分别用真实数据及其逐渐逼真的近似分布训练、再统一在真实测试集上评估时，学习曲线能重合多久。
Card 03 模型与方法

模型与方法

  • 理论模型是用 SGD/梯度流训练的单个 perceptron，在两类矩形分布上做分类。把权重动力学按局部场 \(\lambda=w\)·\(x\)/\(\sqrt D\) 展开，可见初始方向由类别均值差 \(m\) 决定；下一阶包含类内协方差，继续展开才出现四阶及更高 cumulants。
  • CIFAR10 实验构造四级训练分布：只匹配类均值的 isotropic Gaussian、匹配类均值和协方差的 Gaussian mixture、每类 WGAN、扩散模型生成并由教师标注的 cifar5m，以及真实 CIFAR10。所有模型在 CIFAR10 测试集上评估。
  • 网络包括两层全连接、LeNet、DenseNet121、ResNet18 和 ViT；还对 ImageNet 预训练 ResNet18 端到端微调。主设置用 SGD、momentum 0.9、weight decay 5e-4、batch 128、cosine schedule、200 epochs，并对每种训练分布做三次运行。
Card 04 核心结果与证据

核心结果与证据

  • Figure 1 中，Gaussian-mixture/CIFAR10 与真实 CIFAR10 训练的 ResNet18 在最初约 50 个 SGD steps 测试准确率相同；WGAN clone 约匹配 1000 steps，cifar5m 约匹配 2000 steps。越能保留高阶图像统计的 clone，越久复现真实训练动态。
  • perceptron 的渐近展开给出机制实例：初始权重与 mean difference 对齐，协方差修正随后出现，更高阶累积量更晚影响固定点和决策边界。矩形数据的 Gaussian clones 依次重现这些阶段，连接了形式展开与可观察学习曲线。
  • 多种 CNN 与 ViT 都呈现 clone 曲线依复杂度依次分离，ImageNet 预训练 ResNet 也保留该现象；这削弱了“只由独立小初始化/中心极限定理造成”的解释。但 CIFAR100 上深模型的 Gaussian clone 很早分离，作者明确认为需要更好的高阶 clones 才能检验同一 conjecture。
Card 05 有效性与局限

有效性与局限

  • Gaussian 只精确控制一、二阶 cumulants，而 WGAN/cifar5m 并非只增加某一个阶数；它们同时改变生成伪影、覆盖度、标签噪声和样本量。因此曲线重合顺序支持“分布近似复杂度”解释，但不能精确断言网络在某一步只使用第 \(k\) 阶统计。
  • DSB 是作者的 conjecture 加解析 toy model 与经验支持，不是所有参数模型/SGD 的普适定理。三次运行共享标准初始化且数据增强/顺序变化，误差估计有限；CIFAR10 clone 与真实数据的样本数和生成机制不同。曲线重合也不证明 DSB 本身导致最终泛化或防止 overfitting。
