作者信息

Card 02 研究问题

研究问题

  • 扩散理论通常假设 score 已知，却少有可精确跟踪“有限网络如何从数据学 score、参数如何演化、生成分布何时逼近目标”的模型。
  • 对于低秩非线性 DAE 和 Gaussian mixture/结构化高维数据，能否闭合 SGD 动力学，预测 mode learning、skip connection、样本质量和 recursive self-consumption？
Card 03 模型与方法

模型与方法

  • 模型是带 \(r\) 个隐藏单元、非线性 \(\sigma\) 和 skip coefficient b 的浅层 DAE，在不同 noise time \(t\) 上用 denoising loss online SGD 训练；生成阶段把学得 denoiser 嵌入 reverse SDE。
  • 高维 \(d\)、样本率与学习率按比例取极限，参数动力学由 teacher means/covariance 子空间上的 overlaps \(M\)、Gram matrix \(Q\)/\(\Omega\) 和 b 等有限 order parameters 闭合。
  • 理论 ODE 与有限 \(d\) 数值实验比较；目标包括双/三模 Gaussian mixtures，以及具有 MNIST sevens covariance 的 Gaussian proxy。Figure 1 展示 summary statistics 随训练时间。
Card 04 核心结果与证据

核心结果与证据

  • 理论预测 mode-aligned overlaps 从随机初始化增长、隐藏单元发生 specialization，skip connection 与 covariance directions 同步演化；有限维实验总体跟随 order-parameter ODE。
  • 训练进程中生成分布从近 Gaussian 逐步形成 mixture modes，模型宽度 \(r\) 限制可表达方向/模式。Figures 2–3 将解析预测与生成 density 的演化对应。
  • 对真实 MNIST covariance proxy，理论仍抓住主要趋势但出现有限维偏差。反复用模型生成样本再训练会改变 covariance/模式，Figure 4 讨论 model collapse 的可解版本。
Card 05 有效性与局限

有效性与局限

  • 网络浅、hidden rank 固定，数据主要是 Gaussian/mixture 或 covariance proxy；现代 UNet/Transformer 的层级特征、非 Gaussian 图像统计和条件生成不在证明内。
  • 结果依赖高维比例极限、online SGD 和特定 noise schedule；有限 \(d=784\) 已出现差异。闭合 order parameters 捕获宏观统计，不保证逐样本 reverse trajectories。
  • “insights”是可解 toy model 的机制线索，不能直接给大型 diffusion 的定量 scaling law。recursive collapse 实验也简化了数据过滤与再训练。本卡未独立重推。
