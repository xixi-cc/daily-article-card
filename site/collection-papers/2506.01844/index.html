SmolVLA: A Vision-Language-Action Model for Affordable and Efficient Robotics

SmolVLA：面向低成本高效率机器人的视觉—语言—动作模型

Card 02 研究问题

研究问题

  • 主流 VLA 往往有数十亿参数，需要昂贵 GPU 与机构数据。论文问能否用约 450M 参数、社区采集的低成本机器人数据，在单 GPU 训练并部署到消费级 GPU 甚至 CPU，同时保持可竞争的操作成功率。
  • 第二个问题是闭环时序：chunked policy 的感知/推理延迟会让机器人执行陈旧动作。能否把 action generation 与 execution 解耦，在不牺牲稳定性的前提下提高控制刷新率？
Card 03 背景

背景

  • VLA 把语言指令、RGB 与关节状态编码为 token，再生成连续动作序列。动作 chunk 减少推理调用，却造成 observation-to-action latency 和开环漂移；模型尺度、数据覆盖和实时控制共同决定物理成功。
  • SmolVLA 从小型预训练 VLM 出发，截去后层，另接 Action Expert；这不是简单压缩大 VLA，而是重新分配视觉语言表征与控制头的计算。
Card 04 模型与方法

模型与方法

  • Figure 1 中三类输入进入截断 VLM，合并 token 与 Action Expert 的交替 cross/self-attention 交互；动作由 flow matching 从噪声轨迹生成 \(n\)-step chunk。causal attention 防止未来动作泄漏。
  • 预训练使用 LeRobot 社区数据，随后在 LIBERO、Meta-World 与 SO100/SO101 真机任务上单任务或多任务训练。论文同时消融预训练、VLM skip、attention 类型和 observation 更新。
  • 异步 stack 在执行当前队列时并行预测新 chunk；用 overlap 与 joint-space similarity 过滤/拼接，参数 \(g\) 控制队列消耗和重规划频率。策略可在远程 GPU，执行器保持本地控制循环。

核心结果与证据

  • Figure 1 把 community datasets、紧凑 VLM、Action Expert 与 affordable robots 放在同一系统图里，明确效率来自模型与数据/硬件协同，而非只报告参数量。

Card 06 有效性与局限

有效性与局限

  • 预训练主要来自 SO100 单一 embodiment；论文虽展示 SO101 微调，跨机器人、相机布局、动力学与长时域泛化仍有限。社区数据的动作质量和任务分布也可能形成隐含偏置。
  • 真机成功率样本量、初态分布、人工复位和失败定义决定置信区间；异步吞吐提升不等于安全性，队列拼接在接触变化或人机环境中可能执行过时动作。
  • 结果是作者实现和给定硬件上的 observed benchmark success，不是任意低成本机器人上的普遍结论。该卡 no independent reproduction performed。
