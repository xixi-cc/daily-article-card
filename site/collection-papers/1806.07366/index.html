TITLE · ABSTRACT

Neural Ordinary Differential Equations

神经常微分方程

We introduce a new family of deep neural network models. Instead of specifying a discrete sequence of hidden layers, we parameterize the derivative of the hidden state using a neural network. The output of the network is computed using a black-box differential equation solver. These continuous-depth models have constant memory cost, adapt their evaluation strategy to each input, and can explicitly trade numerical precision for speed. We demonstrate these properties in continuous-depth residual networks and continuous-time latent variable models. We also construct continuous normalizing flows, a generative model that can train by maximum likelihood, without partitioning or ordering the data dimensions. For training, we show how to scalably backpropagate through any ODE solver, without access to its internal operations.

Card 02 摘要

摘要

  • 把residual update \(h_{t\)+1}=\(h_{t}\)+\(f\)(\(h_{t}\),\(\theta_{t}\))取连续极限，令dz/\(dt=f(z,t,\theta)\)，网络输出由black-box ODE solver从t0积分到t1。
  • adjoint sensitivity method反向解增广ODE，理论上无需存储所有solver internals，得到相对于初态、参数和时间的梯度。
  • instantaneous change-of-variables把flow的log-Jacobian determinant替换为vector field Jacobian trace，形成continuous normalizing flows；另以latent ODE建模不规则采样时间序列。
Card 03 背景

背景

  • 离散ResNet层数固定、每层要存activation；ODE表示将“深度”交给adaptive solver，用tolerance控制function evaluations与数值误差。
  • 传统normalizing flow每层需可逆映射并计算log determinant，宽dense Jacobian代价高；连续流在Lipschitz uniqueness条件下整体自动可逆，密度变化只需trace。
  • RNN通常把时间间隔离散化或附加Δt；latent ODE由共享continuous dynamics在任意observation times求状态，天然支持不规则时间戳。
Card 04 模型与方法

模型与方法

  • ODE block计算z(\(t_{1}\))=\(z\)(\(t_{0}\))+∫\(f\)(\(z\)(\(t\)),\(t\),\(\theta\))dt；solver按absolute/relative tolerance自适应选步，NFE是更实际的implicit depth。
  • 定义adjoint a(\(t\))=\(\partial L\)/\(\partial z(t)\)，满足da/dt=−\(a^{T}\)∂\(f\)/\(\partial z\)；从t1反向同时重建z并积分parameter VJP，Algorithm 1用一次augmented ODE solve求梯度。
  • 该constant-memory说法针对不保存forward solver trajectory的adjoint实现；vector-Jacobian products由autodiff计算，时间仍随forward/backward NFE与f成本增长。
  • CNF定理：若f对z uniformly Lipschitz且对t连续，\(d\) log \(p\)(\(z\)(\(t\)))/dt=−tr(\(\partial f\)/\(\partial z\))。trace对sum线性，使M hidden units代价随M线性而非dense determinant的立方。
  • MNIST ODE-Net把6个residual blocks替为ODESolve；论文用SciPy LSODE/VODE implicit Adams、GPU TensorFlow dynamics和Python autograd adjoint。
  • latent ODE用25-unit RNN识别z0 posterior、4维latent、20-hidden-unit dynamics和20-hidden-unit decoder；数据为1000条双向二维spirals、每条100 time points加Gaussian noise。
Card 05 核心结果与证据

核心结果与证据

  • Table 1 MNIST：ResNet test error 0.41%、0.60M params、memory \(\mathrm{O}(L)\)；RK-Net 0.47%、0.22M、memory/time O(\(L\)~)；adjoint ODE-Net 0.42%、0.22M、memory \(\mathrm{O}(1)\)、time O(\(L\)~)。
  • Figure 3显示tolerance越严NFE与forward time越高，并验证output error随tolerance受控；训练过程中NFE上升，说明solver为变复杂的vector field自动增加计算。
  • 同一Figure报告backward NFE约为forward一半，从而作者在该MNIST实现中观察到adjoint不仅省memory也较direct-through-solver反传省计算；这不是所有ODE/solver的普遍保证。
  • CNF toy density matching中CNF用Adam 10,000 iterations，planar NF按原建议用RMSprop 500,000 iterations；Figure 4常见CNF loss更低，但optimizer和训练预算不等，不能视为严格同成本architecture ablation。
  • 64-wide CNF与64个单hidden-unit NF layers的two-circles/two-moons图显示CNF能平滑旋转/变形density；论文未给标准图像likelihood或高维bits/dim benchmark。
  • Table 2 irregular spiral extrapolation RMSE：30/100 observations时RNN 0.3937、Latent ODE 0.1642；50点0.3202 vs 0.1502；100点0.1813 vs 0.1346。
  • classification tolerance可放宽至10⁻3、density至10⁻5而无观察到性能下降；sequence默认1.5×10⁻8。数值为本文配置经验，不是跨任务安全阈值。
Card 06 有效性与局限

有效性与局限

  • ODE-Net不是求解已知物理ODE：f本身由网络学习；连续时间参数化提供inductive bias和solver interface，但不自动带来物理守恒、可解释性或因果动力学。
  • \(\mathrm{O}(1)\) memory依赖从终点反向重建state；若forward dynamics反向不稳定或solver误差累积，gradient会偏。Section 6建议checkpointing，但正文实验只作informal reversal check。
  • adaptive batching可能由最难样本决定全batch步数，理论最坏可比单独solve多K倍；刚性系统和不光滑vector fields也可能显著增加NFE。
  • Picard uniqueness需uniform Lipschitz与finite weights；数值solver仍只近似轨迹，可逆连续flow也无法让trajectories crossing，从而限制某些拓扑变换。
  • MNIST结果只说明小网络accuracy可匹配ResNet，未验证CIFAR/ImageNet规模、wall-clock优势或硬件利用率；implicit CPU/Fortran solver与GPU callbacks也不代表现代部署。
  • CNF比较的optimizer与iterations差异巨大，而且只是二维toy targets；“more expressive/easier to train”证据是特定设置下的loss与图。
  • latent ODE只在合成spirals上比较简单RNN，没有真实clinical/irregular dataset、calibration或long-horizon stability。
  • 本站未运行torchdiffeq、adjoint gradient check或任何训练。
