Softmax is not Enough (for Sharp Size Generalisation)

Softmax 还不够：关于尖锐的规模泛化

Card 02 研究问题

研究问题

  • 许多推理电路需要近似 argmax、检索最大键等尖锐操作。训练分布内 softmax 可以高度集中，但当测试 token 数远大于训练规模时，固定温度是否仍能把质量稳定分配给正确项？
  • 核心风险是“尺寸泛化”：即便单个干扰项得分略低，大量干扰项的指数权重总和仍会稀释目标注意力。
Card 03 模型与方法

模型与方法

  • 作者分析固定词表、非零温度下，由 MLP 与 softmax self-attention 组成的网络。Theorem 2.2 表明，对任意注意力头，输入足够长时注意力系数必然分散；该结论不依赖训练是否在较小规模上表现尖锐。
  • 实验包含最大值检索、CLRS-Text 算法推理和 Gemma 2B 提示分析。作者提出推理时 adaptive temperature：根据注意力熵估计更低温度，无需重新训练即可增强尖锐度。
Card 04 核心结果与证据

核心结果与证据

  • Figure 2 显示最大值检索头在 16 项时集中于最大键，规模连续翻倍后权重逐渐分散；Figure 3 中 Gemma 2B 多个头的熵也随序列长度上升。
  • 自适应温度在最大值检索的规模外测试上改善准确率和注意力集中度，CLRS-Text 的若干任务也受益。但修正是经验性的，不能消除所有架构或分布变化造成的外推失败。
  • 数学上，目标项与每个干扰项之间即便保持固定 logit 间隔，分母中的干扰项数量仍随长度增长。要维持固定目标质量，间隔或逆温度必须随规模增加；这解释了为什么训练长度内的尖锐可视化不能作为任意长度电路稳定性的证据。
Card 05 有效性与局限

有效性与局限

  • 定理针对固定有限参数与特定算子集合；包含显式长度信号、硬注意力、动态归一化或其他非 softmax 机制的模型不自动落入结论。所谓“足够长”可能远超某些实际上下文窗口。
  • adaptive temperature 的熵到温度映射来自拟合，可能在多峰、重复最大值或需要分散注意的任务上过度锐化；论文没有证明它对通用语言模型整体能力安全有效。本卡未独立复现。
  • 熵下降也不等价于算法正确：一个头可以非常尖锐地选错位置，多头系统还可能依靠分散聚合。复现实验应同时观察任务输出、注意力模式和中间电路，而不能仅以平均熵作为成功指标。

Card 07 阅读指南

阅读指南

  • 先读 Theorem 2.2 与 Figure 1，把“参数固定、输入增长、质量被稀释”的量化逻辑弄清；再看最大值检索与 Gemma 实验，最后把 adaptive temperature 当作缓解手段而非定理的逆命题。
  • 附录给出最大值任务的数据生成、网络与超参数，以及 dispersion 对推理性能的补充实验；若只看主文结论，容易忽略定理对词表、温度和网络算子的具体前提。
