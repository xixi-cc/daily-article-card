Card 02 研究问题

研究问题

  • 常见 diffusion guidance 给单个样本奖励，但实验校准、群体多样性和构象比例等目标是整个生成分布的泛函 $R(\mu)$。直接把 batch reward gradient 加进 drift 通常不知道最终采样了什么分布。本文把控制目标定义为 $\max_\mu R(\mu)-KL(\mu\|p_1)$，推导能跟踪其自洽 tilted measure 的加权 McKean–Vlasov 粒子算法。
Card 03 模型与方法

模型与方法

  • 点奖励 $r(x)$ 的最优目标是 $p_1(x)e^{r(x)}$；分布奖励则由一阶变分 $\Psi(x,\mu)=\delta R/\delta\mu$ 给出隐式自洽条件 $\mu^*(x)\propto p_1(x)e^{\Psi(x,\mu^*)}$（Proposition 3.1）。
  • 作者在 diffusion/flow 的中间边缘 $p_t$ 上定义 $R_t$ 与 $\Psi_t$，将 $\nabla_x\Psi_t(x,\mu_t)$ 加入 drift，产生粒子相互作用的 mean-field/McKean–Vlasov 动力学。
  • 仅改 drift 不会精确给出目标路径，因此 Theorem 3.2 同时推导 Feynman–Kac log-weight correction，补偿 transport、时间变化和均值场依赖。
  • Algorithm 1 用 $N$ 个加权相互作用粒子近似 $\mu_t$，可用 fixed-point iterations 估计 $\dot\Psi_t$，并按固定间隔 residual resampling 防止权重退化。
  • Theorem 3.4 在正则假设下证明有限粒子加权经验测度向理想 mean-field 目标收敛；当 $R(\mu)=E_\mu r$ 时，$\Psi=r$，框架退化为标准 pointwise steering。
Card 04 核心结果与证据

核心结果与证据

  • 二维可解 MMD 例子目标为 $KL(\mu\|p_1)+\lambda^*MMD^2(\mu,\nu)$。图 2 显示 gradient-only 虽把粒子推向 $\nu$，却不采样规定的 $\mu^*$；加权 mean-field 方法与可计算真目标一致。
  • 图 3 在 $\lambda^*=10$ 比较 fixed-point 次数 1/3/5 与 steering strength 扫描；只有使用正确 $\lambda$ 的 mean-field 方法最小化 objective gap，附录在 $\lambda^*=5,15$ 重复这一趋势。
  • HIV-1 protease 构象实验用 55-residue distance 的经验分布作 MMD 目标；随 $\lambda$ 增大，闭合/半开构象比例向观测数据移动，objective proxy 在正确系数附近最小。
  • 4OLE 蛋白的 residues 423–431 ROI 用 \(X\)-ray electron density 作为分布信息。base diffusion 几乎只采 conformation A，而分布 steering 覆盖两个 mode 并更贴近观测密度。
  • 作者将蛋白结果定位为高维 behavior demonstration：环境空间 KL 不可算时用一维/低维 proxy 评估，未声称像低维实验那样精确验证完整目标测度。
Card 05 有效性与局限

有效性与局限

  • 主要限制是依赖 resampling；这需要一批并行粒子、粒子间通信和权重维护，不适合严格单样本、低延迟生成。
  • 有限粒子下 first variation、时间导数和经验测度均有噪声；fixed-point 次数、resampling 频率与粒子数形成额外计算–偏差权衡。
  • 理论收敛需要 Lipschitz/有界等正则条件，实际蛋白奖励和神经 score 近似不一定满足。
  • 蛋白实验用 proxy objective 和有限观测特征，不能证明生成的全原子构象分布等于真实物理 ensemble。
  • 方法假设有可用的 pretrained diffusion/flow 与可微分布泛函；如何设计科学上正确的 $R(\mu)$ 仍依赖领域知识。
