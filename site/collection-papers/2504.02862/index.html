作者信息

Card 02 研究问题

研究问题

  • 视觉知识在 LVLM 的语言后端中如何逐层转化为词汇预测？最终答案只给终点，无法区分信息何时形成、稳定或发生突变。
  • 作者从目标 token 概率、完整词表分布和 hidden feature encoding 三个层次寻找关键层与 mutation layer，并据此划分演化阶段。
Card 03 模型与方法

模型与方法

  • 在各 transformer blocks 后接共享/校准 output head 做 early exit，记录正确 token 概率与排名；用分布距离比较全词表预测，并分析 hidden feature 相似性/方向。
  • 跨问题、图像、模型和任务聚合层级轨迹，依据变化率定位 critical 与 mutation layers；将阶段划分与回答正确性和视觉/语言信息关联。
Card 04 核心结果与证据

核心结果与证据

  • 作者报告快速演化、稳定、突变三阶段：前段目标概率和分布迅速成形，中段趋稳，后段某些层发生决定性重排。
  • Figure 1 展示三种分辨率互补：单 token 容易漏掉替代答案，全分布描述竞争词汇，feature 分析提供表征层证据。
  • 早退 output head 与最终 unembedding 的适用性是关键假设；probe 可读不等于模型因果使用，critical/mutation 阈值也可能依赖标定。
Card 05 有效性与局限

有效性与局限

  • 只含 11 页的经验研究，模型/任务覆盖和层阈值细节限制普适性；不同 LVLM connector、语言模型深度与 prompting 会改变阶段位置。
  • 线性输出或相似度探针可能把可解码信息误认成计算完成，需要 layer intervention、activation patching 与反事实视觉输入。
  • 论文给出的图形、相关性或有限规模干预只支持其明示范围；跨数据、架构、模型规模与训练制度时需要重新验证。本卡未独立复现，不能把受控实验直接提升为普适机制。
  • 对结论做强审计时，应设置能产生相似表面指标的替代机制、匹配参数量与计算预算、报告失败案例和置信区间，并检查阈值、归一化、样本选择及评价器是否预先偏向作者假说。
  • 若论文声称发现机制，还应要求前向预测新的干预结果，而不只事后解释已有曲线；至少应在未用于选择假说的数据、不同随机种子和合理替代基线上保持。
  • 此外应明确负结果的含义：未观察到效应可能来自统计功效、测量误差或实现差异，不能自动当作理论反证；观察到效应也需排除共同原因。
