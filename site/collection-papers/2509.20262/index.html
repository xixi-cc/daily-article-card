Are Neural Networks Collision Resistant?

神经网络具有抗碰撞性吗？

When neural networks are trained to classify a dataset, one finds a set of weights from which the network produces a label for each data point. We study the algorithmic complexity of finding a collision in a single-layer neural net, where a collision is defined as two distinct sets of weights that assign the same labels to all data. For binary perceptrons with oscillating activation functions, we establish the emergence of an overlap gap property in the space of collisions. This is a topological property believed to be a barrier to the performance of efficient algorithms. The hardness is supported by numerical experiments using approximate message passing algorithms, for which the algorithms stop working well below the value predicted by our analysis. Card 02 摘要

摘要

  • 给定A∈\(R^{P\)×\(N\)}和binary input \(x\)∈{−1,1}^\(N\)，函数f_A(\(x\))=\(\phi\)(Ax)输出P个二值标签；碰撞是x≠y但f_A(\(x\))=\(f_{A}\)(\(y\))。
  • 选择周期square-wave activation φδ，研究N,P→∞且α=P/N固定时，碰撞存在阈值和m-overlap gap property。
  • 在一段仍存在指数多碰撞的参数区，解空间出现external-overlap forbidden interval；这能排除stable algorithms，但不是一般多项式时间硬度证明。
  • 用error-correcting code排除q≈1的近邻碰撞后，作者提出仍具压缩率α̃<1的候选collision-resistant hash family。
  • local search与reinforced AMP在理论OGP区之前即失效，为难度猜想提供算法证据，但未建立密码学归约或生产级安全性。
Card 03 背景

背景

  • inversion固定输出标签，second-preimage固定一个输入，collision-finding允许攻击者联合选择两个输入；三者的典型复杂性不能混同。
  • 密码学CRH要求任何高效算法找到碰撞的概率可忽略，且hash还需输出短于输入；随机CSP中的OGP只覆盖稳定、低阶或若干已知算法类。
  • binary perceptron把通常所称网络权重x反过来当函数输入，把随机pattern matrix A当public instance，因此‘neural network hash’是特定理论构造。
  • 周期激活的快速符号翻转类比模运算，但作者还研究截断和随机化切换点，主张关键更可能是高频sign switches而非严格周期性。
Card 04 模型与方法

模型与方法

  • Square Wave Perceptron用φδ(\(h\))=sgn[(\(h\)/(2δ)) mod 1]，δ控制振荡周期；内部重叠q_i=\(x^{\mathrm{Ty}}\)/N等价于碰撞输入的归一化Hamming距离。
  • 碰撞数Z(\(q_{1}\);A)的quenched free entropy \(\Phi=lim\) \(N^{-1}E\) log \(Z\)；first-moment annealed entropy给不存在碰撞的上界，replica-symmetric计算在本文模型中与其重合。
  • 两碰撞c_a=(\(x_{a}\),\(y_{a}\))、c_b的external overlap定义为(\(x_{a}^{\mathrm{Tx}}_{b}\)+\(y_{a}^{\mathrm{Ty}}_{b}\))/(2N)；\(m\)-OGP要求任意m个固定q1碰撞不能两两落入某个中间overlap区间。
  • 通过Markov inequality把m-tuple数的annealed entropy ϕ_m^a(\(p\),\(q_{1}\))≤0转成excluded interval；其计算化为2m×2m covariance matrix Q上的变分最大化。
  • 为可计算性采用symmetric ansatz，把交叉块降为一个q0；\(\delta\to 0\) strong-hashing limit中m=2可证明该ansatz且q0=\(p\)+\(q_{1}\)−1，对m>2主要在此ansatz下推导。
  • 有限系统用exhaustive collision search检查SAT/UNSAT和ansatz；攻击实验包括从随机超立方体顶点bit-flip local search与reinforced approximate message passing。
Card 05 核心结果与证据

核心结果与证据

  • Figure 1显示固定δ、q1时存在α_c(\(q_{1}\))：高于它，给定extensive overlap的碰撞以高概率不存在；\(q_{1}\)→1时α_c发散，因为相同或sub-extensive近邻输入总会留下碰撞。
  • strong-hashing limit给annealed存在阈值α_c^\(a(q_{1})=1\)+\(H_{B}\)(\(q_{1}\))/log2，随q1单调下降；有限尺寸exhaustive search支持RS/annealed阈值，但并非渐近严格等式证明。
  • Figures 2–3展示m=5时ϕ_m^a(\(p\))在中间p形成负区，从而产生m-OGP；该阈值严格低于碰撞消失阈值，于是二者之间仍有指数多解却猜测难找。
  • \(\delta\)→0时在symmetric ansatz下α_OGP^\(m\)(\(q_{1}\))=[log2+\(H_{B}\)(\(q_{1}\))]/log(1+\(m\))，随m增大降低；更大的m给stable-algorithm障碍更强的上界。
  • 由于任何δ>0的OGP曲线在q1→1附近发散，单独SWP不能阻止近邻碰撞；上游ECC把codewords限制到q1≤\(q_{\mathrm{code}}\)。
  • 用Gilbert–Varshamov存在界r=1−\(H_{2}\)(\(q_{\mathrm{code}}\))并取α_adv=\(max_{q_{1}\le q_{\mathrm{code}}\)}\(\alpha_{\mathrm{OGP}}\)，Figure 5出现α̃=\(\alpha_{\mathrm{adv}}\)/\(r\)<1区域，构成候选压缩CRH。
  • \(\delta=0\).6时rAMP只在α约0.15以下找到q1≈0碰撞，而m=5 OGP估计约0.9；Figure 6的T_sol显示接近α_r时幂律发散与finite-size collapse。
  • 局部有限bit-flip邻域的期望碰撞数在P=O(\(N\))时消失，说明从随机reference的朴素local search不可行；这仍不是对自适应全局攻击的排除。
Card 06 有效性与局限

有效性与局限

  • 论文反复把结果称为candidate与conjecture：OGP严格排除的是stable algorithms等特定类别，不能推出所有PPT攻击都失败。
  • 没有Ajtai/SIS式worst-case-to-average-case reduction，也没有基于标准密码困难假设的security proof；因此不能用于实际密码协议。
  • RS存在阈值与symmetric covariance ansatz并非全参数严格成立；作者只在strong-hashing、\(m\)=2等受限情形证明，并以小系统exhaustive checks支持其余区域。
  • annealed \(m\)-tuple entropy通过Markov不等式给OGP出现的充分上界，未必等于真实quenched阈值；\(m\)=5图不能代表m→∞。
  • ECC部分使用Gilbert–Varshamov码率存在界；没有给出同时达到该码率、可高效编码且与网络组合的具体完整实现。
  • A为随机i.i.\(d\).矩阵且渐近N,P同比增长；存储A、计算Ax与输出bit成本会影响实际hash效率，正文未做硬件/吞吐基准。
  • 算法证据只覆盖local search和特定rAMP，二者早于OGP阈值失败也可能反映算法次优，不能校准真正attack threshold。
  • ‘neural network’这里只是binary single-layer random perceptron与特殊不连续激活，不说明常规ReLU/Transformer或训练网络具有碰撞抗性。
  • 量子攻击、side channel、结构化A、finite-precision实现和多目标攻击未评估；候选构造离密码学部署仍远。
Card 07 复现与资源

复现与资源

  • 先固定N、\(\alpha\)、\(\delta\)、A分布和random seeds，枚举小N的全部pairs，分别估计每个q1 bin的collision count与SAT probability。
  • 实现ϕ_m^a变分时保存Q eigenvalues、\(q_{0}\) optimum和多起点结果；对m=2 strong-hashing解析式做单元测试，再扩展m与有限δ。
  • 有限尺寸阈值至少用多N外推和bootstrap，区分annealed bound、RS conjecture、observed exhaustive threshold与OGP sufficient threshold。
  • rAMP复现需冻结initialization、reinforcement schedule、convergence criterion和最大iterations；报告成功率而不仅T_sol，并与random restart及其他CSP solvers比较。
  • ECC组合应给具体code family、block length、minimum distance、encoder complexity和总体α̃；逐项验证shrinking、domain separation与近邻碰撞排除。
  • 密码审计必须加入通用birthday、meet-in-the-middle、SAT/MILP、lattice-inspired和quantum query attacks，且不要用OGP图替代security parameter估算。
  • 公开实现前还需定义A如何生成/发布、矩阵与激活精度、hash output serialization和constant-time要求。
