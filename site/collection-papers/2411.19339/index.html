Towards a Mechanistic Explanation of Diffusion Model Generalization

迈向扩散模型泛化的机制解释

Matthew Niedoba、Berend Zwartsenberg、Kevin Murphy、Frank Wood · 预印本 · arXiv:2411.19339 · 论文原文 ↗

标准 denoising loss 在有限经验分布上的精确最优解会把 noisy input 映回训练样本的全局 posterior mean；若网络足够拟合该解，反向过程应趋向记忆。为什么实际 CNN diffusion model 却能生成新图像？

研究问题

  • 标准 denoising loss 在有限经验分布上的精确最优解会把 noisy input 映回训练样本的全局 posterior mean；若网络足够拟合该解，反向过程应趋向记忆。为什么实际 CNN diffusion model 却能生成新图像？
  • 作者假设有限感受野和卷积局部性使网络学习的是 patch-level posterior：不同位置可选择来自不同训练图的局部证据，再通过重叠补丁组合成新样本。

模型与方法

  • 先精确计算 CIFAR-10 有限训练集的 empirical optimal denoiser，并在同一 noisy \(z\)、time \(t\) 上比较 DDPM++、DiT 等网络输出。MSE 随 \(t\) 扫描定位偏离最大的中间噪声区。
  • 用输出像素对输入 \(z\) 的 Jacobian gradient sensitivity heatmap 测量实际 receptive field；再定义 patch posterior mean，只在裁剪窗口内计算经验 posterior，并把多窗口输出重叠平均形成 learning-free PSPC denoiser。
  • Figure 1 按相同 reverse inputs 并列 empirical、多个网络与 PSPC 输出；随后比较 memorization、sample quality 和网络局部性。

核心结果与证据

  • 实际网络在很小和很大 \(t\) 接近 empirical denoiser，却在中间 \(t\) 以相似方式系统偏离；不同架构的偏差共性提示不是单一训练失败。Figure 3 显示 denoiser 对局部 patch 更敏感，且有效范围随 \(t\) 变化。
  • 局部 patch posterior 能在小 \(t\) 精确匹配对应 optimal patch，在较大 \(t\) 需要更大窗口。PSPC 不训练神经网络，只组合训练图局部 posterior，却能生成非训练样本并在若干指标/视觉上接近 learned denoiser。
  • 结论是 architectural locality 可阻止全局 empirical memorization并支持 patch recombination；这是一种机制候选，不是所有 diffusion generalization 的完备解释，尤其不覆盖全局 self-attention 的语义组织。

有效性与局限

  • PSPC 直接访问完整训练集并做 posterior 计算，计算方式与训练后的神经网络不同；视觉相似不证明网络内部显式执行同一算法。Patch size、形状和重叠规则是手工选择。
  • CIFAR-10 小图像与卷积架构最适合局部解释；高分辨率、文本条件、Transformer/attention diffusion 需要全局一致性，局部马赛克机制可能不足。
  • sample originality 若只以最近邻或有限指标衡量，仍可能存在 patch-level memorization。需训练集删改、patch provenance 和因果 receptive-field干预。本卡未独立复现。
