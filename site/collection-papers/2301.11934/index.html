Compression theory for inhomogeneous systems

非均匀系统的压缩理论

作者信息

Card 02 研究问题

研究问题

  • 传统 RG 借助平移不变性和波长组织自由度；准晶、无序图、生物组织等非均匀系统没有统一 Fourier 模式，局部粗粒化的形状和输出维数也可能随位置变化。作者问：能否只从图结构与配置样本出发，自动选出保留长程物理的局域集体变量？
  • 核心主张不是机器学习替代 RG，而是把“相关自由度”定义为受容量限制、同时最大保留与远处环境互信息的压缩变量；神经网络用于估计目标并优化映射。该定义依赖采样分布、block/environment 划分和压缩容量。
Card 03 模型与方法

模型与方法

  • 把图分成局域 block Vᶦ、与其隔开缓冲区的远环境 Eᶦ，并学习 Hᶦ=\(\tau\)(Λᶦ·Vᶦ)。每个位置的 Λᶦ独立优化，使 I(Hᶦ:Eᶦ) 最大；离散化 \(\tau\) 限制 \(H\) 的信息容量，迫使短程细节被丢弃而长程相关保留。压缩变量间相关性再定义 emergent supergraph。
  • 高维互信息不可直接算，RSMI-NE 用 contrastive classification 的可微下界：critic \(f(H,E)=u(H)\)^\(T\) v(E) 区分联合样本与独立重排样本。本文用线性/多线性 \(\Lambda\)、退火离散化以及小型两层 critic；逐步增加 bit 数，以 mutual-information plateau 选择不同 block 所需的 code length。
  • 主案例是 Ammann–Beenker（AB）准晶上的 close-packed dimer model。block 取自 \(\sigma\)⁻² 或 \(\sigma\)⁻⁴ deflation 的局域星形 patch，Monte Carlo 配置作为训练数据。补充案例把方法用于近二分随机图上的反铁磁 Ising 模型，学习与最大割相关的全局 order parameter。
Card 04 核心结果与证据

核心结果与证据

  • Figure 1 概括 geometry-independent coarse graining：组织或胶体都抽象为不规则图，各位置用自己的 Λᶦ 将局部向量 Vᶦ压成 Hᶦ；压缩目标由远环境 Eᶦ决定，而非预设平移或旋转卷积核。
  • 在 AB dimer 模型中，8-coordinated 与 3-coordinated supervertices 的保留互信息分别在 4 bits 与 2 bits 饱和。学到的 code 状态稀疏占据 bitstring 空间，形成抽象 Z₈ 与 Z₃ clock variables；\(\Lambda\) 的 C₈/镜面对称作用正好诱导这些 clock 状态的循环/反射。
  • 相邻 clock variables 的相关性把每个 supervertex 与唯一邻居配成 emergent super-dimer，并在 \(\sigma\)⁻²、\(\sigma\)⁻⁴ 两个尺度复现微观 dimer constraint 与长程相关，支持 discrete scale invariance。作者据此称其为连续 conformal/scale symmetry 破缺到离散子群的 exotic criticality；证据来自所研究模型和有限尺度数值，不是任意准晶的普适定理。
Card 05 有效性与局限

有效性与局限

  • 方法需要足够且平衡的 equilibrium samples，并预先选择图距离、block/environment/buffer、bit capacity、\(\Lambda\) ansatz 和 MI estimator。神经互信息下界可能有估计偏差或局部最优；互信息 plateau 与 learned code 的物理解读仍需对称性、相关函数和已知约束交叉验证。
  • AB 结果覆盖特定 close-packed dimer ensemble 与两个可达 deflation 尺度；有限大小和 Monte Carlo mixing 限制对渐近临界性的判断。随机图附例说明几何适应性，但近二分构造比一般强挫折图更受控。动态图或节点置换不固定时，文中固定索引技巧不能直接使用。
