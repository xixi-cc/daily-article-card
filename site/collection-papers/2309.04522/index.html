Card 02 研究问题

研究问题

  • NTK 描述宽网在初始化附近的线性化确定性学习，NNGP 描述参数先验诱导的函数分布/贝叶斯平衡；两者通常是分离理论。论文问能否用一个 time-dependent kernel 描述从快速拟合到长期解空间漂移的完整轨迹。
  • 额外小噪声使参数在低训练误差 manifold 上扩散。预测函数是否稳定、hidden representation 如何漂移，以及初始化方差 \(sigma0^{2}\) 与 prior 方差 \(sigma^{2}\) 如何选择两阶段时间尺度？
Card 03 背景

背景

  • 宽度趋于无穷时，网络输出和响应由 kernel 集中。确定性 gradient descent 的 early-time kernel 是 NTK；Langevin equilibrium 对应带 Gaussian parameter prior 的 Bayesian predictor，相关函数接近 NNGP objects。
  • 需要 two-time Neural Dynamical Kernel \(K\)(\(t\),\(t\)')，因为扩散阶段不再 time-translation trivial：当前预测既相关于初始化，也相关于不断漂移的 hidden features。
Card 04 模型与方法

模型与方法

  • 参数 obey loss gradient、Gaussian prior restoring force 和 white noise 的 Langevin equation。作者对深宽网络构造 generating functional，得到 mean predictor、covariance 与 two-time NDK 的自洽解析式。
  • 短时/低温极限恢复 NTK 指数收敛；长时平衡恢复 NNGP/Bayesian kernel。ReLU 与 erf activation、linear network 提供可解或数值自洽案例。
  • 实验用宽度 10^4 的单隐藏层网络在 CIFAR-10/MNIST 二分类验证，并追踪 test/train loss、weight spread、kernel 和 neuron activation drift。
Card 05 核心结果与证据

核心结果与证据

  • Figure 1 显示两阶段：test/train loss 先快速下降；随后 train loss 保持很低，weights 标准差继续扩散，test loss 可缓慢反弹或非单调。这把 optimization 与 equilibrium exploration 分开。
  • NDK 在初始期由 sigma0 控制，长期则由 prior sigma 与 noise temperature 控制；sigmoidal activation 对两种方差尤其敏感，小方差近线性并可能泛化差。
  • 持续 learning signal 可同步 hidden/readout drift，使 representation 改变而 output 保持任务性能；冻结 readout 后，只有 architecture-induced drift-invariant features 才能维持预测。
Card 06 有效性与局限

有效性与局限

  • 理论聚焦 infinite-width lazy regime 与显式 Gaussian Langevin noise；实际 SGD noise 有 state dependence、非高斯和 finite-batch structure，不能直接等同 temperature。
  • finite width、feature-learning/nonlazy regime、数据规模随宽度增长的比例极限可能改变 kernel 和 drift；生物 representational drift 的联系是机制类比，不是神经数据拟合。
  • 实验为小型二分类与单隐藏层验证，未证明现代深网长期训练遵循同一 equilibrium。该卡 no independent reproduction performed。
