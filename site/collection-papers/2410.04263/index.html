Card 02 研究问题

研究问题

  • 离散 graph diffusion 往往把训练 noise schedule 与推理 rate matrix 绑定，任何采样改动都可能要求重训。论文问：能否只学习 clean-graph posterior，再在推理时独立选择 time distortion、CTMC stochasticity 与 target guidance，同时保持 node-permutation symmetry 和可控的分布误差？
Card 03 背景

背景

  • 图被写成 node labels 与 edge labels 的 categorical variables。forward path 直接规定 (\(p_{t\)|1}(\(z_{t}\)|\(z_{1}\)))，reverse CTMC 的 marginal rate 则对 learned posterior (\(p_{1\)|\(t\)}^\theta(\(z_{1}\)|\(z_{t}\))) 做平均；网络用逐变量 cross-entropy 学 clean endpoint。
  • Figure 1 左侧对比 diffusion 的耦合训练/采样与 DeFoG 的解耦；右侧展示从 initial noise graph 经离散跳变逐步去噪到目标 graph。
Card 04 模型与方法

模型与方法

  • 基础 path 是 data 与 noise categorical laws 的线性插值；sampling 通过 Euler-discretized CTMC 更新。训练/推理均可用 monotone distortion (\(t\)'=\(f\)(\(t\))) 重分配时间区域；推理还可加入满足 detailed balance 的额外 rate (\(R_{t}^{DB}\)) 或 target-guidance rate (\(R_{t}\)^\omega)。
  • graph transformer 对 node permutation equivariant，并用 RRWP positional features 提升超越基本 message passing 的表达力。Theorem 1 把 CE loss 连接到 rate-matrix estimation error upper bound；Theorem 2 再把 total-variation deviation 分解为有限步 discretization 与 rate estimation 两部分。
Card 05 核心结果与证据

核心结果与证据

  • Figure 1 是机制图：训练只学习 endpoint posterior，推理侧的 distortion、rate design 和 guidance 成为可替换模块；这正是效率改进的来源，而不是把连续坐标硬套到图上。
  • synthetic Planar 数据的 valid-unique-novel（V.U.\(N\).）达到 99.5%。作者报告 DeFoG 常用 diffusion baselines 仅 5–10% 的 sampling steps；在 GuacaMol 用 25 steps 已超过 500-step DiGress。
  • target guidance 可显著提高 validity，但过强会降低 novelty 和 graph-statistics ratio；最佳 training/sampling distortion 又随 dataset 改变。因而论文展示的是可调设计空间，不是一个跨数据集统一最优 schedule。
Card 06 有效性与局限

有效性与局限

  • 理论界限依赖 posterior/rate estimation assumptions，并显式包含有限 (\(K\)) 的 discretization error；它不保证一个有限网络用 25 steps 精确复制真实 graph law。V.U.\(N\). 接近 1 只检查指定 validity、uniqueness、novelty，不等同于科学用途或 chemical quality。
  • rate-matrix/guidance 搜索使用验证数据和 dataset-specific choices；不同 baselines 的 steps、architectures 和 metrics protocol 不完全等价。fully connected edge variables 与 transformer attention 对大图仍有二次尺度压力。
