Flow map matching with stochastic interpolants: A mathematical framework for consistency models

基于随机插值的流映射匹配：一致性模型的数学框架

Card 02 研究问题

研究问题

  • 速度模型学习每个时刻的局部矢量场 \(b_{t}\)(\(x\))，采样需数值积分。论文改学 \(X_{s\),\(t\)}(\(x\))：它把任意 s 时刻状态直接送到 \(t\)，并满足 identity、composition 和 transport PDE。
  • 问题是怎样从已知 teacher velocity 蒸馏，或从 stochastic interpolant 直接训练这个 map，同时得到误差控制、双向传播和训练后可调 NFE。
Card 03 背景

背景

  • 精确流映射满足 \(X_{t\),\(t\)}=Id 与 \(X_{s\),\(t\)}=\(X_{u\),\(t\)} composed with \(X_{s\),\(u\)}。若网络学到完整 two-time map，同一模型既能一步跳转，也能在任意网格上组合多步；一致性模型只是其特定边界参数化。
  • 随机插值 \(I_{t}\) 连接 base 与 data，并诱导 probability-flow ODE。map 可由 Lagrangian trajectory matching 或 Eulerian transport equation 约束。
Card 04 模型与方法

模型与方法

  • LMD 沿 teacher trajectories 比较网络 map 与真实积分终点；EMD 在采样中间态上最小化 transport PDE residual，避免对每对时间完整积分。论文给出相应期望误差/Wasserstein 控制。
  • 直接 FMM 不需要预训练 velocity：用 stochastic interpolant 的 conditional quantities 估计 Eulerian target，并加 identity/composition consistency；PFMM 逐阶段扩大时间跨度以改善一步训练。
  • 实验含二维 checkerboard、CIFAR-10、ImageNet-32 与 class-conditional style transfer，比较 SI teacher、LMD、EMD、PFMM 和多种 NFE。
Card 05 核心结果与证据

核心结果与证据

  • Figure 1 用花朵图像展示同一个 \(X_{s\),\(t\)} 可从 0 到 s、s 到 \(t\)、\(t\) 到 1 任意拼接，也可反向；这比只从噪声到数据的 endpoint consistency 更一般。
  • 二维结果显示一步 FMM 能恢复 checkerboard，增加 map-composition 步数进一步接近 80-step reference。CIFAR-10/ImageNet-32 的生成时间相对 flow integration 降低约 10–20 倍，同时保持相近质量。
  • Figure 5 的 style transfer 先把真实图像反推到中间时间，再用新类别前推，主体改变而部分风格保留，验证 learned map 的双向和中间时刻语义。
Card 06 有效性与局限

有效性与局限

  • 误差界依赖平均 residual 和 regularity，有限采样/网络不能保证严格 semigroup；组合多步会累积 map error。直接一步训练仍较难，作者明确把改善收敛列为未来工作。
  • FID 与小分辨率图像不足以证明高维大模型上的同等 speed-quality frontier；10–20× 与硬件、batch、teacher solver tolerance 有关。
  • LMD 继承 teacher 偏差，FMM 依赖 interpolant 设计；style transfer 是定性展示。该卡 no independent reproduction performed。

阅读指南
