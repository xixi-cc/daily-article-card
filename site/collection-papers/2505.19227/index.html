Scaling Laws for Gradient Descent and Sign Descent for Linear Bigram Models under Zipf's Law

Zipf 定律下线性二元模型的梯度下降与符号下降缩放律

Frederik Kunstner、Francis Bach · 预印本 · arXiv:2505.19227 · 论文原文 ↗

文本词频常满足 \(pi_{k}\) proportional 1/\(k\)。若词表随规模增大，许多罕见 token 构成巨大 tail；常规 GD 是否会因这些坐标而显著变慢，且 sign descent 的坐标尺度不敏感更新为何可能缓解问题？作者将频率一般化为 \(pi_{k}\) proportional \(k^{-alpha}\)，关心达到相对误差 epsilon 所需步数 \(t\) 对 vocabulary dimension \(d\) 的标度，特别比较 Zipf \(alpha=1\) 与较轻尾 alpha>1。

研究问题

  • 文本词频常满足 \(pi_{k}\) proportional 1/\(k\)。若词表随规模增大，许多罕见 token 构成巨大 tail；常规 GD 是否会因这些坐标而显著变慢，且 sign descent 的坐标尺度不敏感更新为何可能缓解问题？作者将频率一般化为 \(pi_{k}\) proportional \(k^{-alpha}\)，关心达到相对误差 epsilon 所需步数 \(t\) 对 vocabulary dimension \(d\) 的标度，特别比较 Zipf \(alpha=1\) 与较轻尾 alpha>1。

背景

  • 已有很多理论缩放律假设 Hessian/数据谱指数 alpha>1，此时质量集中于头部，维度可在极限中变得不重要。文本 Zipf 的 \(alpha=1\) 正好在边界：尾部概率总量不可忽略，却有极端频率不平衡。Adam 的优势常被归因于 preconditioning 或逐坐标归一化；本文以 sign descent 抽取“更新幅度对坐标尺度较均匀”这一性质。必须注意 sign descent 不是 Adam 的完整动力学，线性 bigram 也不是 transformer 的 embedding/attention/softmax。

模型与方法

  • 给定 one-hot token 对 \(X\),\(Y\)，学习 \(d\) by \(d\) 条件表 W，最小化平方 Frobenius loss。边缘词频和条件频率服从作者的幂律近似；损失与 GD、SD 动态因此能按频率坐标写成闭式。relative accuracy 定义为剩余次优损失占初始次优损失的比例 epsilon。作者对 GD 在不同 alpha 推出 large-\(d\) 缩放；对 SD 因更新会振荡，引入将振荡阶段近似为常数的 Assumption 4.1，并为固定训练 horizon 选择随 \(d\),\(t\) 调整的步长。有限 \(d\) 时又以 OpenWebText 的 BPE 词表频率和条件表评估闭式误差。

核心结果与证据

  • Theorem 1.1 的非正式表述称：GD 在 alpha<1 时 \(t\) approximately \(d^{a}lpha\) log(1/epsilon)，在 \(alpha=1\) 时为 \(d\)^(1-epsilon)，alpha>1 时不需随 \(d\) 增长。对 SD，阈值转为 \(alpha=1\)/2；Zipf \(alpha=1\) 时 \(t\) approximately \(d\)^(1/2)/sqrt(epsilon)。故在高精度 epsilon 小时，Zipf GD 近线性地受词表大小限制，而 SD 仅平方根。Figure 1 显示 GD 在 \(alpha=1\) 的维度恶化最突出，Figure 2（第 2--3 页）以 OpenWebText/不同 \(d\) 的点与 c \(d\)^(1-epsilon)、c \(d\)^(1/2) 虚线比较；Figure 3 验证词频和条件频率的 Zipf 近似，Figure 4、7 分别展示两算法跨 alpha 的有限维趋近。

有效性与局限

  • 贡献在于把“Zipf 对优化困难”的经验说法分出 alpha 区域，且得到 GD 与 SD 不同的维度阈值；它还强调哪种算法更好取决于数据尾部，而非绝对。条件很强：linear bigram、square loss、deterministic full-data dynamics、近似幂律条件表和 SD 振荡近似。结果是 large-\(d\) 渐近，\(alpha=1\) 的有限维收敛可能慢；论文不覆盖 online stochasticity、momentum、bilinear embeddings 或 cross-entropy。SD 的最优步长依赖 horizon，故图示不等于实践 Adam 的默认超参收益；对于 alpha>1 SD 反而可能有更差维度缩放。

复现与资源

  • 复核可先生成满足 Assumption 2.3 的条件频率表，利用文中闭式而非显式 \(d^{2}\) 训练，计算 \(r_{d}\)(\(t\)) 并用 \(tau=log(t)\)/log(\(d\)) 比较曲线。再从 OpenWebText 建 BPE 词表（论文报告 1000、3612、10000、31622），估计边缘/条件频率，复算 Figure 2 各 epsilon 的 time-to-error；SD 需网格搜索 phi 并固定所选 horizon。应单独记录 \(d\)、alpha、epsilon、normalizer、GD learning rate 和 SD schedule，不能把对 \(d\) 的运行时间复杂度与迭代次数混同。本卡只核验 28 页 PDF、完整 MinerU Markdown 和既有渲染页，未下载语料或运行计算。

阅读指南

  • 先读 Theorem 1.1 的 relative accuracy 定义：epsilon 是剩余误差比例，不是 token perplexity。再看 Figure 1--2，把 Zipf \(alpha=1\) 的 \(d\)^(1-epsilon) 与 SD \(d\)^(1/2) 放在同一精度条件下解释。随后读 Figure 3 和 Assumption 2.3，确认真实文本只近似满足模型频率。第 3、4 节应并读，因 SD 结果依赖不同的阈值 \(alpha=1\)/2 和调步长策略。最后读 limitations，尤其不要把“sign descent proxy”扩张成 Adam 已被完全理论刻画，或把线性 square-loss 结论直接外推到端到端 transformer。
