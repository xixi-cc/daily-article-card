Physics-Informed Neural Operator for Learning Partial Differential Equations

用于偏微分方程学习的物理信息神经算子

In this paper, we propose physics-informed neural operators (PINO) that combine training data and physics constraints to learn the solution operator of a given family of parametric Partial Differential Equations (PDE). PINO is the first hybrid approach incorporating data and PDE constraints at different resolutions to learn the operator. Specifically, in PINO, we combine coarse-resolution training data with PDE constraints imposed at a higher resolution. The resulting PINO model can accurately approximate the ground-truth solution operator for many popular PDE families and shows no degradation in accuracy even under zero-shot super-resolution, i.e., being able to predict beyond the resolution of training data. PINO 把低分辨率 input–solution data loss 与更高分辨率 PDE residual/initial/boundary loss联合训练，从一族 parametric PDE 学习 solution operator。 训练好的 operator 既可直接 amortized inference，也可作为单个 PDE instance 的初始化，再用 PDE 和 anchor loss fine-tune；后者牺牲在线时间换精度。 Burgers、Darcy 与 Kolmogorov flow 结果显示 high-resolution physics loss 能抑制 data-only FNO 在更细网格的误差增长，但 long-time、chaotic 和无数据设置仍有明显边界。

Card 03 背景

背景

  • FNO 可在不同 grid 评价，但若只见 coarse data，未见频率没有真值约束；简单插值无法恢复缺失动力学。PINO 在更细 grid 计算 governing-equation residual，试图补足这一信息。
  • 与逐实例 PINN 不同，PINO 先跨 initial conditions 学 operator，再迁移到新实例；与纯 data FNO 不同，它可以采样额外 PDE instances 而不生成对应 numerical solution。
  • 论文也区分 resolution convergence 与 representation equivalence：FNO/PINO 有 pointwise nonlinearities 和 aliasing，并非逐层无 alias 的严格等价表示。
Card 04 模型与方法

模型与方法

  • 总 loss 可含 supervised operator loss、PDE residual、boundary/initial conditions；Burgers data 32×25、PDE loss 128×100，Darcy data 11×11、PDE 61×61，Kolmogorov data 64²×33、PDE 256²×65。
  • Burgers 用 800 low-res data+800 PDE instances，Darcy 1000+1000；Kolmogorov短时用 800 data+2200 PDE instances，200 test instances；对较长 \(T=0.5\) 另做 4000 data 与高分辨率 initial conditions。
  • 实例 fine-tuning 从 pretrained operator parameters 开始，以 anchor loss 约束接近 operator prediction，再最小化 PDE；比较 PINN/LAAF/SA-PINN 和 GPU pseudo-spectral solver。
  • inverse Darcy 既比较 forward/inverse operator，也用 500000-step accelerated MCMC；二值 coefficient recovery 同时报告 output relative \(L_{2}\) 与 input classification accuracy。
Card 05 核心结果与证据

核心结果与证据

  • Table 1：Burgers data-only error 从 low-res 0.32% 增至 4× 3.76%，PINO 为 0.17%→0.38%；Darcy 为 5.41%→9.46% vs 5.23%→1.58%；Kolmogorov data-only约 8.3%，PINO 在三分辨率约 6.0%。
  • 无 paired data 的 Darcy PINO error 1.50%，有 data 为 1.22%，引用 DeepONet data baseline 为 6.97%；Burgers PINO 为 0.38%，引用 PI-DeepONet 1.38%。跨论文 baseline 实现差异需谨慎。
  • Kolmogorov Re=500短时：0/800/2200 data 配同 2200 PDE instances 的 error 为 6.22%/6.01%/5.04%，说明 physics-only 可训练但 paired data 仍改善。
  • long transient \(T=50\) 中 PINN 与 scratch PINO 都 >50% error；4800 data 的 direct PINO 2.87%，test-time fine-tune 后 1.84%，相对 GPU solver 保留约 400× direct-inference speedup。
  • 单实例 Kolmogorov \(T=0.5\) Table 4：PINN 18.7%/4577s，pretrained PINO variants 0.9%/473–608s。所谓 20× error、25× speed 是该实现与初始化条件下的对比。
Card 06 有效性与局限

有效性与局限

  • PDE loss 依赖已知且正确的方程、边界与数值 differentiation；模型误设或 noisy observational physics 会直接把偏差写进训练目标。
  • 高分辨率 residual 需要更多 memory/compute，且更细网格比延长 gradient descent 更有效的观察说明优化仍是瓶颈。
  • zero-shot super-resolution 不等于严格 representation equivalence；aliasing 和有限 modes 仍可能产生不可约/离散误差，尤其对 shock 和 non-periodic boundaries。
  • 速度数字需区分 offline training（Darcy约单 \(V_{100}\) 1h，Kolmogorov可到单 V100两天）、direct inference 与 per-instance fine-tuning；不同 query 数会改变摊销结论。
