A Multi-agent Framework for Physical Laws Discovery

用于发现物理规律的多智能体框架

Discovering explicit physical laws has traditionally depended on human intuition and domain expertise. Recent advances in artificial intelligence, particularly large language models (LLMs), offer a new route to accelerate this process by automating key steps from hypothesis generation to interpretable model construction. Here we develop an LLM-based multi-agent framework for physical-law discovery that integrates literature-guided variable selection, hypothesis formulation, symbolic regression, formula derivation, and mechanistic explanation. We validate the framework on three representative materials problems: the glass-forming ability (GFA) of metallic glasses, the Vickers hardness of compounds, and the Young's modulus of multi-component alloys. Card 03 背景

背景

  • 深度模型可预测材料性质，却常缺少可解释机制；传统 symbolic regression 又面对组合搜索和变量选择。作者将 LLM 的跨领域先验用于提出物理上可读的公式 skeleton，再用确定性的数值评分筛选。
  • LLM 幻觉被明确视为风险：RAG、允许算符集合、可执行 Python 表达式、无效表达式剔除和 reflection 是约束层，但它们不能保证发现的是因果定律。
Card 04 模型与方法

模型与方法

  • 流程含六阶段：文献/数据准备、任务 prompt、beam 初始化、候选生成与评分、科学解释、下游设计（pp. 2–3, Fig. 1）。Gemini-2.5-flash 与 DeepSeek-\(V_{3}\) 在固定变量和算符下各独立运行三次。
  • 候选按 \(s(f)=Error(f,y)\)+λC(\(f\)) 排名；Error 默认 NMSE，\(C\) 是加权 operator count。每层保留 \(K\) 个节点、每节点生成 \(N\) 个子式，搜索到深度 \(D\)；trajectory memory 和 reflection 反馈抑制重复与无效语法（pp. 2–4, Eqs. 1–2, Algorithm 1）。
  • 数据规模分别为 GFA 56 个 metallic-glass compositions、hardness 61 compounds、Young’s modulus 170 binary/ternary compositions；descriptor 由实验、DFT 或 matminer 提供（Methods pp. 9–10）。
Card 05 核心结果与证据

核心结果与证据

  • hardness 轨迹从 bulk-modulus baseline 经指数修正到加入 shear modulus，score 从 0.254 降至 0.193；最终平均 R²≈0.85，与同数据既有研究相近（\(p\). 4, Fig. 2）。
  • Young’s-modulus 公式在 held-out binary/ternary 数据上 R² 接近 0.97；去掉平均质量项后 test R² 从 0.97 降到 0.89，展示 accuracy–interpretability 权衡（pp. 5–6）。
  • quaternary Mo–Nb–Ta–W 扫描中，formula 相对 DPA-3.1-3M 的 MAPE 大多 <5%，LoM 某些组成超过 17%；特定组成的 MAPE 相对 LoM 最多降低 78.8%（pp. 6–7, Fig. 3）。
  • quinary Mo–Nb–Ta–W–V 用 NSGA-II 同时优化 E 与 B/G，各元素 5–35 at.%、1 at.% 步长；三组 Pareto compositions 与 DPA-3.1-3M 比较时两个目标 MAPE 均 <10%（\(p\). 8, Table II）。
Card 06 有效性与局限

有效性与局限

  • LLM 对专业物理领域的深度依赖训练语料；当前 RAG 每任务只用代表性文献，数据整理与文献选择仍需人工。
  • symbolic regression 仍是高成本搜索；goodness-of-fit 主导的选择可能产生敏感常数或过复杂公式。作者把量纲一致性、稳健性和先验物理约束列为后续选择准则。
  • 三个案例都是小型 tabular materials datasets；没有多模态原始谱图/显微图，也不能据此断言框架会发现未知基本定律。
  • 代码说明为“upon acceptance/按请求提供”，因此当前卡片不把代码可得性或完整复现性视为已确认。
