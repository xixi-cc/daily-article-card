Card 01 作者信息

作者信息

  • 作者为 Dan Friedman、Alexander Wettig 与 Danqi Chen（Princeton University / Princeton Language and Intelligence）。arXiv:2306.01128v2。工作从 RASP/Tracr 出发，让 Transformer 在训练后可确定性地转成离散 Python 程序。
Card 02 研究问题

研究问题

  • 后验电路分析通常需要大量人工判断且难以得到完整、忠实的算法描述。论文问：能否把可解释性直接写入模型参数化，使梯度训练所得网络本身就位于可反编译为人类可读程序的子空间？
  • 目标不是解释任意预训练大模型，而是训练一类受约束的新模型，并测试这种可解释性与任务性能、序列长度和程序简洁性之间的权衡。
Card 03 模型与方法

模型与方法

  • Transformer Program 把 residual stream 划分为命名离散变量的正交子空间；每个模块只读固定变量并写入独立地址。categorical attention 用离散的 query-key 谓词和 hard attention，MLP 变成有限查找表。
  • 训练时对变量选择、谓词和离散操作采用 Gumbel-Softmax 连续松弛并退火；完成后取最大似然离散权重，再映射成 RASP 风格 Python。生成程序与离散 Transformer 功能等价，可用普通调试器追踪。
  • 评估覆盖玩具 in-context learning、RASP 算法任务、CoNLL-2003 NER 和文本分类，并与参数规模相近的标准 Transformer 或基线比较。
Card 04 核心结果与证据

核心结果与证据

  • 玩具 in-context task 学到由两个 attention heads 组成的 induction-like 程序，held-out 测试达到完美准确率；Figure 1 概括从训练模型到等价程序的流程。
  • 在多项 RASP 任务上可以获得可读程序，但随着序列长度和词表扩大，Transformer Programs 比标准 Transformer 退化更快；最困难设置的差距超过 50 个百分点，说明离散优化/结构限制仍是主要瓶颈。
  • CoNLL-2003 与文本分类实验显示受约束模型能达到合理性能并支持代码级错误分析，但论文没有在现代大语言模型规模、开放生成或安全审计场景验证。
Card 05 有效性与局限

有效性与局限

  • 功能等价仅指训练后离散 Transformer 与导出的程序；连续松弛训练阶段并不等价。人类可读也不自动意味着简洁：模型可能使用冗余模块、死代码或仅对训练长度成立的规则。
  • 方法要求预先定义变量、最大 cardinality、可用模块和组成语言，表达能力受到 hard attention 与有限查找表限制。实验规模小，最长输入和 NLP 基准远小于通用 LLM，不能外推为对现有黑箱模型的解释方案。

复现与资源
