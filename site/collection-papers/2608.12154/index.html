Card 02 研究问题

研究问题

  • 要得到整个参数区间的稳态响应，传统做法在每个 $\lambda_i$ 独立松弛并采样；直接有限速率扫描又会因 distributional lag 产生偏差。STPS 的目标是加入辅助控制，让有限时间轨迹始终跟随瞬时稳态族，从一次 sweep 同时估计连续响应曲线。
Card 03 模型与方法

模型与方法

  • 对任意归一化稳态密度 $\rho_{st}=e^{-\Phi}$，使用精确恒等式 $R_A=\partial_\lambda\langle A\rangle=\langle\partial_\lambda A\rangle-\mathrm{Cov}(A,\partial_\lambda\Phi)$。
  • 控制扩散过程的辅助力写成 $f=\dot\lambda u(x,\lambda)$；escort field 满足输运方程 $\partial_\lambda\rho_{st}=\nabla\cdot(u\rho_{st})$，从而消除 finite-rate lag。
  • 平衡态可用 Boltzmann 分布和 covariance response；未知 NESS 中从稳态样本学习 score $s=\nabla\log\rho_{st}$ 与 escort $u$。
  • 由输运式得到 $G=\partial_\lambda\log\rho_{st}=\nabla\cdot u+u\cdot s$，无需重建归一化密度，也不需识别产生 NESS 的真实物理 drift。
  • 多体系统用两个图神经网络分别参数化 score 和 escort；同一受控轨迹可复用来计算多个 observables 的响应。
Card 04 核心结果与证据

核心结果与证据

  • 三个测试均把 $\lambda:2\to4$ 在协议时间 $\tau=2$ 内扫描，时间步 $10^{-3}$，用 $10^5$ 条独立轨迹，observable 为 $A=U_0$。
  • 一维平移 harmonic trap（$k=2$）有解析 escort $f=-\dot\lambda/k$，STPS 复现精确理论响应，直接验证控制与 estimator。
  • 二维 Gaussian-core 平衡多体系统用 $N=10,\sigma=a=1$；GNN 学习的 escort 在无闭式控制时仍给出与 reference 一致的连续曲线。
  • 旋转 NESS 用 $N=8,\sigma=a=b=1,\omega=1.5$，破坏 detailed balance，稳态密度与精确 shortcut 均未知；联合 score/escort 仍恢复 reference response。
  • 图 2 下排的 $M_1,M_2,M_4$ 受控矩跟随各瞬时稳态矩，作为沿目标 stationary path 的分布一致性诊断。
  • 这些是单次有限时间 protocol 的数值证据；论文没有把它转换为相对于逐点方法的统一 wall-clock speedup。
Card 05 有效性与局限

有效性与局限

  • 形式构造只在 score 与 escort 精确时无偏；学习版叠加训练分布覆盖、score error、输运残差、divergence 数值误差和 covariance sampling noise。
  • 亚稳态、慢混合或相邻分布重叠弱时，这些误差可能显著放大。
  • 当前结果缺少定量 error bound、cost–accuracy scaling 与基于 transport residual 的通用诊断。
  • 离线学习两个网络本身有成本；只有在同一 sweep 可复用许多参数点/observables 时，才可能抵消该成本。
  • 多维参数需为每个方向学习 escort field；更大系统还需要显式 permutation/Euclidean equivariance。
