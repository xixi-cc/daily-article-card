Discovering Symbolic Models from Deep Learning with Inductive Biases

借助归纳偏置从深度学习中发现符号模型

We develop a general approach to distill symbolic representations of a learned deep model by introducing strong inductive biases. We focus on Graph Neural Networks (GNNs). The technique works as follows: we first encourage sparse latent representations when we train a GNN in a supervised setting, then we apply symbolic regression to components of the learned model to extract explicit physical relations. We find the correct known equations, including force laws and Hamiltonians, can be extracted from the neural network. We then apply our method to a non-trivial cosmology example-a detailed dark matter simulation-and discover a new analytic formula which can predict the concentration of dark matter from the mass distribution of nearby cosmic structures. Card 02 摘要

摘要

  • 方法先训练具有物理分解结构的 Graph Network（GN），用 bottleneck、\(L_{1}\)、KL 或 Hamiltonian 结构迫使 message 变得低维；随后只对内部 edge/node function 做符号回归，再把局部表达式组合为整体公式。
  • 这种“先神经分解、后符号搜索”把高维直接搜索拆成较小子问题：若两个函数各有 10^9 个候选，直接组合约 10^18，而分开拟合约 2×10^9。
  • 论文在合成 \(n\)-body 系统恢复已知力和势能，并在 215854 个 dark-matter halos 的模拟快照上提出 overdensity 公式；后者仍需独立物理研究验证。
Card 03 背景

背景

  • 纯符号回归在高维粒子状态上组合爆炸，深度网络能拟合却难解释。GN 的 edge、node、global 模块提供接近相互作用分解的结构，使解释目标从整网降为局部函数。
  • 关键假设是内部表征必须足够稀疏或低维，才能与真实力分量形成简单变换；普通 100-dimensional message 即使预测好，也未必可符号化。
  • 研究因此把预测精度与可解释表征分开：先用新随机种子数据测 acceleration，再用真实力对 message 做线性拟合，最后才运行 symbolic regression。
Card 04 模型与方法

模型与方法

  • Newtonian case 训练 Standard（100 message components）、Bottleneck（2/3 components）、\(L_{1}\)（权重 10^-2）和 KL 四类 GN，以粒子瞬时加速度的 MAE 为损失；FlatHGN 则把 pair/self Hamiltonian 显式拆开。
  • 选择最高方差或 KL 的 \(D\) 个 message features，与真实力分量线性拟合；随后对最显著 component 记录样本，用 Eureqa 在质量、电荷、位移、距离等输入上搜索 Pareto expressions，并以相邻复杂度的最大 log-MAE 降幅选式。
  • 宇宙学案例用公开 \(N\)-body 模拟最终时刻：215854 halos，50 distance units 内连边，共 30437218 条有向边、平均 71 neighbors；\(L_{1}\) GN 预测局部 smoothed overdensity。
  • OOD 检验遮蔽 \(\delta\)>1 的 20% halos，只在其余数据训练 GN、提取表达式并拟合常数，再分别比较训练区和遮蔽区误差。
Card 05 核心结果与证据

核心结果与证据

  • Table 1 显示 Standard message 与真力几乎不相关（R² 多为 0–0.036）；Bottleneck 在八个系统为 0.947–1.000，\(L_{1}\) 除 charge cases 为 0.002/0.004 外，其余多为 0.977–1.000。紧凑性是可解释性的关键，但 \(L_{1}\) 并非每类系统都成功。
  • 符号回归从合适的 \(L_{1}\)/Bottleneck 模型恢复 spring、1/\(r\)、1/r² 与 discontinuous force 的结构；FlatHGN 的 charge case 得到 \(H_{\mathrm{pair}}\approx 0.0019\) q1q2/\(r\) 加不影响动力学的偏置项（pp. 7, 22–23）。
  • 宇宙学 Table 2 中手工 simple formula 的平均绝对误差为 0.121，新公式 without mass 为 0.120、with mass 为 0.0882；作者解释式中邻居质量和距离依赖符合 bias–mass 直觉，但其他差异尚不清楚。
  • 遮蔽 \(\delta\)>1 后，GN 的 train/OOD error 为 0.0634/0.142，抽取的符号式为 0.0811/0.0892：符号式牺牲训练误差却在这一单次 OOD 切分更好，不能直接推广成普遍结论。
  • Appendix 的 raw Eureqa 对完整多粒子输入即使收敛也给出无意义、差拟合表达式；因而证据支持的是“GN 归纳偏置后的局部符号化”，不是 Eureqa 单独解决高维发现。
Card 06 有效性与局限

有效性与局限

  • 作者明确不试图给出符号恢复何时成功的普遍判据；成功依赖 message dimensionality、正则化、算符集、复杂度选择和训练随机性。
  • 多项力学实验来自已知生成方程的合成数据，并向符号回归提供 Δx 与 \(r\) 等简化变量；这比未知实验坐标和未知有用变量的真实发现更容易。
  • 宇宙学只用一套模拟的 zeroth run/final timestep；候选公式优于特定 hand-designed baseline，不等同于优于现代宇宙学模型或被观测确认。
  • OOD 结果是单一 \(\delta\) threshold 划分，且符号式由同一个 GN 表征抽取；需要多 simulation、不同 cosmology、halo finder 与观测选择效应测试。
