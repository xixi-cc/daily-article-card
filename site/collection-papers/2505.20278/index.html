Characterizing Pattern Matching and Its Limits on Compositional Task Structures

刻画模式匹配及其在组合任务结构中的边界

Paper Collection · Compositional Generalization and Mechanistic Interpretability · 原文

Card 01 作者信息

作者信息

  • Hoyeon Chang、Jinho Park、Hanseul Cho、Sohee Yang、Miyoung Ko、Hyeonbin Hwang、Seungpil Won、Dohaeng Lee、Youbin Ahn 与 Minjoon Seo 合作完成，单位为 KAIST AI、UCL 与 LG AI Research。PDF 首页为 arXiv:2505.20278v3 [cs.LG]（2026-03-02），并标注 ICLR 2026。论文尝试把常被笼统称作 LLM“pattern matching”的行为变成一个由训练数据可检验、能预测成功和失败边界的定义。
Card 02 研究问题

研究问题

  • 组合泛化实验常同时允许代数不变性、重复模板、记忆或真正的结构推理，因此模型成功时很难知道是否只是模式匹配。作者将模式匹配限定为 functional-equivalence-based generalization：若两个输入子片段在共享上下文中反复给出相同输出，模型可在其他见过的上下文中用一个替换另一个。问题是这种证据到底覆盖哪些 test instances、需要多少 contexts 才可靠，以及当一个变量通过多条路径影响输出时，模型能否形成统一的中间状态表征。
Card 03 背景

背景

  • 在两跳任务 \(t\)=\(f_{2}\)(\(f_{1}\)(\(x_{1}\),\(x_{2}\)),\(x_{3}\)) 中，若两个 (\(x_{1}\),\(x_{2}\)) 都映射到同一中间 b，并和同一 \(x_{3}\) 配对给相同 \(t\)，它们构成功能等价的观察证据。论文把输入视为 substitution graph 节点，只在 functionally equivalent fragment 替换时连边；训练点和可达点组成 coverage。这个框架故意是 data-centered、model-agnostic：它不声称模型真的显式执行 \(f_{1}\)，而是规定只依靠这种替换证据时，coverage 外没有可期待的可靠预测。
Card 04 模型与方法

模型与方法

  • 作者构造 2-HOP、PARALLEL-2-HOP、3-HOP 与 NON-TREE 等合成任务，刻意移除其他泛化捷径。训练 decoder-only GPT-2 的不同规模以及 Mamba；按一个实例中支持相关功能等价的 context 数 \(k\) 分组，比较 ID accuracy 与 coverage。为分析内部表征，使用 Intra-Inter Cosine Gap（IICG）：同一 intermediate state 的表征聚类相对不同 state 的差异，并结合 causal tracing/indirect effect。对两跳结构推导 perfect ID generalization 所需数据 \(N_{\mathrm{req}}\) 对 token set size 的紧界/指数，再在多模型和 token-size 网格拟合。最后添加 chain-of-thought (CoT) 中间监督，测试是否减少数据需求或消除 path ambiguity。
Card 05 核心结果与证据

核心结果与证据

  • Figure 3 显示覆盖和准确率随 \(k\)/context evidence 增加而提高，而 \(k=0\) 的 coverage 外 test accuracy 长时间仍近似 chance（约 1/50）。Figure 4 的 IICG/PCA 表明成功模型在特定层/位置将同一 b 的输入表征聚类。作者推导并测得 \(N_{\mathrm{req}}\) 随 |\(X\)| 的幂律；Figure 5（第 5--6 页）左侧给各任务斜率，右侧显示 GPT-2 68M、96M、1.5B 与配置的 Mamba 在 2-HOP 中仍有相近的 log-log 线性关系（文中所有拟合 \(R^{2}\)>0.99）。NON-TREE 中一个变量有多条路径时，Figure 6 发现中间状态按 context 分裂、ID success 的陡峭转变消失，扩大模型也未解决。Figure 7 显示 CoT 能降低 \(N_{\mathrm{req}}\)，却仍无法统一 path-ambiguous 表征。
Card 06 有效性与局限

有效性与局限

  • 价值在于把“模式匹配”从贬义标签变成带 coverage 边界、\(k\) 预测和 sample-complexity 断言的可反驳机制，并用内部表征/因果 tracing 交叉检查。边界同样严格：functional equivalence 来自合成任务的已知生成函数及共享 context 观察；自然语言中的语义等价、长程依赖和数据偏差未被该定义穷尽。\(N_{\mathrm{req}}\) 指数取决于 perfect ID success 的阈值、token 采样、训练 epochs 与任务树形结构；大模型数从 68M 到 1.5B 的稳定斜率不证明无限尺度无新机制。NON-TREE 失败说明这套 pattern-matching 机制的限制，但不排除不同训练、表示、外部工具或更强推理方法取得别的泛化。
Card 07 复现与资源

复现与资源

  • 最小复核可实现 2-HOP 的随机 token 函数表，枚举 substitution graph 和每个 test instance 的 \(k\)/coverage，再训练小 decoder-only 模型并按 \(k\)-cutoff 汇总 accuracy；\(k=0\) 应与 chance 基线分开报告。估计 \(N_{\mathrm{req}}\) 时要预先固定“training accuracy 后何时/何阈值算 perfect ID generalization”、token-set 网格、seeds、模型和训练预算，再在 log coordinates 拟合而非只报单点。机制分析还需导出指定位置/层 representation，计算 IICG，并按相同 b、不同 b、或 (b,\(x_{2}\)) 分组；CoT 实验要分开输入/输出监督格式。本卡只核验 55 页 PDF、完整 MinerU Markdown 和既有渲染页，未训练模型、复算边界或运行 causal tracing。
Card 08 阅读指南

阅读指南

  • 先读 Figure 1 和 Definitions 3.1--3.2，确认 paper 的 pattern matching 仅指覆盖内的功能等价替换。再看 Figure 3：它既给为何 context 数重要，也给 coverage 外不可预测的负结果。随后以 Figure 4 的 IICG/PCA 区分行为成功与中间状态聚类证据。Figure 5 是数据标度主张，应连同 \(N_{\mathrm{req}}\) 的 operational definition 与任务树读；不要把斜率当自然语言的普适 scaling law。最后对照 Figure 6--7：NON-TREE 的 path ambiguity 是该机制明确的结构障碍，而 CoT 的改善是数据效率而不是消除该障碍。
