AI is increasingly playing a pivotal role in transforming how scientific discoveries are made. We introduce The AI Scientist-v2, an end-to-end agentic system capable of producing the first entirely AI generated peer-review-accepted workshop paper. This system iteratively formulates scientific hypotheses, designs and executes experiments, analyzes and visualizes data, and autonomously authors scientific manuscripts. Card 02 摘要

摘要

  • AI Scientist-\(v_{2}\) 从一般研究 idea 出发，不依赖人写实验模板；Experiment Progress Manager 管四阶段 agentic tree search，节点生成/运行代码、保存结果、画图并由 VLM 检查，最终自动写作与修改论文。
  • 团队把三篇完全由系统在单次 run 内生成的稿件送入 ICLR workshop 盲审；一篇得 6、7、6，平均 6.33，达到工作坊接收线，另两篇拒稿。
  • “完全自主”只适用于被选中的单次 run 内部：人类提供 workshop 主题，从约 40 个 AI ideas 中挑 3 个，多 seed 运行后再挑每个 idea 的最好完整稿件提交。
Card 03 背景

背景

  • \(v_{1}\) 依赖 human-authored code template 且线性改进；\(v_{2}\) 提高抽象层级，先做 idea/literature search，再用分支树分别 debug、improve、hyperparameter tune、ablate、replicate 和 aggregate。
  • 四阶段为 initial implementation、baseline establishment、research agenda execution、ablation；每阶段由 LLM manager 选择 best node 进入下一阶段，并在结尾做不同 seed replications。
  • VLM 同时检查实验图的异常/可读性，以及写作阶段 caption、正文引用与图像是否一致；它改善呈现但不能替代代码和统计正确性审查。
Card 04 模型与方法

模型与方法

  • code generation 用 Claude 3.5 Sonnet \(v_{2}\)，LLM/VLM feedback 与 summary 用 GPT-4o；每节点最大 1 小时，debug depth 3，四阶段 node allocations 为 21/12/12/12，单篇总运行通常数小时、上限 15 小时。
  • 三个投稿先由系统围绕 ICBINB negative-results 主题生成约 20 ideas，再经人为 prompt 调整到真实领域再生成约 20；人挑 3 ideas，分别多 seed 运行，并从多个完整 manuscripts 中挑最好者。
  • 43 篇 workshop submissions 中混入三篇 AI 稿；reviewers 预先知道可能有 AI 稿且可 opt out，但不知道具体稿件。达到接收线的稿件在 meta-review/出版前依协议撤回。
  • 作者随后人工审查三篇的实验、代码、方法、引用和图文；附录公开完整稿件、内部评语与部分获授权的 workshop reviews。
Card 05 核心结果与证据

核心结果与证据

  • 唯一达到接收线的稿件研究 LSTM temporal/compositional regularization 的负结果，review scores 6/7/6，平均 6.33，约在 43 篇投稿 top 45%；两篇关于 calibration label noise 与 pest detection 的稿件被拒。
  • workshop reviewers 欣赏清晰呈现负结果，但要求更好理论动机、更多架构和真实任务；这支持“可达 workshop 边界”，不支持 main-track 质量。
  • 作者内部 code review 发现 train/test 约 57% overlap、Figure 3 caption 误释 validation loss、Figure 5 明显显示 attention model 优于 LSTM 却与文字冲突，并质疑简单任务上的 100% accuracy。
  • 该稿限制于短序列和 synthetic arithmetic，regularization 实际施加于 input embeddings 而非容易被读者理解的 hidden states；缺关键 LSTM 引用。作者判定 borderline workshop accept，但不够 full conference。
  • 结果是强 selection：目标明确为“至少一篇存活”，不是估计生成论文的接收率；从约 40 \(ideas\to 3\) funded ideas→每 idea 多 seeds→最佳完整输出→3 \(submissions\to 1\) 达线，不能把 1/3 当系统自然成功概率。
Card 06 有效性与局限

有效性与局限

  • workshop 通常接收率约 60–80%，领先主会约 20–30%；作者明确说 \(v_{2}\) 既未稳定达到 workshop level，也未达到顶会标准。
  • reviewers 知道可能出现 AI 稿且可退出，样本只有三篇、一个 workshop，无法估计匿名常规评审中的普遍表现。
  • peer-review acceptance signal 没有发现 57% overlap、caption/claim 冲突等全部问题，说明过审不能替代代码审计与独立复现。
  • idea 与 run 的人工 meta-selection 是实质资源分配和 winner selection；虽然没有改选中稿件文本/代码，仍影响最终展示的能力边界。
