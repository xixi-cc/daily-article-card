Challenges and Research Directions for Large Language Model Inference Hardware

Card 02 研究问题

研究问题

  • Transformer 训练以大矩阵乘和高并行度为主，而 autoregressive decode 每步只产生一个 token、反复读取 weights 与 KV cache。论文问：未来硬件应继续堆峰值 FLOPs，还是优先提高容量、带宽和跨芯片低延迟通信？
  • 长上下文、MoE、test-time compute、agentic workload 和多用户 serving 同时放大状态容量与通信，现有 HBM 容量/成本和 scale-out 网络可能成为系统上限。
Card 03 背景

背景

  • Prefill 可对 prompt tokens 并行，算术强度较高；decode 的 batch 和序列形状使每个 token 的权重/KV 数据移动占主导。Roofline 图像下，decode 更接近 memory-bandwidth bound，而非 compute bound。
  • KV cache 随层数、head dimension、序列长度和并发请求增长；当单芯片放不下模型与 cache，tensor/pipeline/expert parallel 会把每个 token 的串行依赖暴露为 interconnect latency。
Card 04 模型与方法

模型与方法

  • 论文按 capacity、bandwidth、latency 与 energy/cost 分解 inference path，比较 HBM、DDR/flash、near-memory processing、3D memory-logic stacking 和 scale-up/scale-out interconnect 的物理约束。
  • 提出四类机会：具有接近 HBM 带宽且约 10× 容量潜力的 High Bandwidth Flash；processing-near-memory；3D memory-logic stacking；低延迟高带宽互连。并讨论 datacenter 与 mobile 的不同功耗/容量边界。
  • 论证综合器件趋势、cost per capacity/bandwidth、LLM execution phases 和系统拓扑；它不是某一芯片的 benchmark，也没有声称单一技术能同时解决所有层级。
Card 05 核心结果与证据

核心结果与证据

  • Figure 3 对比 2023–2025 HBM3e 与 2022–2025 DDR4 的单位容量/带宽成本趋势：HBM 提供带宽却以显著容量成本为代价，DDR/flash 便宜但供数不足，直观暴露 memory hierarchy 的空档。
  • 作者指出 decode time-to-completion 与 output length 近线性，单 token latency 不能被大 batch 完全隐藏；长输出和 agent loop 使 low-latency interconnect 变成用户可见瓶颈。
  • High Bandwidth Flash 的 10× 容量是研究目标而非已量产结论；PNM 与 3D stacking 可缩短数据搬运，但热、良率、编程和制造成本决定其可行区。
Card 06 有效性与局限

有效性与局限

  • 文章是 architecture agenda，缺少统一端到端原型和同模型、同精度、同负载的实测 speedup。成本曲线来自特定时间窗口，价格、封装和供应链变化快。
  • 量化、speculative decoding、KV compression、continuous batching 与模型架构会改变瓶颈；将今日 decode 特征外推到未来模型存在不确定性。HBM-like flash、3D 堆叠和 PNM 也各有 endurance、thermal 和 software ecosystem 风险。
  • 移动端的功耗、隐私和间歇负载不同于数据中心，不能直接套用结论。该卡 no independent reproduction performed，未做硬件测量。
