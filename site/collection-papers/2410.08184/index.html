Scaling Laws For Diffusion Transformers

Card 02 研究问题

研究问题

  • 语言模型有成熟 compute-optimal scaling laws，但 diffusion transformer 的 loss、FID、模型参数与数据量是否也 obey power laws 尚不清楚。论文在 10^17–6×10^18 FLOPs 扫描，并外推到 10^21。
  • 目标不仅拟合 loss(C)，还要从固定预算的 IsoFLOP curves 找 \(N_{\mathrm{opt}}\)(C)、\(D_{\mathrm{opt}}\)(C)，并验证 pretraining loss 是否能预测生成 FID 与 OOD metrics。
Card 03 背景

背景

  • 在每个 compute budget 下，改变模型大小会出现 U-shaped loss：过小模型欠容量，过大模型 token 不足。各预算抛物线最低点组成 compute-optimal frontier。
  • DiT 的 diffusion formulation、timestep sampling、prediction target、conditioning architecture 会改变常数乃至 exponent，因此标度律必须绑定具体训练 recipe。
Card 04 模型与方法

模型与方法

  • Figure 1 左图对每个 budget 扫 model size/训练数据并拟合最小点；中/右图用这些 optima 拟合 \(N_{\mathrm{opt}}\) 与 \(D_{\mathrm{opt}}\) 的 power laws。实验架构含 in-context concatenation 和 cross-attention variants。
  • metrics 包括 train/validation loss、offset VLB/NLL、FID 和 CLIP；COCO 2014 做 OOD evaluation。作者用较小预算拟合后预测 1B、约 10^21 FLOPs run 的 loss/FID。
  • 附录逐项核算 transformer FLOPs，并消融 diffusion/noise/timestep schedule、prediction type、aspect ratio 和 EMA，减少 recipe drift 对 scaling fit 的污染。
Card 05 核心结果与证据

核心结果与证据

  • Figure 1 的 IsoFLOP minima 沿 budget 系统移动，拟合得到 vanilla in-context 约 N exponent 0.56、D exponent 0.43、loss exponent -0.0273；cross-attention 对应约 0.54、0.46、-0.0385。
  • 预训练 loss 与 FID 随 compute 的趋势匹配；小预算 fit 对 1B/10^21 run 的 hold-out 点给出接近预测，构成真正的外推检验而非只看 in-sample R²。
  • OOD COCO metrics 也单调改善但整体平移，说明 exponent-like trend 可迁移，绝对 loss 仍受 data distribution 影响。cross-attention 的 loss 降得更快，架构选择会改变 frontier。
Card 06 有效性与局限

有效性与局限

  • 预算跨度和单个 1B hold-out 仍有限；power law 可能在更大数据、分辨率或 quality saturation 后弯曲。FID 对 sampler、CFG、sample count 和 feature extractor 敏感。
  • compute-optimal 只在作者固定数据质量和 recipe 下成立；改变 caption quality、augmentation、latent tokenizer 或 diffusion objective 会移动常数/指数。
  • pretraining loss 与视觉质量相关不表示所有 prompt fidelity、美学和安全维度同标度。该卡 no independent reproduction performed。
