Is This the Subspace You Are Looking for? An Interpretability Illusion for Subspace Activation Patching

Card 02 研究问题

研究问题

  • 若沿某个激活子空间 patch 后，模型输出表现得像目标 feature 被替换，是否足以说明该子空间在自然前向过程中表示并因果传递了该 feature？
  • 作者证明答案可能是否定的：成功干预可以把一个 causally disconnected direction 上的自然变化，旋转为数据分布上 dormant、但人工激活后能影响输出的方向，从而制造‘行为正确、解释错误’的子空间。
Card 03 模型与方法

模型与方法

  • 标准一维 patch 把样本 B 的 activation 在单位方向 v 上的投影替换为样本 A 的投影。若 v 混合 disconnected 与 dormant components，投影差由前者携带 feature 信息，但 patch vector 的后者把变化写入输出相关通道。Figure 1 用二维几何显示这种旋转。
  • 论文先构造计算恒等映射的极简网络，展示 \(h_{1}\) 与输出断连、\(h_{2}\) 在数据上 dormant，却可由混合方向 patch 模仿真正 causal \(h_{3}\)。随后在 GPT-2 small 的 indirect object identification 与 factual recall 上用 distributed alignment search 等方法寻找子空间，并将方向分解到 MLP \(W_{\mathrm{out}}\) 的 rowspace 与 kernel。
  • 作者以只 patch rowspace、只看自然 activation distribution、查看下游写入路径和既有人工 circuit knowledge 作为 faithfulness checks；还把 factual recall 现象联系到 rank-1 fact editing 中 editing success 与 localization 的脱节。
Card 04 核心结果与证据

核心结果与证据

  • 数学例子说明，\(v_{\mathrm{illusory}}\)=(\(v_{\mathrm{disconnected}}\)+\(v_{\mathrm{dormant}}\))/sqrt(2) 可以在单维 patch 中同时取得可读出 feature variation 与可改变输出的方向，尽管这两个性质来自互不相干的 components。成功操控因此不蕴含同一子空间在自然计算中具有因果作用。
  • 在 IOI 的 MLP8 等位置，找到的 patching direction 依赖 \(W_{\mathrm{out}}\) kernel 中的大 disconnected component；移除该 component、只沿 rowspace patch 时效果可显著消失。论文也展示 residual-stream success case：已有手工 circuit evidence 且不存在同样绕过瓶颈的路径时，subspace 解释更可信。
  • 在 factual recall 中，DAS patch 与 rank-1 editing 可依赖 nullspace 信息来决定干预幅度，再沿 dormant rowspace 方向写入输出。这给出 fact editing 能成功却未忠实定位事实存储位置的一种具体机制，而非声称解释所有 editing methods。
Card 05 有效性与局限

有效性与局限

  • ‘幻觉’依赖对真实解释和自然 causal mediation 的定义；作者承认解释标准具有概念选择。发现 counterexample 足以否定单凭 patch success 的推理，但不说明所有 subspace patching 都不可信。
  • 实证集中于特定 GPT-2 small 任务、层和线性子空间；更大模型、非线性 features、不同 patch operators 与多维 subspaces 的发生率仍未知。\(W_{\mathrm{out}}\) kernel 提供清晰断连结构，但其他组件未必有同样几何。
  • rowspace projection、natural-activation support 和下游 circuit tracing 是必要的额外证据候选，并非完备认证。成功 case 借助已有 IOI circuit analysis，说明方法可靠性依赖外部机制知识；本卡未独立复现实验。
