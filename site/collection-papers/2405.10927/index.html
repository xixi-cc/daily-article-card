作者信息

Card 02 研究问题

研究问题

  • 同一个网络函数常有许多等价参数化：例如 attention 中只有矩阵乘积而非每个因子单独决定输出。若解释方法直接读取单个 neuron、weight 或 activation，它可能把参数化冗余误当成计算结构。论文问：哪些内部退化会遮蔽模块，以及能否构造对这些重参数化不变的表示？
  • 作者区分 activation vectors 线性相关、反向 Jacobian/gradient 线性相关，以及 ReLU 在数据集上具有相同 firing pattern 三类退化。核心不是把低 Hessian eigenvalue 简单等同于无用参数，而是刻画保持网络行为的自由方向及其相互作用。
Card 03 模型与方法

模型与方法

  • Singular learning theory 用 learning coefficient 描述低损失体积 V(\(\epsilon\)) 随 \(\epsilon\) 收缩的标度；局部版本把分析限制在给定解附近。论文将训练 loss 换成 behavioral loss，即比较候选网络与参考网络在有限数据上的输出，从而把“实现同一行为”的参数集合当作解释对象。
  • 在 MSE behavioral loss 下，Hessian 可写成输出 Jacobian 的 Gram 结构。若一层 activations 只张成低维子空间，某些 incoming-weight 方向不可辨识；若 downstream Jacobians 线性相关，某些 outgoing-weight 方向不可辨识。Interaction Basis 通过对 activation 与 Jacobian covariance/SVD 方向做规范化，尝试消除这两类线性退化。
  • 作者进一步用 free directions 是否发生联合高阶相互作用构造模块性启发式：真正独立模块的自由方向应形成直积，而不是仅在坐标轴上分别保持零损失。这里主要是理论论证与 toy evidence，不是对大模型模块的成熟识别基准。
Card 04 核心结果与证据

核心结果与证据

  • Figure 1 的 \(\mathrm{L}(w)\)=w₁²w₂² 是关键反例：沿任一坐标轴损失均为零，但同时移动两个参数损失上升；零损失集合是十字而非二维平面。因此“两个各自自由的方向”不能直接减去两个有效参数，局部学习系数会感知联合几何。
  • 论文证明/论证 activation 与 Jacobian 的线性依赖分别产生具体重参数化自由度，并说明 ReLU 同步 firing 可产生另一种数据依赖退化。Interaction Basis 对前两类退化不变，且在作者的结构性论证中应使跨特征 interaction 更稀疏。
  • 结论部分明确给出后续检验边界：相关 Local Interaction Basis 在 toy models 上得到稀疏、模块化、可解释表示，但应用到 LLM 时效用显著下降。这使本文更适合作为诊断框架与候选规范，而非已验证的通用解释器。
Card 05 有效性与局限

有效性与局限

  • Behavioral loss 依赖有限数据集；数据未激活的方向会被判为退化，但它们可能影响分布外行为。MSE 输出距离也不是唯一语义等价标准，换成 KL、任务指标或 intervention set 会改变局部几何。
  • Interaction Basis 只直接处理 activation/Jacobian 的线性退化，不能自动消除 ReLU firing-pattern、permutation、nonlinear gauge 或跨层等价。SVD 在简并奇异值附近的基也不唯一，数值稳定性需要额外约定。
  • 模块性指标来自 free-direction interaction 的启发式与 toy construction；没有证明低 interaction 等价于因果独立模块。论文未提供大规模 benchmark、跨架构消融或与 SAE/circuit discovery 的公平比较。本卡未独立复现。
