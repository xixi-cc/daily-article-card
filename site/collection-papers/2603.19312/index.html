LeWorldModel: Stable End-to-End Joint-Embedding Predictive Architecture from Pixels

LeWorldModel：从像素稳定端到端训练 JEPA 世界模型

Joint Embedding Predictive Architectures (JEPAs) offer a compelling framework for learning world models in compact latent spaces, yet existing methods remain fragile, relying on complex multi-term losses, exponential moving averages, pre-trained encoders, or auxiliary supervision to avoid representation collapse. In this work, we introduce LeWorldModel (LeWM), the first JEPA that trains stably end-to-end from raw pixels using only two loss terms: a next-embedding prediction loss and a regularizer enforcing Gaussian-distributed latent embeddings. This reduces tunable loss hyperparameters from six to one compared to the only existing end-to-end alternative. With ~15M parameters trainable on a single GPU in a few hours, LeWM plans up to 48x faster than foundation-model-based world models while remaining competitive across diverse 2D and 3D control tasks. Card 03 背景

背景

  • 论证节点“端到端 JEPA 为什么容易坍缩？”。
  • 世界模型希望在紧凑 latent space 预测未来，而非重建每个像素。
  • 已有 JEPA 常依赖 stop-gradient、EMA、预训练 encoder 或多项辅助损失防坍缩。
  • 唯一既有端到端替代使用多达六个损失超参数，训练脆弱。
  • LeWM 只保留 next-embedding prediction 与 SIGReg 两项损失。
  • 作者把稳定性问题收缩为：如何让潜变量既可预测又保持分布多样性。
  • JEPA 坍缩问题与 LeWM 两损失设计。 （\(p\). 1）

模型与方法

  • 论证节点“SIGReg 用随机投影正态性阻止常数坍缩”。
  • 设定：$u_k$ 为随机单位方向，$Z$ 为 batch embedding
  • 关键关系：\mathcal \(L\) &= \\\|\hat \(z_{t\)+1}-\(z_{t\)+1}\\\|_2^2+\lambda\,\mathcal \(R_{SIG}\)(\(Z\)) \\ \mathcal \(R_{SIG}\)(\(Z\)) &= \frac1K\sum_k NormalityTest(\(u_{k}\)^\top \(Z\))

  • 结论边界：预测损失保留动力学，SIGReg 防止所有样本缩到同一点。
  • 两项损失与随机投影 SIGReg。 （\(p\). 5; equation Eqs. 1-3; sections/3-method.tex）

Card 05 核心结果与证据

核心结果与证据

  • Fig. 1：encoder 从像素得到 $z_t$；predictor 用动作预测 $z_{t+1}$；SIGReg 同时约束两端嵌入。
  • 证据解释：无需冻结分支、EMA 或预训练表征，encoder 与 predictor 可共同反向传播。
  • LeWM 训练管线。 （\(p\). 1; figure Fig. 1）
  • Fig. 2：编码、潜在动力学 rollout 与 CEM 动作序列搜索组成规划循环。
  • 证据解释：15M 参数模型可在单 GPU 数小时训练，并把基础模型式世界模型规划加速最高 $48\times$。
  • LeWM 潜在规划流程与速度结论。 （\(p\). 6; figure Fig. 2）
  • 论证节点“规划表现：更轻量，同时保持或提高任务成功”。
  • 在 PushT 上相对 PLDM 成功率提高 $18$ 个百分点。
  • 在多种 2D/3D 像素控制任务上与更重基线保持竞争。
  • 固定 FLOP 比较显示收益不只是更多搜索预算。
  • 训练只剩一个有效损失权重 $\lambda$；$[0.01,0.2]$ 上 PushT 成功率均超过 $80\%$。
  • 方法优势主要体现在训练简化、规划速度与稳定性，而非每个环境绝对领先。
  • 控制结果、速度与 lambda 消融。 （\(p\). 7; figure Figs. 3,6）
  • Fig. 5：对视觉或物理不可能扰动，预测误差形成 surprise 峰；不同环境可分性不同。
  • 证据解释：潜空间编码了一些物理结构，但 OGBench-Cube 上并非所有扰动都显著可检出。
  • violation-of-expectation 物理理解测试。 （\(p\). 8; figure Fig. 5）

Card 06 有效性与局限

有效性与局限

  • 论证节点“短 horizon、离线覆盖与动作标签是当前瓶颈”。
  • 规划仍局限短时域，长任务需要分层世界模型。
  • 训练依赖覆盖充分的 offline action-labelled 数据。
  • 低复杂度、低多样性环境中，高维高斯匹配可能削弱 SIGReg。
  • 可用大规模视频预训练或逆动力学减少域数据与动作标签依赖。
  • 稳定端到端训练已被验证，但并未解决长期开放世界建模。
  • 作者列出的 planning horizon、coverage 与 action label 局限。 （\(p\). 9）
  • 论证节点“LeWM 以分布正则替代训练技巧堆栈”。
  • JEPA 只预测下一 latent embedding，不承担像素重建。
  • SIGReg 通过随机投影高斯性提供防坍缩约束。
  • 两损失、15M 参数和单 GPU 训练显著降低世界模型门槛。
  • 规划、probe 与 surprise 测试提供互补证据，也暴露环境依赖边界。
  • 最可信的贡献是“简单且稳定的端到端 JEPA 基线”，而不是完整物理推理系统。
  • 论文结论概括稳定性、效率与物理表征。 （\(p\). 9）
