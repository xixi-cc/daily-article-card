Outliers with Opposing Signals Have an Outsized Effect on Neural Network Optimization

具有相反信号的离群样本对神经网络优化产生超额影响

Card 01 作者信息

作者信息

  • 作者 Elan Rosenfeld 与 Andrej Risteski，来自 Carnegie Mellon University。论文研究自然数据的 heavy-tailed sample structure 如何与网络深度和 steepest-descent optimization 共同塑造训练动力学。arXiv:2311.04163v1。
Card 02 研究问题

研究问题

  • 深度网络训练中的 progressive sharpening、edge of stability、loss spikes 与 Adam/SGD 差异通常被分开讨论。作者提出：是否有少量、成对出现且提供相反梯度的高影响样本，成为这些现象的共同微观来源？
  • 所谓 opposing signals 是在模型当前表示中具有大幅度特征的两个样本群：沿一群的梯度降损会以相近幅度提高另一群损失。它们未必是输入空间的异常值，而是数据、标签、架构和训练时刻共同定义的动态对象。
Card 03 模型与方法

模型与方法

  • 主要实验以 CIFAR-10 上的 ResNet-18、VGG-11 与 Vision Transformer 为主，也检查文本 next-token transformer、Chebyshev polynomial MLP、SGD 和 Adam。训练时记录每个样本逐步 loss change，选出增幅最大和降幅最大的样本，再按可见共享特征分组。
  • 作者同时跟踪 per-sample gradient norm、个体 Hessian curvature 在全局 top eigenvector 上的投影、合成纯色输入的 logits 与 feature norm。Figure 1 把若干 opposing groups 的交替损失与总体训练 loss spikes 对齐。
  • 机制解释把网络视为先快速放大易学但非决定性的信号，再进入平衡两组相反梯度的窄谷；随 sensitivity/sharpness 增长，有限步长越过谷底并使两组损失交替放大。一个二层线性模型给出受控理论分析，SplitSGD 案例用于探查 Adam 的固定尺度更新效应，而非提出成熟优化器。
Card 04 核心结果与证据

核心结果与证据

  • 在 full-batch GD 的 CIFAR-10 训练中，background color、redness、vehicle features 与 grass texture 等组的损失呈反相振荡，幅度增长与总体 loss spike 同步；这些组在梯度范数和主曲率方向上也显著偏大。
  • synthetic color blocks 的预测轨迹符合 toy mechanism：网络先增强简单特征，进入振荡后逐步降低对该特征的依赖。小学习率近似 gradient flow 时缺少同样的离散振荡且特征范数持续增长，支持有限步长振荡可能产生隐式正则化。
  • SGD 下仍观察到 noisy but paired oscillations；Adam 更快压低这些高幅度特征。作者构造的 SplitSGD 在若干 ResNet 与早期 GPT-2 实验中接近 Adam，用来说明少量大梯度参数的步长控制可能关键，但不是广泛基准后的新算法结论。
Card 05 有效性与局限

有效性与局限

  • 样本分组包含人工视觉检查，作者明确承认尚缺严格自动定义；因此‘普遍存在’主要由多架构、多种子图像与少量文本/函数案例支持，频率和效应大小未形成无偏总体估计。
  • loss spikes 与 opposing-group oscillations 的时间对应、toy model 和二层线性证明共同提供机制证据，但不能排除其他导致 edge of stability 的路径。把它称为直接原因仍带有模型与设置依赖。
  • CIFAR 网络和早期 GPT-2 不能代表现代大模型完整训练；Adam/SGD 与 SplitSGD 结果受调参预算、batching 和训练区间影响。与 grokking、simplicity bias、SAM 和 generalization 的联系多为假说或未来方向；本卡未独立复现实验。
