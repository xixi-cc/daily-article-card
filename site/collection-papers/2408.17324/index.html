Transformer 的模块性：神经元可分离性与专门化

作者信息

  • Nicholas Pochinkov、Thomas Jones 与 Mohammed Rashidur Rahman，独立研究者。论文用 selective pruning 与 MoEfication 聚类比较 ViT 和 Mistral 7B 中面向不同类别/数据子集的 MLP neurons。arXiv:2408.17324v1。
Card 02 研究问题

研究问题

  • 如果 Transformer 内部存在 task-specific modules，针对一个类别选出的重要 neurons 在剪除后应优先损害该类，对相关类别的 neuron sets 应有较大 overlap，并与 weight-space MoE clusters 对齐。
  • 作者还比较 pretrained 与 randomly initialized models，问哪些 overlap 来自架构/随机几何，哪些由训练强化。
Card 03 模型与方法

模型与方法

  • Selective-pruning score 用 neuron 在 retained dataset \(D_{r}\) 与 to-be-unlearned \(D_{u}\) 上的平均 activation ratio排序；逐步剪除高相对重要 neurons，直到目标类别性能下降到指定比例。ViT 用 CIFAR20/100，Mistral 7B 用 next-token corpora 与 subject-split MMLU。
  • 对每个 class/subset 取 top-ranked neurons，计算 pairwise intersection percentage。再对 MLP input-weight columns做 balanced \(k\)-means（MoEfication），用 Lorenz curve/AUC 衡量 task-selected neurons 是否集中在少数 clusters。
  • Random baseline 保持同架构但未训练。Figure 1 的 ViT transfer matrix：每个竖条剪除针对一个类的 neurons，矩阵其余 cells 显示其他类 relative accuracy。
Card 04 核心结果与证据

核心结果与证据

  • Figure 1 显示对目标 CIFAR class 的性能可被定向压低，而许多非目标类保持接近 baseline；不过若干语义相关类别也受明显影响，说明 specialization 与共享并存。Mistral 的文本/MMLU矩阵出现类似但更弱或更分散的 separability。
  • Trained models 的重要-neuron overlaps 具有类别结构，但 random models 也呈现非零甚至相似 pattern，表明有限维 random features/architecture 已产生基线模块性。训练通常改变 extreme overlaps，而非从零创造全部结构。
  • MoEfication alignment 在早期和后期 layers 更强，中间层较弱；这支持 cluster 与 task importance 部分一致，但 AUC 是统计集中度，不证明每个 cluster 实现单一可解释功能。
Card 05 有效性与局限

有效性与局限

  • Activation-ratio score 和逐 neuron pruning 忽略冗余、synergy 与 downstream compensation；剪除会制造 off-distribution activations。Target drop 的阈值和 selected percentage 会改变 overlap matrix。
  • Random initialized model 没有相同任务性能，因此对其 activation-defined importance 的语义比较并不完全对称。CIFAR class 与 MMLU/data subsets 粗粒度，不能代表 token-level circuits。
  • 样本、模型和 seeds有限，Mistral 是特定 checkpoint；没有 fine-tuning/causal mediation 或恢复性 patching 证明 clusters 必要充分。模块性结论应称为部分统计证据。本卡未独立复现。
