How Transformers Learn Causal Structure with Gradient Descent

Transformer 如何通过梯度下降学习因果结构

Card 02 研究问题

研究问题

  • Self-attention 能跨序列位置传递信息，但‘可表达某种 causal computation’不等于‘训练会发现它’。本文构造一个 in-context learning 任务：每条序列由共同的有向无环图 G 决定位置依赖，但 transition matrix \(\pi\) 在不同 context 间随机变化；模型必须由一条 context 同时识别哪些位置互为父子并估计当前 \(\pi\)，才能预测 query token 的后继。
  • 核心问题是：标准的 gradient signal 是否足以辨认真实 parent edge？若能，第一层 attention 如何编码图，第二层又如何把图结构变成 transition-counting algorithm？Markov chain 情形是否自然退化为 induction head？
Card 03 模型与方法

模型与方法

  • 输入 token 同时带 symbol 与 position embedding。作者研究 two-layer attention-only 的 disentangled transformer：它把 residual stream 的不同通道显式保留，并以单个 attention matrix \(A=QK^{T}\) 表示 query-key interaction；附录证明在允许宽度扩张时与相应 decoder transformer 等价。
  • Task 1 先限制每个非根节点至多一个 parent。训练分两阶段：先固定第二层与输出方向，分析第一层 A^(1) 的梯度；再固定已学图结构，训练第二层 content attention。理想化梯度 \(g_{i}\),j 可写成 token pair 的 χ² mutual-information quantity。由 conditional Markov chain 与 data-processing inequality，真实 parent \(p\)(i) 对应的梯度严格大于其他较早位置，因而 attention pattern 向 graph adjacency 对齐。
  • 前向算法中，第一层让每个 token 读取并附加其 parent token；第二层寻找历史中 parent value 等于当前 query value 的位置，平均这些位置的 child symbols。这个操作等价于用 graph edges 构造 empirical transition matrix。作者还给出多父节点时由多个 heads 分摊 parent sets 的构造，并以训练实验检查所得 attention maps。
Card 04 核心结果与证据

核心结果与证据

  • Theorem 1 在树状/单父节点图、特定初始化、步长和分阶段训练等假设下证明：gradient descent 使第一层恢复 G，并使第二层输出接近真实 transition \(\pi\)；当 G 是相邻位置组成的 Markov chain 时，所得机制就是 induction head。
  • 关键证据不是相关性可视化，而是 gradient ordering。对真实 parent，\(g_{i}\),\(p\)(i)=I_{χ²}(\(s_{i}\);\(s_{p}\)(i)|\(\pi\))；对 \(j\ne p(i)\)，data-processing inequality 给出严格更小的上界。Figure 4 画出对应 attention entry 更快增长，随后 softmax 放大差距，形成离散 parent selection。
  • Figure 2/6 的合成实验显示训练后的 position-position block 复现链、树和随机图；Figure 3 逐步展示 first-layer parent retrieval 与 second-layer matching 如何计算预测分布。Figure 5/7 中，多头模型在 \(k=2\) 或 3 个 parents 的任务上把不同 parent relation 分配给不同 heads，与构造的定性预言一致。
Card 05 有效性与局限

有效性与局限

  • 结论针对已知拓扑顺序、离散 symbols、共享 DAG 且 transition 来自受控 prior 的任务；它不是从 observational data 中处理 hidden confounders、干预或 Markov-equivalent graphs 的一般 causal discovery 结果。这里的‘causal’首先指生成任务中预设的有向位置依赖。
  • 主定理依赖单父节点树、irreducible/aperiodic Markov transitions、information gap、初始化尺度、足够样本/有效序列长度以及人为分开的训练 stages。多父节点部分主要是表达构造与数值支持，没有给出同等强度的 gradient-descent recovery theorem。
  • 模型是两层 attention-only/disentangled architecture；标准 Transformer 实验规模有限，MLP、normalization、optimizer、有限宽度与真实语言分布可能改变动力学。严格 mutual-information ordering 在弱依赖或近并列 parent 候选下会变脆弱。本文未证明预训练 LLM 内部实际使用同一算法，本卡也未独立复现实验。
