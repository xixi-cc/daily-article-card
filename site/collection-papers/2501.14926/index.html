Interpretability in Parameter Space: Minimizing Mechanistic Description Length with Attribution-based Parameter Decomposition

参数空间可解释性：用基于归因的参数分解最小化机制描述长度

Card 02 研究问题

研究问题

  • superposition 使同一神经元/权重参与多个机制，按 neuron 阅读网络会混杂功能。能否直接在 parameter space 中找到一组组件 \(P_{c}\)，使其和重构原网络，同时每个输入只需少数组件解释输出？
  • 理想分解要兼顾 faithfulness、minimality 和 simplicity，并用较短 mechanistic description 表达目标网络，而不是任意把矩阵拆成代数基。
Card 03 模型与方法

模型与方法

  • APD 训练一个参数组件集合，约束 \(\theta\)*≈\(\Sigma_{c}\) \(P_{c}\)。对每个输入先计算组件 attribution \(A_{c}\)(\(x\))，选择高归因组件组合成输入特定子网络；minimality loss 要求该子网络复现目标输出，simplicity/regularization 限制组件规模与重叠。
  • Figure 1 展示展平目标参数、分解为多个红色稀疏 components、求和重构网络；Figure 2 给出归因与 minimality 优化两步。
  • 实验从 Toy Models of Superposition（TMS）到含 residual MLP 的 compressed computation toy model，再到更复杂设置，使用已知 ground-truth features/mechanisms 检查组件恢复。
Card 04 核心结果与证据

核心结果与证据

  • TMS 中 APD 学得组件与目标权重列高度对齐，mean max cosine similarity 接近 1；每个组件倾向对应一个 activation feature，而非整个 neuron。
  • compressed computation 模型中，多个机制共享 neuron，APD 仍能按输入 feature 分离参数贡献，说明 parameter decomposition 可越过 neuron polysemanticity。Ablations 检查 attribution、minimality 和组件数。
  • 结果支持 APD 在具有已知机制的玩具网络中恢复更短描述，但尚未证明在大型语言模型中得到人类可命名、唯一或因果完整的组件。
Card 05 有效性与局限

有效性与局限

  • 参数分解一般不唯一，神经网络还有 permutation、scaling 和 basis symmetries；loss/regularizer 选择决定哪个等价分解被偏好。组件数量和阈值也是重要超参数。
  • faithfulness 多在目标数据分布和输出上测量，分布外输入或内部 activations 可能偏离；attribution method 本身可饱和或遗漏交互。
  • toy ground truth 有利于评价，但真实网络机制可能重叠、连续且层间分布式。计算和存储随组件数增长。本卡未独立复现。
