Local Kernel Renormalization as a mechanism for feature learning in overparametrized Convolutional Neural Networks

局域核重整化作为过参数卷积神经网络特征学习机制

Card 01 作者信息

作者信息

Card 02 研究问题

研究问题

  • 无限宽网络等价于固定核学习，通常缺少随训练变化的表示。为什么有限宽 FCN 的最好性能常趋向无限宽，而有限通道 CNN 可能优于其无限宽核？论文提出 locality 与 weight sharing 允许数据依赖的局域核重整化。
  • 所研究的是 P、宽度同时趋于无穷而比值 \(\alpha=P\)/\(N\) 固定的过参数 Bayesian/低温设置，架构只有一层。它不是对现代深 CNN、SGD 动力学或 mean-field 参数化的普遍定理。
Card 03 模型与方法

模型与方法

  • 对单隐层 FCN，有限宽有效作用只产生标量 \(Q\)̄，对 NNGP kernel 作全局缩放；给定激活与数据规模，这一缩放可吸收到优化过的 Gaussian prior，因此有限宽 FCN 在该设置中不能超过最佳无限宽核。
  • 对一维 CNN，作者在通道数 Nc、样本数 P 同时增大的固定 αc 极限，对局部 patch covariance 推导矩阵序参量 \(Q\)̄ij。renormalized kernel 是所有局部 Kij 的数据依赖加权和；LCN 只有对角向量权重，CNN 因 weight sharing 还能调节跨 patch 的非对角相关。
  • 数值部分比较训练前后 hidden representation similarity matrix 的尺度律，并在 Gaussian teacher 与 CIFAR-10 cars/planes 二元任务上，用 ADAM 或近零温 Langevin 训练不同宽度/卷积核大小的单层网络。
Card 04 核心结果与证据

核心结果与证据

  • Figure 1 与 Table I 总结：FC 的重整化自由度是一个标量，LCN 是各 patch 的对角权重向量，CNN 是完整 \(Q\)̄ij 矩阵。局域连接和权重共享都需要，缺少共享的 LCN 不能调节跨 patch 相关。
  • Figure 2 的有限尺度分析中，FC 训练前后 similarity matrix 差异的方差随宽度趋零，表明表示变化是有限尺寸修正；CNN 的相应差异在固定 \(\alpha\) 的 proportional limit 不消失，与局域重整化预测一致。
  • Figure 3 的受控 CIFAR-10 二元回归中，FC test loss 随宽度单调接近无限宽极限；若卷积核小于全图，有限通道 CNN 可从下方接近极限，在约 \(Nc\approx 50\) 处得到更低 loss。该结果只在大 Gaussian prior、bias-dominated、近零温设置支持机制。
Card 05 有效性与局限

有效性与局限

  • 推导使用 Gaussian equivalence 的非严格论证、odd activation、平方损失、单隐层和特定输入/stride 随规模的极限；mean-field regime、深层组合、有限温度与常用交叉熵不在覆盖范围。
  • \(Q\)̄ij 未在训练中直接测量，实验通过 similarity matrix 和 bias/variance 的间接后果验证。理论是 Bayesian Gibbs ensemble，而部分数值用 ADAM；两者一致是经验观察，不是动力学等价证明。
  • CIFAR 实验只取两个类别、灰度粗粒化、\(P=500\)，且 Langevin 训练约 5×10^6 步。有限 CNN 优势不应外推为实际大数据网络必有最优有限通道数。参考文献 [1]–[55] 位于讨论和附录之间且无标准标题，已对原 PDF 分页核查。
