Scaling behavior in non-reciprocal and odd conserved dynamics near criticality

研究问题

  • 非互易 Cahn–Hilliard dynamics 同时受 temperature-like \(r\) 与 nonreciprocal coupling \(\alpha_0\) 调控。论文问：接近相分离临界点时，equal-time structure 与 response dynamics 是否仍由同一 correlation length 控制，还是 activity 产生新的 scaling exponent/regimes？

背景

  • 平衡临界动力学中 fluctuation–dissipation relation 把结构与响应锁在同一尺度。非互易耦合破坏 parity/time reversal，可产生 traveling patterns。Figure 1 从 enzyme/active-colloid micro scale 到 density-field meso scale，再到 macro domains，标出 \(r,\alpha_0\) 如何调节 crossover length。

模型与方法

  • NRCH 是两个 conserved fields 的 Model-B-like Langevin equation，mobility 中含 antisymmetric/odd part，free-energy-like reciprocal sector 与 linear/nonlinear nonreciprocal couplings 并存。作者定义 equal-time correlation 的 \(\xi_s\) 和 response/dynamic correlation 的复长度 \(\xi_d\)。 线性模型的动力学长度可为复数，对应响应的衰减与振荡；它不能直接视作恒为正实数的尺度。
  • 作者用一圈 momentum-shell RG 和包含两圈自能的 Callan–Symanzik 分析计算 beta functions、固定点与交叉标度；二者只在共同阶上比较。

核心结果与证据

  • 在论文的双场 \(\mathrm{SO}(2)\) 模型、微扰展开与标度假设下，作者提出结构长度 \(\xi_s\sim r^{-\nu}\)，其中 \(\nu=1/2+\epsilon/10+O(\epsilon^2)\)。附录中结构标度函数的相关渐近为依据线性结果的推测。动态长度的交叉变量为 \(\sigma=\alpha_0-\theta r\)：EE 区跟随 \(r^{-\nu}\)，非互易区按 \(|\sigma|^{-\nu_n}\) 标度，\(\nu_n=1/2+O(\epsilon^2)\)；简单的 \(r\) 或 \(\alpha_0\) 幂律需对应项在 \(\sigma\) 中占优。
  • 临界点本身流向具有 odd mobility 的 conserved equilibrium-like OCH fixed point；在有限但很大的 \(\xi_d\) 尺度上，\(\mathrm{NR}\pm fixed\) points 描述动态长度大但有限的非临界交叉及 broken-FDT behavior。Figure 2/3 划分 EE、\(\alpha\)NR、rNR 与 suppressed-NR regimes。
  • 结果意味着 structural snapshot 可能看似 Wilson–Fisher，而 relaxation/correlation time 却由 nonreciprocity 单独调节。论文提出代谢/催化 rate 可作为 living mixtures 的 dynamical tuning parameter，但未做实验或数值格点验证。

有效性与局限

  • 一圈结果在两种 RG 表述共同阶上的一致性和 fixed-point/crossover map 是理论优势；显式区分 \(\xi_s\) 与 \(\xi_d\) 也给实验 observable 清晰分工。
  • 结论来自 \(\epsilon\)-展开、一圈动量壳与包含两圈自能的微扰分析；OCH 的更高阶稳定性及结构长度标度函数仍需验证。OCH 的受限 FDT 不等于完整平衡，且稳态可有概率流。真实活性体系可能有额外流体动力学、有色噪声及有限尺寸交叉。
