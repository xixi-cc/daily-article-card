Card 02 研究问题

研究问题

  • 非互易 Cahn–Hilliard dynamics 同时受 temperature-like \(r\) 与 nonreciprocal coupling \(\alpha_0\) 调控。论文问：接近相分离临界点时，equal-time structure 与 response dynamics 是否仍由同一 correlation length 控制，还是 activity 产生新的 scaling exponent/regimes？
Card 03 背景

背景

  • 平衡临界动力学中 fluctuation–dissipation relation 把结构与响应锁在同一尺度。非互易耦合破坏 parity/time reversal，可产生 traveling patterns。Figure 1 从 enzyme/active-colloid micro scale 到 density-field meso scale，再到 macro domains，标出 \(r,\alpha_0\) 如何调节 crossover length。
Card 04 模型与方法

模型与方法

  • NRCH 是两个 conserved fields 的 Model-B-like Langevin equation，mobility 中含 antisymmetric/odd part，free-energy-like reciprocal sector 与 linear/nonlinear nonreciprocal couplings 并存。作者定义 equal-time correlation 的 \(\xi_s\) 和 response/dynamic correlation 的复长度 \(\xi_d\)。
  • 通过 momentum-shell 与 Callan–Symanzik 两种 RG 计算 beta functions、fixed points 和 crossover scaling；\(4-d=\epsilon\) 展开给 Wilson–Fisher/OCH 与 manifestly NR fixed points。
Card 05 核心结果与证据

核心结果与证据

  • 结构长度始终按 temperature 控制：\(\xi_s\sim r^{-\nu}\)，\(\nu=1/2+\epsilon/10+O(\epsilon^2)\)。动态长度在 effective-equilibrium regime 跟随 \(\xi_s\)，但在 NR regimes 可按 \(r^{-\nu_n}\) 或 \(|\alpha_0|^{-\nu_n}\) 发散，\(\nu_n=1/2+O(\epsilon^2)\)。
  • 临界点本身流向具有 odd mobility 的 conserved equilibrium-like OCH fixed point；在有限但很大的 \(\xi_d\) 尺度上，\(\mathrm{NR}\pm fixed\) points 控制 broken-FDT behavior。Figure 2/3 划分 EE、\(\alpha\)NR、rNR 与 suppressed-NR regimes。
  • 结果意味着 structural snapshot 可能看似 Wilson–Fisher，而 relaxation/correlation time 却由 nonreciprocity 单独调节。论文提出代谢/催化 rate 可作为 living mixtures 的 dynamical tuning parameter，但未做实验或数值格点验证。
Card 06 有效性与局限

有效性与局限

  • 两个独立 RG formulations 的一致性和 fixed-point/crossover map 是理论优势；显式区分 \(\xi_s\) 与 \(\xi_d\) 也给实验 observable 清晰分工。
  • 结论来自 \(\epsilon\)-expansion 和 perturbative two-loop analysis，作者指出 OCH fixed-point 的稳定性/更高阶修正仍需数值与 higher-loop verification。真实活性体系可能有额外 hydrodynamics、noise color、composition tuning 和 finite-size crossover。
