Towards Understanding Inductive Bias in Transformers: A View From Infinity

理解 Transformer 的归纳偏置：来自无限宽极限的视角

作者信息

  • 作者 Itay Lavie、Guy Gur-Ari 与 Zohar Ringel。论文从 infinitely over-parameterized Gaussian-process limit 研究 Transformer kernel 的 sequence-space inductive bias，并用 symmetric-group representations 分解可学习模式。arXiv:2402.05173v2。
Card 02 研究问题

研究问题

  • Transformer 为何偏好某些 sequence functions？当数据分布在 token permutations 下对称时，目标函数属于哪些 irreducible representations，如何决定 sample complexity 和 context-length scaling？
  • 作者还问无限宽解析预测能否描述 finite-width networks 与 OOD distribution shift，以及自然语言数据是否至少在 first-order correlations 上近似具有所需 permutation symmetry。
Card 03 模型与方法

模型与方法

  • 无限宽随机 Transformer 对应 Gaussian process，kernel \(k(X,Y)=E_{\mathrm{theta}}\)[\(f_{\mathrm{theta}}\)(\(X\))\(f_{\mathrm{theta}}\)(\(Y\))]；Bayesian regression 中 kernel integral operator 的 eigenvalues 决定每个 target component 的 shrinkage \(lambda_{i}\)/(\(lambda_{i}\)+\(sigma^{2}\)/\(N\))。
  • 若 kernel 和 data distribution 对 symmetric group G 的 simultaneous token permutations 不变，eigenfunctions 可按 irreps 分块。representation dimension \(dim_{R}\) 与 multiplicity \(Omega_{R}\) 共同限制 eigenvalue budget；更对称、位于低维 irreps 的 functions 更易学。
  • 作者先解简化 attention block，再给 standard block 的 eigenvalue bounds，比较 exact GP、wide finite networks 和 OOD tests；最后测 WikiText-2 线性 feature correlations 在不同 nontrivial permutation modes 间的相似性。
Card 04 核心结果与证据

核心结果与证据

  • 理论把 Transformer bias 表述为对更 permutation-symmetric target components 的偏好。随 context length \(L\) 增长，某些 irreps 的 dimension 快速增大，使学习非对称模式所需 samples 出现可计算 scaling bounds。封面示意图展示不同 representation blocks 的 dimension 与 multiplicity。
  • Figure 2 中解析 GP learning curves 与 exact inference 符合，并在多数测试点 OOD 的情况下预测 MSE；Figure 3 显示 wide finite networks 接近 GP，softmax-attention eigenvalue bounds 在实验里较紧。
  • WikiText-2 的 first-order correlation matrices 在抽样的非零 modes 间显示较高相似性，作者据此认为低阶/有限样本场景近似满足 symmetry。它不是证明自然语言整体 permutation invariant；word order 显然包含关键信息。
Card 05 有效性与局限

有效性与局限

  • GP limit 冻结随机 features，不含 representation learning 与 finite-width corrections；真实训练 Transformer 的 kernel 会演化。无限宽预测与有限网络接近于受控任务，不保证覆盖深层大模型。
  • 核心定理要求 kernel 与 data distribution 的精确或近似 permutation symmetry。WikiText 检查只涉及 first-order correlations 和有限 modes；higher-order syntax/semantics 强烈破坏全排列对称，因此 scaling bounds 的自然语言适用范围有限。
  • 归纳偏置通过 prior/kernel eigenvalues 定义，依赖初始化、architecture、positional encoding 和 normalization。较大 eigenvalue 表示 Bayesian learnability，不等同于 optimization speed 或 downstream utility；本卡未独立复现。
