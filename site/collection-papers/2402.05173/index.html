研究问题

  • Transformer 为何偏好某些 sequence functions？当数据分布在 token permutations 下对称时，目标函数属于哪些 irreducible representations，如何决定 sample complexity 和 context-length scaling？
  • 作者还问无限宽解析预测能否描述 finite-width networks 与 OOD distribution shift，以及自然语言数据是否至少在 first-order correlations 上近似具有所需 permutation symmetry。

模型与方法

  • 无限宽随机 Transformer 的 NNGP 给出函数先验；论文以 Langevin 权重动力学联系 Bayesian posterior。\(lambda_{i}\)/\(lambda_{i}+sigma^{2}/N\) 是大 \(N\)、数据集平均及同分布投影下的 equivalent-kernel 模态收缩近似，不是任意有限训练集的精确等式。
  • 若 kernel 和 data distribution 对 symmetric group G 的 simultaneous token permutations 不变，eigenfunctions 可按 irreps 分块。表示维数造成简并，有限迹给出谱上界；较低维仅放宽该上界，不能单凭上界断言任意具体模态的实际特征值或学习速度排序。
  • 作者先解简化 attention block，再给 standard block 的 eigenvalue bounds，比较 exact GP、wide finite networks 和 OOD tests；最后测 WikiText-2 线性 feature correlations 在不同 nontrivial permutation modes 间的相似性。

核心结果与证据

  • 理论以群表示简并约束核谱和模态可学习性。随 context length \(L\) 增长，某些 irreps 的 dimension 增大，对相应特征值给出标度上界；特定模型及目标上的实际谱和学习行为仍需单独计算或验证。封面示意图展示不同 representation blocks 的 dimension 与 multiplicity。
  • Figure 2 中解析 GP learning curves 与 exact inference 符合，并在多数测试点 OOD 的情况下预测 MSE；Figure 3 显示 wide finite networks 接近 GP，softmax-attention eigenvalue bounds 在实验里较紧。
  • WikiText-2 的 first-order correlation matrices 在抽样的非零 modes 间显示较高相似性，作者据此认为低阶/有限样本场景近似满足 symmetry。它不是证明自然语言整体 permutation invariant；word order 显然包含关键信息。

有效性与局限

  • 本文的 NNGP/Bayesian 极限与 Langevin 权重训练不能简单称为冻结随机特征；它也不能直接描述一般有限宽网络的特征学习及修正。有限网络 SGD 与 GP 在所测受控任务上的接近不保证覆盖深层大模型。
  • 核心定理要求 kernel 与 data distribution 的精确或近似 permutation symmetry。WikiText 检查只涉及 first-order correlations 和有限 modes；higher-order syntax/semantics 强烈破坏全排列对称，因此 scaling bounds 的自然语言适用范围有限。
  • 归纳偏置通过 prior/kernel eigenvalues 定义，依赖初始化、architecture、positional encoding 和 normalization。较大 eigenvalue 表示 Bayesian learnability，不等同于 optimization speed 或 downstream utility；本卡未独立复现。
