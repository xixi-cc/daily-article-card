Half-Space Feature Learning in Neural Networks

神经网络中的半空间特征学习

Card 02 研究问题

研究问题

  • 神经网络 feature learning 常被两种极端叙述夹住：infinite-width NTK 近似暗示 gates/features 几乎不变；hierarchical representation 叙述则强调深度能表达复杂结构，却未说明 gradient descent 实际会学出哪些结构。本文寻找一个可全局画出的中间模型。
  • 作者把 deep network 写成大量 path experts 的混合。问题变为：每条 path 的 gate 在输入空间选择什么区域？训练中这些区域是否移动以贴合 target function 的平滑部分？不同层 neurons 是否出现可量化 clustering？
Card 03 模型与方法

模型与方法

  • 对每条从输入到输出的 path \(\pi\)，网络输出写成 gate f_π(\(x\)) 与 linear expert g_π(\(x\)) 的乘积之和。ReLU 中 gate 依赖前层 hidden activations，边界可随组合产生非凸/不连续变化；DLGN 另用 linearly propagated gating stream U，使每个 neuron gate 是输入 \(x\) 上的 half-space indicator。
  • 深度 \(L\) 的 path gate 是 \(L\)−1 个 half-spaces 的交集，因此仍为几何上简单的 convex-like region，而 expert weights W 在线性组合这些局部模型。分离 U 与 W 后，作者可冻结 gates 形成 fixed-kernel baseline，或训练 U 观察 overlap kernel 与 empirical NTK 如何适应任务。
  • 核心合成任务把二维单位圆上的 angle 映射到 piecewise-smooth target。作者训练 5-layer ReLU/DLGN，画 loss、output、trace-normalized overlap/NTK matrices 与每层 half-space normals；附录再给 convolutional DLGN 在 CIFAR-10/100 与 Fashion-MNIST 的性能对照。
Card 04 核心结果与证据

核心结果与证据

  • Figure 2 中 trainable-gate DLGN 与 ReLU 快速降低合成任务 loss，而 frozen-gate DLGN 超过 2000 iterations 才到约 0.01，说明改动 half-space gates 确有优化作用，而不只是固定随机 features 上拟合 linear experts。
  • Figures 3–5 显示 overlap kernel 与 empirical NTK 从近均匀结构演化为按圆周 target regions 分块，模型输出同步贴近 piecewise function。Figure 6 把每层部分 neurons 的 active half-spaces 全局画出：后层 normals 更集中于易区域边界，支持‘多数 neurons 承担 easy region’的作者观察。
  • DLGN 的可解释性以性能为代价：附录 ResNet-style CIFAR-10 test accuracy 为 ReLU 91%/94% 对 DLGN 86%/89%（34/110 layers），CIFAR-100 为 56.68%/73% 对 51.6%/67%。因此论文主要贡献是观察工具和假说，不是 SOTA classifier。
Card 05 有效性与局限

有效性与局限

  • DLGN 的 gating stream 是人为简化；其 path regions 严格是 half-space intersections，并不能推出 ReLU network 的 regions 或 dynamics 完全同构。作者对 ReLU 的相似机制明确使用 hypothesis 语言。
  • 最清晰的 feature-learning evidence 来自二维角度任务，便于可视化但与高维图像差距很大。显示少量 neurons/paths 不能穷尽指数多 experts；layer clustering 的定量指标和跨 seed uncertainty 较有限。
  • CIFAR 对照显示 DLGN consistently lower test accuracy，architecture/training parity 也不能证明 expressivity tradeoff 是根因。NTK 随训练变化说明离开 lazy regime，但不能单凭 kernel heatmap识别语义 features。本卡未独立复现。
