Training Dynamics Underlying Language Model Scaling Laws: Loss Deceleration and Zero-Sum Learning

Card 02 研究问题

研究问题

  • 为何扩大语言模型会改善损失？作者聚焦训练早期的 loss deceleration：log-log 损失曲线出现突然减速。其机制假说是 zero-sum learning (ZSL)：不同 token/样本的梯度和损失变化系统性相反，使总体下降被抵消。
Card 03 背景

背景

  • 普通 scaling-law 拟合描述参数或数据尺度与 loss 的关系，却少触及训练动力学。本文用 smoothly broken power law（BNSL）把曲线拆成减速时刻 \(t_{d}\)、减速损失 \(L_{d}\) 和减速后斜率 \(r_{d}\)；大模型表现为更小 \(t_{d}\)、\(L_{d}\) 和更高 \(r_{d}\)。
Card 04 模型与方法

模型与方法

  • 定义总体 loss 改善 Delta \(L\) 为 token 级 Delta \(ell_{i}\) 的平均；理想无抵消改善 Delta \(L\)* 用绝对值之和。destructive interference \(D=1\)-|\(sum_{i}\) Delta \(ell_{i}\)|/\(sum_{i}\)|Delta \(ell_{i}\)|，\(D\) 接近1代表 ZSL。论文也对梯度定义同类 \(D\)，因精确逐 token backward 成本约增加1000倍，采用 proxy 并在至多144M模型上以真梯度验证。BNSL 拟合提取 deceleration 指标，实验比较多种模型尺度、batch、context length 与 optimizer。
Card 05 核心结果与证据

核心结果与证据

  • Figure 3 显示每 token loss-improvement 的 \(D\) 在 deceleration 前后陡增并趋近最大，时间窗口 \(Delta_{t}\)^{2t}ell 用来平滑短尺度振荡，作者指出这会低估更长窗口上的 ZSL。Figure 5 将 \(D\) 和平均幅度 \(M\) 分解：一个案例中 \(M\) 从0.75降至0.5仅对应约1.5倍 loss-improvement 降低，而 \(D\) 从0.5升至0.95对应约10倍降低，支持抵消而非单纯每 token 信号变小。Figure 4 的 gradient interference 同期上升；缩放通过延后/降低 deceleration 并提高后期 \(r_{d}\) 改善最终 loss。 量化实验还显示大模型的 deceleration 出现在更低 loss、更早或不同的 step 区域，并在之后保持更陡的 log-log 改善率；这把通常只由终点拟合表达的 scaling improvement 重写为可逐段测量的训练动力学变量。作者将 per-token opposition 解释为模型在一个样本集合上改进会在另一集合上造成相近退化的受限区域，因此 total loss 仍下降但速度受瓶颈。对比 sharpness、单纯梯度幅度衰减等解释时，论文强调 \(D\) 的变化贡献更大，但这些观测仍需要更广模型、数据和干预实验来确定机制边界。
Card 06 有效性与局限

有效性与局限

  • 这些证据主要是时间上的共现、分解和 proxy/真梯度一致性，不是对所有因果路径的严格干预证明；sharpness 在减速前峰值后下降的关系也被作者留为开放问题。\(D\) 依赖测量窗口且 proxy 系统性低估真梯度干扰。零和机制目前针对所测训练设置，不能直接推出所有 tokenization、数据混合或 RL 训练。附录对 Muon/AdEMAMix 的结果被称为初步，不能据此给出通用优化器优劣结论。 量化实验还显示大模型的 deceleration 出现在更低 loss、更早或不同的 step 区域，并在之后保持更陡的 log-log 改善率；这把通常只由终点拟合表达的 scaling improvement 重写为可逐段测量的训练动力学变量。作者将 per-token opposition 解释为模型在一个样本集合上改进会在另一集合上造成相近退化的受限区域，因此 total loss 仍下降但速度受瓶颈。对比 sharpness、单纯梯度幅度衰减等解释时，论文强调 \(D\) 的变化贡献更大，但这些观测仍需要更广模型、数据和干预实验来确定机制边界。
Card 07 复现与资源

复现与资源

  • 复现应保存每 token loss 在 \(t_{1}\),\(t_{2}\) 间的变化，计算 Delta \(L\)、Delta \(L\)*、\(D\) 和 \(M\)，并用多个窗口检查平滑偏差；小模型上逐 token backward 核验 gradient proxy。以 BNSL 拟合 log-log loss，报告参数标准差、RSLE、\(t_{d}\)/\(L_{d}\)/\(r_{d}\)，而非只报最终 loss。作者的 batch/sequence ablation 用144M、batch 1M/4M tokens、sequence 1024/2048；优化器实验对比 AdamW、Muon、AdEMAMix。还应保存同 loss 的 checkpoint 下游结果以检查 loss 与 generalization 的区分。
