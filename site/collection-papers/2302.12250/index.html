Phase diagram of early training dynamics in deep neural networks: effect of the learning rate, depth, and width

作者信息

Card 02 研究问题

研究问题

  • 局部二次优化给出 \(\eta\)<2/\(\lambda_{\mathrm{max}}\)(\(H\)) 的稳定直觉，但深网曲率在训练初期快速变化，超临界步长可能先 catapult 再落入更平坦区域。作者问：以初始 sharpness 归一化 \(\eta=c\)/\(\lambda_{0}^{H}\) 后，loss/sharpness 的瞬态如何随 depth \(d\) 和 width w 改变？
  • 论文区分早期 transient、intermediate saturation、progressive sharpening 与晚期 EoS 四阶段，重点绘制前两阶段的 phase diagram，而不是把训练全程压成单一稳定阈值。
Card 03 模型与方法

模型与方法

  • 实验覆盖 FCN、Myrtle-style CNN 与无 batch normalization 的 ResNet，在 MNIST、Fashion-MNIST、CIFAR-10 上用 vanilla SGD；主结果用 MSE，附录加入 cross-entropy。每次初始化计算 \(\lambda_{0}^{H}\)，并扫描 c、\(d\)、w，早期约 10 steps 密集测量 loss 与 \(\lambda_{t}^{H}\)。
  • 定义 \(c_{\mathrm{loss}}\) 为 early window 内 loss 首次高于初值所需的最小 c，\(c_{\mathrm{sharp}}\) 类似地针对 sharpness，\(c_{\mathrm{max}}\) 是仍能训练的最大 c；另用 \(c_{\mathrm{crit}}\)/response derivatives 标记 intermediate sharpness transition。把这些临界线画在 (c,1/w) 或 (c,\(d\)) 平面，得到 normal、sharpness reduction、loss catapult、loss–sharpness catapult 与 divergence 区域。
  • 为理解机制，作者研究两层线性 uv model \(f(x)=v^{\mathrm{Tux}}\)/\(\sqrt w\)，在单样本 (1,0) 上解析更新 \(f_{t}\) 与 tr(\(H_{t}\))。其中 1/w 修正把无限宽阈值分裂，说明 finite width 与大 initial output 可打开 sharpness-reduction phase。
Card 04 核心结果与证据

核心结果与证据

  • Figure 3 的 width phase diagram 显示：宽网络接近 \(c\approx 2\) 的经典 catapult picture；随 1/w 增大，\(c_{\mathrm{loss}}\)、\(c_{\mathrm{sharp}}\)、\(c_{\mathrm{max}}\) 分离，并出现 loss 仍下降但 sharpness 先下降的区域。增加 depth 产生相似扩展，深而窄的网络可在远高于 2 的 c 才发生 loss catapult。
  • 论文报告两个此前未强调的区：sharpness reduction，以及 loss–sharpness catapult。把网络最后一层置零或对输出做 centering 后，超临界 sharpness reduction 大幅缩小/消失，支持初始输出相对标签尺度是关键驱动，而不只是 Hessian eigenvalue 本身。
  • uv model 复现相图的定性拓扑，并把 tr(\(H\)) 更新中的 ηf_t²(\(\etatrH_{t}\)−4)/w 项识别为 finite-width 来源。它是单样本线性模型，解释的是一种机制而非对 ReLU CNN 全部临界线的精确预测。MSE 主图每点平均 10 次初始化；部分深窄区随机波动使边界难以分辨。
Card 05 有效性与局限

有效性与局限

  • \(\lambda_{\mathrm{max}}\)(\(H\)) 只刻画最尖方向，不能完整描述非正规、梯度噪声或多方向 instability；有限 batch 下 Hessian 与 trajectory 都有随机性。以 \(\lambda_{0}^{H}\) 归一化有利于比较，但不同 parameterization、loss/output scale、normalization 与数据编码会改变 c。
  • 主相图针对短 early window、固定 optimizer 和 architecture families；momentum、Adam、weight decay、augmentation、schedule 与 batch normalization 未纳入核心结论。sharpness reduction 不等同于更好 generalization，catapult 后的 basin connectivity 也只用线性插值等有限诊断。
