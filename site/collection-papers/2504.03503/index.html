Operator learning has emerged as a powerful tool in scientific computing for approximating mappings between infinite-dimensional function spaces. A primary application of operator learning is the development of surrogate models for the solution operators of partial differential equations (PDEs). These methods can also be used to develop black-box simulators to model system behavior from experimental data, even without a known mathematical model. In this article, we begin by formalizing operator learning as a function-to-function regression problem and review some recent developments in the field. Card 03 背景

背景

  • operator 的输入输出是函数，但训练时只能看到有限 sensors/grid；模型通常还通过 encoder E、finite latent map \(h\)、decoder \(D\)，把无限维对象截断为有限维。
  • 训练 input 常从 GP(0,\(\alpha\)(-\(\Delta\)+βI)^-\(\gamma\)) 的 Karhunen–Loève expansion 截断采样；\(\gamma\) 控制 smoothness，截断 modes 与 grid 会把 prior 假设写入 benchmark。
  • 因此 test error 不只是“模型好坏”：训练 \(\mu\)、函数 smoothness、solver、截断 basis、grid 和 loss metric 共同决定风险。
Card 04 模型与方法

模型与方法

  • 统计框架定义 hypothesis class F、loss ℓ、source distribution \(\mu\) 与 learning rule；well-specified 假设要求 G 可被 F 小误差逼近，否则 approximation error 即使 \(n\)→∞ 也不消失。
  • FNO 通过 Fourier truncation/kernel layers近似 operator；DeepONet 常以固定 sensor vector E(v) 编码，若不改 encoder 就不能自然接受另一 input grid。inner-product/integral encoder 可改善 discretization invariance。
  • 评价建议既做 in-distribution held-out \(\mu\)，也通过改变 GP smoothness \(\gamma\)、Karhunen–Loève coefficients 分布或 PDE parameters 构造 OOD；只换 output grid 不是完整 OOD。
  • physics-informed loss 可看成 empirical risk 加约束 regularizer，可能缩小有效 hypothesis class并提升 sample efficiency，但权重、方程误设与 residual sampling 影响统计解释。
Card 05 核心结果与证据

核心结果与证据

  • 文章给出核心分解：approximation error 来自 G∉F；statistical error 来自有限 \(n\)；truncation error来自 GP/data、encoder/decoder、Fourier/PCA modes；discretization error来自有限 grid 上训练与评价。
  • 现有 universality/error-bound 工作主要解决 approximation；对“train grid \(N_{1}\)、test grid \(N_{2}\)”的一般 multiresolution generalization 仍缺理论，因此 zero-shot super-resolution 的经验成功尚无统一统计基础。
  • 一般 Lipschitz operator class 的 minimax error 可慢至约 (log \(n\))^-1，说明仅用 Lipschitz 正则的类太大；实际可高效学习的 PDE operator 必须利用更强结构。
  • DeepONet/FNO 的现有 generalization bounds 往往通过 covering/Rademacher complexity，随参数量或层数指数恶化，数值上过松，不能解释经验成功。
  • i.i.\(d\). \(\mu\) 模型本身可能不适合可主动调用 solver 的场景；active learner 可选择 vi、resolution 和 acquisition，理论目标应包括单次 label 的 solver cost 与信息量。
Card 06 有效性与局限

有效性与局限

  • 文章是选择性理论综述，未穷尽快速发展的 operator-learning 文献；提出的统一误差图景不等于已证明各项可独立相加。
  • 很多理论假设 compactness、smoothness、Gaussian input 或已知 function spaces，与 shock、irregular geometry、adaptive mesh 和实验噪声有距离。
  • population risk 对 \(\mu\) 平均，可能掩盖 rare/extreme inputs；OOD、worst-case、conservation 与 calibrated uncertainty 需额外目标。
  • physics constraints 并不自动带来正确性：若 PDE/BC 不完整或模型误设，regularizer 会系统性偏向错误 operator。
