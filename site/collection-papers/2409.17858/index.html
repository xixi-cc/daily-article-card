How Feature Learning Can Improve Neural Scaling Laws

Card 02 研究问题

研究问题

  • kernel/lazy theory 把 features 冻结，常能推出 loss 对时间、width 与 data 的 power laws，却无法解释 rich feature learning 是否改变指数。论文问：相对于初始 NTK 的 source exponent \(\beta\) 在什么范围内，feature evolution 会改变 asymptotic learning exponent 和 fixed-compute 的最优 width/time 配比？
Card 03 背景

背景

  • data/architecture 由 kernel spectrum exponent \(\alpha\) 与 target source exponent \(\beta\) 描述。易任务 \(\beta\)>1 位于初始 infinite-width NTK 的 RKHS 内；hard tasks \(\beta\)<1 在其外。参数 \(\gamma\) 控制 feature-learning strength，\(\gamma\to 0\) 给出 lazy limit。
  • Figure 1 直接画出 \(\chi\)(\(\beta\)) 以及 lazy/rich 两张 ((\alpha,\beta)) phase diagrams，标明时间、模型 bottleneck 与 SGD-noise terms 的主导区域；这是全文最重要的理论地图。
Card 04 模型与方法

模型与方法

  • 作者研究 projected gradient descent 下的 two-layer linear network，并在 width (\(N\))、batch (B)、time (\(t\)) 的极限中导出 DMFT equations。loss scaling 由 spectrum/source tail、finite-width cutoff 与 SGD variance 竞争决定。
  • fixed compute 取 (\(C=Nt\))，在各 phase 内平衡 time-limited 与 width-limited terms 得到 compute-optimal (\(N\)^*(\(C\)),\(t\)^*(\(C\)))。numerics 对 32 个 random-matrix instances 比较 DMFT；随后训练 circle 上 power-law Fourier targets 的 ReLU MLP、vision CNN，并检查 \(C_{4}\) transformer scaling。
Card 05 核心结果与证据

核心结果与证据

  • Figure 1 的核心结论是分段的：hard regime \(\beta\)<1 中，lazy learning 为 (\(L\)\sim \(t^{-\)\beta})，rich feature learning 变为 (\(L\)\sim \(t^{-2\)\beta/(1+\beta)})，因此指数提高但不超过 1；\(\beta\)>1 的 easy regimes 不改变主 exponent。
  • 在 hard regime 把 (\(t^{-\)\chi}) 与 (\(N^{-\)\alpha\beta}) 于 (\(C=Nt\)) 下平衡，得到 compute-optimal loss (\(L\)^*(\(C\))\sim \(C^{-\)\alpha\beta\chi/(\alpha\beta+\chi)})，其中 rich \(\chi\) 为 (2\beta/(1+\beta))。这改变资源分配，不是简单常数倍 speedup。
  • Figure 2 的 DMFT 与 random experiments 显示 finite-\(\gamma\) crossover；ReLU MLP 的 Fourier tasks 和 CNN vision results 支持 hard/easy 分区。作者还估计 CNN kernel spectrum \(\alpha\approx 2\)、target source \(\beta\approx 0.075\)，并在 \(C_{4}\) transformer cross-entropy 中观察到更符合 feature-learning exponent 的趋势，但这些是有限规模经验支持。
Card 06 有效性与局限

有效性与局限

  • 严格可解对象是 two-layer linear network 与特定 projected dynamics；把 \(\alpha\)、\(\beta\) 从 finite neural kernels/data spectra 估计后外推到深 nonlinear nets，并不是定理。asymptotic crossover time 可随小 \(\gamma\) 很大，实际训练可能仍停在 lazy-like transient。
  • hard/easy 是相对于初始 kernel RKHS 的谱定义，不等于人类对任务难度的直觉。compute (\(C=Nt\)) 忽略 depth、activation memory、communication、data reuse 和 inference cost；SGD-noise phases 还依赖 batch scaling。CNN/transformer evidence 支持趋势，未唯一识别同一 DMFT mechanism。
