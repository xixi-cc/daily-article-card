Card 02 研究问题

研究问题

  • 把预训练 VLM 后训练成机器人 VLA 时，空间几何能力是整体降低，还是被某些后层动作计算专门覆盖？本文在权重匹配的 Molmo2-ER 与 MolmoAct2-LIBERO 上，逐 decoder layer 解码单目深度，并用模块/窗口消融定位最终层的额外退化。
Card 03 模型与方法

模型与方法

  • 对同一批 LIBERO 双相机帧，在 36 层每层视觉 token 上分别训练容量相同的 DPT depth probe，以 Depth-Anything-3 为 pseudo-ground truth；按 rollout 切分避免相邻帧泄漏。
  • 深度指标 $d_1$ 在 affine alignment 后计算阈值内像素比例；另以线性 ridge probe 和 RMSE 核查 probe 架构依赖。
  • 作者把 VLA 相对 VLM 全层持续差距称 floor，把 \(L_{28}\)–\(L_{35}\) 中 VLM 回升而 VLA 反向下跌称 cliff。
  • 因果定位采用 2×2×12 全栈设计：VLM/VLA × MLP/attention，在每个不重叠 3 层窗口将对应 residual write 置零，再重新训练 \(L_{35}\) probe。
  • 最后直接 probe 累积 MLP deposits $\sum_{i\le\ell}m_i$ 与 residual stream，并比较写入/流的 token norm，解释为何晚层单次写入影响更大。
Card 04 核心结果与证据

核心结果与证据

  • VLM 从 \(L_{0}\) 的约 0.71 降至 \(L_{8}\) 约 0.66，最终恢复至 0.752；VLA 在全部 36 层更差。表 2 的 early/mid/late 均值分别为 VLM 0.705/0.701/0.744，对应 VLA 0.617/0.606/0.578。
  • \(L_{35}\) 差距达 0.246（0.752 对 0.506）；\(L_{28}\to L_{35}\) 的 VLM 斜率 +0.040，VLA 为 −0.123，明确区分持续 floor 与额外 terminal cliff。
  • 消融 VLA \(L_{33}\)–35 MLP writes 将 \(L_{35}\) $d_1$ 从 0.506 提至 0.584（+0.078），恢复 cliff 的多数；\(L_{30}\)–32 提升 +0.050。attention 末窗仅 +0.031，VLM MLP 末窗仅 +0.015。
  • VLM 的累积 MLP deposits 全程约 0.80–0.84，比 residual stream 0.66–0.75 更易解码；VLA deposits 在末层从约 0.68 崩至 0.38，ridge SNR 接近 0.03。
  • 前 2/3 深度 residual stream norm 比单个 MLP write 大 100–1000 倍，后层压缩到约 10 倍；这解释晚层 write 可产生更强相对扰动，但不是证明动作能力与深度必然冲突。
Card 05 有效性与局限

有效性与局限

  • 只研究一对 Molmo 权重匹配模型、一个 LIBERO 数据域和一种几何 primitive；不能代表所有 VLA 或完整 3D 理解。
  • 监督来自 Depth-Anything-3 且评估做 affine alignment，测的是与强单目 estimator 的一致性，不是 metric depth ground truth。
  • 消融结果是 representation-level、单 seed；论文没有显示删除 MLP writes 会改善 closed-loop policy。
  • 重新训练 probe 证明“可解码性恢复”，不保证恢复的是原 VLM 相同 code。
  • action post-training 包含数据与训练阶段的整套 bundled treatment，尚未分离哪个具体损失/阶段造成 cliff。
Card 06 复现与资源

复现与资源

  • 原文 PDF：https://arxiv.org/pdf/2608.08904。
  • 复现需使用权重匹配 checkpoint、按 rollout split、同一 DPT/teacher/affine protocol，并完整跑 2×2×12 ablation，而非只挑末层。
  • 报告 depth probe 同时应附 closed-loop eval，避免把更高 $d_1$ 直接等同于更好机器人策略。
