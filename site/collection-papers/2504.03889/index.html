Identifying and Evaluating Inactive Heads in Pretrained LLMs

识别并评价预训练 LLM 中的不活跃注意力头

Card 01 作者信息

作者信息

  • Pedro Sandoval-Segura 等七位作者系统比较 12 种 inactive-head score，并用消融验证预训练 LLM 中的计算冗余，arXiv:2504.03889v4。
Card 02 研究问题

研究问题

  • 高 attention weight 不等于有大输出：某个头可能关注 sink，却因 value/output 很小而几乎不影响模型。怎样定义和验证“不活跃”？
  • 作者比较权重、entropy、value norm 与 head-output norm 等指标，要求 threshold 选出的头在特定 context 中可被消融而不显著损失能力。
Card 03 模型与方法

模型与方法

  • 在三个模型家族上计算六类原始及标准化评分，共 12 项；按分布阈值选候选 inactive heads，并比较集合重叠与尺度变化。
  • 对选中 heads 做 context-specific/批量 ablation，以 MMLU 等任务测性能；比较 pretraining/fine-tuning 和模型规模间 score distributions。
Card 04 核心结果与证据

核心结果与证据

  • 平均超过 12% heads 在所测 context 可消融且 MMLU 下降保持 1% 内；head output norm 指标跨模型最稳定地找到这类头。
  • 仅使用 first-token attention sink 会平均漏掉超过 7% inactive heads。Figure 1 说明权重指标忽略 value 与输出，因而功能判定不完整。
  • 不活跃是数据/上下文/任务相关状态，不一定是全局可永久剪枝；MMLU 保持也不证明生成、安全或稀有能力不受影响。
Card 05 有效性与局限

有效性与局限

  • 阈值与干预粒度决定比例，head 之间有补偿和协同；单头消融无害不表示同时删除集合仍无害。
  • 三个模型家族和有限任务不足以支持普适剪枝，fine-tuning 行为“变化小”也可能被聚合分布掩盖。
  • 论文给出的图形、相关性或有限规模干预只支持其明示范围；跨数据、架构、模型规模与训练制度时需要重新验证。本卡未独立复现，不能把受控实验直接提升为普适机制。
  • 对结论做强审计时，应设置能产生相似表面指标的替代机制、匹配参数量与计算预算、报告失败案例和置信区间，并检查阈值、归一化、样本选择及评价器是否预先偏向作者假说。
  • 若论文声称发现机制，还应要求前向预测新的干预结果，而不只事后解释已有曲线；至少应在未用于选择假说的数据、不同随机种子和合理替代基线上保持。
  • 此外应明确负结果的含义：未观察到效应可能来自统计功效、测量误差或实现差异，不能自动当作理论反证；观察到效应也需排除共同原因。
